## 📌 Repository Policy

- 실습 Source와 정리된 Wiki를 분리합니다.
- README와 내부 문서는 GitHub 상대 경로로 연결합니다.
- `BACKUP/`은 Local Backup 영역으로 분리합니다.
- 실제 파일명을 기준으로 Link를 작성하고 인코딩이 깨진 파일명을 사용하지 않습니다.
- 문서 추가·삭제 시 README의 문서 수와 Navigation을 함께 갱신합니다.
