# CSS Basic

## 소개

이 디렉터리는 CSS의 기본 개념부터 실무에서 가장 많이 사용하는 레이아웃 기술(Flexbox, Grid)까지 정리한 문서들로 구성되어 있다.

학습 순서대로 문서를 읽으면 CSS의 기초 문법부터 반응형 레이아웃까지 자연스럽게 이해할 수 있도록 구성하였다.

---

# 학습 목표

- CSS의 기본 문법 이해
- 선택자와 우선순위 이해
- Box Model 이해
- Display와 Position 이해
- Flexbox를 이용한 1차원 레이아웃 작성
- Grid를 이용한 2차원 레이아웃 작성
- 실무 레이아웃 설계 능력 향상
