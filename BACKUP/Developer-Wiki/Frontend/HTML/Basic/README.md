# HTML Basic

HTML Basic는 웹 개발의 가장 기초가 되는 HTML 문법과 시맨틱 마크업을 학습하는 단계이다.

HTML은 웹 페이지의 **구조(Structure)** 를 담당하며, 이후 학습하는 CSS와 JavaScript의 기반이 된다.

---

# 학습 목표

이 과정을 완료하면 다음 내용을 이해할 수 있다.

- HTML 문서의 기본 구조 작성
- 다양한 HTML 태그 활용
- 링크, 이미지, 표 작성
- 사용자 입력(Form) 구현
- 시맨틱 마크업 이해
- 접근성을 고려한 HTML 작성
- CSS와 JavaScript를 위한 올바른 HTML 구조 작성

# 문서 설명

## HTML_제목_태그

문서의 제목 구조와 h1~h6 사용법을 학습한다.

---

## HTML_문단과_텍스트_태그

본문 작성과 다양한 텍스트 관련 태그를 학습한다.

---

## HTML_목록_태그

순서 있는 목록과 없는 목록, 정의 목록을 학습한다.

---

## HTML_링크_태그

하이퍼링크와 페이지 이동, 외부 링크 작성 방법을 학습한다.

---

## HTML_이미지_태그

이미지 삽입과 alt 속성, 접근성을 학습한다.

---

## HTML_표_태그

표 구조와 rowspan, colspan 등을 학습한다.

---

## HTML_폼_태그

사용자 입력, GET/POST, Form 요소와 유효성 검사를 학습한다.

---

## HTML_시맨틱_태그

시맨틱 마크업과 HTML5 레이아웃 구조를 학습한다.

---

## HTML_전역_속성

HTML 요소에서 공통으로 사용하는 전역 속성을 학습한다.

---
