# HTML 문단과 텍스트 태그

## 개요

웹 페이지는 제목뿐 아니라 문단, 강조 문구, 줄바꿈, 인용문 등 다양한 형태의 텍스트로 구성된다.

HTML에서는 텍스트의 역할과 의미를 표현하기 위해 여러 가지 태그를 제공한다.

대표적인 텍스트 관련 태그는 다음과 같다.

| 태그 | 역할 |
|---|---|
| `<p>` | 하나의 문단을 표현 |
| `<br>` | 줄바꿈 |
| `<hr>` | 주제 또는 내용의 구분 |
| `<strong>` | 중요한 내용 강조 |
| `<em>` | 문맥상 강조 |
| `<b>` | 시각적으로 굵게 표시 |
| `<i>` | 다른 어조나 용어를 구분 |
| `<mark>` | 하이라이트 표시 |
| `<small>` | 부가 설명이나 작은 글씨 |
| `<del>` | 삭제된 내용 |
| `<ins>` | 추가된 내용 |
| `<sub>` | 아래 첨자 |
| `<sup>` | 위 첨자 |
| `<span>` | 인라인 영역 구분 |

텍스트 태그는 단순히 모양을 바꾸는 것이 아니라 문장의 구조와 의미를 브라우저, 검색 엔진, 보조 기술에 전달하는 역할을 한다.

---

# 핵심 개념

## 텍스트의 의미와 표현

HTML에서는 텍스트의 **의미**와 **디자인**을 구분해야 한다.

예를 들어 특정 문장이 중요하다는 의미를 표현하려면 `<strong>`을 사용한다.

```html
<p>
    회원 가입 시
    <strong>이용 약관을 반드시 확인해 주세요.</strong>
</p>
```

단순히 글자를 굵게 보이게 만들고 싶다면 CSS를 사용할 수 있다.

```html
<p class="product-name">
    무선 키보드
</p>
```

```css
.product-name {
    font-weight: 700;
}
```

HTML은 텍스트가 어떤 의미를 가지는지 표현하고, CSS는 텍스트가 어떻게 보이는지 결정한다.

# 문단 태그

## `<p>`

`<p>`는 Paragraph의 약자로, 하나의 문단을 나타낸다.

```html
<p>HTML은 웹 페이지의 구조를 만드는 마크업 언어입니다.</p>
```

여러 문단은 각각 별도의 `<p>` 요소로 작성한다.

```html
<p>
    HTML은 웹 페이지의 구조를 정의합니다.
</p>

<p>
    CSS는 웹 페이지의 디자인과 레이아웃을 담당합니다.
</p>

<p>
    JavaScript는 웹 페이지에 동적인 기능을 추가합니다.
</p>
```

브라우저는 각 문단을 서로 구분하여 표시하며, 기본적으로 문단 위아래에 여백을 적용한다.

---

## 문단을 여러 줄로 작성하기

HTML 코드에서 문장을 여러 줄로 나누어 작성하더라도 브라우저에서는 일반적으로 하나의 공백으로 처리된다.

```html
<p>
    HTML은
    웹 페이지의
    구조를 만듭니다.
</p>
```

브라우저에서는 다음과 같이 표시된다.

```text
HTML은 웹 페이지의 구조를 만듭니다.
```

HTML은 연속된 공백과 줄바꿈을 대부분 하나의 공백으로 처리한다.

이를 **공백 축약**이라고 한다.

---

## 공백을 여러 번 입력한 경우

```html
<p>HTML은     웹 페이지의 구조를 만듭니다.</p>
```

브라우저에서는 일반적으로 다음과 같이 표시된다.

```text
HTML은 웹 페이지의 구조를 만듭니다.
```

간격을 만들기 위해 스페이스바를 여러 번 누르는 방식은 사용하지 않는다.

여백과 간격은 CSS의 `margin`, `padding`, `gap` 등을 사용하여 조절해야 한다.

---

# 줄바꿈 태그

## `<br>`

`<br>`은 Line Break를 의미하며, 문장 내부에서 강제로 줄을 바꿀 때 사용한다.

```html
<p>
    서울특별시 강남구 테헤란로 123<br>
    Developer Building 5층
</p>
```

브라우저에서는 다음과 같이 표시된다.

```text
서울특별시 강남구 테헤란로 123
Developer Building 5층
```

`<br>`은 종료 태그가 없는 빈 요소이다.

```html
<br>
```

---

## `<p>`와 `<br>`의 차이

`<p>`와 `<br>`은 모두 화면에서 줄이 바뀌는 것처럼 보일 수 있지만 역할이 다르다.

| 구분 | `<p>` | `<br>` |
|---|---|---|
| 의미 | 하나의 문단 | 문장 내부의 줄바꿈 |
| 구조 | 독립적인 문단 생성 | 현재 문단 안에서 줄만 변경 |
| 기본 여백 | 문단 위아래 여백이 생길 수 있음 | 별도 문단 여백 없음 |
| 사용 예 | 설명문, 기사 본문 | 주소, 시, 노래 가사 |

## 올바른 문단 구분

```html
<p>
    HTML은 웹 페이지의 구조를 정의합니다.
</p>

<p>
    CSS는 웹 페이지의 디자인을 담당합니다.
</p>
```

## 문장 내부 줄바꿈

```html
<p>
    고객센터 운영 시간<br>
    평일 09:00~18:00<br>
    주말 및 공휴일 휴무
</p>
```

문단 사이의 여백을 만들기 위해 `<br>`을 반복해서 사용하는 것은 좋지 않다.

```html
<p>첫 번째 문단</p>

<br>
<br>
<br>

<p>두 번째 문단</p>
```

문단 사이의 여백은 CSS로 조절한다.

```css
p {
    margin-bottom: 24px;
}
```

# 수평선 태그

## `<hr>`

`<hr>`은 주제 또는 내용의 전환을 나타낸다.

```html
<p>
    지금까지 HTML의 기본 문법을 살펴보았습니다.
</p>

<hr>

<p>
    다음으로 CSS의 기본 문법을 학습합니다.
</p>
```

브라우저에서는 기본적으로 수평선으로 표시되지만, 본래 목적은 단순한 장식용 선이 아니라 **내용의 주제 구분**이다.

`<hr>`도 종료 태그가 없는 빈 요소이다.

```html
<hr>
```

단순히 선을 그리기 위한 디자인 요소가 필요한 경우에는 CSS의 `border` 등을 사용하는 것이 더 적절할 수 있다.

```css
.section {
    border-bottom: 1px solid #ddd;
}
```

---

# 중요한 내용 강조

## `<strong>`

`<strong>`은 내용의 중요성, 심각성 또는 긴급성을 나타낸다.

```html
<p>
    결제 후에는
    <strong>주문 정보를 변경할 수 없습니다.</strong>
</p>
```

브라우저에서는 기본적으로 굵은 글씨로 표시되지만, 핵심은 글자 모양이 아니라 **중요하다는 의미**이다.

```html
<strong>반드시 비밀번호를 변경해 주세요.</strong>
```

화면 낭독기와 같은 보조 기술도 `<strong>`의 의미를 참고할 수 있다.

---

## `<strong>`의 중첩

더 강한 중요성을 표현하기 위해 `<strong>` 내부에 또 다른 `<strong>`을 사용할 수 있다.

```html
<p>
    본 서비스는
    <strong>
        만 14세 미만 사용자의
        <strong>법정대리인 동의</strong>가 필요합니다.
    </strong>
</p>
```

하지만 실제 문서에서는 지나친 강조를 피하고 중요한 부분에만 사용하는 것이 좋다.

---

# 문맥상의 강조

## `<em>`

`<em>`은 문장 안에서 특정 단어나 구절을 강조할 때 사용한다.

```html
<p>
    제출 마감일은 금요일이 아니라
    <em>목요일</em>입니다.
</p>
```

`<em>`은 기본적으로 기울임꼴로 표시될 수 있지만, 핵심은 문맥상 강조이다.

강조 위치에 따라 문장의 의미가 달라질 수 있다.

```html
<p>
    <em>제가</em> 그 파일을 삭제한 것은 아닙니다.
</p>

<p>
    제가 <em>그 파일을</em> 삭제한 것은 아닙니다.
</p>

<p>
    제가 그 파일을 <em>삭제한</em> 것은 아닙니다.
</p>
```

각 문장은 강조하는 대상이 다르기 때문에 전달되는 의미도 달라진다.

---

# `<strong>`과 `<em>`의 차이

| 태그 | 의미 |
|---|---|
| `<strong>` | 내용 자체가 중요하거나 긴급함 |
| `<em>` | 문장 안에서 특정 부분을 강조함 |

```html
<p>
    <strong>주의:</strong>
    비밀번호는 다른 사람과 공유하지 마세요.
</p>
```

```html
<p>
    비밀번호는 다른 사람이 아니라
    <em>본인만</em> 알고 있어야 합니다.
</p>
```

`<strong>`과 `<em>`은 상황에 따라 함께 사용할 수도 있다.

```html
<p>
    <strong>
        결제 전 배송 주소를
        <em>반드시</em> 확인해 주세요.
    </strong>
</p>
```

---

# 시각적으로 굵게 표시

## `<b>`

`<b>`는 주변 문장과 구분할 필요가 있지만, 특별한 중요성을 부여하지 않는 텍스트에 사용할 수 있다.

```html
<p>
    상품명:
    <b>무선 기계식 키보드</b>
</p>
```

브라우저에서는 기본적으로 굵은 글씨로 표시된다.

`<b>`는 단순히 글자를 굵게 만드는 용도로만 이해하기보다, 키워드나 제품명처럼 주변 내용과 시각적으로 구분되는 텍스트에 사용할 수 있다.

다만 특별한 의미 없이 디자인만을 위해 굵게 표시해야 한다면 CSS를 사용하는 편이 더 적절하다.

```html
<span class="product-name">
    무선 기계식 키보드
</span>
```

```css
.product-name {
    font-weight: 700;
}
```

---

# 다른 어조나 용어 구분

## `<i>`

`<i>`는 일반 문장과 다른 어조, 외국어, 전문 용어, 등장인물의 생각 등을 구분할 때 사용할 수 있다.

```html
<p>
    HTML의 <i>element</i>는 요소를 의미합니다.
</p>
```

```html
<p>
    그는 속으로 <i>이번에는 꼭 성공해야 한다</i>고 생각했다.
</p>
```

브라우저에서는 기본적으로 기울임꼴로 표시된다.

단순히 디자인을 위해 글자를 기울이고 싶다면 CSS의 `font-style`을 사용하는 것이 좋다.

```css
.term {
    font-style: italic;
}
```

---

# `<strong>`과 `<b>`의 차이

두 태그는 브라우저에서 모두 굵게 보일 수 있지만 의미가 다르다.

| 태그 | 역할 |
|---|---|
| `<strong>` | 중요한 내용 |
| `<b>` | 중요성 없이 시각적으로 구분할 내용 |

```html
<p>
    <strong>경고:</strong>
    이 작업은 되돌릴 수 없습니다.
</p>
```

```html
<p>
    오늘의 추천 상품은
    <b>Developer Keyboard</b>입니다.
</p>
```

중요성이나 경고의 의미가 있다면 `<strong>`을 사용한다.

제품명이나 키워드를 주변 텍스트와 구분하는 목적이라면 `<b>`를 사용할 수 있다.

---

# `<em>`과 `<i>`의 차이

두 태그는 브라우저에서 모두 기울임꼴로 보일 수 있지만 의미가 다르다.

| 태그 | 역할 |
|---|---|
| `<em>` | 문맥상 강조 |
| `<i>` | 다른 어조, 외국어, 전문 용어 등을 구분 |

```html
<p>
    제출일은 금요일이 아니라
    <em>목요일</em>입니다.
</p>
```

```html
<p>
    HTML의 <i>markup</i>은 표시 또는 표기라는 의미를 가진다.
</p>
```

---

# 하이라이트 표시

## `<mark>`

`<mark>`는 현재 문맥에서 중요하거나 관련성이 높은 부분을 표시한다.

```html
<p>
    검색 결과에서
    <mark>HTML</mark>이라는 단어가 발견되었습니다.
</p>
```

브라우저에서는 일반적으로 형광펜으로 표시한 것처럼 보인다.

검색 결과의 검색어 강조, 문서에서 특정 구간 강조 등에 사용할 수 있다.

```html
<p>
    수강 신청 기간은
    <mark>7월 21일부터 7월 31일까지</mark>입니다.
</p>
```

단순히 노란색 배경을 넣기 위한 목적으로만 사용하기보다는 문맥상 주목해야 할 부분을 나타낼 때 사용한다.

---

# 부가 설명

## `<small>`

`<small>`은 저작권, 법적 고지, 주석, 부가 설명처럼 본문보다 중요도가 낮은 정보를 표현할 때 사용한다.

```html
<p>
    월 이용료 9,900원
    <small>부가세 포함</small>
</p>
```

```html
<footer>
    <small>
        Copyright 2026 Developer Wiki.
        All rights reserved.
    </small>
</footer>
```

`<small>`은 단순히 글자를 작게 만드는 디자인 태그가 아니라 부가적인 정보를 나타낸다.

---

# 삭제된 내용

## `<del>`

`<del>`은 문서에서 삭제되었거나 더 이상 유효하지 않은 내용을 나타낸다.

```html
<p>
    정상 가격:
    <del>50,000원</del>
</p>
```

브라우저에서는 일반적으로 취소선으로 표시된다.

```html
<p>
    행사 기간:
    <del>7월 20일까지</del>
</p>
```

단순히 취소선을 장식으로 사용하는 것이 아니라 이전 내용이 삭제 또는 변경되었다는 의미를 가진다.

---

# 추가된 내용

## `<ins>`

`<ins>`는 문서에 새롭게 추가된 내용을 나타낸다.

```html
<p>
    행사 기간:
    <del>7월 20일까지</del>
    <ins>7월 31일까지</ins>
</p>
```

브라우저에서는 일반적으로 밑줄로 표시된다.

`<del>`과 `<ins>`를 함께 사용하면 변경 전후의 내용을 표현할 수 있다.

---

# 아래 첨자

## `<sub>`

`<sub>`는 아래 첨자를 표현한다.

```html
<p>
    물의 화학식은 H<sub>2</sub>O입니다.
</p>
```

브라우저에서는 `2`가 기준선 아래쪽에 작게 표시된다.

대표적인 사용 예는 다음과 같다.

- 화학식
- 수학식의 아래 첨자
- 변수의 인덱스

```html
<p>
    CO<sub>2</sub>
</p>

<p>
    a<sub>1</sub> + a<sub>2</sub>
</p>
```

---

# 위 첨자

## `<sup>`

`<sup>`는 위 첨자를 표현한다.

```html
<p>
    2<sup>3</sup>은 8입니다.
</p>
```

대표적인 사용 예는 다음과 같다.

- 거듭제곱
- 서수
- 각주 번호
- 단위 표현

```html
<p>
    넓이: 100m<sup>2</sup>
</p>

<p>
    E = mc<sup>2</sup>
</p>
```

# 범용 인라인 요소

## `<span>`

`<span>`은 텍스트의 일부를 하나의 인라인 영역으로 묶을 때 사용한다.

`<span>` 자체에는 특별한 의미나 기본 디자인이 없다.

```html
<p>
    수강 상태:
    <span>모집 중</span>
</p>
```

주로 CSS나 JavaScript를 적용하기 위한 범위로 사용한다.

```html
<p>
    수강 상태:
    <span class="status">모집 중</span>
</p>
```

```css
.status {
    font-weight: 700;
}
```

JavaScript에서 특정 텍스트를 선택할 때도 사용할 수 있다.

```html
<p>
    남은 시간:
    <span id="timer">10</span>초
</p>
```

```javascript
const timer = document.querySelector('#timer');

timer.textContent = '9';
```

---

## `<span>`을 사용하는 이유

문장 전체가 아니라 특정 부분에만 스타일이나 기능을 적용해야 할 때 사용한다.

```html
<p>
    총 결제 금액:
    <span class="price">29,000원</span>
</p>
```

```css
.price {
    font-size: 24px;
    font-weight: 700;
}
```

`<span>`은 의미를 가진 전용 태그가 존재하지 않을 때 사용하는 범용 요소이다.

중요한 텍스트라면 `<strong>`, 강조가 필요하다면 `<em>`, 삭제된 내용이라면 `<del>`처럼 의미에 맞는 태그를 우선 사용해야 한다.

# 블록 요소와 인라인 요소

텍스트 관련 태그를 이해하려면 블록 요소와 인라인 요소의 차이를 알아둘 필요가 있다.

## 블록 요소

블록 요소는 일반적으로 새로운 줄에서 시작하며 사용 가능한 가로 영역을 차지한다.

대표적인 예는 다음과 같다.

```html
<p>문단</p>
<h1>제목</h1>
```

## 인라인 요소

인라인 요소는 문장 흐름 안에서 필요한 만큼의 영역만 차지한다.

대표적인 예는 다음과 같다.

```html
<strong>중요한 내용</strong>
<em>강조할 내용</em>
<span>일부 영역</span>
```

## 비교

```html
<p>
    HTML은
    <strong>웹 페이지의 구조</strong>를 만드는 언어입니다.
</p>
```

위 예제에서 `<p>`는 문단 전체를 구성하는 블록 요소이고, `<strong>`은 문장 일부를 구성하는 인라인 요소이다.

| 구분 | 블록 요소 | 인라인 요소 |
|---|---|---|
| 줄바꿈 | 일반적으로 새로운 줄에서 시작 | 문장 흐름을 유지 |
| 너비 | 일반적으로 부모의 가로 영역을 차지 | 콘텐츠 크기만큼 차지 |
| 예시 | `p`, `h1`~`h6` | `strong`, `em`, `span` |

> CSS의 `display` 속성을 사용하면 표시 방식을 변경할 수 있지만, HTML 요소의 기본 의미와 구조까지 바뀌는 것은 아니다.

# HTML 특수문자

HTML 코드에서 일부 문자는 태그나 문법으로 해석될 수 있다.

이러한 문자를 화면에 그대로 표시하려면 문자 참조를 사용할 수 있다.

| 표시 문자 | 문자 참조 | 설명 |
|---|---|---|
| `<` | `&lt;` | Less Than |
| `>` | `&gt;` | Greater Than |
| `&` | `&amp;` | Ampersand |
| `"` | `&quot;` | 큰따옴표 |
| `'` | `&apos;` | 작은따옴표 |
| 공백 | `&nbsp;` | 줄바꿈되지 않는 공백 |
| © | `&copy;` | 저작권 기호 |

## 태그 문법을 텍스트로 표시

```html
<p>
    문단 태그는 &lt;p&gt;로 작성합니다.
</p>
```

브라우저에는 다음처럼 표시된다.

```text
문단 태그는 <p>로 작성합니다.
```

## 앰퍼샌드 표시

```html
<p>HTML &amp; CSS</p>
```

브라우저에는 다음처럼 표시된다.

```text
HTML & CSS
```

---

## `&nbsp;` 사용 시 주의

`&nbsp;`는 줄바꿈되지 않는 공백을 나타낸다.

```html
<p>10&nbsp;km</p>
```

`10`과 `km` 사이에서 줄이 바뀌지 않게 할 수 있다.

하지만 화면의 간격을 만들기 위해 `&nbsp;`를 반복해서 사용하는 것은 좋지 않다.

```html
<p>HTML&nbsp;&nbsp;&nbsp;&nbsp;CSS</p>
```

간격과 레이아웃은 CSS로 조절한다.

```css
.skills {
    display: flex;
    gap: 16px;
}
```

# 자주 하는 실수

## 1. 문단을 구분하기 위해 `<br>`을 반복한다

### 좋지 않은 예

```html
<p>첫 번째 문단입니다.</p>

<br>
<br>
<br>

<p>두 번째 문단입니다.</p>
```

### 권장 방식

```html
<p>첫 번째 문단입니다.</p>

<p>두 번째 문단입니다.</p>
```

```css
p {
    margin-bottom: 24px;
}
```

`<br>`은 문장 내부의 줄바꿈에 사용하고, 문단 간격은 CSS로 조절한다.

---

## 2. 모든 텍스트를 하나의 `<p>`에 작성한다

### 좋지 않은 예

```html
<p>
    HTML은 구조를 담당합니다.
    CSS는 디자인을 담당합니다.
    JavaScript는 동작을 담당합니다.
</p>
```

각 내용이 서로 다른 문단이라면 별도의 `<p>`로 작성한다.

```html
<p>HTML은 구조를 담당합니다.</p>

<p>CSS는 디자인을 담당합니다.</p>

<p>JavaScript는 동작을 담당합니다.</p>
```

---

## 3. 글자를 굵게 만들기 위해 무조건 `<strong>`을 사용한다

```html
<strong>상품명</strong>
```

내용이 중요한 것이 아니라 단순히 디자인을 위한 것이라면 CSS를 사용할 수 있다.

```html
<span class="product-name">상품명</span>
```

```css
.product-name {
    font-weight: 700;
}
```

---

## 4. `<strong>`과 `<b>`를 완전히 같은 태그로 생각한다

두 태그는 기본 화면 표시가 비슷할 수 있지만 의미가 다르다.

```html
<strong>결제 취소가 불가능합니다.</strong>
```

```html
<b>Developer Keyboard</b>
```

중요한 경고에는 `<strong>`, 주변 내용과 구분되는 키워드에는 `<b>`를 사용할 수 있다.

---

## 5. `<em>`과 `<i>`를 완전히 같은 태그로 생각한다

```html
<em>반드시</em>
```

문맥상 강조를 의미한다.

```html
<i>Semantic Markup</i>
```

외국어 또는 전문 용어를 구분한다.

---

## 6. 디자인을 위해 `<mark>`를 사용한다

```html
<mark>모든 문장</mark>
```

`<mark>`는 단순한 노란색 배경 효과가 아니라 현재 문맥에서 관련성이 높은 내용을 나타낸다.

단순 배경색은 CSS를 사용한다.

```css
.highlight {
    background-color: yellow;
}
```

---

## 7. `<span>`으로 모든 요소를 작성한다

### 좋지 않은 예

```html
<span>중요한 안내입니다.</span>
```

중요한 내용이라면 다음과 같이 의미에 맞는 태그를 사용한다.

```html
<strong>중요한 안내입니다.</strong>
```

`<span>`은 의미를 가진 전용 태그가 없을 때 사용하는 범용 요소이다.

---

## 8. 공백을 만들기 위해 스페이스바를 반복한다

```html
<p>HTML          CSS          JavaScript</p>
```

브라우저에서는 연속된 공백이 하나의 공백으로 축약될 수 있다.

레이아웃과 간격은 CSS로 처리한다.

---

## 9. `&nbsp;`를 반복하여 레이아웃을 만든다

```html
<p>
    HTML&nbsp;&nbsp;&nbsp;&nbsp;CSS
</p>
```

`&nbsp;`는 줄바꿈되지 않는 공백이 필요한 상황에서 제한적으로 사용한다.

요소 간 간격은 CSS의 `gap`, `margin`, `padding` 등을 사용한다.

---

## 10. `<hr>`을 장식용 선으로만 사용한다

`<hr>`은 주제 전환이라는 의미를 가진다.

단순한 장식용 선이라면 CSS의 `border`를 사용하는 것이 더 적절할 수 있다.

---

## 11. 문단 안에 블록 요소를 무분별하게 넣는다

다음과 같이 문단 안에 또 다른 문단을 넣으면 안 된다.

```html
<p>
    첫 번째 문단
    <p>두 번째 문단</p>
</p>
```

각 문단을 분리해서 작성한다.

```html
<p>첫 번째 문단</p>
<p>두 번째 문단</p>
```

# 면접 포인트

## Q1. `<p>` 태그는 어떤 역할을 하나요?

`<p>` 태그는 하나의 문단을 나타낸다.

서로 다른 내용의 문단은 각각 별도의 `<p>` 요소로 작성해야 하며, 문단 간격을 만들기 위해 `<br>`을 반복해서 사용하지 않는다.

---

## Q2. `<p>`와 `<br>`의 차이는 무엇인가요?

`<p>`는 독립적인 문단을 만들고, `<br>`은 현재 문장이나 문단 내부에서 줄만 바꾼다.

설명문처럼 내용이 구분되면 `<p>`를 사용하고, 주소나 시처럼 같은 문맥에서 줄바꿈이 필요하면 `<br>`을 사용한다.

---

## Q3. `<hr>` 태그는 단순히 수평선을 그리는 태그인가요?

브라우저에서는 기본적으로 수평선으로 보이지만, 의미상으로는 내용 또는 주제의 전환을 나타낸다.

단순한 장식용 선은 CSS의 `border`를 사용하는 것이 더 적절할 수 있다.

---

## Q4. `<strong>`과 `<b>`의 차이는 무엇인가요?

`<strong>`은 중요한 내용이라는 의미를 가진다.

`<b>`는 특별한 중요성을 부여하지 않으면서 키워드나 제품명처럼 주변 텍스트와 구분되는 내용을 나타낼 수 있다.

두 요소는 기본적으로 모두 굵게 표시될 수 있지만 의미가 다르다.

---

## Q5. `<em>`과 `<i>`의 차이는 무엇인가요?

`<em>`은 문맥상 특정 단어나 문장을 강조할 때 사용한다.

`<i>`는 외국어, 전문 용어, 다른 어조처럼 일반 문장과 구분되는 텍스트에 사용할 수 있다.

두 요소는 기본적으로 모두 기울임꼴로 표시될 수 있지만 의미가 다르다.

---

## Q6. `<span>`은 언제 사용하나요?

문장의 일부를 묶어 CSS나 JavaScript를 적용해야 하지만 해당 내용에 적합한 의미 태그가 없을 때 사용한다.

`<span>` 자체에는 특별한 의미나 기본 디자인이 없다.

---

## Q7. HTML에서 여러 개의 공백이 하나로 표시되는 이유는 무엇인가요?

HTML은 일반적으로 연속된 공백과 줄바꿈을 하나의 공백으로 축약하여 처리한다.

여백과 간격은 HTML의 공백이 아니라 CSS를 사용해 조절해야 한다.

---

## Q8. 블록 요소와 인라인 요소의 차이는 무엇인가요?

블록 요소는 일반적으로 새로운 줄에서 시작하고 사용 가능한 가로 영역을 차지한다.

인라인 요소는 문장 흐름 안에서 필요한 콘텐츠 크기만큼 영역을 차지한다.

`<p>`는 대표적인 블록 요소이고, `<strong>`, `<em>`, `<span>`은 대표적인 인라인 요소이다.

---

## Q9. `<del>`과 `<ins>`는 언제 사용하나요?

`<del>`은 삭제되었거나 더 이상 유효하지 않은 내용을 나타내고, `<ins>`는 새롭게 추가된 내용을 나타낸다.

문서나 가격, 일정 등의 변경 전후를 표현할 때 함께 사용할 수 있다.

---

## Q10. HTML 특수문자는 어떻게 표시하나요?

HTML 문법으로 해석될 수 있는 문자는 문자 참조를 사용해 표시한다.

예를 들어 `<`는 `&lt;`, `>`는 `&gt;`, `&`는 `&amp;`로 작성할 수 있다.

---

# 핵심 정리

- `<p>`는 하나의 문단을 표현한다.
- 서로 다른 문단은 각각 별도의 `<p>` 요소로 작성한다.
- `<br>`은 문장 안에서 줄을 바꿀 때 사용한다.
- 문단 간격을 만들기 위해 `<br>`을 반복하지 않는다.
- `<hr>`은 내용이나 주제의 전환을 나타낸다.
- `<strong>`은 중요한 내용, `<em>`은 문맥상 강조를 나타낸다.
- `<b>`와 `<i>`는 각각 주변 텍스트와 구분되는 내용이나 다른 어조를 표현할 수 있다.
- `<mark>`는 현재 문맥에서 주목할 부분을 표시한다.
- `<small>`은 부가 설명이나 법적 고지를 나타낸다.
- `<del>`과 `<ins>`는 삭제된 내용과 추가된 내용을 표현한다.
- `<sub>`와 `<sup>`는 아래 첨자와 위 첨자를 표현한다.
- `<span>`은 의미 없는 범용 인라인 영역으로 CSS와 JavaScript 적용에 자주 사용한다.
- 의미가 있는 전용 태그가 존재한다면 `<span>`보다 해당 태그를 먼저 사용한다.
- HTML의 연속된 공백과 줄바꿈은 대부분 하나의 공백으로 축약된다.
- 간격과 시각적인 표현은 HTML이 아니라 CSS로 처리한다.
