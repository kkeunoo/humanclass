# JavaScript 빠른 찾기 — 받는 값·반환값·원본 변경 확인

[과목 목차](README.md) · [읽기 안내](00_JavaScript_V3_동작_백과_읽기법.md)

이 표는 본문을 대신하는 전체 API 사전이 아니라 실제 수업에서 쓴 기능을 다시 찾는 길잡이다. 처음 배우면 연결된 장에서 작은 예제와 실행 결과를 먼저 읽는다.

| 값·기능 | 반환·효과 | 원본 변경 | 설명 |
| --- | --- | --- | --- |
| 문자열 trim | 앞뒤 공백 없는 새 문자열 | 기존 문자열·입력 value 자동 수정 아님 | [10장](10_JavaScript_문자열과_문자열메서드.md) |
| 문자열 split | 나눈 문자열 배열 | 원래 문자열 유지 | [10장](10_JavaScript_문자열과_문자열메서드.md) |
| 배열 push | 새 길이 | 배열 끝에 추가 | [06장](06_JavaScript_배열과_배열메서드.md) |
| 배열 filter | 조건에 맞는 새 배열 | 원래 배열에서 항목 삭제 아님 | [20-02](20-02_JavaScript_날씨응답_필터와_표시.md) |
| 배열 sort | 정렬한 배열 | 배열 자체 순서 변경 | [06장](06_JavaScript_배열과_배열메서드.md) |
| 배열 join | 구분자로 이은 문자열 | 원래 배열 유지 | [17-03](17-03_JavaScript_주문_로그인_피자실습.md) |
| JSON.stringify | JSON 문자열 | 객체가 문자열로 바뀌어 저장되는 것 아님 | [19장](19_JavaScript_객체와_JSON.md) |
| JSON.parse | 문자열을 읽은 값 | 입력 문자열 유지 | [19장](19_JavaScript_객체와_JSON.md) |
| Object.keys | 키들의 배열 | 객체 속성 유지 | [19장](19_JavaScript_객체와_JSON.md) |
| classList.contains | boolean | 검사만 함 | [11-02](11-02_JavaScript_DOM_속성과_클래스.md) |
| querySelector | 첫 일치 요소 또는 null | 조회만 함 | [11장](11_JavaScript_DOM_선택과_속성_클래스조작.md) |
| querySelectorAll | 일치 요소 목록 | 조회만 함 | [11장](11_JavaScript_DOM_선택과_속성_클래스조작.md) |

filter가 새 배열을 만든다고 그 안의 객체를 모두 독립 복제한 것은 아니다. JSON 변환도 함수가 있는 객체의 완전 복제가 아니다. “새 값이 나왔다”와 “원본·안쪽 객체와 관계가 모두 끊어졌다”를 같은 말로 읽지 않는다.

> 💡 **추가로 알면 좋은 것:** 표에 없는 메서드는 필요한 목적이 생겼을 때 공식 문서에서 입력·반환·변경 여부를 확인한다. 기존 BACKUP의 표 전체를 수업에서 배웠다고 확장하지 않는다.
