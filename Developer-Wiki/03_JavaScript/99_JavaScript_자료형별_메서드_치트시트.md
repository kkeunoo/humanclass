# 추가로 알면 좋은 것 — 자료형별 메서드 찾아보기

[JavaScript 목차](README.md) · [기존 자료 분류](추가편_기존자료_학습범위_분류.md)

이 경로는 기존 Wiki의 메서드 표를 찾던 독자를 위한 안내다. 표 전체를 수업에서 다뤘다고 간주하지 않는다. 실제 수업 원본에 사용된 메서드는 [문자열 10장](10_JavaScript_문자열과_문자열메서드.md), [배열 06장](06_JavaScript_배열과_배열메서드.md), [객체·JSON 19장](19_JavaScript_객체와_JSON.md) 등 각 장에서 사용 맥락과 함께 설명한다.

새 메서드를 더 찾아보는 것은 **추가로 알면 좋은 것**이다. 먼저 “어느 값에 호출하는지, 무엇을 반환하는지, 원래 값이 바뀌는지” 세 가지를 확인한다.
