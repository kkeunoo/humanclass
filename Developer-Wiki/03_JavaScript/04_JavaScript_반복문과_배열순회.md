## 2. 무엇이며, 왜 필요한가

for(초기화;조건;증감)의 순서는 초기화 한 번 → 조건 → 본문 → 증감 → 다시 조건이다. 구분 세미콜론은 두 개다. 조건 생략은 참으로 취급되지만 break로 끝낼 수도 있어 반드시 무한 실행이라고 단정하지 않는다.

합계를 만들 때 sum은 반복 밖에서0으로 준비하고 매 회 i를 더한다. 안에서0으로 초기화하면 앞 합이 지워진다. 반대로 피라미드 한 줄의 글자는 각 줄마다 비워야 이전 줄이 섞이지 않는다. ‘초기화 위치’를 목적에 따라 정하는 것이다.

배열은 순서 있는 여러 값이며 첫인덱스0,마지막length-1이다. for...of는 값을 받고 for...in은속성이름을 받는다. forEach·map·filter는 전달한 함수를 원소마다 호출하는 방식이다. 이때 전달하는 함수가 콜백이며 자세한 함수문법은08장에서 이어 본다.

| 반복 방법 | 받거나 만드는 것 |
| --- | --- |
| for...in |'0'같은속성이름,값은arr[i] |
| for...of |원소값 |
| forEach |값·인덱스·배열을콜백에전달,호출반환undefined |
| map |반환값들을담은새배열 |
| filter |참으로판정한원소의새배열 |
| sort |비교함수로원본순서변경 |

break는 가장 가까운 반복을 종료하고 continue는 이번본문의 나머지를 건너뛴다. for에서 continue 뒤에도 증감식은 실행된다. forEach 안에 일반 반복처럼 break를 쓰지는 않는다.

> 📚 **출처 · 본문 설명 확인:** [MDN 반복](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Loops_and_iteration)과 [Array.map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map). 배운 기능의 뜻을 확인한 근거다. 예제·표·풀이 흐름은 수업 코드를 바탕으로 새로 작성했으며 외부 문장을 직접 인용하지 않았다. 확인일: 2026-10-28.

## 3. 작은 예제로 먼저 이해하기

**새 설명 예제 · 전체 스크립트.** [HTML 실행 파일](실습/책형_복습/04_JavaScript_반복문과_배열순회.html)과 같은 폴더의 [JS 파일](실습/책형_복습/04_JavaScript_반복문과_배열순회.js)을 함께 내려받는다. HTML을 브라우저로 열고 Console에서 결과를 확인한다. script는 필요한 HTML 뒤에 연결한다. 콘솔 출력은 페이지 본문에 자동으로 쓰이지 않는다.

```javascript
let sum = 0;
for (let i = 1; i <= 3; i++) {
    sum += i;
    console.log(i, sum);
}
for (let row = 1; row <= 3; row++) {
    let line = '';
    for (let column = 1; column <= row; column++) {
        line += '+';
    }
    console.log(line);
}
```

첫 반복은 합계를 유지해 1→3→6을 만든다. 출력을 본문에 넣어 매 회 i와 sum을 확인했다. 두 번째는 바깥 row가 줄 번호, 안쪽 column이 기호 개수다. line은 바깥 반복 안에서 매번 빈 문자열로 만들어 1·2·3개 기호를 따로 출력한다. 같은 초기화라도 목적이 달라 위치가 다르다.

**예상 출력 또는 관찰:**

```text
1 1
2 3
3 6
+
++
+++
```

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_html/javascript/04_1_pyramid.html` 207–217행

```javascript
            console.log('- - - - - 10단계-1 - - - - -')
            for(let j=1; j<=5; j++) {
                string = ''
                for(let i=1; i<=5-j; i++) {
                    string += '_'
                }
                for(let k=1; k<=2*j-1; k++) {
                    string += '+'
                }
                console.log(string)
            }
```

**발췌 바로 풀이:** 바깥 j는 줄 번호 1–5다. 각 줄에서 string을 비우고, 밑줄 5-j개 뒤에 더하기 기호 2*j-1개를 붙인다. j=1이면 밑줄 4개·기호 1개, j=3이면 밑줄 2개·기호 5개, j=5이면 밑줄 없이 기호 9개다. 내 앞선 복잡한 10단계 풀이보다 이 10단계-1의 개수 식이 목표 모양을 더 직접적으로 설명한다.

내 누적 합은 sum+=i로 강사님의 sum=sum+i와 같은 15를 만든다. 원본은 반복 뒤 한 번 출력한다. map의 현재 코드는 양 갈래에서 홀·짝을 return하므로 r2는 홀·짝이 반복되는 새 배열이며 undefined가 아니다. 내 주석도 return이 없는 가정과 현재 코드를 나누어 읽는다. 피라미드 10단계-1은 줄 j마다 밑줄 5-j개와 +기호 2*j-1개를 쌓아 목표 모양을 만든다.

## 5. 선언·호출·파일이 연결되는 흐름

바깥 변수 준비 → 반복 조건 → 본문에서 읽고 변경 → 출력 시점 순서다. 원본 sum은 앞선 선언이 있고 map의 arr는 앞에서 만든 1~7 배열을 쓴다. 콜백의 function(el,i,a)에서 이름은 매개변수이고 값·인덱스·배열이 전달된다. 네 번째 d를 선언해도 네 번째 인자가 전달되는 것은 아니므로 undefined다. 주사위 중첩 반복은 각각 1~6이고 합 9의 쌍은 [3,6]·[4,5]·[5,4]·[6,3]이다.

<a id="review"></a>

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점:** += 누적과 피라미드 개수식은 변경 이유를 읽기 쉽다. 내 중첩 종료는 강사님의 불필요한 break 직전 j++가 빠져 단순하다. **교정:** map 반환을 undefined로 적은 강사님 주석은 틀렸고 내 주석도 현재 상태와 가정을 나눠야 한다. **한계:** 원본 로또는 난수 6번일 뿐 중복 없는 6개를 보장하지 않는다. **개선 방향:** 누적·초기화·출력 위치를 표에 그린다.

개선안은 원본을 수정한 결과가 아니다. 실제 오류, 수업용 단순화, 목적에 따른 선택을 구별해 판단한다.

## 7. 강사님 코드가 도움이 되는 비교



sum+=i는 동일 계산이라 중복 인용하지 않는다. 강사님 피라미드의 해당 위치는 목표 모양이지 완성 풀이가 아니다. 내 10단계-1의 식은 앞선 복잡한 풀이보다 개수를 직접 설명해 복습에 좋다. map은 실제 return을 근거로 양쪽 주석을 교정한다.

## 8. 결과를 추적하고 한 가지 바꾸기

| 회차 | i | 더하기 전 sum | 더한 뒤 sum |
| --- | --- | --- | --- |
|1 |1 |0 |1 |
|2 |2 |1 |3 |
|3 |3 |3 |6 |

원본 피라미드의 j=1은 밑줄 4·기호 1개, j=3은 밑줄 2·기호 5개, j=5는 밑줄 0·기호 9개다. 11단계는 오른쪽에도 밑줄을 더하고 12단계는 높이를 입력으로 바꾼다. 소수·취소까지 검증된 입력 처리라고 보지는 않는다. 원본 movie.map은 제목 길이 배열, filter는 길이 4 이상 제목을 만든다. sort에서 첫 인자-둘째 인자는 이 숫자 예제의 오름차순이며, 마지막 값이 최대인 것은 직전 오름차순 정렬 조건 때문이다.

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| 첫반복상한만2 |합계출력1·3 |두번실행 |
| 원래sum초기화만본문안으로 |각회1·2·3 |누적지움 |
| 원래line선언을반복밖으로 |+·+++·++++++ |앞줄누적 |
| 별도map에서return제거 |원소가undefined인새배열 |배열자체는남음 |

for...in은 배열 전용 인덱스 반복이 아니라 다른 열거 속성도 대상일 수 있다. 원본 break 예제는 i=11에서 종료 문구를 출력하고 끝내므로 숫자만 찍는 줄은 1~10이다. continue는 짝수 출력을 건너뛰어 1·3·5·7·9를 만든다. 중첩 반복의 flag는 안쪽 break와 바깥 break를 연결하며 cnt=17일 때 i=2·j=7이다.
