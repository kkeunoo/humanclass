# 추가로 알면 좋은 것 — 기존 JavaScript 자료를 읽는 순서

[JavaScript 목차](README.md)

기존 Wiki와 BACKUP은 복습 자료로 남기되 **수업에서 배웠다는 증거로 사용하지 않는다.** 강사님·내 수업 원본에 있는 내용은 01–22 본문에서 다루고, 원본 없이 Wiki에만 있는 큰 주제는 이 추가편에서 구분한다.

| 기존 자료 | 이번 개편에서의 위치 | 판단 근거 |
| --- | --- | --- |
| 옛 23장 ‘실무 코딩 스타일’ | **추가로 알면 좋은 것** | 양쪽 수업 폴더에 23번 원본이 없다. 기존 문서에는 `async/await`, 컴포넌트 구성, 실무 리팩터링 등 수업 원본보다 넓은 내용이 있다. |
| 옛 24장 ‘종합실습’ | **추가로 알면 좋은 것** | 양쪽 수업 폴더에 24번 원본이 없다. 기존 문서의 회원·Todo·검색·저장 통합 프로젝트를 실제 수업 프로젝트로 소개하지 않는다. Todo **개별 실습**은 원본이 있는 [17-04](17-04_JavaScript_메뉴와_Todo실습.md) 본문에 둔다. |
| 옛 99장 ‘자료형별 메서드 치트시트’ | **선택 복습용 참고자료** | `split`, `trim`, `filter`, `join`, `Object.keys`처럼 원본에서 확인되는 메서드는 각 장에서 설명한다. 표 전체를 수업 범위로 간주하지 않는다. |
| BACKUP `JS_localStorage.md` | **추가로 알면 좋은 것** | 이번에 비교한 양쪽 01–22 원본에서 독립적인 저장 실습을 확인하지 못했다. |
| BACKUP `JS_정규표현식.md` | **추가로 알면 좋은 것** | 정규표현식 구현을 수업 본문으로 끌어오지 않는다. 원본에 나오는 간단한 사용만 해당 문맥에서 설명한다. |
| BACKUP `JS_dataset.md` | **수업 본문에 포함** | 강사님 이벤트 퀴즈에서 `option.dataset.name`을 사용했고, 사용자도 수업에서 배웠다고 확인했다. [피자 실습](17-03_JavaScript_주문_로그인_피자실습.md)에 있다. |
| BACKUP의 이벤트·DOM·배열·타이머 기초 | **원본과 대조한 부분만 본문** | 제목이 같더라도 기존 설명 전체가 수업 내용인 것은 아니다. 해당 장에서 실제 원본 발췌 아래 필요한 범위만 설명한다. |

내 `연습용.html`과 `연습용2.html`은 이 폴더 안에 있지만 주로 HTML/CSS 배치 연습이고, `java_중복테스트.html`의 JavaScript는 주석 처리된 개인 시도다. 두 종류 모두 **새 JavaScript 핵심 장의 학습 근거로 확대하지 않는다.** 강사님 `퀴즈/조건문.html`의 가위바위보 문제는 수업 원본이므로 [조건문 03장](03_JavaScript_조건문과_Switch.md)에서 다룬다.

이 분류는 공부 순서에 관한 것이다. 기존 자료를 지우거나 가치가 없다고 판단한 뜻은 아니다. 앞으로 추가편을 별도 집필한다면, 실제 수업에서 배운 부분과 그 이후에 덧붙인 설명을 같은 문단에 섞지 않는다.
