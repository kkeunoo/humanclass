## 📌 Overview

JavaScript는 웹 페이지의 상태와 동작을 제어하는 프로그래밍 언어입니다. 이 과정은 변수와 제어문 같은 기본 문법에서 시작하여 배열과 함수, DOM과 이벤트, 비동기 처리, JSON, Fetch API, Gemini API와 Discord Webhook까지 총 22개의 문서로 이어집니다.

후반부 문서는 외부 서비스와 데이터를 주고받는 실습을 포함하여 브라우저 기반 프로그램이 실제 서비스와 연결되는 흐름을 다룹니다.

## 🎯 Learning Outcome

JavaScript 학습을 마치면 다음 내용을 수행할 수 있습니다.

- 기본 문법과 자료구조를 사용하여 로직을 작성합니다.
- DOM을 선택하고 생성하여 화면을 동적으로 변경합니다.
- 사용자 입력과 다양한 브라우저 이벤트를 처리합니다.
- 비동기 실행 구조와 이벤트 루프의 흐름을 설명합니다.
- JSON과 Fetch API를 사용하여 외부 데이터를 주고받습니다.
- 외부 API와 Webhook을 연결하는 기본 구조를 구현합니다.

---

## 🔐 API Practice Policy

API 관련 문서에서는 구조와 동작 원리를 학습하되, 실제 운영 환경에서는 다음 원칙을 적용해야 합니다.

- API Key와 Webhook URL을 공개 저장소에 커밋하지 않습니다.
- 비밀값은 환경 변수 또는 백엔드 서버에서 관리합니다.
- 네트워크 요청의 성공 상태와 예외를 함께 처리합니다.
- 외부 응답은 구조를 확인한 뒤 안전하게 화면에 출력합니다.
