# 추가로 알면 좋은 것 — 실무 코딩 스타일

[JavaScript 목차](README.md) · [기존 자료 분류](추가편_기존자료_학습범위_분류.md)

양쪽 수업 원본에는 **23번 실습 파일이 없다.** 기존 Wiki의 큰 ‘실무 코딩 스타일’ 문서를 수업 필수 23장으로 읽지 않도록 이 경로에는 안내만 남긴다.

수업에서 실제 작성한 변수·함수·이벤트 코드는 [01장](01_JavaScript_변수와_자료형.md), [08장](08_JavaScript_함수와_콜백_타이머.md), [15장](15_JavaScript_DOM이벤트와_키보드스크롤제어.md) 등 해당 본문에서 원본과 함께 읽는다. 기존 문서의 컴포넌트 구성이나 `async/await` 기반 실무 패턴은 **추가로 알면 좋은 것**에 해당한다.
