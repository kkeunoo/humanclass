# 추가로 알면 좋은 것 — 종합실습 구상

[JavaScript 목차](README.md) · [기존 자료 분류](추가편_기존자료_학습범위_분류.md)

양쪽 수업 원본에는 **24번 종합 프로젝트 파일이 없다.** 기존 Wiki에 적힌 회원·Todo·검색·저장 통합 프로젝트를 실제 수업에서 완성한 결과로 소개하지 않는다.

수업에서 작성한 **Todo 개별 실습**은 [17-04 메뉴와 Todo](17-04_JavaScript_메뉴와_Todo실습.md)에 강사님 코드와 내 코드를 나란히 실었다. 통합 프로젝트를 새로 만든다면 그때는 **추가로 알면 좋은 것**으로 구분하고 실행 결과를 별도로 검증한다.
