수업 원본 문제·내 풀이와 이 폴더의 새 예제는 구분한다. 파일을 원본 폴더에 덮어쓰지 않고 별도 복습용으로 사용한다.

## 2. 준비와 실행

HTML만 복사하고 같은 이름의 JS를 빠뜨리면 동작하지 않는다. DOM 예제는 필요한 body·CSS도 본문에 실었다. Console 출력인지 화면 변화인지 예상 결과의 종류를 먼저 확인한다. 버튼과 키보드 실험은 각 장의 조작 순서대로 수행한다.

20장 AJAX 예제는 book-users.json을 같은 폴더에 두고 로컬 웹 서버로 제공한다. 해당 장 3절의 준비를 따른다. 날씨·AI·웹훅의 작은 예제는 가상 데이터·미리 보기이며 외부 서비스에 요청하지 않는다. 시간·난수·선택 상태는 안내한 조건과 구별한다.

## 3. 확인하고 확장하기

예측 → 실행 → 차이 설명 → 한 가지 변경 순서로 복습한다. 오류가 나면 본문의 확인 순서를 따르고 원본 코드와 개선 예제를 섞지 않는다. [스타일](../23_JavaScript_실무_코딩스타일.md)을 읽고 [종합실습](../24_JavaScript_종합실습.md)의 성공 기준까지 확인한다. 저장·서버 동기화 등은 각 장 하단 TIP의 추가 학습이다.
