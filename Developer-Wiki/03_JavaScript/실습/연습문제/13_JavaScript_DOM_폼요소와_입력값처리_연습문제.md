## 문제

폼의 이름 입력과 선택 목록을 읽어 `이름: 선택값`을 화면에 표시하자.

**확인 기준:** 값을 바꾸고 누르면 변경된 두 값이 반영된다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`input.value`와 `select.value`를 확인한다. 폼의 `name`은 전송 이름이고 DOM에서 읽는 `value`는 현재 값이다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
