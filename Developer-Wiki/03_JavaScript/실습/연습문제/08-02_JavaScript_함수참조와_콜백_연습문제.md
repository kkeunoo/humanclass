**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

`run(callback)`이 콜백을 한 번 부르게 작성하고 `run(() => console.log("완료"))`를 실행하자.

**확인 기준:** `완료`가 한 번 출력된다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

함수 이름을 인자로 전달하고 `run` 안에서 `callback()`을 호출한다. `callback()`을 인자 자리에 쓰면 미리 실행된다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
