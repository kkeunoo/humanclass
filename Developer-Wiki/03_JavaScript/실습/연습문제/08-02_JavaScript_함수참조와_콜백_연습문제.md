# 08-02. 함수 참조와 콜백 — 함수 전달과 호출 결과 — 연습문제

[본문](../../08-02_JavaScript_함수참조와_콜백.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

함수 값·호출·반환값을 구분한다. 전달받은 함수가 어디에서 실제 호출되는지 찾고 콜백이 항상 비동기는 아님을 설명한다.

[전체 실행 HTML](../책형_복습/08-02_JavaScript_함수참조와_콜백.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../08-02_JavaScript_함수참조와_콜백.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
function sayHi() {
    console.log('안녕');
}
function run(fn) {
    console.log('시작');
    console.log(typeof fn);
    if (typeof fn === 'function') {
        fn();
    }
    console.log('끝');
}
const later = sayHi;
run(later);
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
시작
function
안녕
끝
```

later에 담을 때는 안녕이 출력되지 않는다. run이 시작을 출력하고 fn의 종류를 확인한 다음 fn()에서 sayHi를 호출한다. 이 호출이 끝나 돌아와 끝을 출력한다. 모든 과정이 현재 호출 안에서 순서대로 이루어져 비동기 예약은 없다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1. 나중에 호출하도록 함수 값을 넘기려면 fn과 fn() 중 무엇인가?
2. 콜백은 반드시 비동기인가?
3. test2가 함수를 받으면 자동 호출되는가?

<details>
<summary>풀이</summary>

fn을 넘긴다. fn()은 지금 호출한 결과다. 콜백은 즉시 호출될 수 있다. test2처럼 받은 값을 출력만 하면 자동 호출하지 않는다.

| 원본 호출 | 출력 흐름 | 이유 |
| --- | --- | --- |
| test2(test1()) |test1→test2→3 |인수계산이먼저 |
| test2(test1) |test2→함수표시 |test2는a호출안함 |

양쪽 원본은 원래 console.log를 c1에 저장한 뒤 숫자3과 새 함수로 바꾸는 실험도 한다. 숫자인 동안 호출하면 함수가 아니어서 오류지만 해당 호출은 주석이다. 새 함수 안에서 다시 console.log를 부르면 자기 자신을 반복 호출할 수 있어 원본은 c1을 쓴다. 실습 문구는 실제 침입 증거가 아니다. 복구하려면 console.log=c1을 쓰는 설명용 수정을 할 수 있다. 원본 desc의 sort().reverse는 배열 장과 같이 원본 변경·기본 문자 정렬의 한계를 가진다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **run(later)를run(later())로**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| run(later)를run(later())로 |안녕→시작→undefined→끝 |먼저실행결과전달 |
| 원래run의fn()만제거 |시작·function·끝 |전달해도호출안함 |
| 원래run인수만3으로 |시작·number·끝 |종류검사로호출안함 |

함수로 받은 줄 알았는데 undefined이면 호출 괄호를 확인한다. 로그가 평소와 다르면 출력 함수를 덮는 원본 실험과 섞였는지 본다. 콜백의 정의·전달·실제 호출 위치를 각각 찾는다.

</details>
