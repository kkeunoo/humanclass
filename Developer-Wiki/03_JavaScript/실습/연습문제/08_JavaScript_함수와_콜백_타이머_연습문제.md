**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

함수 선언문 `add(a, b)`를 작성해 두 숫자의 합을 반환하자. `add(2, 3)`과 `console.log(add)`는 각각 무엇을 보여 주는지 구분하자.

**확인 기준:** 괄호를 붙여 호출할 때와 함수 이름만 참조할 때의 차이를 말한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

```javascript
function add(a, b) {
  return a + b;
}
console.log(add(2, 3)); // 5
console.log(add);       // 함수 자체를 표시
```

두 번째 `console.log`의 함수 표시 형식은 실행 환경에 따라 달라진다. 중요한 것은 그 줄이 `add`를 **호출하지 않는다**는 점이다. 함수 참조를 다른 함수에 넘기는 일은 [다음 08-02장](../../08-02_JavaScript_함수참조와_콜백.md)에서 연습한다.

</details>
