실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

정의·호출·매개변수·인수·반환을 구분한다. 함수 정의부터 호출과 결과 사용까지 따라가고 범위·기본값을 설명한다.

[전체 실행 HTML](../책형_복습/08_JavaScript_함수와_콜백_타이머.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../08_JavaScript_함수와_콜백_타이머.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
function showDouble(number) {
    console.log(number * 2);
}
function getDouble(number) {
    return number * 2;
}
const shown = showDouble(3);
console.log(shown);
const result = getDouble(3);
console.log(result + 1);
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
6
undefined
7
```

showDouble은6을 출력하지만 반환하지 않아 shown은undefined다. getDouble은6을 반환하여 result에 저장하고, 다음 식이1을 더해7을 출력한다. 함수 정의 두 개와 호출 위치를 모두 보여 주므로 다른 파일의 숨은 함수 없이 따라갈 수 있다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1.출력만 하는 함수의 반환은?
2.plus(2,plus(5,6))의 바깥 인수는?
3.y=0 자체가null도 처리하는가?

<details>
<summary>풀이</summary>

명시적 반환이 없으면undefined다. 바깥에는2와11이 전달된다. 기본 매개변수 자체는null을0으로 바꾸지 않는다.

| 원본 호출 | 매개변수 처리 | 반환 |
| --- | --- | --- |
| getArea(10,20) |출력만 함 |undefined |
| getArea2(10,20) |면적 계산 후return |200 |
| plus3(2) |y가undefined라 기본0 |2 |
| plus3(2,3,4) |본문에서x·y만 사용 |5 |
| plus3(2,null) |기본값은null유지,본문==검사가0으로변경 |2 |

마지막 결과를 기본 매개변수가null까지 처리했다고 설명하면 원인을 잘못 짚은 것이다. 실행 순서와 별도 if가 핵심이다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **getDouble의return만제거**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| getDouble의return만제거 |마지막NaN |undefined+1 |
| 원래인수3만4로 |해당호출결과8 |전달값변경 |
| 원래result+1만result로 |마지막6 |반환뒤사용변경 |

함수를 만들었는데 출력이 없으면 호출했는지 확인한다. 출력은 있는데 계산에undefined가 들어가면return을 확인한다. 함수 안 이름을 바깥에서 읽으려다 오류가 나면 반환으로 전달할 값인지 검토한다.

</details>
