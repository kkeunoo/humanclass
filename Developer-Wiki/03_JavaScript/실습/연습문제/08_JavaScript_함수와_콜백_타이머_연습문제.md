## 문제

일반 함수와 화살표 함수 각각으로 두 숫자의 합을 반환하고, 콜백 자리에서 어느 함수를 전달하는지 확인하자.

**확인 기준:** 두 함수 모두 `2 + 3`에서 5를 반환한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

함수 선언과 호출을 구별한다. 화살표 함수의 한 줄 반환과 `{ return ... }` 형태를 비교한다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
