# 14 JavaScript 동기비동기와 이벤트루프 — 연습문제

**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

`console.log(1); setTimeout(() => console.log(2), 0); console.log(3);`의 출력 순서를 먼저 적고 실행하자.

**확인 기준:** 세 번째 `console.log`보다 타이머 콜백이 먼저 실행된다고 단정하지 않는다. 예약과 실행을 구분한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

첫 줄이 1을 출력한다. 둘째 줄은 콜백을 예약하고 다음 줄로 넘어간다. 현재 동기 코드의 마지막 줄이 3을 출력한 뒤 예약된 콜백에서 2가 출력되므로 **1 → 3 → 2**다. `0ms`는 “지금 이 자리에서 동기적으로 실행”이라는 뜻이 아니다.

</details>

강사님·내 원본의 더 긴 출력 순서도 같은 방법으로 **현재 실행 중인 함수와 예약된 콜백**을 나누어 추적한다. `setTimeout`이 반드시 정확히 0ms 뒤 출력된다는 약속으로 읽지 않는다.
