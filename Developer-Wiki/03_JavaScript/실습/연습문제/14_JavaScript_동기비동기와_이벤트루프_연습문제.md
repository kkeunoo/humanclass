## 문제

`console.log(1); setTimeout(() => console.log(2), 0); console.log(3);`의 출력 순서를 먼저 적고 실행하자.

**확인 기준:** 출력 순서는 1, 3, 2다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

현재 호출 스택의 동기 문장이 끝난 뒤 예약된 콜백이 실행된다. 0ms는 동기 실행이 아니다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
