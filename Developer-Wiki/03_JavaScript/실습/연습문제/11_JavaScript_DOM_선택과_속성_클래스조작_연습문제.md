## 문제

버튼을 누를 때 설명 요소의 `active` 클래스를 붙였다 떼고 `classList.contains`를 출력하자.

**확인 기준:** 연속 두 번 누르면 처음 상태로 돌아온다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`classList.toggle("active")`로 바꾸고 클래스 유무를 읽는다. 선택자 결과가 `null`인지 먼저 확인한다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
