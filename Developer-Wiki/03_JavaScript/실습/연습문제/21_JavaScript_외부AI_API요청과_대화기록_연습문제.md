## 문제

대화 기록 배열에 사용자 문장과 미리 준비한 답변 문자열을 차례로 넣어 화면에 그리자.

**확인 기준:** 질문과 답변이 순서대로 보이며 API 키가 필요 없다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

실제 외부 AI 요청은 하지 않는다. 입력·요청 데이터·응답 표시 단계 중 표시 단계만 재구성한 실습이다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
