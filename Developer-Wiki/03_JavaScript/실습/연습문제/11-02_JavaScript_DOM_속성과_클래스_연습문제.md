## 문제

`data-name="민지"`가 있는 버튼을 눌렀을 때 `dataset.name`을 읽어 문장에 넣자.

**확인 기준:** 버튼 클릭 후 화면에 `민지 선택`이 나타난다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

HTML `data-name`과 JavaScript `element.dataset.name`을 대응시킨다. 출력에는 `textContent`를 쓴다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
