**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

가격 12,000원, 수량 2개, 쿠폰 3,000원으로 합계를 구하고 20,000원 이상인지 비교하자.

**확인 기준:** 곱셈·뺄셈·비교 순서와 중간 금액을 적는다. 가격·수량을 바꾸었을 때도 같은 식이 동작하는지 살핀다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

```javascript
const total = 12000 * 2 - 3000;
const enough = total >= 20000;
console.log(total);  // 21000
console.log(enough); // true
```

처음 곱셈은 24,000원, 쿠폰을 빼면 21,000원이다. 그 결과를 20,000원과 비교한다. `>=`에는 **같은 값도 포함**된다. 20,000원일 때 결과를 별도로 예측하자.

</details>

수업의 실제 계산 문제와 비교할 때는 **식의 결과**와 증감 연산으로 **변수에 저장된 값**이 같은지 구분한다. 이 새 문제에는 증감 연산자가 없다.
