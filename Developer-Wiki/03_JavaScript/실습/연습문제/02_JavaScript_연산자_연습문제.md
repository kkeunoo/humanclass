## 문제

가격 12,000원, 수량 2개, 쿠폰 3,000원으로 합계를 구하고 20,000원 이상인지 비교하자.

**확인 기준:** 합계는 21,000원이고 비교 결과는 `true`다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`12000 * 2 - 3000`을 먼저 계산하고 `>= 20000`을 적용한다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
