# 02. 연산자 — 식이 내놓는 값과 변수 변화 — 연습문제

[본문](../../02_JavaScript_연산자.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

산술·대입·비교·논리·삼항을 구분한다. 전위·후위 증감의 평가 순서와 실제 계산 문제의 입력 한계를 설명한다.

[전체 실행 HTML](../책형_복습/02_JavaScript_연산자.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../02_JavaScript_연산자.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
let k = 10;
let before = k++;
console.log(before, k);
k = 10;
let after = ++k;
console.log(after, k);
console.log(3 == '3', 3 === '3');
let num = 7;
let result = num % 2 === 0 ? '짝수' : '홀수';
console.log(result);
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
10 11
11 11
true false
홀수
```

before에는 증가 전 10이 들어가지만 첫 출력 시 k는 이미 11이다. 다시 10으로 초기화한 뒤 after에는 증가 후 11을 넣는다. 숫자 3도 문자열 3과 엄격 비교하면 false다. num 7의 나머지는 1이어서 삼항은 홀수를 선택하고, 그 값을 result에 저장한 뒤 출력한다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1. k=10에서 m=k++ +1이면 m과 k는?
2. 삼항은 출력 기능인가?
3. 17,500원을 두 권종으로 나누면 남는 금액은?

<details>
<summary>풀이</summary>

m=11·k=11이다. 삼항은 값 선택 식이다. 5천원 3장·천원 2장으로 500원이 남는다.

| 단계 | 식에 제공한 값 | 그 직후 k |
| --- | --- | --- |
| k=10에서 ++k |11 |11 |
| 이어서 k++ |11 |12 |
| 둘을 더해 m 저장 |22 |12 |

할인 계산은 할인액 8,000×15/100=1,200원을 먼저 구하고 원가에서 뺀다. 소수 둘째 자리 예제는 반올림이 아닌 버림이다. 각각 다른 요구사항이므로 결과만 외우지 않는다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **작은 예제 k초기값만20**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| 작은 예제 k초기값만20 |20·21 /11·11 | 두 번째는다시10으로초기화 |
| num만8 |짝수 |나머지0 |
| 3==='3'의문자열만숫자로 |true |같은숫자값·자료형 |

전위·후위를 식 전체 전후의 변경으로 기억하면 복합식이 틀린다. 각 표현을 평가한 직후의 변수값을 적는다. 17,500원 지폐 복습은 5천원 3장·천원 2장·잔액 500원이며 소수 장수를 정답으로 쓰지 않는다.

</details>
