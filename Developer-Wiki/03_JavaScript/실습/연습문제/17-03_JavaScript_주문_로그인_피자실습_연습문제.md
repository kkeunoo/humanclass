**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

피자 크기와 수량을 선택받아 합계를 보여 주고, 수량이 0 이하이면 안내문을 표시하자.

**확인 기준:** 유효한 입력에서는 단가×수량, 잘못된 입력에서는 합계를 만들지 않는다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

원본의 주문·폼 읽기 순서대로 입력 → 숫자 변환 → 조건 확인 → 화면 출력을 분리한다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
