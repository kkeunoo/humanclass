**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

미리 주어진 `{list:[{rain:0},{rain:4},{rain:1}]}`에서 비가 1 이상인 항목만 골라 콘솔에 출력하자.

**확인 기준:** 이 작은 데이터가 **실제 API 응답 구조가 아닌 새 연습 자료**임을 확인한다. 조건을 통과한 항목의 원래 순서를 유지한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

```javascript
const sample = { list: [{ rain: 0 }, { rain: 4 }, { rain: 1 }] };
const rainy = sample.list.filter(function(item) { return item.rain >= 1; });
console.log(rainy); // [{rain: 4}, {rain: 1}]
```

필터는 4와 1을 통과시키고 순서를 바꾸지 않는다. 화면 표를 만들기 전에 **응답 배열의 어느 속성을 검사하는지** 확인한다. 수업의 실제 날씨 응답은 `category` 등 다른 필드 구조이므로 이 `rain` 예제를 원본 응답이라고 표시하지 않는다.

</details>

강사님 원본은 필요한 종류를 고른 뒤 **같은 시각의 값끼리 묶는다**. 내 원본도 묶기를 시도했지만 같은 시각의 값을 한 행으로 만들지 못했다. 이 문제는 그중 항목을 고르는 첫 단계만 떼어 낸 것이다. 이어서 [본문 3절](../../20-02_JavaScript_날씨응답_필터와_표시.md)에서 두 결과를 비교한다.
