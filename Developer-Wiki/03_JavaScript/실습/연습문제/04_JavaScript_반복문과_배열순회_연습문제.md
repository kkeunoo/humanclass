# 04. 반복문과 배열 순회 — 바뀌는 상태를 표로 추적하기 — 연습문제

[본문](../../04_JavaScript_반복문과_배열순회.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

for의 실행 순서와 누적·중첩 반복을 설명한다. break·continue, 배열의인덱스·값·새배열반환, 피라미드의 줄별 개수식을 구분한다.

[전체 실행 HTML](../책형_복습/04_JavaScript_반복문과_배열순회.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../04_JavaScript_반복문과_배열순회.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
let sum = 0;
for (let i = 1; i <= 3; i++) {
    sum += i;
    console.log(i, sum);
}
for (let row = 1; row <= 3; row++) {
    let line = '';
    for (let column = 1; column <= row; column++) {
        line += '+';
    }
    console.log(line);
}
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
1 1
2 3
3 6
+
++
+++
```

첫 반복은 합계를 유지해 1→3→6을 만든다. 출력을 본문에 넣어 매 회 i와 sum을 확인했다. 두 번째는 바깥 row가 줄 번호, 안쪽 column이 기호 개수다. line은 바깥 반복 안에서 매번 빈 문자열로 만들어 1·2·3개 기호를 따로 출력한다. 같은 초기화라도 목적이 달라 위치가 다르다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1. sum 초기화를 안으로 옮기면 왜 누적이 안 되는가?
2. map의 콜백이 return하면 호출 결과는 무엇인가?
3. 원본 피라미드 넷째 줄은?

<details>
<summary>풀이</summary>

매 회 앞 합을 0으로 지우기 때문이다. map은 각 반환값의 새 배열을 준다. 넷째 줄은 밑줄 1개와 + 7개인 _+++++++다.

| 회차 | i | 더하기 전 sum | 더한 뒤 sum |
| --- | --- | --- | --- |
|1 |1 |0 |1 |
|2 |2 |1 |3 |
|3 |3 |3 |6 |

원본 피라미드의 j=1은 밑줄 4·기호 1개, j=3은 밑줄 2·기호 5개, j=5는 밑줄 0·기호 9개다. 11단계는 오른쪽에도 밑줄을 더하고 12단계는 높이를 입력으로 바꾼다. 소수·취소까지 검증된 입력 처리라고 보지는 않는다. 원본 movie.map은 제목 길이 배열, filter는 길이 4 이상 제목을 만든다. sort에서 첫 인자-둘째 인자는 이 숫자 예제의 오름차순이며, 마지막 값이 최대인 것은 직전 오름차순 정렬 조건 때문이다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **첫반복상한만2**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| 첫반복상한만2 |합계출력1·3 |두번실행 |
| 원래sum초기화만본문안으로 |각회1·2·3 |누적지움 |
| 원래line선언을반복밖으로 |+·+++·++++++ |앞줄누적 |
| 별도map에서return제거 |원소가undefined인새배열 |배열자체는남음 |

for...in은 배열 전용 인덱스 반복이 아니라 다른 열거 속성도 대상일 수 있다. 원본 break 예제는 i=11에서 종료 문구를 출력하고 끝내므로 숫자만 찍는 줄은 1~10이다. continue는 짝수 출력을 건너뛰어 1·3·5·7·9를 만든다. 중첩 반복의 flag는 안쪽 break와 바깥 break를 연결하며 cnt=17일 때 i=2·j=7이다.

</details>
