## 문제

실제 네트워크 대신 `Promise.resolve({items:[1,2]})`를 사용해 성공 결과와 오류 처리를 구분하자.

**확인 기준:** 성공 때 `1,2`가 표시된다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`then`에서 값의 모양을 읽고 `catch`에서 오류를 표시한다. `fetch`를 쓰는 원본과 비교하되 외부 서버 성공은 전제하지 않는다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
