# 22 JavaScript 웹훅 POST요청 — 연습문제

[해당 본문](../../22_JavaScript_웹훅_POST요청.md) · [장별 문제 목차](README.md)

**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

웹훅 전송 전에 `{message:"연습"}`를 `JSON.stringify`하고 method·headers·body 값을 출력하자.

**확인 기준:** method는 POST, body는 JSON 문자열이다. 실제 웹훅 전송은 없다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

전송 전 요청 객체의 내용을 점검한다. 외부 URL과 비밀 값을 연습 문서에 넣지 않는다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
