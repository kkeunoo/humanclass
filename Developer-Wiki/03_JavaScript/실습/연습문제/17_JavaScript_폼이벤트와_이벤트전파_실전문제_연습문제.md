**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

폼 `submit`에서 입력값을 읽고 브라우저 기본 제출을 막아 현재 화면에 요약을 표시하자.

**확인 기준:** 페이지 이동 없이 입력 요약이 보인다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`event.preventDefault()`는 제출의 기본 동작을 막는다. 이벤트 전파를 막는 함수와 혼동하지 않는다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
