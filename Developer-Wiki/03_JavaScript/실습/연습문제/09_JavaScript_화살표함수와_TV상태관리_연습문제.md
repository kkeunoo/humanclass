**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

버튼 이벤트에서 현재 TV 채널을 한 번 올리고 화면의 채널 숫자를 다시 그리자.

**확인 기준:** 클릭 한 번에 채널 값과 화면 표시가 함께 1 증가한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

상태를 먼저 바꾼 뒤 표시 함수를 호출한다. 화살표 함수의 `this`를 버튼이라고 가정하지 않는다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
