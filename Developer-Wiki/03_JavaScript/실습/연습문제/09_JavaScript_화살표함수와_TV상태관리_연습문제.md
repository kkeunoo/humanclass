실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

블록 본문과 식 본문의 반환을 구분한다. 쉼표 반환과 여러값 출력, 원본 문장 경계 오류를 설명한다.

[전체 실행 HTML](../책형_복습/09_JavaScript_화살표함수와_TV상태관리.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../09_JavaScript_화살표함수와_TV상태관리.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
const block = (a, b) => {
    return a + b;
};
const expression = (a, b) => a + b;
const noReturn = (a, b) => {
    a + b;
};
console.log(block(2, 3));
console.log(expression(2, 3));
console.log(noReturn(2, 3));
```

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
5
5
undefined
```

세 함수는 같은2·3을 받지만 마지막은 계산만 하고 반환하지 않는다. 짧은 식 본문과 return이 있는 블록은5를 반환한다. 함수 정의만 있을 때는 결과 출력이 없으므로 아래 호출까지 함께 읽는다.

## 문제 2. 개념을 자신의 말로 설명

1.블록 안에서 a+b만 계산하면 반환은?
2.return a,b는 두 값 반환인가?
3.괄호 시작 문장 앞에서 어떤 경계를 확인하는가?

<details>
<summary>풀이</summary>

명시적 반환이 없으면undefined다. 쉼표의 마지막 값만 반환한다. 앞 호출 끝의 세미콜론 등 문장 경계를 확인한다.

| 코드 | (2,3) 호출 결과 | 이유 |
| --- | --- | --- |
| return a+b |5 |합 반환 |
| 식 본문 a+b |5 |식 결과 반환 |
| 블록 안 a+b만 |undefined |반환 없음 |
| return a,b |3 |마지막 표현 값 |

원본 fn1(1,2)의 반환은2다. 숫자를 출력한 것, 숫자를 반환한 것, 반환한 숫자를 다시 호출하려다 실패한 것은 서로 다른 단계다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **noReturn에return 추가**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| noReturn에return 추가 |마지막5 |명시적 반환 |
| expression의+만*로 |두번째6 |식 계산 변경 |
| block 인수만4,3으로 |첫번째7 |해당 호출 입력 변경 |

undefined이면 중괄호 안 return을 확인한다. 뒤 함수 선언이 보이는데 사용할 수 없다면 앞에서 실행이 중단되었는지 본다. 줄바꿈이 모든 문장의 끝을 보장하는 것은 아니다.

</details>
