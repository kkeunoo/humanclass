## 문제

문자열 `"7"`과 숫자 `7`을 각각 변수에 넣고 `typeof`, `+`, `===` 결과를 출력하자.

**확인 기준:** `"7" + 7`은 `"77"`, 엄격 비교는 `false`다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

값과 자료형을 함께 읽는다. 문자 결합이 먼저 일어나므로 숫자 덧셈을 원하면 변환한 뒤 더한다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
