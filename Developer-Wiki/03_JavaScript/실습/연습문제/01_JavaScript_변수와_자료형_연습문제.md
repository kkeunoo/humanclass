# 01. 변수와 자료형 — 이름·값·변환을 나누어 읽기 — 연습문제

[본문](../../01_JavaScript_변수와_자료형.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

선언·대입·출력을 구분하고 let·const·var의 기본 차이를 설명한다. 문자열과 숫자 변환을 추적하며 실제 회식비 풀이를 몫·나머지로 확인한다.

[전체 실행 HTML](../책형_복습/01_JavaScript_변수와_자료형.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../01_JavaScript_변수와_자료형.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
let score = 60;
score = 65;
console.log(score);
const text = '10.1';
console.log(text + 2);
console.log(Number(text) + 2);
console.log(parseInt(text));
console.log(Number('10개'));
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
65
10.12
12.1
10
NaN
```

score는60에서65로 바뀐 뒤 출력된다. text의 초기값은 문자열이고 재대입하지 않는다. 문자열에2를 연결하면10.12, 숫자 변환 뒤 더하면12.1이다. Console에서는 문자열과 숫자가 비슷하게 보일 수 있으므로 글자 모양만 보지 말고 typeof와 계산 과정을 함께 확인한다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1. let 숫자 변수에 문자열을 대입할 수 있는가?
2. Number와 parseInt는 항상 같은가?
3. 회식비 주최자 금액을 합계로 어떻게 확인하는가?

<details>
<summary>풀이</summary>

가능하다. const의 제한은 재대입이다. Number는 전체 변환, parseInt는 앞부분 정수 해석이어서10개 같은 입력에서 다르다.11,111×8+11,112=100,000으로 검산한다.

| 실행 | 사용 값 | 결과 | 값의 종류 |
| --- | --- | --- | --- |
| text+2 | '10.1',2 | '10.12' | 문자열 |
| Number(text)+2 | 10.1,2 |12.1 | 숫자 |
| parseInt(text) | '10.1' |10 | 숫자 |
| Number('10개') | 전체 변환 불가 |NaN | 숫자 계산 실패 표현 |

원본 alert는 안내, confirm은true/false, prompt는문자열 또는 취소null을 돌려준다. 상당수 호출은 주석이다. Number(null)과Number('')는0이므로 취소·빈 입력을 구분하려면 변환 전 값을 확인한다. 원본 평 환산은1평=3.3㎡인 수업용 근사이며10평→33㎡,82㎡→82/3.3평처럼 단위도 함께 읽는다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **text만 '10'으로**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| text만 '10'으로 | 연결102·덧셈12 | 입력 변경 |
| Number('10개')를 parseInt로 |10 | 전체 변환과 부분 해석 차이 |
| score 재대입만 제거 |60 출력 | 초기값 유지 |

숫자 계산이 이상하면 따옴표·입력 함수의 반환형·변환 시점을 확인한다. NaN은 문자열 "NaN"과 구분한다. 같은 범위의 let 재선언을 실험할 때는 별도 파일에서 확인하고, 정상 예제에 오류 줄을 함께 켜 두지 않는다.

</details>
