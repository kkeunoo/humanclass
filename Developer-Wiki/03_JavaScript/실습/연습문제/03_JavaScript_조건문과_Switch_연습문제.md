# 03. 조건문과 switch — 실행 경로와 경계값 — 연습문제

[본문](../../03_JavaScript_조건문과_Switch.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

if·else if·독립 if의 차이를 설명한다. switch의 비교와 break, 원본 난수·승패·시간·범위 문제의 경계값을 확인한다.

[전체 실행 HTML](../책형_복습/03_JavaScript_조건문과_Switch.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../03_JavaScript_조건문과_Switch.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
let score = 85;
if (score >= 90) {
    console.log('A');
} else if (score >= 80) {
    console.log('B');
} else {
    console.log('C');
}
let hour = 23;
let minute = 51;
minute += 35;
if (minute >= 60) {
    hour++;
    minute -= 60;
}
if (hour >= 24) {
    hour -= 24;
}
console.log(`${hour}시 ${minute}분`);
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
B
0시 26분
```

85는 90 이상에서 거짓, 80 이상에서 참이므로 B만 출력한다. 시간은 51+35=86분을 먼저 만들고, 60분을 빼고 시간을 하나 올려 24시26분으로 만든 뒤, 24시를0시로 보정한다. 한 번에35분을 더하는 조건에서는 각 보정 한 번이면 충분하다. 매우 큰 임의 시간까지 처리하는 일반 날짜 계산기라는 뜻은 아니다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1.95점인데70이상부터검사하면어떤갈래에먼저걸리는가?
2.숫자3과문자열3은switch에서같은가?
3.사각형x10~90·y20~100의테두리포함조건은?

<details>
<summary>풀이</summary>

먼저 적은70이상 갈래에 걸린다. switch는 엄격 비교여서 다르다. `x>=10&&x<=90&&y>=20&&y<=100`이다. 마지막은 새 복습 답이며 내 미완성 원본의 완성 풀이 인용이 아니다.

| 원본 문제 | 다시 확인할 조건 |
| --- | --- |
| 양수·0·음수 | 0은 별도 분류, 양수가 아님 |
| 홀짝 | `!값 % 2 == 0`과 전체 조건 부정은 다름 |
| 큰 값 | 같음 처리와 취소·빈 입력 구분 |
| 교통비 |7000·6999·3000·2999 경계 |
| 두 값 사이 |끝점 포함 여부·x/y 뒤집힘 |
| 월·계절 |prompt의 '3'과'03'은 다른 문자열 |
| 온도 | -3→‘영하3도’라면 부호 변경, 정수 변환은 아님 |
|35분 뒤 |60분 미만·24시 미만으로 보정 |
| 두 자리 같은 숫자 |10~99 범위를 먼저 확인,0·110 반례 |
|369 |십·일의 자리 풀이를 임의 자릿수로 일반화하지 않음 |
| 사각형 포함 |내 원본은 문제만 있음 |

온도의 -1곱하기는 부호 변경이라 -3.5→3.5이며 정수 변환이 아니다. 원본 경고 문구를 건강 판단 기준으로 삼지 않는다. 학습 예제의 출력 의미와 실제 판단 용도는 다르다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **score만95**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| score만95 |A |첫 갈래 참 |
| 원래 minute만25 |0시0분 |정확히60분 경계 |
| 원래 hour만22 |23시26분 |24시 보정 불필요 |
| 별도 switch시험의 phone만i15 |내오류 드러남 |현재s23만 보면 놓침 |

잘못된 결과가 나오면 어느 조건에서 처음 참이 되었는지 적는다. 난수를 계속 돌려 우연히 확인하기보다 입력값을 잠시 고정해 무승부·승리·패배·잘못된 입력을 각각 확인한다. 난수 생성과 승패 판정은 다른 검토 대상이다.

</details>
