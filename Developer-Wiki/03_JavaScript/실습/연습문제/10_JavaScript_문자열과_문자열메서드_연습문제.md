# 10. 문자열 — 찾고 자르고 바꾼 결과를 사용하기 — 연습문제

[본문](../../10_JavaScript_문자열과_문자열메서드.md) · [문제 목차](README.md)

실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님 원본 퀴즈와 구분한다. 예상 → 이유 → 수정 순서로 풀고, 정답은 먼저 답한 뒤 펼친다.

## 목표와 실행 조건

인덱스·길이·부분 문자열·변환 결과를 구분한다. trim과 취소 확인, 이메일 가리기의 누적·입력 한계를 설명한다.

[전체 실행 HTML](../책형_복습/10_JavaScript_문자열과_문자열메서드.html)과 같은 폴더의 JS를 함께 준비한다. Console을 열고 새로고침하면 처음부터 실행한다. 원본과 별도 파일이므로 기존 변수·타이머·출력 변경 실험의 영향을 섞지 않는다. 실제 입력·현재 시각·난수는 고정 결과와 구별한다.

입력·버튼·키보드·스크롤 예제는 [본문의 3절](../../10_JavaScript_문자열과_문자열메서드.md#example)에 적힌 조작 순서대로 결과를 예상한다. 통신 예제는 해당 절의 가상 JSON 파일과 로컬 웹 실행 준비가 필요하며 HTML을 직접 여는 조건과 다르다. Console 출력이 없는 문제는 화면의 값·개수·선택 상태를 답한다.

## 문제 1. 실행 순서와 결과 예상

다음은 **새 설명 예제**다. 출력 전에 어떤 값이 어떤 순서로 만들어지는지 적는다.

```javascript
function maskEmail(email) {
    const pos = email.indexOf('@');
    if (pos < 1) {
        return '이메일을 확인하세요';
    }
    const id = email.slice(0, pos);
    let stars = '';
    for (let i = 2; i < id.length; i++) {
        stars += '*';
    }
    return id.slice(0, 2) + stars + email.slice(pos);
}
console.log(maskEmail('abcd@example.com'));
console.log(maskEmail('abcd'));
const word = '사과 주스';
console.log(word.replace('사과', '포도'));
console.log(word);
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 입력·현재 상태·실행 시점·반환값을 따로 표시한다.

```text
ab**@example.com
이메일을 확인하세요
포도 주스
사과 주스
```

maskEmail은@앞 위치가1이상인지 보고 ID앞두글자를 남긴 뒤 나머지 길이만큼 별표를 쌓는다. 원본을 바탕으로 한 새 개선 함수다. @없는 입력은 즉시 안내를 반환한다. 완전한 이메일 형식 검증이나 암호화가 아니라 출력 가공이다. 마지막 두 줄은 replace가 새문자열을 돌려주고 word는 그대로임을 보여 준다.

</details>

## 문제 2. 개념을 자신의 말로 설명

1. replace는 원본을 바꾸는가?
2. trim은 중간 공백도 모두 제거하는가?
3. @없는 이메일에서 바로 마스킹 출력해도 되는가?

<details>
<summary>풀이</summary>

새 문자열을 반환한다. 양끝 공백만 제거한다. 필요 조건이 없으면 안내하고 돌아가는 등 처리 정책을 정해야 한다.

| 내 추가 기록 | 의미·한계 |
| --- | --- |
| emailValue |@없으면slice(0,-1)로끝글자빠짐 |
| genderValue |일부예제코드만비교,일반식별검증아님 |
| resultCheck |고정형식의월·분split,일반Date파싱아님 |
| 마스킹문제4표시 |실제는고정별표4개아닌길이만큼방식 |

문제4의 ‘별표 네 개 고정’과 문제5의 ‘가린 개수만큼’을 구분한다. trim은 양끝만 제거하므로 '    1 2  3   '→'1 2  3'이며 중간 공백 두 개도 남는다. substring의 끝 인덱스와 substr의 개수도 구분한다.

</details>

## 문제 3. 한 가지를 바꾸어 확인

먼저 **첫이메일ID만abcdef로**를 바꾸면 무엇이 달라질지 적는다. 그다음 실행 파일에 해당 변경만 적용해 실제 결과와 비교한다. 나머지 실험도 원래 예제로 돌아가 하나씩 수행한다.

<details>
<summary>변경 결과와 막힐 때 확인</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| 첫이메일ID만abcdef로 |ab****@example.com |길이6에서두글자남김 |
| 원래ID만a로 |a@example.com |이정책에가릴글자없음 |
| 원래word.replace결과를word에저장 |const재대입오류 |반환과선언구분 |

원본이 안 바뀌면 메서드 실패라고 단정하지 말고 반환값 저장을 본다. 문자를 위치로 교체하려고 replace(email[j],"*")를 쓰면 앞에 같은 글자가 있어 다른 위치를 바꿀 수 있다. 입력 형식이 틀린 경우와 코드 계산 오류를 나눈다.

</details>
