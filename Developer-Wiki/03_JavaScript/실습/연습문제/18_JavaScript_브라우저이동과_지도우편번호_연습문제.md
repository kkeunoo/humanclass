## 문제

외부 지도나 우편번호 서비스 없이, 상대 주소와 절대 주소 두 링크를 만들고 클릭 전 목적지를 설명하자.

**확인 기준:** 상대 주소는 현재 문서 주소를 기준으로, 절대 주소는 적힌 주소로 해석된다.
