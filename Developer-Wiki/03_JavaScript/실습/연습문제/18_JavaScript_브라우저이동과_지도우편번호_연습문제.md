# 18 JavaScript 브라우저이동과 지도우편번호 — 연습문제

[해당 본문](../../18_JavaScript_브라우저이동과_지도우편번호.md) · [장별 문제 목차](README.md)

**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

다음 코드의 각 줄이 **현재 주소 읽기**, **새 주소로 이동 시도**, **현재 페이지 다시 불러오기** 중 무엇인지 구분하자. 실제 실행은 필요 없다.

```javascript
console.log(location.href);
location.href = 'next.html';
location.reload();
```

**확인 기준:** 코드를 위에서 아래로 실제 실행하면 마지막 줄까지 도달한다고 단정할 수 있는지 설명한다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

첫 줄은 현재 주소를 콘솔에 출력한다. 둘째 줄은 `next.html`로 **이동을 시도**한다. 이동하면 기존 문서는 떠나므로 셋째 줄이 원래 페이지에서 의도한 순서로 실행·관찰된다고 보장할 수 없다. `reload()`를 시험하려면 이동 줄을 빼고 별도로 실행한다. 지도·우편번호 API 응답과 이 기본 주소 조작은 다른 문제다.

</details>

강사님·내 원본도 `location.href`를 읽고 바꾸는 코드가 있다. 이 문제의 `next.html`은 외부 서비스 없이 그 동작을 설명하기 위한 새 주소다.
