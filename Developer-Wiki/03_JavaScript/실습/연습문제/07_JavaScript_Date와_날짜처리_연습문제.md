## 문제

`new Date(2026, 0, 2, 9, 5)`의 월·일·시·분을 두 자리 문자열로 표시하자.

**확인 기준:** 예상 표시: `01-02 09:05`.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`getMonth()`는 0부터 시작하므로 1을 더한다. `padStart(2, "0")`로 두 자리를 만든다.

</details>
