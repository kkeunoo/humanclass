# 07 JavaScript Date와 날짜처리 — 연습문제

[해당 본문](../../07_JavaScript_Date와_날짜처리.md) · [장별 문제 목차](README.md)

**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

원본에서 사용한 날짜 문자열 형식으로 `new Date('2026-06-29')`를 만들고 월·일·시·분을 읽어 출력하자. **한국 시간대에서 실행한다는 조건**으로 결과를 예상하고, 월 숫자를 그대로 보여 줄 때와 사람이 읽는 월로 바꿨을 때의 차이를 설명하자.

**확인 기준:** `getMonth()`의 결과와 실제 1월을 구분한다. 날짜 객체를 만든 뒤 자동으로 현재 시각으로 변하는지까지 생각해 본다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

```javascript
const date = new Date('2026-06-29');
console.log(date.getMonth());      // 5
console.log(date.getMonth() + 1);  // 6
console.log(date.getDate());       // 29
console.log(date.getHours());      // 9
console.log(date.getMinutes());    // 0
```

`getMonth()`는 0부터 시작한다. 날짜만 있는 이 문자열은 UTC 자정이며, 한국 시간대에서는 같은 순간이 6월 29일 09:00이다. 다른 시간대에서는 로컬 시·날짜가 달라질 수 있다. 이 날짜 객체는 만들 때 정한 시각을 담고 있으므로 시간이 지나도 `date` 자체가 자동 갱신되지 않는다.

</details>

## 💡 추가로 알면 좋은 것

> [!TIP]
> 두 자리 `01-02 09:05` 형식까지 꾸미려면 문자열 앞에 `0`을 채우는 `padStart()` 같은 방법이 있다. **양쪽 Date 수업 원본에서 확인되지 않아** 이 문제의 필수 조건으로 두지 않았다. 기본 연습은 월의 0 시작과 각 `get...()` 결과를 설명하는 것이다.
