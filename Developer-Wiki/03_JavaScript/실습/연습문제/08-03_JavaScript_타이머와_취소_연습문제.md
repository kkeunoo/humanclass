**새로 구성한 연습문제**다. 먼저 해당 본문에서 강사님·내 코드와 실제 동작을 읽는다.

## 문제

버튼을 누를 때 `setTimeout`으로 1초 뒤 메시지를 예약하고 취소 버튼에서 그 예약을 지우자.

**확인 기준:** 취소를 먼저 누르면 예약 메시지가 나오지 않는다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

타이머 ID를 변수에 보관하고 `clearTimeout(id)`에 같은 ID를 준다.

</details>

원본 코드에서 같은 기능을 찾고, 입력값·반환값·화면 변화가 문제와 어디서 달라지는지 한 문장으로 적어 보자.
