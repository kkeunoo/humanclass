## 문제

`[10, 20, 30]`에서 20 이상만 남겨 각각 2배로 만든 새 배열을 구하자. 원본도 출력하자.

**확인 기준:** 새 배열은 `[40, 60]`, 원본은 `[10, 20, 30]`이다.

<details>
<summary>해설 — 직접 해 본 뒤 펼치기</summary>

`filter`로 조건을 고르고 `map`으로 변환한다. 두 메서드의 반환값을 변수에 받아 확인한다.

</details>
