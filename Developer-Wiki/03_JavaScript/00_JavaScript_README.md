## 📌 Overview

JavaScript는 웹 페이지에 동적인 기능을 제공하는 프로그래밍 언어입니다.

이 디렉토리는 JavaScript를 학습하며 작성한 문서를 모아둔 공간으로, 문법 학습뿐 아니라 실제 브라우저 환경에서 동작하는 기능을 중심으로 정리했습니다.

- JavaScript 문법 및 핵심 개념
- DOM/BOM 조작
- Event 처리
- 비동기 프로그래밍
- AJAX · JSON · Fetch API
- Open API 활용
- 강사 코드 비교 및 개선 포인트
- 복습 문제 및 체크리스트

Developer-Wiki는 **학습 → 비교 → 개선 → 복습**의 흐름을 반복하며 실무 개발 역량을 키우는 것을 목표로 합니다.
