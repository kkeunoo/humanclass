# JavaScript 리팩토링 자체 검토 기록

## 결론

기존 상세 본문을 축약하지 않고, 수업 원본의 실제 차이와 실행 재현·복습을 보강했다. 기존 문서에 이미 있던 오류 교정도 유지했다. 외형만 바꾸어 완료 처리하지 않았다.

## 보존과 검증 수치

- 기존 번호형 본문 1,584개 절의 번호와 순서를 유지했다.
- 기존 코드 블록 2,470개를 보존했다. 실행 언어 블록 1,668개 중 21번 개선 모델 상수 한 곳만 의도적으로 설정용 placeholder로 바꿨다.
- 01~24와99의 25개 문서에 정의·입력·실행·원본 비교·최소 예제·예상 출력·역추적 설명을 연결했다.
- 새 기본·응용 복습 과제 50개와 정답·처리 순서 해설을 추가했다. 기존 예제·풀이도 그대로 읽을 수 있다.
- Markdown 파일 링크와 내부 앵커, 번호, 펜스, 인코딩 문자, 인증정보 노출을 정적 검사했다. 검증 기록은 이 문서의 범위와 한계를 포함한다.

## 원본 대조에서 확인한 사례

- 01~03: var 준비와 미선언 할당, 숫자 문자열 변환, 전위·후위 상태, Falsy 메모 누락, switch 비교, 출력 문자열 오타를 확인했다. 별도 가위바위보 퀴즈의 문자열·숫자 비김 비교도 설명했다.
- 04~06: 합계 변수 위치, 주차장 break, 주사위 조합의 의미, filter 조건, FIFO·참조·메모리 크기 단정을 설명했다. 개인 피라미드 복습과 주석 상태인 중복 테스트도 연결했다.
- 07~10: 연속 Date setter, 콜백 전달과 즉시 재귀, IIFE 문장 연결, TV 경계·음소거 차이, 이메일 마스킹 누적 실패를 설명했다.
- 11~13: 내 메뉴3개/강사님6개, 유사 목록과 배열, 노드 이동, 폼 변경 전후 로그, checks2[i] 차이를 확인했다.
- 14~17: 타이머 순서와 동기화 개념, 게임 초기 위치와 이동 범위, 좌표 기준·mouseup 누락·전파를 설명했다. 강사님 별도 이벤트 퀴즈의 q1~q5 구현과 data-price 방식도 대조했다.
- 18~22: go(-2), 주소 완료 콜백, 누락된 k 프로퍼티, 표 행 생성·날씨 그룹화, model 응답 저장·부모 출력 교체, 빈 Webhook URL·204 응답을 설명했다.

## 실행 테스트와 한계

새 최소 예제25개 중 외부 통신·DOM에 의존하지 않는22개를 Node의 독립 문맥에서 실행해 예상 출력과 비교했다. 추가로 별도 퀴즈·중복 테스트의 순수 예제2개를 확인했다. 원본09의 IIFE 연결 TypeError, [a-Z] 범위 SyntaxError, 복합 증감 결과도 재현했다.

DOM 예제와 실제 화면 렌더링·드래그·폼·저장소는 이번 자동 실행 통과에 포함하지 않았다. 원본의 무한 루프·외부 요청을 통째로 실행하지 않았으며, 실제 API 호출·과금·Discord 메시지 전송도 하지 않았다. 서버 프록시는 별도 구현이 필요한 설계다.

| 브라우저 수동 확인 | 기대 결과 | 확인 위치 |
| --- | --- | --- |
| DOM 선택 후 요소 추가·삭제 | live 목록은 변경 반영, 정적 목록은 다시 조회 | Console·Elements |
| 폼에 공백·0·미선택 입력 | 빈 값과 유효한0 구분, radio null 처리 | Console·화면 |
| 버튼 반복 클릭 | 의도하지 않은 리스너·금액·✔ 누적 없음 | 로그 횟수·화면 |
| 드래그 후 요소 밖에서 해제 | 드래그 상태 종료, 스크롤 후 좌표 일치 | 화면·좌표 로그 |
| Todo 추가·완료·선택·삭제 | 상태·DOM·전체선택 표시 일치 | 화면·Elements |
| 같은 origin에서 저장 후 새로고침 | 상태 복원, 손상 데이터 처리 | Application·화면 |
| API HTTP 오류·빈 본문·누락 필드 | 오류 분리, loading 복구, 빈 본문 parse 안 함 | Network·화면 |

이 표는 수동 확인 계획이며 완료한 브라우저 시험 결과가 아니다. 실제 서비스 성공·CORS·팝업·날씨 발표 시각은 환경과 서비스 계약 확인이 필요하다.
