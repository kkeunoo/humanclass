# 00. JavaScript Wiki 읽기법

[JavaScript 목차](README.md)

코드를 다시 읽을 때는 **입력 → 현재 값 → 실행한 문장 → 결과**를 한 줄씩 적는다. 수업에서 배운 변수·계산을 가장 작게 합친 **설명용 재구성**으로 연습해 보자.

```javascript
let count = 1;
count += 1;
console.log(count); // 2
```

`count`는 처음에 1이고, `+= 1` 뒤에는 2다. 마지막 줄은 값을 새로 바꾸는 대신 현재 값을 콘솔에 보여 준다. 코드에 괄호가 있다고 모든 줄이 같은 일을 하는 것은 아니다.

DOM·이벤트 장으로 가면 “언제 실행되는가?”를 추가로 확인한다. 버튼을 누르기 전과 후, 입력을 읽기 전과 후의 상태가 다를 수 있다. `setTimeout`은 적힌 위치에서 곧바로 콜백 본문을 실행하지 않는다. 각 장의 **예상 출력·화면 변화**를 먼저 적고, 브라우저에서 확인하자.

강사님 코드와 내 코드는 각 본문에 **원본 발췌**로 표시했다. 설명을 위한 새 코드와 원본의 결과를 섞어 읽지 않는다. 수업 원본에서 확인되지 않은 것은 본문 하단의 **추가로 알면 좋은 것**에 두며, [기존 자료의 학습 범위 분류](추가편_기존자료_학습범위_분류.md)도 참고할 수 있다. 이제 [01 변수와 자료형](01_JavaScript_변수와_자료형.md)부터 읽는다.
