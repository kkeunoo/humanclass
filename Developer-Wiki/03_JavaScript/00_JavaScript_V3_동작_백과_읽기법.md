# 00. JavaScript Wiki 읽기법

[JavaScript 목차](README.md)

기존 Wiki에서 이 문서로 오셨다면 [새 JavaScript 목차](README.md)에서 **01장부터 차례대로** 읽으면 된다. 각 장은 강사님 수업 코드, 내 실제 코드, 두 코드의 차이, 직접 확인할 질문 순서로 정리했다.
