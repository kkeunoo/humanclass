# 메모리와 참조 종합실습 — 공유·복사·반환 추적

[00 목차](README.md) · [실습 폴더](실습/README.md)

## 실습 목표

**새로 구성한 종합실습**이다. 강사님·내 원본에 같은 이름의 과제가 있었다는 뜻이 아니다. 수업에서 확인한 `b = a`, `copy()`, `append()`, 함수의 반환값을 한 코드에서 연결한다. [본문의 이름·객체 설명](01_메모리와_참조%28Stack_Heap%29.md#names)을 읽은 뒤 시작하자.

코드를 바로 실행하기 전에 다음 세 질문에 답한다.

1. `first`·`same`·`other`가 가리키는 리스트는 몇 개인가?
2. `append_four(same)` 뒤 어느 이름으로 `[1, 2, 4]`를 볼 수 있는가?
3. 마지막 줄은 `other`의 값과 **함수의 반환값** 중 무엇을 출력하는가?

## 문제 — 네 줄의 출력을 예측하기

```python
def append_four(values):
    values.append(4)

first = [1, 2]
same = first
other = first.copy()
append_four(same)
other[0] = 9

print(first)
print(same is first)
print(other)
print(append_four(other))
```

아래 표를 먼저 채우고 실행 결과와 비교한다.

| 출력 위치 | 예상값 | 어느 객체가 바뀌었는가? |
| --- | --- | --- |
| `print(first)` |  |  |
| `print(same is first)` |  |  |
| `print(other)` |  |  |
| `print(append_four(other))` |  |  |

**완료 기준:** 두 이름이 공유하는 리스트의 변경, 새 바깥 리스트의 요소 교체, `return` 없는 함수의 반환을 **각각 다른 이유로** 설명한다. 특히 마지막 줄의 화면 출력이 `None`이어도 `other`에는 `4`가 추가된다는 점을 말할 수 있어야 한다.

<details>
<summary>예상 결과와 해설 — 먼저 풀고 펼치기</summary>

```text
[1, 2, 4]
True
[9, 2]
None
```

`same`은 `first`와 같은 객체를 가리켜 `append(4)`가 둘 다에서 보인다. `other`는 복사한 바깥 리스트라 요소 0을 바꿔도 `first`는 그대로다. 마지막 호출은 `other`에 4를 추가하지만 함수가 값을 명시적으로 반환하지 않으므로 출력은 `None`이다.

마지막 줄 다음에 `print(other)`를 추가하면 `[9, 2, 4]`가 나온다. 함수가 입력을 바꾸는 일과 값을 돌려주는 일은 서로 별개다. 강사님과 내 실제 함수의 반환값 차이는 [본문 5절](01_메모리와_참조%28Stack_Heap%29.md#function)에서 다시 확인할 수 있다.

</details>

## 💡 추가로 알면 좋은 것

> [!TIP]
> 중첩 리스트를 `copy()`하면 바깥 리스트만 새로 만들어지고 안쪽 리스트는 공유될 수 있다. 이 종합실습의 기본 조건은 **한 단계 리스트**다. 깊은 복사가 필요할 때만 [본문의 보충 설명](01_메모리와_참조%28Stack_Heap%29.md#extra-01-4)을 읽으면 된다.
