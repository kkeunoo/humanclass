# 메모리와 참조 종합실습 — 공유·복사·반환 추적

[00 목차](README.md) · [실습 폴더](실습/README.md)

**새로 구성한 종합실습**이다. 강사님·내 원본에 같은 이름의 과제가 있었다는 뜻이 아니다. 실행 전에 각 `print`의 결과와 이유를 표로 적는다.

```python
def append_four(values):
    values.append(4)

first = [1, 2]
same = first
other = first.copy()
append_four(same)
other[0] = 9

print(first)
print(same is first)
print(other)
print(append_four(other))
```

**완료 기준:** 두 이름이 공유하는 리스트의 변경, 새 바깥 리스트의 요소 교체, `return` 없는 함수의 반환을 따로 설명한다.

<details>
<summary>예상 결과와 해설 — 먼저 풀고 펼치기</summary>

```text
[1, 2, 4]
True
[9, 2]
None
```

`same`은 `first`와 같은 객체를 가리켜 `append(4)`가 둘 다에서 보인다. `other`는 복사한 바깥 리스트라 요소 0을 바꿔도 `first`는 그대로다. 마지막 호출은 `other`에 4를 추가하지만 함수가 값을 명시적으로 반환하지 않으므로 출력은 `None`이다.

</details>

## 추가로 알면 좋은 것

중첩 리스트를 `copy()`하면 안쪽 리스트는 공유될 수 있다. 이 종합실습의 기본 조건은 **한 단계 리스트**이며 깊은 복사는 선택 확장이다.
