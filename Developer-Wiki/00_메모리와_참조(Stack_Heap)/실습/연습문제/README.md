# 메모리와 참조 장별 연습문제

[실습 목차](../README.md) · [00 단원 목차](../../README.md)

본문 한 장에 대응하는 [메모리와 참조 연습문제](01_메모리와_참조_연습문제.md)다. 강사님 원본 문제나 내 당시 풀이가 아닌 **새로 구성한 복습**이다. 먼저 [본문](../../01_메모리와_참조%28Stack_Heap%29.md)의 개념·원본 풀이를 읽는다.

| 단계 | 연습할 것 | 완료 확인 |
| --- | --- | --- |
| 결과 예상 | 같은 리스트와 복사본 | 출력뿐 아니라 객체 수 설명 |
| 이유 설명 | 재할당 뒤 변경 | 어느 객체를 바꿨는지 추적 |
| 작은 수정 | 원본 유지 요구사항 | 복사·수정·반환·결과 받기의 연결 |

각 문제는 새 초기 상태에서 실행한다. 먼저 예상·이유를 적고 접힌 정답을 펼친다. 그 뒤 [종합실습](../../03_메모리와_참조_종합실습.md)으로 이어 간다.
