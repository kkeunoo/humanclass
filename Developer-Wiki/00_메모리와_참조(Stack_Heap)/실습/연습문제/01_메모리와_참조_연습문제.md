## 문제

다음 코드를 실행하기 전에 출력 세 줄을 적자.

```python
a = [1]
b = a
c = a.copy()
b.append(2)
c.append(3)
print(a)
print(b is a)
print(c)
```

<details>
<summary>정답과 이유</summary>

`[1, 2]`, `True`, `[1, 3]`이다. `b`는 같은 리스트를 가리키고, `c`는 새 바깥 리스트다. `append`는 각 대상 객체의 내용을 바꾼다.

</details>
