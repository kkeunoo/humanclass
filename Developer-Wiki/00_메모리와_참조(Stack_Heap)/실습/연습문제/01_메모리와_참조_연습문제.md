# 01 메모리와 참조 — 연습문제

[본문](../../01_메모리와_참조%28Stack_Heap%29.md) · [실습 목차](../README.md)

**새로 구성한 문제**다. 원본 수업 코드를 그대로 옮긴 과제는 아니다. [본문 2~5절](../../01_메모리와_참조%28Stack_Heap%29.md#alias)에서 배운 대입·복사·재할당·반환값을 확인한다. 각 문제는 **출력을 먼저 예상하고, 어떤 객체가 바뀌었는지 한 문장으로 설명**한 뒤 실행하자.

## 문제 1 — 같은 리스트와 복사한 리스트

다음 코드를 실행하기 전에 출력 세 줄을 적자.

```python
a = [1]
b = a
c = a.copy()
b.append(2)
c.append(3)
print(a)
print(b is a)
print(c)
```

<details>
<summary>정답과 이유</summary>

```text
[1, 2]
True
[1, 3]
```

`b`는 `a`와 같은 리스트를 가리키므로 `b.append(2)` 뒤 `a`에도 `2`가 보인다. `c`는 복사한 새 바깥 리스트라 `c.append(3)`은 `a`를 바꾸지 않는다.

</details>

## 문제 2 — 리스트 변경과 이름 재할당

```python
a = [1, 2]
b = a
b = [9]
b.append(10)
print(a)
print(b)
```

`b = [9]` 전후에 `b`가 같은 리스트를 가리키는지 설명해 보자.

<details>
<summary>정답과 이유</summary>

`a`는 `[1, 2]`, `b`는 `[9, 10]`이다. 처음에는 같은 리스트를 가리키지만 `b = [9]`에서 `b`가 새 리스트를 가리킨다. 이후 `b.append(10)`은 새 리스트만 바꾼다.

</details>

## 문제 3 — 변경과 반환값

```python
def add_item(items):
    items.append(3)

numbers = [1, 2]
answer = add_item(numbers)
print(numbers)
print(answer)
```

`answer`가 `None`이면 `numbers`도 그대로일까? 출력 두 줄의 이유를 나누어 적자.

<details>
<summary>정답과 이유</summary>

`numbers`는 `[1, 2, 3]`, `answer`는 `None`이다. `append()`가 전달받은 리스트를 바꾸고, `return`이 없으므로 함수 호출 자체는 `None`을 돌려준다. 내 실제 함수와 강사님 함수의 차이는 [본문 5절](../../01_메모리와_참조%28Stack_Heap%29.md#function)에서 비교한다.

</details>

## 💡 추가로 알면 좋은 것

> [!TIP]
> `is`는 두 이름이 **같은 객체**를 가리키는지, `==`는 값이 같은지 확인한다. 문제 1에서 `c.append(3)`을 실행하기 **전**에 `print(c is a)`와 `print(c == a)`를 추가하면 각각 `False`, `True`가 나온다. 복사 직후 값은 같지만 객체는 다르다. 이 확장 확인은 새 연습이며, 수업 원본 문제의 조건은 아니다.
