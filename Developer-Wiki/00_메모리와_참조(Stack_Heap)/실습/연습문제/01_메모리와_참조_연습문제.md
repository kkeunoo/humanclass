## 문제 1 — 같은 리스트와 복사한 리스트

아래 세 줄의 출력과 이유를 적는다. `c`를 만들었을 때 리스트가 몇 개가 되었는지도 말해 보자.

```python
a = [1]
b = a
c = a.copy()
b.append(2)
c.append(3)
print(a)
print(b is a)
print(c)
```

**힌트:** `b`와 `c`의 이름이 달라서 다른 것이 아니다. 각각 어떤 방식으로 연결했는지를 본다.

<details>
<summary>정답과 풀이</summary>

```text
[1, 2]
True
[1, 3]
```

`b`는 `a`와 같은 리스트를 가리키므로 `b.append(2)`가 `a`에서도 보인다. `c`는 새 바깥 리스트이므로 `c.append(3)`은 `a`에 영향을 주지 않는다. 바깥 리스트는 두 개다.

**흔한 오답:** `a`를 `[1, 2, 3]`이라고 쓰면 `copy()`로 바깥 리스트가 분리된 사실을 놓친 것이다.

</details>

**하나만 바꾸는 실험:** `c = a.copy()`를 `c = a`로 바꾸고 처음부터 다시 실행한다. 세 이름이 같은 리스트를 사용하므로 첫 출력과 셋째 출력이 모두 `[1, 2, 3]`이다. 이름이 아니라 객체 관계가 결과를 결정한다.

## 문제 2 — 재할당 뒤에는 무엇이 바뀔까?

다음 두 출력과 `b = [9]` 전후의 객체 관계를 설명한다. `b.append(10)`이 왜 `a`에는 보이지 않는가?

```python
a = [1, 2]
b = a
b = [9]
b.append(10)
print(a)
print(b)
```

<details>
<summary>정답과 단계별 이유</summary>

```text
[1, 2]
[9, 10]
```

| 시점 | `a` | `b` |
| --- | --- | --- |
| `b = a` 직후 | 기존 리스트 A | 같은 A |
| `b = [9]` 직후 | 기존 A | 새 리스트 B |
| `b.append(10)` 직후 | A 그대로 | B에 10 추가 |

`b = [9]`는 기존 리스트를 `[9]`로 고친 것이 아니라 이름 `b`를 새 객체에 연결했다. 따라서 뒤의 변경은 B에만 적용된다.

</details>

**이유 설명 추가:** 위 코드에서 `b = [9]` 대신 `b[0] = 9`를 쓰면 바깥 리스트 A를 직접 바꾼다. 그 뒤 `append`도 A에 적용돼 두 출력 모두 `[9, 2, 10]`이 된다. 두 표현의 왼쪽 대상을 구별한다.

## 문제 3 — 원본을 유지해야 한다면 어디를 바꿀까?

요구사항은 ‘입력 `[1, 2]`는 유지하고, 3이 추가된 새 목록을 얻는다’다. 아래 코드는 그 요구사항을 만족하는가? 출력 두 줄부터 예상하고, 필요한 줄만 고쳐 보자.

```python
# 새로 구성한 검토 대상 예제
def add_item(items):
    items.append(3)


numbers = [1, 2]
answer = add_item(numbers)
print(numbers)
print(answer)
```

**수정 뒤 기대 결과:** 원본은 `[1, 2]`, `answer`는 `[1, 2, 3]`이어야 한다. 중첩 리스트나 새 라이브러리는 필요 없다.

<details>
<summary>먼저 원래 코드의 결과 확인</summary>

```text
[1, 2, 3]
None
```

`append`가 입력을 바꾸고 반환문이 없어 `None`을 돌려준다. `answer`가 `None`인 것과 원본이 변경된 것은 별도 결과다.

</details>

<details>
<summary>개선 예시와 잘못 고치기 쉬운 부분</summary>

다음은 **원본에 미적용한 새 풀이 · 독립 실행 가능**이다.

```python
def add_item(items):
    copied = items.copy()
    copied.append(3)
    return copied


numbers = [1, 2]
answer = add_item(numbers)
print(numbers)
print(answer)
```

확인한 출력:

```text
[1, 2]
[1, 2, 3]
```

복사·복사본 변경·반환이 함께 필요하다. 단지 원래 함수 끝에 `return items`를 붙이면 `answer`는 생기지만 원본도 바뀌므로 요구사항을 충족하지 않는다. 복사본만 만들고 `return`을 빼면 원본은 유지돼도 호출자가 새 결과를 받지 못한다.

</details>

## 흔한 실수와 다음 학습

| 스스로 물을 질문 | 되짚을 개념 |
| --- | --- |
| 변수 이름이 다르면 객체도 다른가? | 대입과 공유 |
