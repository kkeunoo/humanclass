2. [복습 실행 파일](참조_복습.py) — 공유·복사·함수 반환 출력 확인
3. [종합실습](../03_메모리와_참조_종합실습.md) — 공유·변경·반환을 한 번에 추적

## 파일 관계와 실행 조건

| 파일 | 역할 |
| --- | --- |
| [reference_tools.py](reference_tools.py) | 입력 변경 함수와 복사 후 반환 함수의 전체 정의 |
| [참조_복습.py](참조_복습.py) | 위 함수를 import해 호출하고 결과 출력 |

두 파일을 같은 폴더에 둔다. Python 3만 있으면 되고 추가 패키지·서버는 필요 없다. 터미널의 현재 폴더를 이 `실습` 폴더로 맞춘 뒤 `python 참조_복습.py`를 실행한다. 코드와 같은 작업 폴더를 쓰는 이유는 이 예제의 `reference_tools` 모듈을 찾기 위해서다.

각 실행은 새 리스트에서 시작한다. 핵심 출력은 원본 `[1, 2, 3]`·복사본 `[9, 2]`, 입력 변경 함수의 반환 `None`, 원본 유지 함수의 새 결과 `[1, 2, 3]`이다. **정확한 출력 순서와 전체 코드는 [본문 3절](../01_메모리와_참조%28Stack_Heap%29.md#small-example)**에서 예상한 뒤 비교한다.

## 복습 순서

결과를 먼저 예상하고, 실행 후에는 이름의 연결·변경 대상·반환값을 각각 설명한다. 값만 같아 보이면 `is`와 원본 유지 여부를 다시 확인한다. 잘못된 예상은 [본문의 결과 확인](../01_메모리와_참조%28Stack_Heap%29.md#results)에서 원인을 찾는다.
