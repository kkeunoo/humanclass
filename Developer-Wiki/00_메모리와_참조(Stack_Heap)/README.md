# 00. 메모리와 참조

**리스트와 함수를 공부하다가 “왜 원본이 바뀌지?”가 궁금할 때 읽는 연결 자료**다. 번호가 00이라고 모든 과목에 앞서 학습해야 하는 것은 아니다.

## 수업 본문

[변수와 참조 — 같은 리스트가 함께 바뀌는 이유](01_메모리와_참조%28Stack_Heap%29.md)

| 읽는 시점 | 읽을 부분 | 해결할 질문 |
| --- | --- | --- |
| Python 변수·리스트를 배운 뒤 | 본문 2~4절의 리스트 예제 | 대입과 복사, 변경과 재할당은 어떻게 다른가? |
| Python 함수를 배운 뒤 | 본문 4절 함수 예제와 5~8절 | `return`이 없어도 리스트가 바뀌는 이유는? |
| 복습할 때 | 본문 10절의 빠른 확인표와 장별 문제 | 결과를 예측하고 이유를 설명할 수 있는가? |

본문은 내 `04_list.py`, `11_fn.py`를 중심으로 강사님 `_04_list.py`, `_11_fn.py`와 대조했다. 실행문이 같은 부분은 중복 인용을 줄이고, **함수의 반환값이 실제로 달라지는 부분만 강사님 코드로 비교**한다. 원본 기준일은 2026-10-28이다.

**읽는 흐름:** 개념 → 작은 예제·결과 → 내 코드 풀이 → 파일 연결 → 코드 평가 → 필요한 강사님 비교 → 결과·오류 확인 → 보충 → 복습. 원본 발췌·새 예제·개선안은 표시로 구별한다. 외부 문서로 검증한 설명에는 **📚 출처**, 수업 밖 기능에는 **💡 TIP**을 붙인다.

## 이전 문서에서 달라진 점

기존의 반복되는 원본 비교를 책형 10절 흐름으로 다시 정리했다. 조건문·반복문·개별 자료형의 일반 사용법은 해당 Python 장에서 읽고, 이곳에서는 리스트와 함수의 참조 동작에 집중한다. BACKUP 리스트 문서의 ‘정의·문법·작은 예제·출력·이유’ 전개를 참고했다.

기존 본문 파일명은 유지했다. 기존의 Chapter·Section별 세부 목차는 새 절 구성으로 바뀌었다. [전체 Wiki 첫 화면](../README.md)과 [통합 용어색인](../99_Developer-Wiki_통합_용어색인.md)에서 다른 과목으로 이어 읽을 수 있다.
