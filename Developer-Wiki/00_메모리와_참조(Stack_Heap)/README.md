# 00. 메모리와 참조

**리스트와 함수를 공부하다가 “왜 원본이 바뀌지?”가 궁금할 때 읽는 연결 자료**다. 번호가 00이라고 모든 과목에 앞서 학습해야 하는 것은 아니다.

## 수업 본문

[변수와 참조 — 같은 리스트가 함께 바뀌는 이유](01_메모리와_참조%28Stack_Heap%29.md)

| 읽는 시점 | 읽을 부분 | 해결할 질문 |
| --- | --- | --- |
| Python 변수·리스트를 배운 뒤 | 1~4절 | 대입과 복사, 변경과 재할당은 어떻게 다른가? |
| Python 함수를 배운 뒤 | 5~6절 | `return`이 없어도 리스트가 바뀌는 이유는? |
| 복습할 때 | 7~8절 | 결과를 예측하고 이유를 설명할 수 있는가? |

본문은 강사님 `_04_list.py`, `_11_fn.py`와 내 `04_list.py`, `11_fn.py`를 비교한다. 강사님 코드 설명 바로 아래 내 실제 코드를 배치했으며, 동일한 동작과 반환값 차이를 구분했다.

**원본 발췌**와 **설명용 재구성** 표기를 확인한다. 원본 주석을 그대로 인용한 부분에서도 실제 설명은 바로 아래 교정 내용을 기준으로 읽는다.
