# Python 문자열

## 학습 목표

- 문자열 인덱싱, 슬라이싱, 길이와 주요 메서드를 사용한다.
- 터미널 또는 Python 실행 환경에서 직접 결과를 확인한다.
- 오류 메시지의 줄 번호와 원인을 확인한다.

## 왜 배우는가

Python은 데이터를 저장하고 처리하는 문법을 간결하게 표현합니다. 직접 실행하고 출력 결과를 확인하는 과정이 개념 이해의 핵심입니다.

## 기본 개념

```python
text = 'Python Study'

print(text[0])
print(text[0:6])
print(len(text))
print(text.lower())
```

## 수업 예제

예제를 실행한 뒤 변수의 값이나 코드 일부를 한 번에 하나씩 바꾸고 결과 차이를 확인합니다.

## 수업 문제

### 문제

이름과 나이를 변수에 저장하고 안내 문장을 출력하세요.

### 요구사항

- 이름은 문자열, 나이는 숫자로 저장합니다.
- f-string으로 두 값을 한 문장에 넣습니다.
- 결과는 `홍길동님의 나이는 20세입니다.` 형식입니다.

### 직접 풀어 보기

해설을 열기 전에 실행 결과를 먼저 예상하고 코드를 작성합니다.

<details>
<summary>해설 보기</summary>

```python
name = '홍길동'
age = 20

print(f'{name}님의 나이는 {age}세입니다.')
```
