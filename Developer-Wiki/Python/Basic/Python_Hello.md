# Python 시작과 실행

## 학습 목표

- Python 파일을 실행하고 print와 주석을 사용한다.
- 터미널 또는 Python 실행 환경에서 직접 결과를 확인한다.
- 오류 메시지의 줄 번호와 원인을 확인한다.

## 왜 배우는가

Python은 데이터를 저장하고 처리하는 문법을 간결하게 표현합니다. 직접 실행하고 출력 결과를 확인하는 과정이 개념 이해의 핵심입니다.

## 기본 개념

```python
print('Hello, Python!')

# 한 줄 주석
print('실행되는 코드')
```

## 수업 예제

예제를 실행한 뒤 변수의 값이나 코드 일부를 한 번에 하나씩 바꾸고 결과 차이를 확인합니다.

## 수업 문제

### 문제

세 개의 안내 문장을 각각 한 줄씩 출력하세요.

### 요구사항

- `print()`를 세 번 사용합니다.
- 문자열은 따옴표로 감쌉니다.
- 코드 위에 한 줄 주석을 작성합니다.

### 직접 풀어 보기

해설을 열기 전에 실행 결과를 먼저 예상하고 코드를 작성합니다.

## 자주 하는 실수

- 따옴표를 닫지 않는 경우
- 파일을 저장하지 않고 이전 코드를 실행하는 경우
- 오류 메시지의 줄 번호를 확인하지 않는 경우

## 실무 연결

새 프로젝트에서 간단한 출력문으로 실행 환경과 파일 실행 여부를 확인할 수 있습니다.

## 📌 더 알아보기

Python은 조건문, 반복문, 함수처럼 코드 블록을 작성할 때 들여쓰기를 문법으로 사용합니다. 현재는 들여쓰기가 중요한 특징이라는 점만 기억합니다.
