# Python Hello와 실행


```python
print('Hello, Python!')
```

Python 파일은 `.py` 확장자를 사용한다. 위에서 아래로 순서대로 실행된다.

```python
# 한 줄 주석
print('실행되는 코드')
```

## 주의사항

Python은 들여쓰기가 문법이다. 탭과 공백을 섞지 않고 일반적으로 공백 4칸을 사용한다.
