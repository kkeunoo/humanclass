# Python 변수와 연산자

## 학습 목표

- 변수에 값을 저장하고 산술 연산과 자료형 확인을 수행한다.
- 터미널 또는 Python 실행 환경에서 직접 결과를 확인한다.
- 오류 메시지의 줄 번호와 원인을 확인한다.

## 왜 배우는가

Python은 데이터를 저장하고 처리하는 문법을 간결하게 표현합니다. 직접 실행하고 출력 결과를 확인하는 과정이 개념 이해의 핵심입니다.

## 기본 개념

```python
price = 15000
quantity = 3
total = price * quantity

print(total)
print(type(total))
```

## 수업 예제

예제를 실행한 뒤 변수의 값이나 코드 일부를 한 번에 하나씩 바꾸고 결과 차이를 확인합니다.

## 수업 문제

### 문제

상품 가격과 수량을 변수에 저장하고 총가격을 출력하세요.

### 요구사항

- 가격은 15000, 수량은 3입니다.
- 곱셈 연산자를 사용합니다.
- 결과값과 자료형을 출력합니다.

## 자주 하는 실수

- 변수 이름을 숫자로 시작하는 경우
- 숫자를 문자열로 저장해 계산이 달라지는 경우
- `/`와 `//`의 결과를 혼동하는 경우

## 실무 연결

상품 가격, 수량, 점수처럼 값을 저장하고 계산하는 모든 프로그램의 기초입니다.

## 📌 더 알아보기

`/`는 나눗셈 결과를 실수로 만들고, `//`는 몫, `%`는 나머지, `**`는 거듭제곱을 계산합니다.
