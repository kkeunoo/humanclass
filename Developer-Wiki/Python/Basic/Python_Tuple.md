# Python Tuple


```python
point = (10, 20)
x, y = point
```

Tuple은 순서가 있지만 생성 후 값을 직접 변경할 수 없다.

```python
single = (1,)
```

값 하나짜리 tuple은 쉼표가 필요하다.

## List와 비교

- List: `[]`, 값 변경 가능
- Tuple: `()`, 값 변경 불가

고정된 좌표나 여러 반환값을 묶을 때 사용할 수 있다.
