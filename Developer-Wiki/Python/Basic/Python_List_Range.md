# 개념과 수업 예제

```python
numbers = [1, 2, 3]
numbers.append(4)
print(numbers[0])
```

## 반복

```python
for number in numbers:
    print(number)

for i in range(1, 6):
    print(i)
```

`range(1, 6)`은 1부터 5까지 만든다. 끝 값은 포함하지 않는다.

## 슬라이싱

```python
print(numbers[1:3])
```

## 주의사항

`list.sort()`는 원본을 변경하고 반환값은 None이다.

# 자주 하는 실수

- 예제 코드를 그대로 복사하고 각 줄의 역할을 확인하지 않는 실수
- 입력값과 출력값의 자료형을 확인하지 않는 실수
- 한 번에 많은 코드를 작성해 오류가 발생한 위치를 찾기 어렵게 만드는 실수
- 브라우저 또는 콘솔에서 직접 결과를 확인하지 않는 실수

> [!WARNING]
> 오류가 발생하면 코드를 한꺼번에 바꾸지 않는다. 선택 결과, 변수값, 자료형, 조건식 결과를 `console.log()` 또는 출력문으로 하나씩 확인한다.
