## 1. 이 장에서 배울 것

문자열, JSON으로 표현한 문자열, Pydantic 객체를 구별한다. `.partial()`, `.bind()`, 파서, `with_structured_output()`의 책임을 추적한다.

<a id="concepts"></a>

## 2. 무엇이며, 왜 필요한가

LCEL은 프롬프트·모델·파서처럼 실행 가능한 단계(`Runnable`)를 `|`로 연결해 앞 단계의 출력을 다음 단계에 전달하는 표현이다. `StrOutputParser`는 텍스트를 꺼내고, `PydanticOutputParser`는 출력에 담긴 데이터를 지정한 모델로 해석하고 검증한다.

| 위치 | 수업 예제의 역할 |
| --- | --- |
| `prompt.partial(...)` | 프롬프트의 `format_instructions` 값을 미리 채움 |
| `model.bind(...)` | 모델 실행에 전달할 `response_format` 설정을 붙임 |
| `PydanticOutputParser(...)` | 실제 응답을 `Recipe` 필드와 타입에 맞춰 검사 |
| `model.with_structured_output(Recipe)` | 모델 연동에 스키마를 전달해 구조화된 출력을 요청 |

<a id="example"></a>

## 3. 작은 예제로 먼저 이해하기

**설명용 전체 예제.** [실행 파일](실습/책형_복습/02_출력파서와_구조화출력/example.py)을 해당 장의 Python 환경으로 실행한다. 모든 입력과 모델 대역은 복습용이며 외부 서비스에 요청하지 않는다.

```python
from langchain_core.messages import AIMessage
from langchain_core.output_parsers import PydanticOutputParser, StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableLambda
from pydantic import BaseModel


class Recipe(BaseModel):
    food: list[str]
    steps: list[str]


parser = PydanticOutputParser(pydantic_object=Recipe)
prompt = ChatPromptTemplate.from_messages([
    ('system', '{format_instructions}'), ('human', '{dish}'),
]).partial(format_instructions=parser.get_format_instructions())


def fixed_model(_prompt):
    return AIMessage(content='{"food":["계란"],"steps":["삶기"]}')


model = RunnableLambda(fixed_model)
value = (prompt | model | parser).invoke({'dish': '삶은 계란'})
print(type(value).__name__, value.food, value.steps)
text = (prompt | model | StrOutputParser()).invoke({'dish': '삶은 계란'})
print('문자열로 사용:', isinstance(text, str))
```

**실행 결과**

```text
Recipe ['계란'] ['삶기']
문자열로 사용: True
```

## 4. 내 폴더의 실제 코드 읽기

**원본 발췌 · D:/workspace/workspace_python/08_langgraph/router/langchain_router.py 286–318행**

```python
@router.get('/langchain/chain/pydantic')
def chain_pydantic(dish:str):

    output_parser = PydanticOutputParser(pydantic_object=Recipe)

    prompt = ChatPromptTemplate.from_messages([
        (
            'system',
            '너는 미슐랭 쉐프야. 나는 요리 초보고, 자취생이라 기구가 거의 없어'
            '내가 쉽고 빠르게 만들 수 있는 레시피를 알려줘'
            '{format_instructions}' # 필수는 아니자만, Pydantic의 형식을 미리 보여줌
        ),
        ('human', '{dish}')
    ]).partial( # .partial의 경우 이미 Pydantic을 가져가기 때문에 key값과 양식을 맞추어 줌
        format_instructions=output_parser.get_format_instructions()
    )

    model = ChatOpenAI(
        model='gpt-5.5',
        temperature=0,
        api_key=os.getenv("OPENAI_API_KEY")
    ).bind(
        # 출력 양식을 json으로 한다
        # .bind의 경우 json type으로 응답양식을 맞추지만 Pydantic과 무조건 key값이 일치한다고 보장할 수 없음 
        response_format={'type':'json_object'}
    )

    chain = prompt | model | output_parser

    result = chain.invoke({
        'dish' : dish
    })
    return result
```

**풀이:** JSON 객체 형식 요청을 모델에 붙여도 특정 키와 값 타입이 `Recipe`에 맞는지는 파서가 검사한다. `.partial()`은 포맷 안내 문자열을 템플릿에 고정한다.

<a id="connections"></a>

## 5. import·함수·입력·출력이 연결되는 흐름

`/langchain/output_parser`는 프롬프트 → 모델 → 파서를 각각 `invoke()`하고, `/langchain/chain/pydantic`은 한 체인으로 연결한다. `/langchain/chain/with_structured_output`은 모델에 `Recipe`를 지정하는 별도 실습이다. 마지막 방식의 지원 범위는 모델 통합에 따라 달라진다.

**원본 발췌 · D:/workspace/workspace_python/08_langgraph/router/langchain_router.py 338–342행**

```python
    chain = prompt | model.with_structured_output(Recipe)

    return chain.invoke({
        'dish' : dish
    })
```

<a id="review"></a>

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점.** 같은 레시피를 문자열과 `Recipe` 타입으로 각각 받아 다음 단계에서 쓰기 쉬운 형태를 비교할 수 있다.

**아쉬운 점.** 응답이 JSON 문법에 맞아도 필요한 필드가 빠질 수 있다. 파싱 오류와 모델 요청 오류를 구분해 처리하고, 재료·조리법이 사실인지 확인하려면 별도 근거가 필요하다.

<a id="results"></a>

## 8. 결과를 추적하고 한 가지 바꾸기

고정 응답에서 `steps` 키를 없애 실행해 본다. Pydantic 파서 단계에서 실패하는 이유를 적는다. 문자열 파서에 같은 응답을 직접 넘기면 문자열 출력 자체는 가능한지도 비교한다.
