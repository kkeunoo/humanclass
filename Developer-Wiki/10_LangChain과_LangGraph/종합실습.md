# 종합실습 영화 후보를 검색하고 설명하는 흐름

[단원 목차](README.md) · [실습 환경](실습/README.md)

## 1. 요구 사항

영화 ID를 받은 경우에만 후보를 만들고, 후보가 생기면 텍스트로 설명한다. 목록이 비면 후보 검색과 모델 단계를 건너뛰어 오류를 돌려준다. LangGraph 분기와 LCEL 체인이 연결되는 지점을 확인하는 실습이다.

## 2. 전체 파일과 실행

[example.py](실습/책형_복습/종합실습/example.py)를 수업 환경 Python으로 실행한다. `langgraph`와 `langchain-core`를 사용하고 후보와 설명 모델은 고정 대역으로 둔다.

```python
from typing import TypedDict

from langchain_core.messages import AIMessage
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableLambda
from langgraph.graph import END, START, StateGraph


class State(TypedDict, total=False):
    question: str
    movie_ids: list[int]
    recommends: list[str]
    explain: str
    error: str


def find_candidates(_state):
    return {'recommends': ['복습용 액션 영화']}


def validate(state):
    return 'find' if state.get('movie_ids') else 'error'


def fixed_model(prompt):
    assert '복습용 액션 영화' in prompt.to_messages()[-1].content
    return AIMessage(content='복습용 액션 영화를 추천합니다.')


prompt = ChatPromptTemplate.from_messages([('human', '{question} 후보: {recommends}')])
chain = prompt | RunnableLambda(fixed_model) | StrOutputParser()


def explain(state):
    return {'explain': chain.invoke(state)}


graph = StateGraph(State)
graph.add_node('find', find_candidates)
graph.add_node('explain', explain)
graph.add_node('error', lambda _state: {'error': '영화 ID가 필요합니다.'})
graph.add_conditional_edges(START, validate, {'find': 'find', 'error': 'error'})
graph.add_edge('find', 'explain')
graph.add_edge('explain', END)
graph.add_edge('error', END)

app = graph.compile()
for ids in ([10], []):
    final = app.invoke({'question': '비슷한 영화?', 'movie_ids': ids})
    print(final.get('explain') or final.get('error'))
```

## 3. 출력과 이유

```text
복습용 액션 영화를 추천합니다.
영화 ID가 필요합니다.
```

| 입력 | 검증 결과 | 실행 경로 | 최종 필드 |
| --- | --- | --- | --- |
| `[10]` | 통과 | `find → explain → END` | `recommends`, `explain` |
| `[]` | 오류 | `error → END` | `error` |

## 4. 원본에 대입해 보기

[수업 그래프](04_StateGraph와_조건분기.md)는 먼저 모델로 추천 방식을 선택하고 해당 방식의 필수 입력을 확인한다. 정상 경로에서는 [후보 정리](05_추천노드와_최종상태.md) 후 설명을 만든다. 이 실습은 입력 검사와 후보 전달을 따로 확인하려고 한 종류의 추천만 사용한다.

1. 후보를 두 개로 늘리고 설명 노드에 어떤 목록이 들어오는지 출력한다.
2. 빈 후보를 받으면 설명 대신 별도 안내가 나오도록 조건을 구상한다.
3. 검증 출력과 추천 설명의 출처를 각각 어떤 필드에 기록할지 적는다.

<details>
<summary>풀이 방향</summary>

1. `find_candidates`의 목록을 늘리면 그 값이 최종 상태와 프롬프트 입력에 남는다.
2. `find` 다음의 조건 간선에서 `recommends`가 비었는지 검사한다. 오류 메시지는 영화 ID 누락과 후보 없음이 구별되게 작성한다.
3. 후보는 ID·검색 근거·점수 출처를 담고, 설명과 오류는 별도 필드에 둔다.
