# 실무 코딩스타일 입력과 출력 계약을 분리하기 연습문제

[본문](../../실무_코딩스타일.md) · [문제 목록](README.md)

본문의 실행 파일로 예상과 실제를 비교한다. 먼저 아래 질문에 답하고 8절의 한 가지 변경을 실행해 본다.

1. `RecommendType`과 `State`를 구분한 이유는?
2. 모르는 입력 필드를 검사하면 어떤 오류를 조기에 발견하는가?

<details>
<summary>풀이와 확인 기준</summary>

1. 전자는 분류 결과, 후자는 추천 실행에 필요한 전체 진행 상태를 표현한다.
2. 예제의 `recommedns`처럼 선언과 일치하지 않는 입력 키를 발견한다.
