# 영화 추천 결과를 설명하는 체인 연습문제

[본문](../../03_영화추천결과_설명체인.md) · [문제 목록](README.md)

본문의 실행 파일로 예상과 실제를 비교한다. 먼저 아래 질문에 답하고 8절의 한 가지 변경을 실행해 본다.

1. 제목과 점수만 모델에 전달했을 때 줄거리는 어디서 검증하는가?
2. `provider`를 바꾸면 추천 점수 계산도 바뀌는가?

<details>
<summary>풀이와 확인 기준</summary>

1. 현재 전달 자료에는 줄거리 근거가 없다. 별도 자료를 검색해 출처를 함께 주거나 확인 불가로 표시한다.
2. 현재 분기는 설명 모델 선택에 사용한다. 후보는 `es_router.hybrid()`가 준비한다.

</details>
