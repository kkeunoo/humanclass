# 모델 호출과 대화 메시지 연습문제

[본문](../../01_모델호출과_메시지.md) · [문제 목록](README.md)

본문의 실행 파일로 예상과 실제를 비교한다. 먼저 아래 질문에 답하고 8절의 한 가지 변경을 실행해 본다.

1. 이 예제가 모델에 요청을 보냈는지 설명한다.
2. 고정된 `history`와 이전 요청에서 실제로 저장한 대화의 차이를 말한다.

<details>
<summary>풀이와 확인 기준</summary>

1. 템플릿의 변수에 값을 채워 메시지 세 개를 출력한다. 모델 객체를 만들거나 호출하는 줄이 없다.
2. 고정 이력은 모든 요청에 같은 자료가 들어가며, 실제 이력은 사용자 또는 세션별로 저장과 조회가 필요하다.

</details>
