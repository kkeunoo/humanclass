# 출력 파서와 구조화 출력 연습문제

[본문](../../02_출력파서와_구조화출력.md) · [문제 목록](README.md)

본문의 실행 파일로 예상과 실제를 비교한다. 먼저 아래 질문에 답하고 8절의 한 가지 변경을 실행해 본다.

1. `.partial()`에 포맷 지시를 넣었는데 `steps`가 빠질 수 있는 이유는?
2. 텍스트 파서의 반환을 즉시 `Recipe`처럼 사용할 수 있는가?

<details>
<summary>풀이와 확인 기준</summary>

1. `.partial()`은 요청에 포함할 프롬프트 변수만 채운다. 응답의 실제 필드와 타입 검증은 Pydantic 파서가 수행한다.
2. 예제에서 텍스트 파서는 `str`을 돌려준다. 필드 접근이 필요하면 스키마에 맞게 해석하고 검사한다.

</details>
