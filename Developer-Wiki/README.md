## 👋 About

Developer-Wiki는 학습 과정에서 작성한 코드와 분석 내용을 체계적으로 보관하는 개인 개발 문서 저장소입니다.

단순히 문법을 요약하는 데서 끝나지 않고, **직접 작성한 코드와 강사 코드를 비교하여 차이를 확인하고 개선점을 기록하는 과정**을 중심으로 구성했습니다. 각 문서는 핵심 개념, 대표 예제, 실무 활용, 자주 하는 실수, 복습 문제와 정답까지 하나의 흐름으로 연결됩니다.

> **Learning Flow**  
> 학습 → 실습 → 비교 → 개선 → 복습 → 기록

## ✨ Documentation Features

| Feature | Description |
|:--|:--|
| 🧪 **Practice Based** | 실제 수업 및 실습 코드에 기반한 문서 |

## 📖 Standard Document Structure

모든 학습 문서는 다음 구조를 기준으로 작성합니다.

```text
01. Document Information
02. Learning Objectives
03. Core Concepts
04. Syntax / Comparison
05. Representative Examples
06. Practical Usage
07. My Code vs Teacher Code
08. Improvements
09. Common Mistakes
10. Interview / Review
11. Problems
12. Answers
13. Final Checklist
14. Key Summary
```

동일한 구조를 유지하여 새로운 기술이 추가되더라도 일관된 방식으로 학습하고 복습할 수 있도록 설계했습니다.

## 📌 Repository Policy

- 실제 학습 자료와 코드에 기반하여 작성합니다.
- 원본 코드의 실수나 차이를 임의로 숨기지 않습니다.
- 내 코드와 강사 코드의 차이를 명확히 구분합니다.
- 개선 제안은 원본 내용과 분리하여 기록합니다.
- 문서명, 번호, Markdown 형식을 일관되게 관리합니다.
- 학습이 진행될 때마다 README와 진행 현황을 함께 갱신합니다.

## 🎯 Goal

Developer-Wiki의 목표는 많은 문서를 만드는 것이 아니라, 학습한 내용을 **설명할 수 있는 지식**으로 바꾸는 것입니다.

```text
Learn    → 개념을 이해합니다.
Compare  → 다른 코드와 차이를 확인합니다.
Improve  → 더 안전하고 명확한 방향을 찾습니다.
Archive  → 다시 사용할 수 있는 지식으로 남깁니다.
```
