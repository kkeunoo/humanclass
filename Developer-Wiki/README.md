# 📖 About

Developer-Wiki는 단순한 강의 노트가 아닌 **실습 중심의 학습 기록 저장소**입니다.

각 문서는 다음과 같은 공통 구조를 유지합니다.

- 문서 정보
- 학습 목표
- Core Concepts
- 문법 및 비교
- 대표 예제
- 실무 활용
- My Code vs Teacher Code
- Improvements
- Common Mistakes
- Interview / Review
- Problems
- Answers
- Final Checklist
- Key Summary
