# Developer-Wiki

국비 교육에서 작성한 코드를 **처음 배우는 사람도, 시간이 지난 뒤의 나도 다시 이해할 수 있도록** 정리한 학습 Wiki다. 강사님 코드와 내 코드를 비교하고, 실제로 배운 내용부터 읽는다. 기존 Wiki에 설명이 있더라도 양쪽 수업 코드나 사용자 확인으로 학습 여부를 확인할 수 없으면 **추가로 알면 좋은 것**으로 분리했다.

## 한 장을 읽는 방법

1. 장 첫머리의 **개념과 작은 예시·결과**로 이번 장이 무엇을 하는지 먼저 잡는다. 이 예시는 원본 실행 결과가 아니라 새로 만든 설명일 수 있으므로 표시를 확인한다.
2. 출처를 확인하고 **강사님 원본 → 내 원본** 순서로 읽는다. 같은 입력을 넣었을 때의 결과와 실제 차이를 예상해 본다.
3. 설명에서 **실제 코드 동작과 주석의 차이**를 확인한다. 오류가 있는 내 코드도 학습 기록으로 남겼고, 더 읽기 쉬운 강사님 방식이 있으면 이유를 적었다.
4. 같은 본문 하단의 **추가로 알면 좋은 것**은 배운 내용과 구분해 읽는다. 이어서 **그 장의 연습문제**를 풀고 접힌 정답을 확인한다. 실제 수업 퀴즈는 `실습-OOO` 본문에서 강사님 문제와 내 풀이를 비교한다.
5. 장별 문제를 마친 뒤 과목의 **종합실습 → 실무 코딩스타일**로 이어 읽는다. 헷갈린 개념은 해당 장의 원본 비교로 돌아가 확인한다.

00~09 모든 과목에 `실습/연습문제` 목차와 장별 문제를 마련했다. 총 **127개**이며 수업 원본 문제가 아닌 **새로 구성한 복습**이다. 00~03에는 브라우저 또는 Python으로 확인하는 작은 복습 파일도 있다. 원본 문제·내 당시 풀이와 새 예제의 출처를 섞지 않는다.

코드 울타리의 **원본 발췌**는 표시한 파일·행의 정확한 조각이다. 앞뒤 선언과 실행 환경이 생략될 수 있으므로 조각 하나가 독립 실행 예제라는 뜻은 아니다. 00–06의 기존 원본은 제공된 `workspace_teacher.zip`, `workspace_me.zip`에 보존되어 있고, 07 이후 새 단원은 현재 `D:\workspace_teacher`, `D:\workspace`의 실제 파일을 기준으로 한다. Wiki의 설명은 수업 파일, 사용자 확인, 그리고 코드의 실제 동작을 기준으로 한다.

표시가 **개인 학습 메모**이면 첨부 노트에서 가져온 실행 준비나 관찰이며 양쪽 코드의 원본 발췌가 아니다. **재구성한 예제**는 배운 내용을 설명하기 위해 새로 쓴 코드다. **추가로 알면 좋은 것**은 확인된 수업 본문 밖의 보충 내용이고, **이후 첨부**는 현재 자료만으로 강사님 코드와 비교하거나 학습 범위를 확정할 수 없어 보류한 항목이다. [첨부 메모 반영·보류 기록](편집기록/99_첨부메모_반영_및_이후첨부.md)에서 메모별 판단을 볼 수 있다.

## 과목 사이에서 값이 이동하는 길

HTML 폼의 `name`으로 입력값을 만들고 → JavaScript가 DOM에서 값을 읽거나 요청을 보내고 → FastAPI가 경로·쿼리·폼·모델로 입력을 받아 Python에서 처리하고 → SQL이 DB의 행을 읽거나 바꾼다. 서버는 결과를 JSON 또는 Jinja HTML로 반환할 수 있다. CSS는 이 화면의 표시와 배치를 담당한다. [HTML 폼](01_HTML/07_HTML_폼과_입력요소.md) → [JavaScript 폼](03_JavaScript/13_JavaScript_DOM_폼요소와_입력값처리.md) → [FastAPI 입력값](06_FastAPI/02_FastAPI_Router_Request_Pydantic_CRUD.md) → [SQL 조회](05_SQL/01_SQL_기초와_SELECT.md)을 따라가면 한 값의 출발과 도착을 비교할 수 있다.

## 학습 범위의 경계

FastAPI의 `request.headers` 직접 읽기와 `response_model`은 사용자가 **배우지 않았음**을 확인했다. [FastAPI 추가편](06_FastAPI/추가편_기존자료_학습범위_분류.md)에만 둔다. JavaScript `dataset`은 **배운 내용**이므로 본문에 있다. Python 이터레이터·제너레이터·정규표현식은 개념·간단한 사용 범위로 정리하고 상세 구현은 [Python 추가편](04_Python/추가편_기존자료_학습범위_분류.md)과 구분했다. `0716_exam2_vibe`, `0716_exam3_vibe`, `03_database/00_CSS`는 사용자 요청에 따라 학습 근거에서 제외했다.

각 과목의 README에서 본문과 새 실습, 추가 학습의 위치를 볼 수 있다. 00~02에서 별도 폴더에 있던 보충 설명은 **관련 본문 하단**으로 옮겼다. 03~06의 `추가편_기존자료_학습범위_분류.md`는 옛 Wiki·BACKUP의 범위 판단을 남기는 색인이며 새 필수 진도가 아니다. 00~09의 재학습용 개편과 검증 범위는 [편집기록](편집기록/README.md)에 정리했다. 실제 외부 서비스, MariaDB, 업로드 서버 전체를 실행해서 결과를 보장한 문서는 아니며, 코드 인용과 정적 검증·대표 로컬 화면 확인을 구분해서 기록했다.
