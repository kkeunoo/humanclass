# Developer-Wiki

수업을 잊었을 때 **다시 이해하고 직접 작성할 수 있는 개인 강의 백과사전**이다. 숙련자용 키워드 요약이나 화면만 정돈한 문서가 아니라, 내 코드·강사님 코드·실제 입력·처리·상태·결과·실패를 연결한다.

## 어디서 시작할까?

- 뜻이나 사용 위치가 기억나지 않으면 [통합 용어색인](99_Developer-Wiki_통합_용어색인.md)에서 영어·한글·약어·함수 이름을 찾는다.

- 처음 복습할 때는 아래 과목 README→읽기법→주제 본문→문제→정답 순서로 진행한다.
- 이번 통합판의 수정 사항과 검증 한계는 [전체 검토기록](98_Developer-Wiki_전체_검토기록.md)에서 확인한다.

## 학습 흐름과 파트별 역할

| 순서 | 배워야 하는 이유·핵심 흐름 |
| --- | --- |
| 메모리와 참조 | Stack·Heap을 한 파일에서 이해하고 객체 변경·재할당·복사를 추적한다. |
| HTML | 태그·DOM·화면·Form 요청을 구분한다. |
| CSS | 선택 대상·속성 기준·크기 계산·배치·상호작용을 추적한다. |
| JavaScript | 상태·DOM·이벤트·비동기 통신을 입력과 결과로 연결한다. |
| Python | 자료형·함수·객체·파일·예외·반복 프로토콜을 다시 구현한다. |
| SQL · MariaDB | 조회 중간 결과·제약·변경·transaction·실행 계획을 확인한다. |

HTML에서 입력 요소를 만들고 → CSS로 배치하고 → JavaScript가 값을 읽어 요청을 보내고 → Python/FastAPI가 검증·처리하고 → SQL/DB가 저장·조회하고 → JSON 또는 HTML로 응답한다. 각 과목의 같은 단어도 실행 주체와 객체가 다를 수 있다.

## 개인 강의 백과사전의 기준

1. **무엇인가·왜 배우는가**를 먼저 설명하고 목표는 짧게 둔다.
2. 입력이 주소창·Form·JSON·파일·함수 인자·DB 중 어디서 만들어지는지 밝힌다.
3. 실행 주체와 처리 순서, 변환되는 타입·상태·객체 관계를 설명한다.
4. 예제의 출력·응답·화면·DB 결과와 실패 결과를 구분한다.
5. 내 코드와 강사님 코드의 해당 부분만 발췌하고 실제 차이를 설명한다.
6. 원본 오류를 감추지 않고 원본 실험과 개선 예제를 구분한다.
7. 수업에 없는 유용한 내용은 💡 또는 보강 표기로 표시한다.
8. 이해를 위한 반복 설명·여러 예제·연습량·정답 해설은 형식 정리 때문에 줄이지 않는다.

## 문서를 읽는 방법

기존 번호형 분류와 상세 본문을 유지했다. 앞부분 보강 설명은 개념에서 실제 실행까지 이어지는 길잡이이고, 상세 목차는 특정 함수·속성·문법을 빠르게 찾는 장치다. 메모리와 참조는 한 파일에 통합하고 HTML·CSS 등은 실제 분야별 분류를 유지한다.

코드가 '부분 조각'이면 선언·imports·app·저장소가 생략될 수 있다. '독립 예제'는 별도 연습 파일에 저장해 실행한다. 설명용 샘플과 실제 수업 데이터·실행 검증 결과를 혼동하지 않는다. UUID·임시 포트·객체 주소 등은 매번 달라질 수 있다.

| 과목 | 관찰해야 할 결과 |
| --- | --- |
| HTML | HTML 문자열·DOM·화면·Form 전송 항목·Network |
| CSS | 선택된 요소·Styles·Computed·박스 크기·레이아웃·입력 가능 여부 |
| JavaScript | Console·함수 호출·상태·DOM·이벤트 순서·HTTP 상태 |
| Python | print·return·자료형·참조 관계·파일·Traceback |
| SQL | 중간 결과·행 수·NULL·제약·commit/rollback·EXPLAIN |
| FastAPI | URL·method·Header·Body·검증·터미널·저장 상태·응답 |

## 용어를 찾고 연결하는 방법

[통합 용어색인](99_Developer-Wiki_통합_용어색인.md)은 대표 개념 225개와 문서 제목에서 추출한 코드 이름 548개를 제공한다. 두 범주에는 중복이 있어 고유 개념 773개로 합산하지 않는다. 뜻→설명 위치→다른 적용으로 이동한다. 예를 들어 DB Session과 서명 Cookie Session, 타입 힌트와 response_model, CORS와 인증을 별개로 이해한다.

JavaScript·Python의 99 치트시트는 자료형별 메서드 복습용이다. 통합 색인은 과목을 넘나드는 개념과 실제 설명 위치를 찾는 역할이므로 대체하지 않는다.

## 검증과 관리 원칙

- 문서 링크·목차 anchor·코드블록·details·제목·인코딩·문서 수를 실제 파일과 맞춘다.
- 승인된 코드·출력 블록을 유지하며 안전한 순수 예제와 격리 테스트를 이용한다.
- 실제 브라우저 검증, ASGI 응답 검사, DB 샘플 검사, 정적 검토를 같은 검증으로 부르지 않는다.
- API Key·DB Password·Session 비밀 키·Webhook 주소를 공개 문서에 복사하지 않는다.
- 자동 생성 venv·cache·DB 임시 파일은 수업 앱 코드와 구분한다.
- 문서 추가 시 해당 파트 README·이 README·workspace README·색인을 함께 갱신한다.
- 제목·파일명을 바꿀 때 기존 anchor 호환 또는 링크 수정 여부를 확인한다.
