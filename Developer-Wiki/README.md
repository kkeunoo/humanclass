## 문서 학습 구조

```text
학습 목표 → 왜 배우는가 → 기본 개념 → 수업 예제
→ 수업 문제 → 직접 풀어 보기 → 해설 보기
→ 자주 하는 실수 → 실무 연결 → 📌 더 알아보기
→ 직접 해보기 → Check Point → 최종 요약 → 복습 기록
```

## 학습 원칙

- 기본 본문과 기본 풀이는 해당 시점까지 배운 개념만 사용합니다.
- 이후에 배우는 API와 짧은 문법은 `📌 더 알아보기`에 분리합니다.
- 코드를 복사하는 데서 끝내지 않고 직접 입력하고 값을 바꾸어 결과를 확인합니다.
- README와 각 문서의 이전·다음 링크를 따라 순서대로 학습합니다.
