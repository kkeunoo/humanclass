## 📌 Wiki Policy

- 학습 순서는 `01_HTML → 02_CSS → 03_JavaScript → 04_Python`을 유지합니다.
- 각 Subject의 `README.md`를 해당 영역의 목차와 학습 가이드로 사용합니다.
- 상세 문서는 실제 수업·실습 내용을 기준으로 작성합니다.
- 비교 대상이 없으면 임의의 비교 내용을 만들지 않습니다.
- 원본의 오류와 실무 개선 사항을 구분합니다.
- Subject README의 Section 순서와 Navigation 형식을 동일하게 유지합니다.
- 모든 내부 Link는 GitHub 상대 경로를 사용합니다.
- 문서 추가·삭제 시 Current Progress의 문서 수를 실제 파일 기준으로 갱신합니다.
