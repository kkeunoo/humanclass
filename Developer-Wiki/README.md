# Developer-Wiki — 나만의 국비교육 교재

국비교육에서 실제로 배운 코드로 시작해 **처음 보는 사람도 이해하고, 시간이 지난 뒤에도 다시 배울 수 있는 책**을 만든다. 개념·용어·작은 전체 예제·실행 결과를 먼저 이해한 뒤 내 코드의 동작과 개선 방향을 읽는다. 강사님 코드는 도움이 되는 차이에만 인용한다.

## 2. 모든 본문의 공통 읽기 흐름

| 절 | 읽을 내용 | 직접 해 볼 것 |
| --- | --- | --- |
|1 | 학습 목표 | 끝나면 설명할 질문을 확인 |
|2 | 무엇이며 왜 필요한가 | 용어·비슷한 개념을 구별 |
|3 | 작은 전체 예제와 결과 | 먼저 예상하고 실행 조건 확인 |
|4 | 실제 내 코드와 바로 풀이 | 값·문장·주석을 한 줄씩 연결 |
|5 | 파일·import·함수·다음 단계 | 정의→입력→반환→사용처 추적 |
|6 | 잘한 점·한계·개선 | 원본 오류·수업용 단순화·설계 선택 구별 |
|7 | 필요한 강사님 비교 | 실제 유익한 차이만 확인 |
|8 | 결과 추적·한 가지 변경·오류 | 표·실험으로 이유 설명 |
|9 | 출처·추가로 알면 좋은 것 | 배운 의미와 수업 밖 확장 구별 |
|10 | 복습·접힌 풀이·빠른 정리 | 자신의 말로 다시 설명 |

안내·기존 주소 연결 문서·문제·종합실습·색인은 역할에 맞는 구조다. 같은 내용을 형식에 맞추려고 반복하지 않는다. 실습의 기본 이동은 **본문 → 장별 문제 → 실제 퀴즈가 있으면 비교 → 실무 스타일 → 종합실습**이다.

## 3. 코드와 설명의 출처를 구별하기

| 표시 | 의미 |
| --- | --- |
|원본 발췌·파일·행 범위 | 실제 수업 소스의 조각·독립 실행 파일이라는 뜻은 아님 |
|새 설명 예제·전체 파일 | 배운 개념을 이해하도록 새로 구성·필요한 정의와 입력 제공 |
|개선안 | 원본에 적용하지 않은 제안·원본 코드와 구별 |
|개인 학습 메모 | 첨부 노트의 관찰·실행 준비·코드 원본과 다름 |
|📚 출처 | 외부 문서로 확인한 의미·원문과 자체 풀이 구별 |
|💡 추가로 알면 좋은 것 | 확인된 수업 범위 밖·관련 본문 하단에서 읽기 |
|이후 첨부 | 현재 소스·메모·학습 확인이 부족해 보류 |

09의 `recall_at_k` 이후는 놓친 수업의 강사님 코드를 옮겼다는 사용자 확인을 반영했다. 시작 경계는 사용자 추정이며 학생 직접 작성 성과로 평가하지 않는다. 09는 작업 중 변경을 감지해 2026-10-30 확보한 양쪽 사본을 기준으로 인용·검수했다.

## 4. 실습과 스스로 점검하기

모든 과목에 `실습/연습문제` 목차·스타일·종합실습이 있다. 새 문제는 총 **144개**다. 수업에서 강사님이 낸 문제와 당시 내 풀이는 기존 `실습-OOO` 경로를 유지한다. 새 문제·가상 자료를 실제 제출물처럼 표시하지 않는다.

먼저 예상 → 이유 설명 → 한 가지 변경 순서로 풀고 접힌 풀이를 확인한다. 실행할 때는 각 장의 폴더·전체 파일·입력·패키지를 먼저 본다. 출력·반환값·HTTP 상태·DB 확정·파일 저장·다음 요청·시험 점수는 서로 다른 결과다. 숫자가 맞아도 이유를 설명할 수 없다면 개념과 추적표로 돌아간다.

## 5. 과목 사이의 연결

HTML 폼의 name → JavaScript의 입력값·이벤트 → FastAPI의 요청 인자 → Python 함수 → SQL의 행 → JSON·Jinja 화면으로 이어진다. CSS는 화면 배치를 담당한다. [HTML 폼](01_HTML/07_HTML_폼과_입력요소.md) → [JS 입력값](03_JavaScript/13_JavaScript_DOM_폼요소와_입력값처리.md) → [FastAPI 입력](06_FastAPI/02_FastAPI_Router_Request_Pydantic_CRUD.md) → [SQL 조회](05_SQL/01_SQL_기초와_SELECT.md)를 따라 한 값의 길을 복습한다.

데이터 단원은 CSV의 표→입력·정답→모델 평가로, 검색 단원은 문서→청크·벡터→검색 결과→답변 문맥으로 이어진다. 영화 단원은 내용 특징과 평점 기반 추천을 나누고 Recall의 분자·분모까지 읽는다.

## 6. 실제 학습 범위와 검증

dataset은 배운 내용이다. request.headers 직접 읽기·response_model은 미학습 확인에 따라 TIP이다. 이터레이터·제너레이터·정규식은 개념·간단 사용을 넘어 상세 구현을 배웠다고 넓히지 않는다. 바이브코딩 시험 두 개와 개인 database/CSS는 근거에서 제외했다. 가상환경 자동 생성물은 제외하되 그 폴더 안에 작성한 실습 소스는 포함했다.

작은 실제 실행·브라우저·ASGI 요청·SQLite 교차 검증·고정 대역·정적 검사는 범위를 구별했다. 실제 MariaDB 서버와 외부 검색·AI 서비스 전체의 성공을 보장하는 책은 아니다. 확인한 결과와 원본 주석·가상 예상은 각 장에서 표시한다. [책형 검증·진행 기록](편집기록/책형_개편_진행기록.md)과 [첨부 메모 대응](편집기록/99_첨부메모_반영_및_이후첨부.md)을 참고한다.
