# 05 RAG 질문응답 — 연습문제

[원본 비교 본문](../../05_RAG_질문응답.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. `ask_rag(question)`에서 질문은 먼저 어느 함수로 들어가며, 검색 결과는 어느 변수에 문자열로 모이는가?
2. 강사님과 내 `ask_gemini`는 이름은 같은데 실제 외부 호출은 각각 무엇인가? 응답 문자열을 꺼내는 속성도 비교한다.
3. 프롬프트에 ‘문맥에 없는 내용은 답하지 말라’고 쓰면 모델의 답이 자동으로 검증되는가? 03장의 저장된 `content`를 왜 함께 확인해야 하는가?

<details>
<summary>정답과 확인할 점</summary>

1. `hybrid(question)`으로 검색하고, 결과마다 만든 문자열을 `contexts` 목록에 넣은 뒤 `context`로 합친다.
2. 강사님은 `gemini.models.generate_content`의 `response.text`, 나는 `gpt.responses.create`의 `response.output_text`를 사용한다. 함수 이름만으로 서비스를 판단하지 않는다.
3. 아니다. 원본에는 답변의 사실성을 자동 검증하는 단계가 없다. 청크 임베딩을 만들었어도 `_source['content']`가 원래 전체 본문일 수 있어 문맥 내용도 점검해야 한다.

입력→처리→결과의 실제 원본 사례는 [본문](../../05_RAG_질문응답.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

> 💡 **TIP · 수업 범위 밖:** 답변에 출처를 함께 보여 주고 검색 결과가 없으면 답변을 중단하는 설계는 다음 단계에서 배울 주제다. 원본에 이미 구현됐다고 읽지 않는다.
