# 02 검색과 CRUD — 연습문제

[원본 비교 본문](../../02_검색과_CRUD.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. 양쪽 `term` 함수가 **실제로** 찾는 필드는 `category`인가 `content`인가? 주석의 SQL `LIKE` 비유를 그대로 써도 되는가?
2. `range`의 `gte=min`, `lte=max`에서 경계값은 포함되는가?
3. 두 코드가 `results` 목록을 만든 다음 각각 무엇을 반환하는가? 호출자가 간단한 문서 목록을 받기에는 어느 코드가 더 일관적인가?
4. `document.get(id, -1)`과 `document.get('id', -1)`은 왜 다른가? ID를 전달하지 않으면 내 코드에서도 어떤 문제가 남는가?

<details>
<summary>정답과 확인할 점</summary>

1. 실행 대상은 `content`다. `category` 줄은 주석이다. `term`은 부분 문자열을 찾는 SQL `LIKE`와 다르다.
2. 둘 다 포함한다. 가격은 `min` 이상, `max` 이하다.
3. 강사님은 원본 `response`, 나는 만든 `results` 목록을 반환한다. 간단한 문서 목록을 제공한다는 코드 흐름에는 내 반환값이 더 일관적이다.
4. 첫 `id`는 문자열이 아니라 Python의 내장 함수 이름이고, 둘째는 딕셔너리의 `'id'` 키다. 내 코드도 키가 없으면 `-1`을 쓰므로 여러 누락 문서가 같은 ID를 사용할 수 있다.

</details>
