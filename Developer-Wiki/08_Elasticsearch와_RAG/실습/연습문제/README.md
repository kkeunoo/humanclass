## 3. 풀기와 채점

출력을 가리고 예상한 뒤 이유와 한 가지 변경을 적는다. 고정 응답을 실제 서비스 결과처럼 설명하지 않았는지도 채점한다. 입력·함수 정의·반환·다음 단계가 이어져야 한다. TIP은 기본 정답 조건이 아니다. [종합실습](../../종합실습.md)에서 단계들을 연결한다.
