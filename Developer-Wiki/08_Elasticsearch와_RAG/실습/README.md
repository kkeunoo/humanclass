## 2. 실행

각 장의 폴더에서 `python example.py`를 실행한다. 새 예제는 표준 라이브러리만 필요하며 Elasticsearch·AI SDK를 설치하거나 외부 키를 요구하지 않는다. 원본의 실제 호출을 재현하는 별도 실습을 했다면 이 예제의 출력과 구별해 기록해야 한다.

## 3. 검증 범위

파일 읽기·dict 참조·청크·고정 응답 가공·순위 합산·prompt 전달을 확인한다. 원본 함수 검사에서는 외부 객체를 호출 기록 대역으로 바꿨다. 실제 서버 접속·적재·서비스 지원·과금·검색 품질·답변 정확도는 이 검사로 입증하지 않는다. D 드라이브와 사용자 브라우저를 수정·제어하지 않는다.
