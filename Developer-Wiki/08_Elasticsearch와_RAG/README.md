# Elasticsearch 검색에서 RAG 질문응답까지

[Developer-Wiki 첫 화면](../README.md) · [FastAPI 목차](../06_FastAPI/README.md)

강사님과 내 `workspace_python/07_elastic`의 실제 Python 파일을 비교한다. **검색용 인덱스·문서 적재 → 검색과 수정 → 텍스트 청크·임베딩 → 하이브리드 검색 → 검색 결과로 질문에 답하기** 순서다. 이 단원에서 `text` 필드의 단어 분석과 `dense_vector` 필드의 임베딩은 서로 다른 기능이다. 원본 주석에서 둘을 섞은 부분은 실행 코드 기준으로 바로잡는다.

각 장은 **개념과 작은 예시 → 강사님 원본 → 내 원본 → 실제 처리와 차이 → 연습문제**로 읽는다. 예시 문서와 순위는 이해를 위해 새로 만든 것이고, 발췌는 함수 일부여서 단독 실행 예제가 아니다. 외부 Elasticsearch·AI 서비스에 연결해 응답을 재현하지 않았다. `.env`와 접속키는 학습 설명과 공개 발췌에서 제외했다. `run.py`는 파일 끝에서 적재 함수를 바로 호출하므로 이 Wiki를 검증하려고 실행하지 않았다. 내 `es_router_copy.py`는 주석 처리된 복사 초안이어서 본문 근거에서 제외했다.
