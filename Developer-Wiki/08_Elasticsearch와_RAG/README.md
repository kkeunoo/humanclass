## 2. 실제 수업과 자료 구분

workspace_python/07_elastic의 api·util·라우터·현재 활성 함수를 기준으로 한다. config의 접속키 값·.env는 공개 자료에 옮기지 않는다. run.py의 파일 끝 즉시 적재 호출은 읽기 검사로 실행하지 않는다. es_router_copy.py는 주석 초안으로 본문 근거에서 제외한다. BACKUP의 설명 방식은 참고하되 거기에만 있는 기능을 수업에 포함하지 않는다.

원본은 출처·행 범위로 보존하고 바로 풀이를 붙였다. 같은 코드는 강사님 인용을 줄였으며 실제로 유익한 반환·ID 키·사용 서비스의 차이만 비교했다. 새 복사본·입력 검사·빈 결과 처리·ID 보존은 개선안으로 구분한다.

## 4. 실제로 확인한 범위

새 예제는 Python만으로 독립 실행한다. 미리 정한 응답·순위·벡터·답변은 대역이며 실제 검색·임베딩·AI 추론 결과가 아니다. 원본 함수는 정의만 추출해 외부 호출을 기록 대역으로 바꾸어 인자·반환·참조를 검사했다. 서버 연결·권한·실제 매핑·적재·검색 품질·응답 모델의 사실성은 검증하지 않았다.

text의 단어 분석과 dense_vector의 임베딩, 청크와 저장 content, k·후보·반환 수, 답변 규칙과 자동 검증을 구별한다. [다음: 영화 CSV](../09_영화CSV_청크와_임베딩/README.md)에서는 다른 입력 파일로 이어 간다.
