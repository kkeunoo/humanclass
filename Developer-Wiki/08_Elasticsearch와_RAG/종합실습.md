# 검색·RAG 종합실습 — 자료 준비부터 답변 입력까지 로컬에서 추적하기

[단원 목차](README.md) · [문제 목록](실습/연습문제/README.md)

## 1. 목적과 출발점

수업의 문서·청크·작업·순위·문맥 구성을 연결하는 새 실습이다. 실제 검색 서버나 AI 모델을 로컬로 구현한 프로젝트가 아니다. 외부 경계에는 고정값을 사용해 **어떤 자료가 어떤 함수로 전달되는지** 집중해서 확인한다.

## 2. 요구사항과 준비

Python과 아래 네 파일만 필요하다. 같은 폴더에 저장하고 `python example.py`를 실행한다. 사용자 함수의 전체 정의를 모두 제공했다. 두 문서의 청크 ID·독립 본문·고정 벡터를 만들고, 미리 정한 두 검색 목록을 순위로 합친다. 그 결과가 질문과 함께 prompt에 들어가는지 확인한다.

고정 벡터는 2차원 설명 값으로 의미 임베딩이 아니다. text_hits와 vector_hits는 실제 검색 결과가 아니라 준비한 순위다. fixed_generate의 답도 미리 정한 문장이다. 이 세 경계를 실제 서비스의 성공 결과로 설명하면 과제의 목표와 다르다.

## 3. 구현 순서

1. 문서 두 건을 각 청크의 작업 목록으로 만든다.
2. _id와 _source를 고정 hit 목록으로 연결한다.
3. 문자 순위·벡터 순위를 주고 fuse로 합친다.
4. 합친 document를 build_context가 문자열로 묶는다.
5. 질문·문맥을 생성 대역에 전달하고 보낸 문자열을 검사한다.

**[chunk_tools.py](실습/책형_복습/종합실습/chunk_tools.py) — 새 전체 파일**

```python
import re


def split_text(text, chunk_size=30, overlap_size=6):
    sentences = re.split(r'(?<=[.!?])\s+', text.strip())
    sentences = [s.strip() for s in sentences if s.strip()]
    chunks = []
    temp = ''
    for sentence in sentences:
        candidate = f'{temp} {sentence}' if temp else sentence
        if len(candidate) <= chunk_size:
            temp = candidate
        else:
            if temp:
                chunks.append(temp)
            temp = sentence
    if temp:
        chunks.append(temp)
    overlap_chunks = []
    for index, chunk in enumerate(chunks):
        if index == 0:
            overlap_chunks.append(chunk)
        else:
            prefix = chunks[index - 1][-overlap_size:] if overlap_size > 0 else ''
            overlap_chunks.append(f'{prefix} {chunk}'.strip())
    return overlap_chunks


def build_actions(doc, embed):
    actions = []
    for index, chunk in enumerate(split_text(doc['content'])):
        vector = embed(doc['title'], chunk)
        source = {**doc, 'content': chunk, 'chunk_index': index, 'embedding': vector}
        actions.append({'_index': 'computer_chunk', '_id': f'{doc["id"]}-{index}', '_source': source})
    return actions
```

**[rank_tools.py](실습/책형_복습/종합실습/rank_tools.py) — 새 전체 파일**

```python
def fuse(text_hits, vector_hits, rank_constant=60, size=10):
    scores = {}
    for hits in [text_hits, vector_hits]:
        for rank, hit in enumerate(hits, start=1):
            doc_id = hit['_id']
            if doc_id not in scores:
                scores[doc_id] = {'score': 0.0, 'source': hit['_source']}
            scores[doc_id]['score'] += 1 / (rank_constant + rank)
    ordered = sorted(scores.items(), key=lambda item: item[1]['score'], reverse=True)
    results = []
    for doc_id, data in ordered[:size]:
        results.append({'id': doc_id, 'document': data['source'], 'score': data['score']})
    return {'results': results, 'total': len(scores)}
```

**[rag_tools.py](실습/책형_복습/종합실습/rag_tools.py) — 새 전체 파일**

```python
def build_context(results):
    contexts = []
    for index, result in enumerate(results):
        doc = result['document']
        contexts.append(
            f"[검색 결과 {index}] 문서ID={doc['id']} 청크={doc['chunk_index']}\n"
            f"제목={doc['title']}\n내용={doc['content']}"
        )
    return '\n-------\n'.join(contexts)


def ask_rag(question, search, generate):
    results = search(question)['results']
    if not results:
        return '제공된 문서에서 확인할 수 없습니다.'
    context = build_context(results)
    prompt = f'문맥에 있는 내용으로만 한국어로 답하세요.\n질문: {question}\n문맥:\n{context}'
    return generate(prompt)
```

**[example.py](실습/책형_복습/종합실습/example.py) — 새 전체 파일**

```python
from chunk_tools import build_actions
from rank_tools import fuse
from rag_tools import ask_rag

documents = [
    {'id': 1, 'title': '메모리 안내', 'category': 'laptop', 'content': 'RAM은 16GB입니다.'},
    {'id': 2, 'title': '저장장치 안내', 'category': 'laptop', 'content': 'SSD는 512GB입니다.'},
]


def fixed_embedding(title, content):
    return [0.1, 0.2]


actions = []
for document in documents:
    actions.extend(build_actions(document, fixed_embedding))
hits = [{'_id': a['_id'], '_source': a['_source']} for a in actions]
text_hits = [hits[0]]
vector_hits = [hits[1], hits[0]]
combined = fuse(text_hits, vector_hits)
sent_prompts = []


def fixed_search(question):
    return combined


def fixed_generate(prompt):
    sent_prompts.append(prompt)
    return '고정 응답: RAM은 16GB입니다.'


print('준비 작업:', len(actions))
print('청크 ID:', [a['_id'] for a in actions])
print('합친 순서:', [row['id'] for row in combined['results']])
print(ask_rag('메모리는?', fixed_search, fixed_generate))
print('문맥의 메모리:', 'RAM은 16GB입니다.' in sent_prompts[0])
print('문맥의 저장장치:', 'SSD는 512GB입니다.' in sent_prompts[0])
print('생성 대역 호출:', len(sent_prompts))
print('외부 전송:', False)
```

## 5. 끝까지 추적한 연결

build_actions가 호출하는 split_text는 chunk_tools.py에 있다. 각 작업의 source는 독립 dict이고 content는 청크다. hits는 작업에서 ID·본문을 꺼낸 목록이다. fuse는 두 순위 목록에서 같은 ID를 찾아 점수를 더하고 document·score를 가진 결과를 돌려준다.

fixed_search는 이 고정 결과를 반환한다. 실제 질문을 분석하거나 검색하지 않는다. ask_rag는 그 결과의 본문을 build_context로 묶고 질문과 함께 fixed_generate에 전달한다. sent_prompts에서 확인한 True는 문자열이 포함됐다는 뜻이며 그 문장에 근거한 AI 추론의 증거가 아니다.

## 7. 평가와 한계

청크와 저장 본문이 같은가, ID가 자료를 추적하는가, import 정의가 모두 있는가, 고유 후보 수와 반환 수를 나눴는가, prompt에 실제로 어떤 내용을 넣었는가를 채점한다. 실제 서비스의 응답을 확인하지 않고 검색 품질·모델 성능·사실성을 검증했다고 쓰지 않는다.

원본의 청크 dict 참조와 전체 본문 저장 문제를 고친 새 개선안이다. 빈 결과 처리는 원본에 없다. 실제 전송 실패·입력 한도·서비스 응답 오류·자동 근거 검사는 현재 로컬 예제의 범위 밖이다.
