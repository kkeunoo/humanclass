# 영화 CSV 실무 코딩스타일 — 완료한 처리와 미완성 코드를 분리하기

[단원 목차](README.md) · [종합실습](종합실습.md)

강사님과 내 `08_langgraph/router/es_router.py`를 비교해 **현재 코드에서 확인 가능한 처리**를 읽는 새 자료다. 폴더 이름만 보고 LangGraph 그래프를 배웠다고 표시하지 않는다.

## 먼저: 단계와 완료 상태를 함께 기록하기

영화 CSV를 읽어 검색용 문자열을 만든 일, 문자열을 청크로 나눈 일, 임베딩 요청 코드를 적은 일, 서버에 저장한 일은 각각 다르다. 수업 코드를 복습할 때 **입력 → 처리 → 반환값 → 실제 실행 여부**를 나란히 적으면 미완성 `pass`와 작성된 코드를 혼동하기 어렵다.

## 1. 원본 CSV의 연결 기준부터 확인하기

[01장](01_CSV읽기와_검증.md)에서 영화·태그 자료의 행과 열을 확인한다. 태그는 영화 제목의 문자열이 아니라 `movieId`로 영화에 연결한다. [02장](02_영화텍스트와_청크.md)의 `groupby('movieId')['tag'].agg(list).to_dict()`와 `movie_tags.get(id, [])`가 그 관계를 만든다. 태그가 없으면 빈 목록으로 이어지는 흐름을 먼저 추적한다.

## 2. 문자열 처리와 임베딩을 다른 단계로 적기

장르 `Action|Comedy`를 나누고 공백 제거·소문자화를 거쳐 제목·장르·태그를 `content_text`로 합친다. 이것은 **검색에 넣을 문자열**이지 벡터가 아니다. 겹치는 청크를 만든 뒤 내 코드의 임베딩 요청 준비로 이어진다. [03장](03_임베딩과_미완성경계.md)에서 실제 구현된 부분과 아직 연결하지 않은 부분을 확인한다.

```python
# 수업 단계의 입력·출력을 축약한 설명용 예시
genres = [part.strip().lower() for part in 'Action|Comedy'.split('|')]
content_text = ' '.join(['Example Movie'] + genres + ['friendship'])
# 여기까지는 문자열 처리이며 임베딩 결과가 아니다.
```

## 3. `pass`와 요청 준비를 성공 결과로 적지 않기

강사님 코드의 `pass`는 해당 처리가 미구현임을 뜻한다. 내 코드의 임베딩 요청 준비도 실제 외부 API 성공이나 ES 벌크 저장 성공을 입증하지 않는다. 두 파일 모두 `Literal[...]`을 사용하면서 import하지 않은 문제가 있어 라우터 로딩 자체가 실패할 수 있다. 원본을 고친 척하지 않고, **코드상 확인한 범위와 실행 확인한 범위**를 따로 적는다.
