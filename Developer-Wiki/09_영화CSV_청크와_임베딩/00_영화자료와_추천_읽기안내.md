# 영화 자료와 추천 읽기 안내 — 내용 특징과 평점 관계를 나누어 보기

[단원 목차](README.md)

## 1. 두 흐름

내용 흐름은 영화·태그 CSV→검색 문자열→청크→임베딩·적재→검색·특징 기반 추천이다. 평점 흐름은 ratings→사용자별 시간 분할→Surprise 학습→미평가 후보 예측→Recall@K다. 제목·장르를 합치는 함수에 평점이 자동으로 들어가지는 않는다.

## 2. 같은 숫자라도 다른 단위

movieId·userId·청크 번호·행 위치·요청 응답 index·모델 내부 ID를 구별한다. 30명 이웃·상위 50개 추천·50글자 크기처럼 수 옆에 단위를 남긴다. 표의 행 수·고유 ID 수·청크 수·평가 관련 영화 수도 다르다.

## 3. 원본과 새 예제

4절의 출처·행 범위는 확보한 실제 소스 사본이다. 3절은 필요한 전체 정의·자료를 제공한 새 예제다. 실제 CSV·가상 표·고정 임베딩·실제 가상 자료 모델 학습을 구별한다. 후반부는 강사님 코드를 옮겼다는 사용자 확인을 반영했다. 정확한 시작 경계는 추정이다.

## 4. 복습 순서

입력·함수 정의·반환·다음 소비자를 먼저 적는다. 결과를 예상하고 한 가지만 바꾼 뒤 이유를 설명한다. 학습 전에 분할한 자료인지, 추천 후보에 정답 영화가 들어올 수 있는지까지 확인한다. 현재 코드가 바뀌면 과거 pass 상태나 오래된 행 번호를 그대로 믿지 않는다.
