## 1. 목적과 출발점

실제 수업의 두 흐름을 작은 가상 자료로 연결한 새 실습이다. 제목·장르·태그로 검색 자료를 준비하고, 별도의 평점 자료로 협업 모델을 학습해 Recall을 계산한다. 문자열 준비와 평점 모델을 하나의 모델인 것처럼 섞지 않는다.

## 2. 준비와 요구사항

pandas·Surprise 환경과 아래 다섯 파일이 필요하다. 같은 폴더에 저장하고 `python example.py`를 실행한다. 필요한 사용자 함수 정의를 모두 제공했다. 외부 CSV·접속키·검색 서버는 필요하지 않다.

문자열은 가상 영화 네 개, 평점은 사용자 세 명의 아홉 행이다. 임베딩은 2차원 고정 응답이고 실제 모델이 아니다. 협업 필터링은 실제 Surprise 모델을 가상 평점에 학습한다. 평가 기준은 새 실습의 threshold=3.0·K=2이며 원본 평가 경로의 2.0·50과 다르다.

## 3. 구현 순서

1. 영화·태그 표로 content_text를 만든다.
2. 50/15 설정의 청크와 고정 응답을 연결해 actions를 준비한다.
3. 평점을 사용자별 과거·최신으로 분할한다.
4. train으로 학습하고 본 영화를 제외한 후보를 예측한다.
5. test의 선호 기준과 상위 추천으로 Recall@2를 계산한다.

**[movie_tools.py](실습/책형_복습/종합실습/movie_tools.py) — 새 전체 파일**

```python
import pandas as pd


def parse_genre(value):
    text = str(value).strip()
    if text == '' or text == '(no genres listed)':
        return []
    return [genre.strip().lower() for genre in text.split('|')]


def make_content(movies, tags):
    result = movies[['movieId', 'title']].copy()
    result['title'] = result['title'].astype(str).str.strip()
    result['list_genre'] = movies['genres'].map(parse_genre)
    clean_tags = tags[['movieId', 'tag']].dropna(subset=['tag']).copy()
    clean_tags['tag'] = clean_tags['tag'].astype(str).str.strip().str.lower()
    clean_tags = clean_tags.drop_duplicates(['movieId', 'tag'])
    by_movie = clean_tags.groupby('movieId')['tag'].agg(list).to_dict()
    result['list_tag'] = result['movieId'].map(lambda movie_id: by_movie.get(movie_id, []))
    result['content_text'] = result.apply(
        lambda row: ' '.join([row['title']] + row['list_genre'] + row['list_tag']).strip(),
        axis=1,
    )
    return result.reset_index(drop=True)


def make_chunks(frame, size=50, overlap=15):
    if not 0 <= overlap < size:
        raise ValueError('겹침은 0 이상 크기 미만이어야 합니다.')
    chunks = []
    for row_index, row in enumerate(frame.to_dict(orient='records')):
        text = row['content_text'].strip()
        for chunk_index, start in enumerate(range(0, len(text), size - overlap)):
            chunks.append({
                'index': row_index, 'movieId': int(row['movieId']),
                'title': row['title'], 'genres': list(row['list_genre']),
                'tags': list(row['list_tag']), 'content': text[start:start + size],
                'chunk_index': chunk_index,
            })
    return chunks
```

**[vector_tools.py](실습/책형_복습/종합실습/vector_tools.py) — 새 전체 파일**

```python
def attach_vectors(chunks, response_rows, index_name, dimensions=2):
    rows = sorted(response_rows, key=lambda row: row['index'])
    if [row['index'] for row in rows] != list(range(len(chunks))):
        raise ValueError('입력과 응답 index를 확인하세요.')
    actions = []
    for chunk, row in zip(chunks, rows):
        vector = row['embedding']
        if len(vector) != dimensions:
            raise ValueError('벡터 차원을 확인하세요.')
        source = {**chunk, 'embedding': vector}
        actions.append({
            '_index': index_name,
            '_id': f'{chunk["movieId"]}-{chunk["chunk_index"]}',
            '_source': source,
        })
    return actions
```

**[cf_tools.py](실습/책형_복습/종합실습/cf_tools.py) — 새 전체 파일**

```python
import math
import pandas as pd
from surprise import Dataset, Reader, KNNWithMeans


def recent_split(ratings, test_size=0.2):
    if not 0 < test_size < 1:
        raise ValueError('시험 비율은 0보다 크고 1보다 작아야 합니다.')
    data = ratings.copy()
    data['original_order'] = range(len(data))
    data['timestamp'] = pd.to_numeric(data['timestamp'], errors='coerce')
    if data['timestamp'].isna().any():
        raise ValueError('유효한 timestamp가 필요합니다.')
    test_indices = []
    for _, group in data.groupby('userId', sort=False):
        if len(group) <= 1:
            continue
        ordered = group.sort_values(['timestamp', 'original_order'], kind='stable')
        count = min(len(ordered) - 1, max(1, math.ceil(len(ordered) * test_size)))
        test_indices.extend(ordered.tail(count).index.tolist())
    test = data.loc[test_indices].sort_values('original_order').drop(columns='original_order')
    train = data.drop(index=test_indices).sort_values('original_order').drop(columns='original_order')
    return test.reset_index(drop=True), train.reset_index(drop=True)


def recommend(train, user_id, top_k=2):
    if user_id not in set(train['userId']):
        raise ValueError('학습 자료에 없는 사용자입니다.')
    if top_k <= 0:
        raise ValueError('추천 수는 양수여야 합니다.')
    reader = Reader(rating_scale=(0.5, 5.0))
    dataset = Dataset.load_from_df(train[['userId', 'movieId', 'rating']], reader)
    train_set = dataset.build_full_trainset()
    model = KNNWithMeans(k=30, sim_options={'name': 'cosine', 'user_based': True}, verbose=False)
    model.fit(train_set)
    inner_id = train_set.to_inner_uid(user_id)
    seen = {train_set.to_raw_iid(movie_id) for movie_id, _ in train_set.ur[inner_id]}
    candidates = [train_set.to_raw_iid(i) for i in range(train_set.n_items) if train_set.to_raw_iid(i) not in seen]
    result = [{'movieId': movie_id, 'score': model.predict(user_id, movie_id).est} for movie_id in candidates]
    result.sort(key=lambda row: row['score'], reverse=True)
    return result[:top_k]
```

**[evaluation_tools.py](실습/책형_복습/종합실습/evaluation_tools.py) — 새 전체 파일**

```python
def recall_at_k(user_id, test, recommendations, threshold=4.0, k=10):
    if k <= 0:
        raise ValueError('k는 양수여야 합니다.')
    relevant = set(test.loc[
        (test['userId'] == user_id) & (test['rating'] >= threshold), 'movieId'
    ])
    if not relevant:
        return -1.0
    recommended = {item['movieId'] for item in recommendations[:k]}
    return len(relevant & recommended) / len(relevant)
```

**[example.py](실습/책형_복습/종합실습/example.py) — 새 전체 파일**

```python
import pandas as pd
from movie_tools import make_content, make_chunks
from vector_tools import attach_vectors
from cf_tools import recent_split, recommend
from evaluation_tools import recall_at_k

movies = pd.DataFrame([
    [1, 'Example Movie', 'Action|Comedy'],
    [2, 'Second Movie', 'Action'],
    [3, 'Third Movie', 'Drama'],
    [4, 'Fourth Movie', 'Comedy'],
], columns=['movieId', 'title', 'genres'])
tags = pd.DataFrame([[1, 'friendship'], [1, 'funny']], columns=['movieId', 'tag'])
content = make_content(movies, tags)
chunks = make_chunks(content)
fixed_response = [{'index': i, 'embedding': [0.1, 0.2]} for i in reversed(range(len(chunks)))]
actions = attach_vectors(chunks, fixed_response, 'practice_movies')
print(content.iloc[0]['content_text'])
print('영화·청크·작업:', len(content), len(chunks), len(actions))
print('외부 임베딩·적재:', False)

ratings = pd.DataFrame([
    [10, 1, 4.0, 100], [10, 2, 5.0, 110], [10, 3, 3.0, 120],
    [20, 1, 4.0, 100], [20, 3, 5.0, 110], [20, 4, 2.0, 120],
    [30, 2, 5.0, 100], [30, 4, 3.0, 110], [30, 3, 4.0, 120],
], columns=['userId', 'movieId', 'rating', 'timestamp'])
test, train = recent_split(ratings)
recommendations = recommend(train, 10, top_k=2)
print('학습·시험:', len(train), len(test))
print('추천:', [item['movieId'] for item in recommendations])
print('가상 자료 Recall@2:', recall_at_k(10, test, recommendations, threshold=3.0, k=2))
```

## 5. 함수와 자료 연결

make_content·make_chunks는 movie_tools, attach_vectors는 vector_tools, recent_split·recommend는 cf_tools, recall_at_k는 evaluation_tools에서 가져온다. 위 정의가 모두 제공돼 있다. 제목 가공의 결과를 평점 모델의 정답으로 넣는 구조가 아니다.

첫 흐름은 청크별 ID·본문·벡터를 가진 저장 준비 목록에서 끝난다. 두 번째는 시험 자료를 남긴 채 학습하고 사용자 10의 미평가 후보를 예측한 뒤 관련 영화 집합과 비교한다. 자료가 작은 가상 예제라 좋은 점수가 나와도 실제 추천 서비스의 성능을 뜻하지 않는다.

## 7. 평가와 한계

각 ID의 단위, 입력·반환·파일 정의, 두 흐름의 분리, 시간 분할, 시험 선호 기준, 분자·분모를 설명하면 성공이다. 최고 점수 달성만 채점하지 않는다. -1.0을 정상 Recall 점수로 평균 내지 않는다. 고정 임베딩과 실제 가상 평점 학습의 확인 범위도 구별한다.

입력 검사·응답 대응·원본 보존·timestamp 정책은 새 개선안이다. 실제 원본은 그대로 두었다. 원본 후반부의 강사님 복사 자료와 이 새 종합실습도 서로 다른 출처다.
