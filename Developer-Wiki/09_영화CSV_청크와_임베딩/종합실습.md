# 영화 CSV 종합실습 — 한 영화의 검색 문장 만들기

[단원 목차](README.md) · [장별 연습문제](실습/연습문제/README.md)

**CSV 관계·장르 분리·태그 연결·검색문 만들기**를 묶은 새 오프라인 복습이다. 강사님 원본의 미구현 `pass`나 내 임베딩 요청을 성공한 실행 사례로 만들지 않는다.

## 주어진 값

```text
movieId: 10
title: Example Movie
genres: Action|Comedy
tags: [" Friendship ", "Funny"]
```

1. 장르를 `|`로 나누고 각 값의 양쪽 공백을 지운 뒤 소문자로 바꾼다.
2. 태그의 양쪽 공백과 대소문자를 정리한다.
3. 제목, 장르, 태그를 순서대로 한 문자열로 합친다.
4. 이 문자열이 아직 임베딩 벡터가 아닌 이유를 설명한다.

<details>
<summary>예시 풀이 — 직접 결과를 예상한 뒤 펼치기</summary>

```python
# 원본 발췌가 아닌 작은 새 복습 입력
title = 'Example Movie'
genres = [value.strip().lower() for value in 'Action|Comedy'.split('|')]
tags = [value.strip().lower() for value in [' Friendship ', 'Funny']]
content_text = ' '.join([title] + genres + tags).strip()
print(content_text)  # Example Movie action comedy friendship funny
```

`content_text`는 단어를 합친 문자열이다. [02장](02_영화텍스트와_청크.md)의 원본은 여러 영화의 CSV를 다루고, 같은 `movieId`의 태그를 묶어 연결한다. 이 작은 문제는 한 영화의 결과를 손으로 확인하기 위한 재구성이다.

</details>

**성공 기준:** 한 영화의 문자열을 예상하고, 원본의 `movieId` 연결과 청크 단계가 어디에 오는지 [01장](01_CSV읽기와_검증.md)·[02장](02_영화텍스트와_청크.md)에서 찾는다. 실제 임베딩 호출·ES 적재·LangGraph 실행은 요구하지 않는다.
