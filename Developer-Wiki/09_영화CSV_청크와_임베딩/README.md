# 영화 CSV 가공·청크·임베딩

[Developer-Wiki 첫 화면](../README.md) · [08 Elasticsearch·RAG](../08_Elasticsearch와_RAG/README.md)

양쪽 `workspace_python/08_langgraph`의 **실제 구현 범위**를 읽는다. 폴더명과 달리 현재 Python 파일에 LangGraph의 그래프·노드·간선 생성 코드는 없다. 이번 단원의 본문은 MovieLens CSV 확인 → 제목·장르·태그 합치기 → 겹치는 청크 만들기 → 내 코드의 임베딩 요청 준비다. 실행되지 않는 강사님 `pass`나 미구현 ES 벌크를 완성된 기능으로 취급하지 않는다.

## 읽는 순서

1. [01 CSV 읽기와 자료 관계 확인](01_CSV읽기와_검증.md)
2. [02 영화 검색문 만들기와 청크](02_영화텍스트와_청크.md)
3. [03 학생의 임베딩 구현과 미완성 경계](03_임베딩과_미완성경계.md)

각 장은 **강사님 코드 → 내 코드 → 실제 처리와 차이** 순서다. 발췌는 독립 실행 예제가 아니다. 두 파일 모두 `Literal[...]`을 함수 주석에 쓰면서 `Literal`을 import하지 않아, 현재 모습 그대로 서버 라우터를 불러올 때 `NameError`가 날 수 있다. 원본을 조용히 고쳐서 성공 사례로 소개하지 않는다. 외부 임베딩 API도 실제 호출해 성공을 확인하지 않았다. `.env`·접속키·가상환경 자동 생성 파일은 인용에서 제외했다.

## 추가로 알면 좋은 것

LangGraph의 상태 그래프, 영화 추천 모델, 실제 벡터 저장·검색 운영은 지금 양쪽 소스의 구현 근거가 없다. 후속 파일이 첨부되면 그때 수업 범위를 다시 판단한다.
