## 2. 현재 소스와 작성 출처

2026-10-30 책형 사본을 기준으로 작성한 장별 발췌를 보관했다. 2026-11-09 조회 기준으로 검색과 협업 필터링 발췌를 갱신하고 RRF 장을 추가했다. 당시 확인상 `recall_at_k`부터의 후반부는 놓친 수업의 강사님 코드를 옮긴 복습 자료이며, 시작 경계는 사용자 추정이다. 이후 개인·공동 풀이의 경위는 코드 주석 등 근거가 있는 경우에만 표시한다.

## 3. 이전 안내에서 바뀐 내용

현재 양쪽은 CBF의 재검색에 벡터를 사용한다. 내 적재와 검색은 OpenAI, 강사님은 Gemini로 연결되어 있다. 내 협업 필터링도 사용자 값 검사, 이웃 최대 50명과 pearson으로 변경됐다. `Literal`은 현재 내 코드에서 가져온다. 양쪽 시간 분할에는 변환 결과를 실제 timestamp 열에 반영하지 않는 문제가 남아 있다. [07장](07_CBF_CF와_RRF_하이브리드추천.md)에서 추가된 추천 결합 흐름을 읽는다.
