## 2. 환경과 실행

각 장 폴더에서 `python example.py`를 실행한다. pandas를 쓰는 장과 표준 라이브러리만 쓰는 장을 본문에서 구별했다. 협업 모델과 종합실습은 Surprise가 필요하다. 검증 환경은 기존 수업의 Python 3.14.6·pandas 2.3.3·Surprise 1.1.5이며 새 패키지를 설치하지 않았다.

## 3. 확인 범위

실제 CSV는 영화 9,742·태그 3,683·평점 100,836행이고 양쪽 가공 결과는 청크 17,669개다. 새 가상 예제와 원본 함수 정의 검사를 수행했다. 외부 임베딩·적재·검색은 실제 호출하지 않았으며 대역을 명시했다. 사본 이후 변경은 다음 검토 대상이다. D 원본을 수정하지 않는다.
