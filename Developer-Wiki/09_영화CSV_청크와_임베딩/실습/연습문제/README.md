## 3. 풀기와 채점

먼저 출력·자료 모양을 예상하고 이유를 적은 뒤 한 가지만 바꾼다. 풀이를 펼쳐 비교한다. ID 단위·분모·기본값과 실제 전달값·외부 호출 경계를 설명한다. TIP은 필수 정답 조건이 아니다. [종합실습](../../종합실습.md)에서 두 자료 흐름을 연결한다.
