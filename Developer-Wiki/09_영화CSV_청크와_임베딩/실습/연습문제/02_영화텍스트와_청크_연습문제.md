# 02 영화텍스트와 청크 — 연습문제

[원본 비교 본문](../../02_영화텍스트와_청크.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. `Action|Comedy`와 태그 `Fun`을 가진 제목 `Movie A`의 `content_text` 결과를 예상한다. 이 값은 벡터인가?
2. `size_chunk=50`, `overlap=15`라면 `step`은 얼마이며 첫 두 청크의 시작 위치는?
3. 강사님 청크와 내 청크의 딕셔너리 필드 차이는 무엇인가? 내 `index`와 `movieId`는 같은 값인가?
4. 수동 루프로 만든 `movie_tags`가 최종 결과에 그대로 쓰이는가?

<details>
<summary>정답과 확인할 점</summary>

1. `Movie A action comedy fun`이다. `|`로 나누고 정리한 뒤 제목·장르·태그를 공백으로 잇는다. 아직 **문자열**이다.
2. `50-15=35`이므로 시작 위치는 0, 35다. 길이가 충분하면 첫 청크의 마지막 15글자가 둘째와 겹친다.
3. 내 코드에는 원본 DataFrame의 행 위치 `index`가 더 있다. 이것은 영화의 식별자 `movieId`와 별개다.
4. 수동 루프도 실행되지만 곧 `groupby(...).agg(list).to_dict()`의 결과로 같은 변수를 덮어쓴다.

입력→처리→결과의 실제 원본 사례는 [본문](../../02_영화텍스트와_청크.md)에서 확인한다.

</details>
