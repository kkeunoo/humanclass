실제 수업 내용을 바탕으로 **새로 구성한 연습문제**다. 원본·당시 내 코드·새 개선안을 구별한다. 예상 → 이유 → 한 가지 변경 순서로 푼다.

## 목표와 준비

map과 apply(axis=1), groupby·agg(list)·dict의 관계를 설명한다. 리스트를 더한 뒤 join하는 흐름과 영화 ID별 태그 연결을 추적한다. 50글자·15글자 겹침·35글자 이동의 차이, 행 위치 index와 movieId를 구별한다.

[본문 3절](../../02_영화텍스트와_청크.md#example)의 폴더·설치·입력·실행 조건부터 확인한다. 아래 필요한 파일 전체를 같은 구조로 저장한다. 가져오는 함수·모델 정의도 빠뜨리지 않는다.

## 문제 1. 실행 결과 예상

**movie_tools.py**

```python
import pandas as pd


def parse_genre(value):
    text = str(value).strip()
    if text == '' or text == '(no genres listed)':
        return []
    return [genre.strip().lower() for genre in text.split('|')]


def make_content(movies, tags):
    result = movies[['movieId', 'title']].copy()
    result['title'] = result['title'].astype(str).str.strip()
    result['list_genre'] = movies['genres'].map(parse_genre)
    clean_tags = tags[['movieId', 'tag']].dropna(subset=['tag']).copy()
    clean_tags['tag'] = clean_tags['tag'].astype(str).str.strip().str.lower()
    clean_tags = clean_tags.drop_duplicates(['movieId', 'tag'])
    by_movie = clean_tags.groupby('movieId')['tag'].agg(list).to_dict()
    result['list_tag'] = result['movieId'].map(lambda movie_id: by_movie.get(movie_id, []))
    result['content_text'] = result.apply(
        lambda row: ' '.join([row['title']] + row['list_genre'] + row['list_tag']).strip(),
        axis=1,
    )
    return result.reset_index(drop=True)


def make_chunks(frame, size=50, overlap=15):
    if not 0 <= overlap < size:
        raise ValueError('겹침은 0 이상 크기 미만이어야 합니다.')
    chunks = []
    for row_index, row in enumerate(frame.to_dict(orient='records')):
        text = row['content_text'].strip()
        for chunk_index, start in enumerate(range(0, len(text), size - overlap)):
            chunks.append({
                'index': row_index, 'movieId': int(row['movieId']),
                'title': row['title'], 'genres': list(row['list_genre']),
                'tags': list(row['list_tag']), 'content': text[start:start + size],
                'chunk_index': chunk_index,
            })
    return chunks
```

**example.py**

```python
import pandas as pd
from movie_tools import make_content, make_chunks

movies = pd.DataFrame([{'movieId': 1, 'title': 'Example Movie', 'genres': 'Action|Comedy'}])
tags = pd.DataFrame([
    {'movieId': 1, 'tag': 'friendship'},
    {'movieId': 1, 'tag': 'funny'},
    {'movieId': 1, 'tag': ' FUNNY '},
])
frame = make_content(movies, tags)
chunks = make_chunks(frame)
print(frame.iloc[0]['content_text'])
print('태그:', frame.iloc[0]['list_tag'])
print('문자 수:', len(frame.iloc[0]['content_text']))
print('청크 길이:', [len(c['content']) for c in chunks])
print('둘째 내용:', chunks[1]['content'])
print('행 위치·영화 ID:', chunks[0]['index'], chunks[0]['movieId'])
```

실행 전에 결과를 먼저 적는다. 자료의 모양·분류 결과·확률·점수·현재 변수의 대상을 구별한다.

## 문제 2. 이유 설명

1. 44글자에 50/15 설정이면 왜 두 청크인가?
2. axis=1에서 lambda는 무엇을 받는가?
3. ratings는 이 content_text에 쓰이는가?

<details>
<summary>풀이</summary>

1. 시작 간격 35라 0과 35가 모두 범위 안이다.
2. 현재 영화 한 행의 값들이다.
3. 제목·장르·태그를 쓰며 평점 기반 추천은 뒤 장의 다른 흐름이다.

</details>

## 문제 3. 한 가지만 바꾸기

| 한 가지만 변경 | 예상 |
| --- | --- |
|태그 중복을 추가 | 같은 영화·같은 정규화 태그는 하나 |
|태그 없는 영화 추가 | 빈 목록과 제목·장르는 유지 |
|overlap을 0으로 | 50씩 이동·겹침 없음 |
|overlap을 size와 같게 | 새 예제 ValueError·원본 상수는 해당 값이 아님 |
|apply axis를 바꿈 | 함수가 받는 방향이 달라져 같은 행 풀이가 성립하지 않음 |

<details>
<summary>막힐 때 확인</summary>

join의 타입 오류는 목록 안의 값이 문자열인지 확인한다. 태그가 중복돼 보이면 정규화 전후와 영화 ID 기준을 본다. 청크가 너무 짧으면 range 시작점과 마지막 슬라이스를 계산한다. index와 movieId가 다르다는 이유만으로 자료가 어긋났다고 단정하지 않는다.

</details>
