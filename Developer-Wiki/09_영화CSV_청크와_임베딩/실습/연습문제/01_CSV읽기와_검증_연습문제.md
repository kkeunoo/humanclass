# 01 CSV읽기와 검증 — 연습문제

[원본 비교 본문](../../01_CSV읽기와_검증.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. 영화·태그·평점 CSV를 연결할 때 기준 열은 무엇인가? `head()`의 기본 반환 행 수는?
2. `movie_ids={1,2}`, `tag_ids={2,3,3}`이라면 집합으로 만든 뒤 `len(tag_ids - movie_ids)`는 몇인가? 태그 행 수와 같은가?
3. 강사님과 내 라우터에서 `Literal[...]` 사용과 import 목록을 비교하면 어떤 실행 문제가 보이는가?

<details>
<summary>정답과 확인할 점</summary>

1. `movieId`로 대응시킨다. `head()`는 기본적으로 앞 5행을 보여 준다.
2. `tag_ids - movie_ids`는 `{3}`이므로 **1**이다. 중복을 제거한 서로 다른 ID 수이지 태그 행 수가 아니다.
3. 두 원본 모두 `Literal`을 함수 주석에 쓰지만 import하지 않았다. 파일을 그대로 불러오면 이름을 찾지 못할 수 있다. `from typing import Any, Literal`은 **개선 제안**이지 이미 적용된 코드가 아니다.

입력→처리→결과의 실제 원본 사례는 [본문](../../01_CSV읽기와_검증.md)에서 확인한다.

</details>
