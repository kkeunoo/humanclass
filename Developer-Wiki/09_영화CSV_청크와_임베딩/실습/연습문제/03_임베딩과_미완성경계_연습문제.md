# 03 임베딩과 미완성경계 — 연습문제

[원본 비교 본문](../../03_임베딩과_미완성경계.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. 강사님 임베딩 함수의 `pass`와 내 `util.py` 임베딩 함수는 구현 상태가 같은가?
2. 내 Gemini 함수는 청크를 몇 개씩 요청하고, OpenAI 함수는 한 번에 최대 몇 개씩 요청하도록 적혀 있는가?
3. `_index`, `_id`, `_source`를 갖춘 action 목록을 반환하면 Elasticsearch 저장까지 끝나는가? `/es/bulk`의 상태는?
4. 내 원본 주석에서 Base64를 ‘양방향 암호화’라고 적은 것을 어떻게 바로잡아야 하는가?

<details>
<summary>정답과 확인할 점</summary>

1. 다르다. 강사님 함수는 `pass`로 미구현이고, 내 함수는 외부 요청·응답 처리가 작성돼 있다. 실제 성공은 확인되지 않았다.
2. Gemini는 청크 하나씩, OpenAI는 입력 목록을 최대 **2047개씩** 묶는다.
3. 아니다. action 준비와 서버 전송은 다르며 내 `/es/bulk`도 `pass`다.
4. Base64는 데이터의 표현 방식이다. 암호화라고 설명하면 비밀을 안전하게 보호한다는 잘못된 인상을 준다.

입력→처리→결과의 실제 원본 사례는 [본문](../../03_임베딩과_미완성경계.md)에서 확인한다.

</details>
