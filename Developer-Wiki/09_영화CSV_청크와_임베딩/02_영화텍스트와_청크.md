## 1. 이 장에서 배울 것

map과 apply(axis=1), groupby·agg(list)·dict의 관계를 설명한다. 리스트를 더한 뒤 join하는 흐름과 영화 ID별 태그 연결을 추적한다. 50글자·15글자 겹침·35글자 이동의 차이, 행 위치 index와 movieId를 구별한다.

## 2. 무엇이며, 왜 필요한가

### 여러 열을 한 줄로 합치기 전에 자료형을 맞춘다

장르는 Comedy|Drama 같은 문자열이고 태그는 같은 영화에 여러 행으로 흩어져 있다. 원본은 장르를 |로 나눠 소문자 목록으로 만들고 태그도 소문자·양끝 공백을 정리한 뒤 영화 ID별 목록으로 묶는다. 제목 하나는 `[title]`로 감싸 목록으로 만든다. 그래야 `[제목] + 장르목록 + 태그목록`을 한 목록으로 더할 수 있다. 마지막 `' '.join(...)`이 목록의 문자열들을 공백으로 잇는다.

| 도구 | 이번에 받는 것 | 결과 |
| --- | --- | --- |
| Series.map(parse_genre) | genres 열의 값 하나씩 | 각 영화의 장르 목록 |
| groupby(movieId) | 같은 ID의 태그 행 | 영화별 그룹 |
| agg(list) | 한 그룹의 tag 값들 | 태그 목록 |
| to_dict | 영화별 태그 집계 | ID → 목록 dict |
| apply(..., axis=1) | 같은 행의 제목·장르·태그 | 영화별 content_text |

apply가 항상 모든 열을 처리한다는 뜻은 아니다. axis=1이면 함수를 행 단위로 적용한다는 의미다. 여기서 함수가 그 행의 세 열을 직접 골라 사용한다. map의 lambda도 지금 각 movieId를 받아 해당 태그 목록을 찾는 함수다. lambda라는 이름 때문에 자동으로 나중에 실행되는 특별한 자료가 되는 것은 아니다.

### 없는 태그와 중복 태그

movie_tags.get(movieId, [])는 태그가 없는 영화에 빈 목록을 준다. 태그가 없다는 이유로 영화 자체를 제거하지 않는다. drop_duplicates(['movieId','tag'])는 같은 영화에 정규화한 동일 태그가 여러 번 있으면 한 번 남긴다. 서로 다른 영화에 같은 태그가 있다고 전부 하나로 합치는 것은 아니다.

원본은 수동 dict 반복도 실행한 뒤 groupby 결과로 같은 movie_tags를 다시 덮어쓴다. 둘을 더한 결과가 아니다. 새로운 교재 예제는 최종 사용하는 집계 방식 하나로 정리했다. 결측 태그는 문자열 변환 전에 dropna로 제외하는 개선도 표시했다. pandas 버전에 따라 결측을 문자열로 바꾸는 동작이 달라질 수 있으므로 모든 NaN이 반드시 문자 nan이 된다고 일반화하지 않는다.

### 청크 크기와 이동 간격은 다른 수다

size_chunk=50, overlap=15이면 step은 35다. 시작점 0·35·70…마다 `text[start:start+50]`을 만든다. 인접 구간은 최대 15글자를 공유한다. 길이 44인 문자열도 시작점 0과 35가 모두 범위 안이므로 길이 44·9의 두 조각이 생긴다. “50글자 미만이면 항상 하나”라는 추측과 실제 반복 조건을 구별해야 한다.

이 방식은 문자 슬라이스이므로 문장 중간에서도 자른다. 08의 문장 묶기와 알고리즘이 다르다. 숫자 50은 토큰 수가 아니며, 각 청크에 붙는 movieId·chunk_index는 원문과 조각을 추적하기 위한 값이다.

```python
import pandas as pd


def parse_genre(value):
    text = str(value).strip()
    if text == '' or text == '(no genres listed)':
        return []
    return [genre.strip().lower() for genre in text.split('|')]


def make_content(movies, tags):
    result = movies[['movieId', 'title']].copy()
    result['title'] = result['title'].astype(str).str.strip()
    result['list_genre'] = movies['genres'].map(parse_genre)
    clean_tags = tags[['movieId', 'tag']].dropna(subset=['tag']).copy()
    clean_tags['tag'] = clean_tags['tag'].astype(str).str.strip().str.lower()
    clean_tags = clean_tags.drop_duplicates(['movieId', 'tag'])
    by_movie = clean_tags.groupby('movieId')['tag'].agg(list).to_dict()
    result['list_tag'] = result['movieId'].map(lambda movie_id: by_movie.get(movie_id, []))
    result['content_text'] = result.apply(
        lambda row: ' '.join([row['title']] + row['list_genre'] + row['list_tag']).strip(),
        axis=1,
    )
    return result.reset_index(drop=True)


def make_chunks(frame, size=50, overlap=15):
    if not 0 <= overlap < size:
        raise ValueError('겹침은 0 이상 크기 미만이어야 합니다.')
    chunks = []
    for row_index, row in enumerate(frame.to_dict(orient='records')):
        text = row['content_text'].strip()
        for chunk_index, start in enumerate(range(0, len(text), size - overlap)):
            chunks.append({
                'index': row_index, 'movieId': int(row['movieId']),
                'title': row['title'], 'genres': list(row['list_genre']),
                'tags': list(row['list_tag']), 'content': text[start:start + size],
                'chunk_index': chunk_index,
            })
    return chunks
```

```python
def makeChunk():
    size_chunk = 50
    overlap:int = 15
    # 자료형을 미리 지정하기 chunks = []
    # Any를 import해서 object처럼 아무거나 들어와도 되도록 사용할 수 있음
    chunks:list[dict[str, Any]] = []

    dataFrame = makeContent()
    content = dataFrame.to_dict(orient='records')

    step = size_chunk - overlap
    for idx_content, info in enumerate(content) :
        text = info.get('content_text', '').strip()
        if not text :
            continue

        # for idx_start in range(0, len(text), step):
        for idx, idx_start in enumerate(range(0, len(text), step)):
            chunk = text[idx_start : idx_start+size_chunk]
            if chunk :
                chunks.append({
                    'index' : idx_content,
                    'movieId' : int(info['movieId']),
                    'title' : str(info['title']),
                    'genres' : list(info['list_genre']),
                    'tags' : list(info['list_tag']),
                    'content' : chunk,
                    'chunk_index' : idx
                })

    return chunks
```

**발췌 바로 풀이:** 시작점을 35씩 이동해 최대 50글자를 자른다. 내 결과에는 idx_content라는 처리 행 위치 index가 추가되고 영화 ID와 다르다. /make/chunk는 전체 청크 목록의 앞 10개만 반환한다. 전체를 만들지 않고 10개에서 멈추는 코드가 아니다.

makeContent는 util.load_csv로 영화·태그를 읽고 가공 표를 반환한다. makeChunk는 그 표를 records로 바꿔 반복한다. 내 파일은 행 위치 index를 보존하고 강사님은 기본적으로 영화 ID·청크 번호로 조각을 나타낸다. ratings의 점수는 이 content_text 구성에 쓰이지 않는다. 검색 텍스트 가공과 평점 기반 추천을 구별한다.

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점:** 영화별 태그 목록과 장르를 실제 문자열에 연결하고 ID·청크 번호를 보존했다. **아쉬운 점:** 수동 집계와 groupby가 함께 있어 최종 결과가 무엇인지 혼동하기 쉽다. 결측 태그·빈 장르 조각·짧은 마지막 청크의 정책도 별도다. **개선:** 최종 방식 하나를 중심으로 읽고 결측을 변환 전에 확인한다. 크기를 매개변수로 바꿀 때는 0 이하 step이 생기지 않도록 새 예제처럼 조건을 검토한다.

원본 오류·수업용 단순화·목적에 따른 설계를 나눈다. 새 개선안은 당시 내 코드나 D 드라이브 수정본이 아니다.

## 7. 강사님 코드가 도움이 되는 비교



동일한 map·groupby·apply는 강사님 코드를 다시 붙이지 않는다. 내 index는 원래 행을 추적하는 보조 정보라는 장점이 있지만 영화의 고유 식별자로 쓰면 안 된다. 청크 크기·겹침은 양쪽 모두 50·15다.

## 8. 결과를 추적하고 한 가지 바꾸기

| 단계 | 새 예제 값 |
| --- | --- |
|장르 | action·comedy |
|태그 | friendship·funny |
|합친 문자열 | 44글자 |
|시작점 | 0·35 |
|청크 길이 | 44·9 |
|식별 | 영화 ID 1·청크 번호 0/1·행 위치 0 |

| 한 가지만 변경 | 예상 |
| --- | --- |
|태그 중복을 추가 | 같은 영화·같은 정규화 태그는 하나 |
|태그 없는 영화 추가 | 빈 목록과 제목·장르는 유지 |
|overlap을 0으로 | 50씩 이동·겹침 없음 |
|overlap을 size와 같게 | 새 예제 ValueError·원본 상수는 해당 값이 아님 |
|apply axis를 바꿈 | 함수가 받는 방향이 달라져 같은 행 풀이가 성립하지 않음 |

join의 타입 오류는 목록 안의 값이 문자열인지 확인한다. 태그가 중복돼 보이면 정규화 전후와 영화 ID 기준을 본다. 청크가 너무 짧으면 range 시작점과 마지막 슬라이스를 계산한다. index와 movieId가 다르다는 이유만으로 자료가 어긋났다고 단정하지 않는다.

**확인 범위:** 새 예제는 임시 폴더에서 Python 처리·요청 모양·고정 응답 가공을 확인한다. Elasticsearch나 AI 서비스의 실제 연결·적재·검색·임베딩·답변 성공을 재현한 것은 아니다. 원본 함수의 별도 검사도 외부 호출을 기록 대역으로 바꾼 범위이며 원본 파일과 패키지는 수정하지 않는다.

## 9. 추가로 알면 좋은 것과 출처

> 💡 **TIP · 수업 범위 밖:** 결측 장르를 처리하는 상세 정책·문장 또는 토큰 기준 청킹·태그 중요도 가중치·검색 품질 평가는 추가 학습이다. 새 예제의 결측 태그 제외와 매개변수 검사는 현재 원본에 적용한 변경이 아닌 개선안이다.



09 소스는 작업 중 변경을 감지해 2026-10-30 확보한 사본을 기준으로 집필했다. 이후 변경은 별도 재검토 대상이다. 확인한 라이브러리 의미와 수업 밖 확장을 구분한다. 위 출처는 본문의 설명 근거이며 TIP에 적힌 새 주제를 이미 배운 것으로 간주하지 않는다.
