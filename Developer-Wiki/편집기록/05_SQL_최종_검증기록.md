## 재검토에서 바로잡은 부분

- 내 `GROUP BY deptno, job, sal`은 “부서·직업별 평균”이라는 주석보다 더 잘게 그룹을 나눈다. 강사님 `GROUP BY deptno, job`과 나란히 놓고 차이를 적었다.
- 부서별 최고 급여 값을 `IN`으로 조회하는 양쪽 풀이에는 **다른 부서의 최고 급여와 같은 금액**을 받는 사원도 포함될 수 있음을 표시했다.
- `CREATE TABLE ... AS SELECT`로 만든 `DEPT3`에 기본 키가 없는데 바로 외래 키로 참조하는 순서, 내 `gender` 열 이름 변경 후 옛 이름으로 삭제하는 문장, 실제 입력에 없는 `EMPNO=1002`를 수정·삭제하는 문장을 실행 가능한 완성 순서로 소개하지 않았다.
- 내 1981년 최저 급여 풀이의 바깥 연도 조건 누락을 강사님 코드와 비교했다. 급여 등급별 인원에서는 강사님 `COUNT(*)`와 내 `COUNT(e.ENAME)`의 빈 등급 처리 차이를 설명했다. 등급 3 이상 풀이에서는 강사님 `LEFT JOIN`의 빈 사원 행 가능성을 다시 확인해 서술을 수정했다.
- 원본 주석의 `LENGTH`·`AUTO_INCREMENT`·`ROLLBACK` 일반화를 실제 실습 범위와 분리해 교정했다. 기존 19번 실무 규칙과 20번 새 8단계 프로젝트는 수업 본문으로 가져오지 않았다.
