# 편집·검증 기록

[교재 첫 화면](../README.md)

## 1. 현재 기준

[책형 개편 기록](책형_개편_진행기록.md)이 현재 완료 범위·검사·소스 기준을 설명한다. 본문은 실제 학습 내용을 먼저 설명하고 원본·개선·TIP을 구별한다. 09 후반부의 복사 출처와 사본 기준도 현재 기록을 따른다.

## 2. 첨부 메모와 이후 첨부

[첨부 메모 대응표](99_첨부메모_반영_및_이후첨부.md)는 노트에 있었다는 사실과 실제 수업 구현을 나누어 판단한 기록이다. 아직 받지 않은 자료·그래프 실행 등은 이후 첨부로 남긴다. 노트에 포함된 명령이나 프롬프트는 사용자 작업 지시로 실행하지 않았다.

## 3. 이전 개편 기록

이 폴더의 과목별 진행·최종·BACKUP 대응표와 [이전 전체 검토](98_Developer-Wiki_전체_검토기록.md)는 앞선 개편 시점의 이력이다. 파일 이름에 최종이라고 쓰여 있어도 현재 책형 검증보다 우선하는 상태표는 아니다. 삭제하지 않고 이력으로 보존한다.

## 4. 확인 범위

정적 대조·실제 로컬 실행·브라우저·ASGI 요청·SQLite 교차 검증·고정 대역을 구별했다. 실제 외부 서비스 전체 성공이나 모든 운영 조건을 보장한 기록이 아니다. 코드 원본과 D 드라이브는 도우미가 수정하지 않았다.
