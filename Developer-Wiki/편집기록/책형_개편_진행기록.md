## 2. 반복 검토에서 고친 것

개념을 코드보다 먼저 설명하고 작은 전체 파일·입력·결과를 제공했다. 내 원본 뒤에는 즉시 풀이를 붙이고 호출하는 사용자 함수의 정의도 연결했다. 강사님 코드는 유익한 차이에만 인용했다. 입력과 반환·출력과 저장·같은 객체와 복사·후보 수와 결과 수·선택 점수와 독립 시험·평가 가능과 불가를 구별했다.

07은 나무 수 증가와 성능 보장, 정수 cv의 기본 층화, 두 CSV의 줄바꿈 차이, 설정 선택 뒤 실제 시험 F1 하락·AUC 상승을 설명했다. 08은 text/벡터·term/LIKE·부분 갱신·공유 dict·저장 content·RRF 총수·프롬프트 지시와 검증의 차이를 보완했다.

09는 최신 코드에 맞춰 옛 pass·벌크 미구현 안내를 고쳤다. Series 인덱스 검사와 값 검사, 버려진 timestamp 변환, 결측 시간 행 처리, 필드 가중 검색과 벡터 재검색, 임베딩 제공자 호환 조건, Recall의 분모·-1.0·실제 전달 2.0/50을 검토했다. 새 연습문제의 예상 출력은 풀이 접기 안으로 옮겨 먼저 풀 수 있게 했다.

## 3. 소스 시점과 복사 출처

00~08은 해당 과목 완료 시의 원본 대조 기록을 따른다. 09는 작업 중 변경을 감지해 2026-10-30 양쪽 util.py·router/es_router.py 사본을 확보했다. manifest와 검사는 work/book-source-snapshot-09에 보존했다. 이후 원본 변경은 별도 검토 대상이다.

사용자 확인상 recall_at_k부터 후반부는 놓친 수업의 강사님 코드를 옮긴 복습 자료다. 시작 경계는 사용자 추정이다. 해당 장의 제목·설명·코드 표시에 출처를 반영했고 직접 작성 성과·부족함으로 평가하지 않았다. 기존 앞부분과 구분한다. 강사님만 추가된 search_vector의 상세 정의는 수강 범위 미확인 보충으로 04장 하단 TIP에 둔다.

## 4. 실제 확인과 한계

정적 원본 대조·전체 예제 일치·실제 로컬 실행·ASGI 요청·별도 headless Chrome·SQLite 교차 검증·고정 대역을 구별했다. HTML은 정적 검사이며 실제 브라우저 폼 제출은 확인 범위 밖이다. MariaDB 고유 동작과 실제 서버·외부 검색·AI 서비스 성공은 실행 검증하지 않았다. 대역 응답과 가상 자료의 점수를 실제 품질로 소개하지 않는다.

검증 환경에는 기존 수업 가상환경을 읽기만 사용했고 설치·수정하지 않았다. D 드라이브 소스·적용 Wiki·DB는 도우미가 변경하지 않았다. 사용자 브라우저·외부 메시지도 제어하지 않았다. 이번 완료 요청에는 PC 절전이 포함되지 않으며 과거 일회성 요청을 다시 실행하지 않는다.

## 5. 결과 파일과 다음 작업

현재 교재는 outputs/Developer-Wiki, 최상위 파일은 outputs/README.md다. 최종 책형 ZIP에는 두 항목과 현재 기록·검증 결과·적용 안내가 함께 들어간다. 예전 재학습 최종 ZIP·과목별 ZIP·책형 중간 ZIP과 구별한다.
