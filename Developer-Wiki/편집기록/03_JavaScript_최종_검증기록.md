## 로컬 화면 검수

검수용 17장 페이지는 원본의 외부 검색 action과 새 창 target을 **로컬 receiver.html과 로컬 iframe**으로 바꿨다. 수업 로직은 그대로 두고 외부 전송은 하지 않았다.

| 대상 | 확인한 결과 |
| --- | --- |
| 강사님·내 폼 | `a` 한 글자는 경고 뒤 수신 페이지가 바뀌지 않음. `  ab  `는 `query=++ab++`로 전달되어 앞뒤 공백 유지 확인. |
| 내 메뉴 | 같은 항목을 두 번 누르면 `✔✔인기상품순`이 됨. |
| 내 Todo | 빈 입력 시 안내창 뒤 빈 요소가 남고 `null` 리스너 오류. 다음 항목 추가에서 `ReferenceError: j is not defined` 기록. |
| 강사님 Todo | 두 항목 추가 후 전체 선택 시 두 항목 모두 선택, 선택 삭제 시 두 항목 모두 제거. |

이 검수는 해당 분기와 화면 동작에 한정된다. JavaScript 모든 줄의 실제 화면 동작을 전수 검사했다고 주장하지 않는다. 이전 장의 별도 검사 결과는 [진행 기록](03_JavaScript_진행과_재개기록.md)에 남겼다.
