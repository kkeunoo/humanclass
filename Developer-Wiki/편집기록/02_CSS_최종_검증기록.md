## 완료 범위와 기준

기존 CSS 20개 Markdown 경로를 유지하면서 실제 수업 본문 01~15, 교정 안내 16, 수업 기반 종합복습 17로 개편했다. 우선순위·상속과 마진·정렬은 각각 별도 문서로 분리했다. 추가편 4개와 실행 HTML 2개를 제공한다. 원본 ZIP·추출 소스는 보존하며 Wiki 전체 README·통합 색인 자체의 최종 편집은 모든 과목 이후로 남겼다.

강사님·내 원본 발췌 55곳을 경로·행과 함께 실었다. CSS 조각에는 CSS 코드 표시를 사용하고, HTML 전체 예제와 구분했다. 양쪽 코드가 같으면 같다고 적고, 학생 코드만 있는 개인 오타 사례에는 비교본이 없음을 밝혔다. 제외 요청한 바이브코딩 시험과 Python 개인 CSS 프로젝트는 학습 근거로 쓰지 않았다.

## 실제 검증한 범위

[이전 중간검사](02_CSS_진행과_재개기록.md)에 선택자·단위·박스·마진·숨김·글꼴·overflow·clearfix·그림자·transition·중앙 정렬·미디어 경계·기본 종합실습의 측정값이 있다. 그 검사는 그대로 이력으로 유지했다. 이번 재개에서는 다음 미검증 조건을 추가 확인했다.

| 추가 확인 | 결과 |
| --- | --- |
| fixed·sticky | 원본 페이지 scrollY 0→600→751. fixed top 633 유지, sticky top 408→50→50 |
| Flex 가운데 정렬 | 원본 주석의 center 두 속성을 적용한 복사본에서 항목 높이 26, 교차축 가운데 정렬 |
| Flex wrap | width:100px·wrap·align-content:flex-start 조건에서 2/2/1개씩 세 줄 |
| Flex 축소 | 같은 width·nowrap 조건에서 1/2/3번 테두리 너비 70, 4번 52, 5번 38px. min-width 제한 확인 |
| contain·cover | 직접 만든 2:1 SVG로 정사각형 영역 비교. contain 전체·상하 빈 공간, cover 좌우 잘림을 화면 확인 |
| transform 합성 | 원본 hover 목표값의 별도 비교 상자. 강사님 경계 약 209×209, 내 경계 약 209×139.33px |

| 추가 프로젝트 조작 | Tab으로 첫 링크에 도착하여 3px solid outline 확인, 클릭 후 #review 이동 |

검증용 복사본에 적용한 변경을 실제 원본 변경과 구분했다. 브라우저 측정용 코드는 수업 필수 지식에 넣지 않았다. 외부 이미지 가용성·폰트 실제 글리프·모든 브라우저·모든 접근성 기술을 검증한 것은 아니다. 움직임 감소 조건은 규칙을 검토했지만 운영체제 선호를 바꾸어 실동작까지 검사하지 않았다.

## 문서 검사

CSS Markdown 26개와 편집기록 2개를 검사했다. 내부 링크 188개, 기존 문서에서 CSS를 가리키는 링크 165개를 확인하고 옛 앵커 146개를 연결했다. 원본 발췌 55곳은 원본 내용과 일치하며, 보존 대상 원본 524개는 기존 해시와 일치했다. 실행 HTML 2개는 해당 문서의 전체 예제와 일치한다. 코드 블록·접기 영역·앵커 중복·파일 경로 검사에서 오류가 없었다.

로컬 Markdown 미리보기에서 README의 목차·표와 선택자 장의 CSS 코드 표시·장별 바로가기를 확인했다. 종합복습의 전체 HTML은 접기 영역 안에 코드로 표시되며 펼치기도 동작했다. 확인한 화면에서 페이지 전체의 가로 넘침은 없었다. 별도 실행 HTML도 브라우저에서 확인했다. 이는 로컬 렌더링 검사이며 GitHub에 게시하거나 GitHub 실제 화면에서 검증한 것은 아니다.
