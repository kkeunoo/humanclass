## 중단 이유와 작업 단위

사용자의 요청에 따라 과목별로 작업하고 사용량을 확인했다. 작업 중 5시간 한도 잔여량이 32%, 이후 15%로 줄어 새 본문 작성을 멈추었다. 15%는 중단 판단 시점의 계정 공유 한도이며, 정확한 잔여 토큰 수나 작업별 전용 사용량을 뜻하지 않는다.

## 확인한 동작과 한계

로컬 HTTP 서버와 Codex 내장 브라우저에서 다음을 확인했다. Browser 스킬의 로컬 화면 검증 절차를 적용했다.

| 확인 대상 | 관찰 결과 |
| --- | --- |
| 일반 문단의 연속 공백·소스 줄바꿈 | `하나 둘 셋`처럼 표시 |
| 문자 참조 | `&lt;br&gt; &copy; &amp;`가 `<br> © &`로 표시 |
| 원본 병합 표 | 2행×3열 점유. 첫 셀 rowSpan 2, 다음 셀 colSpan 2 |
| 내 중첩 목록 | 상위 `리스트2` 아래 하위 항목 표시 |
| 양쪽 목록 문서 제목 | 강사님: `Document`, 내 코드: `<!-- 주석 --> Document` |
| `#bottom` 링크 | 주소에 `#bottom`이 붙고 도착 요소로 이동 |
| `../asset/detail.html` | 로컬 서버의 `/asset/detail.html` 도착 |
| `/asset/detail.html` | 같은 서버의 같은 도착 페이지 확인 |
| 내 원본 표 | 표의 셀·제목·병합 표시 확인. 잘못된 닫기 태그가 있어도 화면이 나오는 사례 확인 |

문서에 포함한 모든 조각을 각각 모든 브라우저에서 실행한 검사가 아니다. 미디어 재생, 폼 제출, 리셋·선택 상태, 추가편, 최종 GitHub 렌더링은 아직 확인하지 않았다. 외부 검색 폼 제출, 전화·메일 발송은 수행하지 않았다.

## 재검토에서 바로잡은 판단

| 발견 | 반영 |
| --- | --- |
| `tel:`·`mailto:`가 양쪽 원본에 있음 | 실제 수업 본문에 포함. 연락처는 설명용 예시 값 사용 |
| 강사님 아래로 이동 링크와 도착 id가 미완성 | 내 코드의 완성된 연결을 장점으로 설명 |
| 양쪽의 `01_hello.html` 상대 경로가 현재 폴더와 맞지 않음 | `../01_hello.html`로 교정 |
| 내 이미지 링크의 여분 따옴표 | 속성 문법 교정 |
| 목록 주석이 title 안에 들어가 제목으로 보임 | 주석을 요소 밖에 두는 강사님 구성을 설명 |
| 양쪽 표의 잘못된 summary, 내 hidden 설명 | caption과 구역 구조로 교정. 숨김을 기계 전용 설명으로 소개하지 않음 |
| readonly 원본에 name이 없음 | name을 보완해야 제출 차이를 비교할 수 있다고 명시 |
| 마지막 체크박스 value, 라디오 초기 checked 차이 | 내 코드가 더 명확한 부분을 구체적으로 비교 |
| color·date·time·number·range도 양쪽 코드에 있음 | 실제 학습 범위에 포함 |
| POST는 주소가 변하지 않는다는 주석 | 쿼리로 붙이지 않는 것과 이동·리다이렉트를 구분 |

## 다음 작업의 순서

5. 기존 08·09·10과 BACKUP을 대조해 추가편과 수업 범위 복습을 작성한다. 옮겼다고 표기만 하고 내용을 누락하지 않는다.
6. 기존 00 읽기법·REFACTOR_REVIEW의 처리 방침을 확정하고 HTML 최종 README를 작성한다.
7. 기존 링크·옛 절 주소·문제/정답·예제 범위를 재검토한 후 전체 검증 기록과 HTML 완료 ZIP을 만든다.
8. 사용량을 보고하고 멈춘다. 이후 02 CSS로 진행한다. Wiki 최상위 README는 모든 과목 이후에 개편한다.

## 적용 중인 기준

- 실제 수업 코드를 메인으로, 상세 확장 내용은 **추가로 알면 좋은 것**으로 분리한다.
- 강사님 코드가 더 나은 경우와 내 코드가 더 나은 경우, 동작이 같은 경우, 양쪽 모두 교정이 필요한 경우를 구별한다.
- 바이브 시험 2개와 `03_database/00_CSS`는 학습 근거에서 제외한다.
- 원본 발췌는 보존하고 수정·재구성 예제는 명시한다.
- 초안 작성 후 범위 → 정확성 → 초보자 읽기 → 중복·누락 → 수정 결과를 확인한다.
