# 개인 풀이와 강사 풀이 비교


## 비교 기준

- 파일 경로가 같고 문제 주석이 있는 구간은 직접 비교했다.
- 개인 코드가 더 길다고 항상 더 좋은 것은 아니며, 검증과 설명이 실제 오류를 줄이는지 확인했다.
- 강사 코드는 핵심 문법을 보여주는 기준 풀이로 보았다.
- 출처가 불명확한 CSS 문제와 일부 깨진 파일명은 공통 학습으로 취합했다.

## 전체 경향

### 개인 풀이

- 입력값 검증과 출력 메시지가 상세하다.
- 문제를 작은 단계로 나누는 주석이 많다.
- 요구사항보다 추가 기능을 구현한 경우가 있다.
- 일부 조건식은 자동 형 변환이나 연산 우선순위에 의존한다.

### 강사 풀이

- 핵심 조건과 반복 구조가 짧고 명확하다.
- 학습 중인 문법에 집중한다.
- 예외 처리가 생략된 경우가 있어 실제 프로그램에서는 보완이 필요하다.

## 권장 결합 방식

강사 풀이의 간결한 핵심 로직을 먼저 작성하고, 개인 풀이에서 확인한 입력 검증과 사용자 안내를 바깥에 추가한다.
