## 풀이 출처 판정

- 강사 ZIP의 `실습`, `퀴즈` 경로는 강사님 기준 코드로 분류했다.
- 개인 Workspace의 `실습_개인`, `실습_hp`, `0702_실습`, `test_*`, `연습용*`, `과제 및 평가`는 개인 풀이 또는 개인 수정 과정으로 분류했다.
- 동일한 기본 수업 파일은 강사 코드에서 시작해 개인이 주석·실행 코드·수정 코드를 누적한 경우가 많다. 작성자를 확정할 수 없으므로 **공통 수업 코드**로 취합했다.
- `_v1`, `_v2`, `_vf`는 단계별 수정 또는 최종본으로 보되, 파일만으로 작성자를 확정하지 않았다.

## HTML 비교 코멘트

강사 자료와 개인 Workspace 모두 `hello → tag → 상대주소 → 목록 → 표 → 이미지 → 폼` 순서가 일치한다. 개인 파일은 실행 확인과 주석이 추가된 경우가 많아, Wiki는 기본 문법을 공통 내용으로 정리했다.

## CSS 비교 코멘트

- 강사 수업은 선택자, 단위, 박스, display, opacity, background, font, position, overflow, float, shadow, transition, transform, media, flex까지 진행됐다.
- 개인 Workspace에는 `0702_실습`, `실습_hp`, `실습_개인`, `test_01~03`이 추가되어 있다. 이는 박스 모델과 배치 속성을 여러 번 수정하며 완성한 개인 문제 풀이로 판단했다.
- 강사 `display` 실습과 개인 `실습_tc`는 폴더명이 다르지만 대응되는 기준/복습 자료로 보아 공통 개념으로 취합했다.

## JavaScript 비교 코멘트

- 강사 수업은 변수, 연산자, 조건문, 반복문, 배열, Date, 함수, 화살표 함수, 문자열, DOM, 폼, 비동기 기초, 이벤트, 지도, JSON, AJAX, Gemini, Discord 실습까지 진행됐다.
- 개인 Workspace의 `04_2_복습`, `연습용`, `연습용2`, `java_중복테스트`는 개인 복습 흔적이다.

## 문제 풀이 반영 방식

문제 파일 전체를 Wiki에 복제하지 않고 다음만 문서에 통합했다.

- 어떤 개념을 조합했는지
- 자주 발생하는 실수
- 단계별 수정에서 확인되는 개선 포인트
