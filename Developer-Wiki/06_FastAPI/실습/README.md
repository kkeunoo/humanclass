## 2. 실행

각 장 폴더에서 본문3절의 명령·설치 조건을 따른다. 같은 api.py라도 서로 다른 앱이다. 템플릿과 보조 모듈을 빼지 않는다. 새 DB·업로드 파일은 별도 연습 폴더에 생긴다. 원본의 실제 접속 정보는 예제에 없다.

## 3. 결과 해석

서버print·반환값·HTTP상태·파일과DB·쿠키·다음 요청을 구분한다. 작성 중 자동 확인은 별도 임시 앱과 사본에 한정했다. 실제 MariaDB서버·원본DB변경은 검증 범위가 아니다.

## 4. 복습

틀린 개념은 해당 장의 정의·작은 표·추적표로 돌아간다. [읽기 안내](../00_FastAPI_상세백과_읽기법.md)에서 전체 연결을 다시 읽는다. 새 연습은 당시 수업 과제라고 표시하지 않는다.
