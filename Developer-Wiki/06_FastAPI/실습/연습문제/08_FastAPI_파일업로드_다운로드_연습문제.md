# 08 FastAPI 파일업로드 다운로드 — 연습문제

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

업로드 HTML 폼에서 `name="file1"`과 `enctype="multipart/form-data"`의 역할은?

<details>
<summary>정답과 확인할 점</summary>

`file1`은 서버 매개변수에 대응하는 이름이고, multipart 설정은 파일을 폼 데이터로 보내는 방식이다.

입력→처리→결과의 실제 원본 사례는 [본문](../../08_FastAPI_파일업로드_다운로드.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
