# 07-02 비밀번호 해시 실습 — 연습문제

[원본 비교 본문](../../07-02_비밀번호_해시_실습.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

같은 비밀번호를 다시 입력했을 때 저장된 해시 문자열과 어떻게 비교하는가?

<details>
<summary>정답과 확인할 점</summary>

평문을 그대로 비교하지 않고 수업 코드의 해시 검증 함수로 입력값을 검증한다. 이 장은 FastAPI 경로 밖의 별도 실습이다.

입력→처리→결과의 실제 원본 사례는 [본문](../../07-02_비밀번호_해시_실습.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
