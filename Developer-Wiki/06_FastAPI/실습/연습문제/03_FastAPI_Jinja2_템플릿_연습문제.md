# 03 FastAPI Jinja2 템플릿 — 연습문제

[원본 비교 본문](../../03_FastAPI_Jinja2_템플릿.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

템플릿에 `name` 값을 전달하고 HTML에 표시할 때 Python 쪽과 Jinja 쪽의 역할을 각각 적어 보자.

<details>
<summary>정답과 확인할 점</summary>

경로 함수가 템플릿에 값을 전달하고 Jinja 문서가 전달받은 변수를 렌더링한다. `extends`·`include`·`macro`는 본문 원본에서 실제 사용한 범위로 확인한다.

입력→처리→결과의 실제 원본 사례는 [본문](../../03_FastAPI_Jinja2_템플릿.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
