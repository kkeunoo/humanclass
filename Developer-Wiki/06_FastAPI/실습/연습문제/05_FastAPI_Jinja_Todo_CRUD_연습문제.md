# 05 FastAPI Jinja Todo CRUD — 연습문제

[원본 비교 본문](../../05_FastAPI_Jinja_Todo_CRUD.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

강사님 Todo의 모델 객체와 내 딕셔너리를 목록에 넣으면 항목의 `item`을 읽는 표현은 어떻게 달라지는가?

<details>
<summary>정답과 확인할 점</summary>

모델 객체는 `todo.item`, 내 딕셔너리는 `todo["item"]`처럼 접근한다. 둘 다 이 장에서는 메모리 리스트에 저장한다.

입력→처리→결과의 실제 원본 사례는 [본문](../../05_FastAPI_Jinja_Todo_CRUD.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
