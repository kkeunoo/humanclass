# FastAPI — 수업 코드로 따라가는 요청·화면·저장

강사님 `workspace_python`과 내 `workspace_python`의 **실제 수업 파일**을 대조했다. 각 장은 강사님 원본을 먼저, 내 원본을 아래에 두고 입력→처리→결과와 차이를 설명한다. `03_database/00_CSS` 개인 실험은 근거에서 제외했다. 기존 백과의 설명만으로 배웠다고 판단하지 않았다.

처음 읽는다면 아래 순서로 읽고, 각 장의 ‘직접 확인할 질문’에 답한 뒤 원본 파일을 열어 보자. 코드 발췌는 독립 실행 파일이 아니며, 경로·DB·템플릿 등 주변 코드가 생략될 수 있다.

본문은 **개념 → 짧은 요청과 예상 결과 → 강사님·내 코드 비교 → 실제 차이 → 연습문제** 순서로 읽는다. 01장의 가상환경 명령은 내가 남긴 **학습 메모의 실행 준비**로 표시했다. 02장 이후의 요청·화면·DB 코드는 양쪽 실제 파일에서 확인했다. 수업 밖 기능은 같은 페이지 끝의 ‘추가로 알면 좋은 것’에 둔다.

## 수업 내용과 보강 내용의 경계

`request.headers`로 직접 헤더를 읽는 예제와 `response_model`은 양쪽 수업 코드에서 확인되지 않았고, 사용자도 배우지 않았다고 확인했다. 이런 항목은 [추가로 알면 좋은 것](추가편_기존자료_학습범위_분류.md)에만 둔다. 반대로 실제로 작성한 Jinja `extends`·`include`·`macro`, 업로드 HTML 폼, 브라우저 쿠키 팝업, 비밀번호 해시는 본문이다.

코드의 주석과 실제 동작이 다른 곳은 그대로 인용한 뒤 본문에서 바로잡았다. 원본에 포함된 DB 접속 정보와 세션 비밀키는 Wiki로 옮기지 않았다. [기존 문서 대응표](../편집기록/06_FastAPI_기존문서_대응표.md)에서 옛 파일 이름의 새 위치를 찾을 수 있다.
