# 07-02. 비밀번호 해시 실습

[FastAPI 목차](README.md) · [이전: MariaDB와 SQLModel](07_FastAPI_MariaDB_SQLModel_사원_CRUD.md)

`03_database/04_암호화.py`는 FastAPI 경로 함수가 아닌 **별도 Python 실습**이다. 두 원본에 모두 있으므로 실제 학습 본문에 둔다. 파일명의 ‘암호화’보다 여기서는 원래 글자를 되돌리는 기능이 없는 **해시와 검증**이 정확하다.

## 먼저: 같은 입력인지 확인하는 결과

다음은 아래 수업 함수 `crypt`와 `verify`의 사용을 줄인 **설명용 재구성**이다. `연습용문자`는 실제 계정 비밀번호가 아니다.

```python
saved_hash = crypt('연습용문자')
print(verify('연습용문자', saved_hash))  # True
print(verify('다른문자', saved_hash))    # False
```

`saved_hash`는 원래 글자 자체가 아니라 해시 결과다. 실행마다 해시 문자열이 같을 필요는 없으므로, **새 입력과 저장한 해시를 `verify`로 검사한 참·거짓**을 결과로 읽는다.

## `CryptContext`로 해시 만들기

### 강사님 코드

출처: `teacher/workspace_python/03_database/04_암호화.py` 1–6행 · **원본 발췌**

```python
from passlib.context import CryptContext

ctx_pw = CryptContext(
    schemes=['argon2'], 
    deprecated='auto'
)
```

출처: `teacher/workspace_python/03_database/04_암호화.py` 10–11행 · **원본 발췌**

```python
def crypt(txt):
    return ctx_pw.hash(txt)
```

### 내 코드

출처: `me/workspace_python/03_database/04_암호화.py` 1–6행 · **원본 발췌**

```python
from passlib.context import CryptContext

ctx_pw = CryptContext(
    schemes=['argon2'],
    deprecated='auto'
)
```

출처: `me/workspace_python/03_database/04_암호화.py` 10–12행 · **원본 발췌**

```python
# argon2 암호화 방식(단방향)
def crypt(txt) :
    return ctx_pw.hash(txt)
```

두 코드 모두 `argon2` 방식의 `CryptContext`를 만들고 `ctx_pw.hash(txt)`로 입력 문자열의 해시를 생성한다. 코드의 예제 비밀번호 자체는 학습할 개념이 아니므로 옮기지 않았다. 해시 결과 문자열은 실행마다 달라질 수 있다.

## 원본과 해시 비교

### 강사님 코드

출처: `teacher/workspace_python/03_database/04_암호화.py` 16–17행 · **원본 발췌**

```python
def verify(orig, hashed) :
    return ctx_pw.verify(orig, hashed)
```

### 내 코드

출처: `me/workspace_python/03_database/04_암호화.py` 19–21행 · **원본 발췌**

```python
# 암호화 된 대상 비교
def verify(orig, hashed) :
    return ctx_pw.verify(orig, hashed)
```

`ctx_pw.verify(orig, hashed)`는 입력한 원본 문자열이 저장된 해시와 맞는지 확인해 참/거짓을 돌려준다. 강사님과 내 코드의 동작은 같다. **해시 문자열을 다시 비밀번호로 복원하는 함수가 아니다.**
