# FastAPI 학습 범위 — 실제 구현과 선택 확장

[FastAPI 목차](README.md)

## 1. 근거

현재 강사님·학생 workspace_python의 실제 파일과 사용자 확인을 기준으로 한다. 기존 Wiki·BACKUP의 설명 방식은 참고하지만 거기만 있는 기능을 실제 수업으로 단정하지 않는다. 원본은 코드·주석·실행 준비 메모를 구별한다. 계정·암호·비밀키 줄은 교재에 복사하지 않는다.

## 2. 본문으로 남긴 것

폼·쿼리·경로·Request의 실제 사용, CORS설정, Pydantic입력, Jinja상속·include·macro·필터, 직접 함수 호출·리다이렉트, 화면Todo, SQLite·PyMySQL·SQLModel·세션 의존성·입력validator, 해시, 업로드·다운로드, 쿠키·세션·미들웨어는 원본에 있다. 원본에 yield가 있다고 상세 제너레이터 구현까지 배웠다고 확대하지 않는다.

## 3. 추가로 알면 좋은 것

response_model·request.headers직접 읽기는 미학습 확인 항목이다. 배포·고급 세션·보안 정책·비동기DB·마이그레이션·대규모 파일 처리 등은 각 본문 하단 TIP에 둔다. 실제 사용한 Response쿠키·CORS의 allow_headers와 헤더를 직접 읽는 예제는 다른 내용이다.

원본의 결함을 고친 새 조회·공백 정리·명시적close·저장명 연결·상태 정책은 교재 개선안으로 표시했다. 이를 당시 내 코드로 바꿔 인용하지 않는다. 전체 파일을 제공한 새 예제라도 실서비스가 완성됐다는 뜻은 아니다.

## 4. 이후 첨부와 확인 한계

현재 파일에 없는 실행 화면·추가 강의 메모는 이후 첨부 때 대응을 다시 판단한다. SQLite대체 예제로 MariaDB접속을 확인했다고 쓰지 않는다. /login의 무검증 상태 저장을 실제 인증 성공으로 설명하지 않는다. 임시 예제·사본 검사와 원본 환경 실행을 구별한다.
