# 추가로 알면 좋은 것 — 기존 FastAPI 자료의 학습 범위

[FastAPI 목차](README.md)

이 문서는 기존 Wiki에 상세히 적혀 있었지만 **수업 원본 구현 또는 학습 확인 없이 메인으로 삼을 수 없는 내용**을 분리한다. 아래 항목을 모른다고 본문 복습에 실패한 것은 아니다.

| 내용 | 분류 이유와 읽을 위치 |
| --- | --- |
| `request.headers`로 직접 요청 헤더 읽기 | 양쪽 Python 수업 코드에서 사용을 확인하지 못했고 사용자가 배우지 않았다고 확인했다. 원본 `CORSMiddleware`의 `allow_headers` 설정과는 다른 기능이다. |
| `response_model`과 응답 필드 제거·응답 검증 | 양쪽 수업 코드에서 선언을 확인하지 못했고 사용자가 배우지 않았다고 확인했다. `-> dict` 반환형 표시나 Pydantic **입력 모델**과 혼동하지 않는다. |
| HTML 전용 응답 클래스의 사용법 | `/html` 원본은 문자열을 반환할 뿐 HTML 전용 응답 클래스를 구현하지 않는다. |
| 가상환경 자동 생성, 패키지 잠금·복원, 배포 설정 | 첫 앱 원본의 주제가 아니므로 실행 환경을 확장해서 알고 싶을 때 읽는다. |
| CORS의 배포 환경별 허용 정책·프리플라이트 | CORS 미들웨어 설정 **자체는 02장 실제 코드**다. 복잡한 정책과 브라우저 세부 동작은 별도 심화다. |
| Jinja 자동 이스케이프·신뢰 경계 | Jinja 상속·포함·매크로와 필터는 03장 실제 코드다. 보안 의미의 확장은 별도로 공부한다. |
| 업로드 확장자·크기 제한, 다운로드 경로 검증 | 08장 원본에는 제한·검증 구현이 없다. 원본 동작과 개선 방향을 구분한다. |
| 실제 사용자 인증과 운영용 세션·비밀키 관리 | 09장 `/login`은 비밀번호 검사 없이 세션을 설정하는 동작 실습이다. |

기존 상세백과에 설명이나 개선 코드가 있다는 사실만으로 실제 수업에서 배웠다고 판정하지 않았다. 학습 범위는 강사님 코드와 내 코드의 공통·차이, 그리고 사용자의 확인을 기준으로 한다.
