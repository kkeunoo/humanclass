## 2. 관찰하고 복습하기

예상 → 파일 열기 → 한 조건 변경 → 저장·새로고침 → 차이 설명 순서로 진행한다. 주석·현재 활성값, 조건 경계, hover 진입·복귀, 박스 너비·그려지는 범위를 구분한다. 실제 재생·로딩·렌더링을 확인하지 않았다면 코드 기준 예상으로 적는다.

[종합 display 복습](display_복습.html)은 [종합실습 본문](../17_CSS_종합실습.md)의 정답과 같다. 외부 이미지·글꼴 없이 두 칸의 너비와 줄바꿈을 계산한다. 버튼은 시각 복습이며 별도 클릭 기능은 없다.

## 3. 선택 추가실습

[학습 카드](학습카드_추가실습.html)는 Grid·gap·포커스·움직임 감소 조건을 추가했다. 본문의 TIP 설명을 먼저 읽고, 기본 문제의 정답과 구분한다. 새 기능을 많이 넣는 것보다 어떤 조건 때문에 결과가 바뀌었는지 설명하는 것이 우선이다.
