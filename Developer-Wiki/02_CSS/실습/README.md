[CSS 목차](../README.md) · [종합실습](../17_CSS_종합실습.md)

본문에서 강사님·내 CSS의 선택·크기·배치를 비교한 뒤 이 폴더에서 결과를 직접 예상한다. 파일은 **새로 구성한 복습 또는 추가실습**이며 수업 당시의 원본 제출물로 표시하지 않는다.

1. [본문 17장별 연습문제](연습문제/README.md) — 각 장을 마친 뒤 하나씩
2. [display 복습 HTML](display_복습.html) — 실제 수업의 두 칸 배치를 재구성해 너비와 줄바꿈 확인
3. [학습 카드 추가실습 HTML](학습카드_추가실습.html) — Grid 등 **추가로 알면 좋은 것**을 선택해서 연습
4. [CSS 종합실습 해설](../17_CSS_종합실습.md)

먼저 뷰포트 너비·부모 너비·자식 width·margin을 적고, 브라우저 화면과 개발자도구에서 비교한다. 추가실습의 새 속성을 기본 문제의 정답 조건으로 삼지 않는다.
