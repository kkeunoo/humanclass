# 05 CSS 투명도와 요소숨김 — 연습문제

[해당 본문](../../05_CSS_투명도와_요소숨김.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`display:none`, `visibility:hidden`, `opacity:0`을 각각 적용했을 때 자리와 클릭 가능성을 비교하자.

**확인 기준:** 각 방식에 대해 **보이는가 / 원래 자리가 남는가 / 마우스로 누를 수 있는가**를 나누어 기록한다. 키보드와 보조 기술 동작은 이 세 줄만으로 일반화하지 않는다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`display:none`은 레이아웃에서 제외되어 자리가 사라진다. `visibility:hidden`은 보이지 않아도 자리 자체는 남으며 보통 포인터 대상으로 선택되지 않는다. `opacity:0`은 투명할 뿐 자리가 남고, 다른 설정이 없다면 포인터로 누를 수 있다. 따라서 **안 보인다 = 클릭할 수 없다**가 아니다.

</details>

## 원본과 연결하기

강사님·내 원본에는 요소 전체의 `opacity`와 색 자체의 알파값도 나온다. 자식까지 함께 투명하게 할지, 배경색만 투명하게 할지에 따라 선택이 달라진다는 점을 [본문 3절](../../05_CSS_투명도와_요소숨김.md)에서 확인하자.
