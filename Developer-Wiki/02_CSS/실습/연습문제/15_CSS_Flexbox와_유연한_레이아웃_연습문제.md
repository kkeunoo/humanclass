**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모에 가로 Flex를 적용하고 항목 세 개 사이의 간격을 10px로 만들자.

**확인 기준:** 부모에 `display:flex; gap:10px`를 두면 항목 사이 간격이 생긴다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

주축·교차축의 정렬값을 섞지 않는다. 항목의 실제 너비는 부모와 자식 선언을 함께 읽는다.

</details>
