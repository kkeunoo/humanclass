# 15 CSS Flexbox와 유연한 레이아웃 — 연습문제

[해당 본문](../../15_CSS_Flexbox와_유연한_레이아웃.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모에 가로 Flex를 적용하고 항목 세 개를 주축의 가운데로 모으자. 부모가 가로 300px이고 항목 세 개의 전체 너비가 150px이라면 양쪽에 남는 공간은 얼마인지 계산하자.

**확인 기준:** Flex와 `justify-content`를 선언할 대상이 부모인지 자식인지 설명한다. 가운데로 모으는 것과 항목 사이에 일정한 간격을 주는 것을 구별한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```css
.row { display: flex; justify-content: center; }
```
세 항목을 감싼 부모 `.row`에 적용한다. 남는 공간 150px이 양쪽에 75px씩 배분된다. 이 선언은 **항목 사이 간격을 10px로 고정하는 설정이 아니다.** 항목의 실제 너비는 부모와 자식의 크기 선언을 함께 봐야 한다.

</details>

## 원본과 연결하기

강사님·내 Flex 원본에는 현재 적용된 선언과 주석 처리한 `justify-content` 실험이 함께 있다. **주석 속 실험을 동시에 실행한 결과처럼 읽지 말고**, 한 선언씩 켜서 축과 크기 변화를 예상하자. 이 문제의 세 항목·300px은 새 연습 조건이다.
