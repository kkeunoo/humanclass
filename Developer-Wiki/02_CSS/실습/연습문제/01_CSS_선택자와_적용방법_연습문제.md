# 01 CSS 선택자와 적용방법 — 연습문제

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`<p class="notice">`에만 글자색을 적용하고 다른 `p`에는 적용하지 않는 선택자를 작성하자.

**확인 기준:** `.notice` 또는 `p.notice`가 해당 요소를 고른다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

선택자가 실제 HTML의 class와 일치하는지 확인한다. 선언이 맞아도 CSS 파일이 연결되지 않으면 화면은 바뀌지 않는다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
