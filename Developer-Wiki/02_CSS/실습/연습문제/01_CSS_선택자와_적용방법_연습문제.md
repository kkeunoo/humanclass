# 01 CSS 선택자와 적용방법 — 연습문제

[해당 본문](../../01_CSS_선택자와_적용방법.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`<p class="notice">`에만 글자색을 적용하고 다른 `p`에는 적용하지 않는 선택자를 작성하자.

**확인 기준:** 선택자가 첫 문단만 고르는지 두 번째 문단과 나란히 놓고 확인한다. CSS 파일을 외부 파일로 저장했다면 연결 경로도 확인한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`p.notice { color: blue; }`는 `p`이면서 `notice` 클래스가 있는 요소를 고른다. `.notice`만 쓰면 다른 태그라도 그 클래스를 가진 요소가 선택된다. 둘 다 아래 첫 문단에 적용되지만, **다른 태그에 같은 클래스가 생길 때 범위가 달라진다.** 선언이 맞아도 CSS 파일이 연결되지 않으면 화면은 바뀌지 않는다.

</details>

## 확인용 HTML — 새로 구성한 예제

```html
<p class="notice">안내</p>
<p>일반 문단</p>
```

강사님·내 원본의 `.c1`과 `h2.c1`은 **클래스만 고르기 / 태그와 클래스를 함께 고르기**라는 차이를 연습한 사례다. 위 HTML은 그 원리를 다른 이름으로 확인하는 새 문제다.
