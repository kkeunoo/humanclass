**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`box-shadow: 4px 6px 8px gray`의 세 길이가 각각 무엇인지 적자.

**확인 기준:** 가로 이동 4px, 세로 이동 6px, 흐림 8px이다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

색과 길이를 구분한다. 추가 spread 값은 본문 밖의 확장 설명이다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
