# 11 CSS 그림자와 시각효과 — 연습문제

[해당 본문](../../11_CSS_그림자와_시각효과.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`box-shadow: 4px 6px 8px gray`의 세 길이가 각각 무엇인지 적자.

**확인 기준:** 세 길이값과 색을 분리해 읽는다. 가로·세로 값을 음수로 바꾸면 어느 방향으로 이동할지 예상한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

첫 값 4px은 가로 방향, 둘째 6px은 세로 방향의 그림자 이동 거리다. 셋째 8px은 흐림 반경이고 `gray`는 색이다. 양수 이동은 보통 오른쪽·아래쪽이다. 음수로 바꾸면 반대쪽으로 이동한다. 이 문제에는 **퍼짐 거리 값**을 넣지 않았다.

</details>

## 원본과 연결하기

강사님·내 원본의 그림자 선언도 길이를 **위치와 흐림**으로 나누어 읽는다. hover에서 그림자가 바뀐다면 기본 상태와 hover 상태를 각각 적고 마우스를 올려 확인하자.
