**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

같은 요소에 `p {color:blue}`와 `.notice {color:red}`를 적용하고 최종 색을 예상하자.

**확인 기준:** 같은 중요도에서 class 선택자의 빨강이 적용된다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

선택자가 둘 다 일치하는지 먼저 확인하고 우선순위를 비교한다. 부모의 상속값은 직접 선언과도 구별한다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
