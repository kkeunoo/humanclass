# 01-02 CSS 우선순위와 상속 — 연습문제

[해당 본문](../../01-02_CSS_우선순위와_상속.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

같은 요소에 `p {color:blue}`와 `.notice {color:red}`를 적용하고 최종 색을 예상하자.

**확인 기준:** 두 규칙이 모두 같은 요소에 맞는지 확인한 뒤, 어느 선언이 적용되는지 이유를 설명한다. 규칙의 순서만 바꾸어 다시 예상한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`<p class="notice">알림</p>`에는 두 선택자가 모두 맞는다. 중요도 조건이 같다면 클래스 선택자인 `.notice`가 태그 선택자인 `p`보다 구체적이므로 **빨강**이 적용된다. 두 규칙의 앞뒤를 바꿔도 이 비교는 같다. 부모에서 물려받은 색과 요소에 직접 선언한 색의 경쟁은 따로 판단한다.

</details>

## 원본으로 돌아가기

강사님·내 코드의 테두리 규칙도 “어느 요소가 선택되었는지”를 먼저 확인해야 했다. 우선순위를 숫자 암기로만 풀기보다 [본문의 원본 테두리 경쟁](../../01-02_CSS_우선순위와_상속.md)을 다시 설명해 보자.
