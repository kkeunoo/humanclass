# 14 CSS 미디어쿼리와 반응형 — 연습문제

[해당 본문](../../14_CSS_미디어쿼리와_반응형.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

뷰포트 너비가 600px 이하이면 두 칸을 한 칸씩 보이게 하는 미디어쿼리 조건을 적자.

**확인 기준:** 뷰포트가 601px, 600px, 599px일 때 어느 규칙이 적용되는지 먼저 표로 적는다. HTML의 부모 너비와 뷰포트 너비를 혼동하지 않는다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```css
.column { display: inline-block; width: 48%; }
@media (max-width: 600px) {
  .column { display: block; width: 100%; }
}
```
좁은 뷰포트에서 각 칸을 한 줄씩 놓는다. 컨테이너 너비 기준 확장은 본문 하단의 추가 설명에 둔다.

601px에서는 아래 미디어쿼리 조건이 거짓이고, 600px과 599px에서는 참이다. 다만 실제 두 칸 배치는 상자 여백·테두리·공백까지 함께 영향을 받으므로, 위의 48%는 새 연습 조건에서 시험하는 값이다.

</details>

## 원본과 연결하기

강사님·내 원본에도 600px 경계가 있다. 이 문제에서는 메뉴가 아니라 두 칸의 배치로 결과를 확인한다. 원본 메뉴가 완성된 모바일 메뉴인지 여부는 [본문 2절](../../14_CSS_미디어쿼리와_반응형.md)에서 별도로 읽자.
