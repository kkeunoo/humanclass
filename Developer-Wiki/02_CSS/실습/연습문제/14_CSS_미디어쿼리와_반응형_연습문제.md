# 14 CSS 미디어쿼리와 반응형 — 연습문제

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

뷰포트 너비가 600px 이하이면 두 칸을 한 칸씩 보이게 하는 미디어쿼리 조건을 적자.

**확인 기준:** `@media (max-width:600px)`에서 각 칸의 너비를 다시 지정한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```css
.column { display: inline-block; width: 48%; }
@media (max-width: 600px) {
  .column { display: block; width: 100%; }
}
```
좁은 뷰포트에서 각 칸을 한 줄씩 놓는다. 컨테이너 너비 기준 확장은 본문 하단의 추가 설명에 둔다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
