# 13 CSS Transform과 요소변형 — 연습문제

[해당 본문](../../13_CSS_Transform과_요소변형.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

상자를 오른쪽 20px 이동시키되 원래 문서 배치 자리를 유지하는 방법을 적자.

**확인 기준:** 상자의 보이는 위치와 다음 요소가 차지하는 위치를 함께 관찰한다. 두 위치가 같은 방식으로 움직이는지 설명한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`transform: translate(20px, 0)`은 상자를 오른쪽으로 보이게 옮긴다. 이는 양쪽 원본에서 사용한 `translate(가로, 세로)`의 값만 바꾼 것이다. 하지만 다음 요소가 배치될 때의 원래 흐름 자리는 유지된다. 따라서 화면에서 겹침이 생길 수 있다. `margin-left`는 실제 배치 간격을 바꾸므로 같은 방법이라고 설명하지 않는다.

</details>

## 원본과 연결하기

강사님·내 원본의 `translate`, `rotate`, `scale` 중 이 문제는 **translate의 한 축**만 쓴다. 숫자를 20px에서 -20px로 바꾸어 방향을 예상해 보자. `translate`가 다른 요소의 자리를 자동으로 밀어 주지는 않는다.
