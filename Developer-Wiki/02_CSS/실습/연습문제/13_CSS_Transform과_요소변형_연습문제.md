# 13 CSS Transform과 요소변형 — 연습문제

[해당 본문](../../13_CSS_Transform과_요소변형.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

상자를 오른쪽 20px 이동시키되 원래 문서 배치 자리를 유지하는 방법을 적자.

**확인 기준:** `transform:translateX(20px)`은 보이는 위치를 옮기지만 원래 흐름의 자리를 그대로 둔다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`margin-left`나 `left`와 결과가 같다고 단정하지 않는다. 기준과 레이아웃 영향을 비교한다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
