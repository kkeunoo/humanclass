# 09 CSS Overflow와 스크롤 — 연습문제

[해당 본문](../../09_CSS_Overflow와_스크롤.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

고정 높이 100px 상자에 긴 글을 넣고 `overflow:hidden`과 `auto`의 결과를 비교하자.

**확인 기준:** 콘텐츠가 실제로 상자의 높이를 넘는지 먼저 확인한다. 그다음 넘친 부분을 볼 수 있는 방법과 스크롤 표시를 각각 적는다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`overflow: hidden`은 상자 밖으로 넘치는 부분을 잘라 보여 준다. `overflow: auto`는 넘칠 때 스크롤 수단을 제공한다. 높이가 없거나 글이 짧아서 **넘치지 않으면** 두 선언의 차이가 눈에 안 보일 수 있다. 비교 전에 같은 너비·높이·내용을 유지한다.

</details>

## 원본과 연결하기

강사님·내 원본의 가로 항목 목록에서는 **가로로 넘치는지**가 질문이었다. 이 문제는 세로 100px 상자로 조건을 바꾼 새 연습이다. `overflow-x`와 `overflow-y`를 어느 쪽에 적용해야 할지 구분해 보자.
