# 03-02 CSS 마진과 가운데정렬 — 연습문제

[해당 본문](../../03-02_CSS_마진과_가운데정렬.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

너비 200px인 block을 부모 너비 600px에서 가운데 놓는 margin 선언을 적자.

**확인 기준:** 상자의 너비가 정해져 있는지, 남은 가로 공간이 얼마인지 계산한다. 세로 정렬까지 함께 일어나는지 확인한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`width: 200px; margin: 0 auto;`처럼 적는다. 부모 내용 너비가 600px이고 다른 가로 여백·테두리가 없다면 남은 400px이 양옆으로 200px씩 분배된다. 여기서 `0`은 위아래 마진이며 **세로 중앙 정렬은 아니다.**

</details>

## 조건 바꾸기

부모 너비를 500px로 바꾸면 남는 공간은 300px, 양쪽은 150px씩이다. 강사님·내 원본의 세로 마진 상쇄는 **서로 맞닿은 세로 마진**에 관한 현상이므로 이 가로 계산에 그대로 적용하지 않는다.
