# 03-02. 마진과 가운데 정렬 — 남는 공간과 맞닿는 간격 — 연습문제

[본문](../../03-02_CSS_마진과_가운데정렬.md) · [문제 목차](README.md)

이 파일은 실제 수업 기능을 바탕으로 **새로 구성한 연습문제**다. 강사님이 내주신 원본 퀴즈와 구분한다. 결과 예상 → 이유 설명 → 수정·검증 순서로 풀고, 각 정답은 먼저 생각한 뒤 펼친다.

## 목표와 실행 조건

일반 block의 가로 auto margin 조건과 계산을 설명한다. 형제 사이·부모 자식 사이 세로 마진 상쇄를 구별한다.

본문의 [전체 실행 파일](../책형_복습/03-02_CSS_마진과_가운데정렬.html)을 별도로 열어 실험한다. 아래 조각을 다른 원본 CSS에 그대로 덧붙이면 기존 규칙과 경쟁할 수 있다. 실험 전 원래 파일을 보존하고 매번 한 조건만 바꾼다. 브라우저에서 확인한 것과 코드 기준 예상을 따로 적는다.

## 문제 1. 작은 예제의 결과 예상

**새 설명 예제의 CSS와 body 조각**이다. 전체 파일은 위 링크에 있다. 어떤 요소가 선택되고 무엇이 어떻게 보일지 적는다. 크기가 있으면 내용·테두리 기준도 구분한다.

```css
        .parent { width: 500px; border: 1px solid black; }
        .child { width: 200px; margin: 10px auto; background-color: lightblue; }
        .first { margin-bottom: 30px; background-color: pink; }
        .second { margin-top: 50px; background-color: lightgreen; }
```

```html
    <h1>마진의 두 역할</h1>
    <div class="parent"><div class="child">가운데 상자</div></div>
    <div class="first">첫 상자</div>
    <div class="second">둘째 상자</div>
```

<details>
<summary>힌트와 풀이</summary>

**힌트:** 선택자 → 속성 → 기준값 → 상태 순서로 읽는다. 주석은 실행하지 않는다.

child는 별도 border·padding이 없어 테두리까지 200px다. 부모의 내용 영역 500px에서 남은 공간을 나눠 좌우 150px이다. 첫·둘째 상자 사이에서는 일반 block 흐름의 두 양수 세로 마진이 맞닿아 50px 간격을 예상한다. 부모 테두리 1px는 그 부모의 내용 500px 바깥이므로 정렬 기준 계산에 섞지 않았다.

</details>

## 문제 2. 비슷한 개념을 설명하기

1. 테두리까지250px인 block을 내용600px 부모에 가운데 놓으면 좌우는?
2. 양수 마진30·50이 상쇄되면?
3. text-align:center와 같은 기능인가?

숫자나 속성 이름만 적지 말고 왜 그런지 문장으로 설명한다. 필요한 전제도 함께 쓴다.

<details>
<summary>풀이와 원본으로 돌아갈 지점</summary>

각175px다. 두 양수 세로 마진은 해당 상쇄 조건에서50px다. 글·인라인 내용 정렬과 block 자체의 auto margin 정렬은 다르다.

실제 작성 기록에서 확인할 부분은 다음과 같다.

내 #auto는 width250·border1이어서 테두리까지 252px다. 강사님 width150은 테두리까지152px다. 같은 부모 너비라면 남는 공간이 달라지지만 둘 다 가운데를 유지하는 원리는 같다. 두 번째 발췌의 div2·div3은 30·50px 세로 마진을 비교하고, 부모 div1에는 overflow:hidden이 활성화되어 있다.

</details>

## 문제 3. 한 조건을 바꾸고 확인하기

먼저 **새 예제 child만 300px**를 적용했을 때의 차이를 예상한다. 예상한 뒤 실제 파일의 해당 선언 하나를 바꾸고 저장·새로고침하여 비교한다. 이후 나머지 변경도 한 번에 하나씩 실험한다. 전환·hover는 상태 변화 전후를, 너비 조건은 경계값을 구분한다.

<details>
<summary>변경 실험의 예상과 점검</summary>

| 한 가지 변경 | 예상 | 이유 |
| --- | --- | --- |
| 새 예제 child만 300px | 좌우100px | 남은200을 나눔 |
| 원래 child에 border1 추가 | 좌우149px | 실제너비202 |
| 원래 second 위만20px | 형제간격30px | 양수30·20 상쇄 |

원본 자식 사이 간격이 부모 overflow:hidden을 줘도50px라면 곧바로 CSS 미적용으로 판단하지 않는다. 어떤 두 요소 사이를 재고 있는지 먼저 확인한다. 좁은 화면의 넘침과 가운데 배치는 별도 조건이다.

</details>
