# 03-02 CSS 마진과 가운데정렬 — 연습문제

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

너비 200px인 block을 부모 너비 600px에서 가운데 놓는 margin 선언을 적자.

**확인 기준:** 남는 가로 공간 400px이 좌우에 200px씩 분배된다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`margin: 0 auto`와 지정한 너비가 함께 필요하다. 세로 중앙 정렬까지 된다는 뜻은 아니다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
