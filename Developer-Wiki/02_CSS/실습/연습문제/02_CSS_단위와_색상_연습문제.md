# 02 CSS 단위와 색상 — 연습문제

[해당 본문](../../02_CSS_단위와_색상.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모 글자 크기가 20px일 때 자식의 `font-size:1.5em` 값을 계산하자.

**확인 기준:** `em`이 기준으로 삼는 글자 크기를 먼저 적고 곱셈을 보여 준다. 같은 부모에서 `rem`을 사용했을 때도 무조건 같은 값인지 생각해 본다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

이 문제는 **자식의 `font-size`**를 계산하므로 부모의 20px이 기준이다. `20 × 1.5 = 30px`이다. `rem`은 문서 루트의 글자 크기를 기준으로 하므로, 루트 크기를 모르면 `1.5rem`의 픽셀값을 이 문제만으로 확정할 수 없다.

</details>

## 값을 바꾸어 보기

부모 글자 크기를 16px로 바꾸면 같은 `1.5em`은 24px이다. 강사님·내 원본의 `em`·`rem` 비교도 **숫자만 보지 말고 기준 요소를 찾는 연습**으로 읽는다. 색 값과 투명도는 [본문의 다음 절](../../02_CSS_단위와_색상.md)에서 별도로 확인한다.
