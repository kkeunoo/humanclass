# 02 CSS 단위와 색상 — 연습문제

[해당 본문](../../02_CSS_단위와_색상.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모 글자 크기가 20px일 때 자식의 `font-size:1.5em` 값을 계산하자.

**확인 기준:** 계산된 크기는 30px이다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`em`의 기준을 해당 속성의 부모 글자 크기에서 확인한다. `rem`의 기준과 섞지 않는다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
