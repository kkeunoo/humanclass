# 10 CSS Float와 Clear — 연습문제

[해당 본문](../../10_CSS_Float와_Clear.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

왼쪽으로 뜬 이미지 옆에 글을 흐르게 하고, 다음 제목부터 float 아래에 오게 하자.

**확인 기준:** 이미지 옆의 글 흐름과 다음 제목의 시작 위치를 따로 관찰한다. 부모의 높이가 자동으로 이미지까지 감싸는지도 확인한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

이미지에 `float: left`, 다음 제목에 `clear: both`를 적용하는 방법이 있다. float은 주변 내용이 옆으로 흐르게 하고, clear는 해당 요소가 float 옆으로 올라오지 않게 한다. **clear를 제목에 준다고 부모 높이 문제가 자동으로 모두 해결되는 것은 아니다.** 부모의 경계도 따로 확인한다.

</details>

## 원본과 연결하기

강사님·내 float 원본에는 부모 높이를 살피는 `clearfix`도 등장한다. 이 문제는 “다음 제목을 아래로 보내기”와 “부모가 자식을 감싸기”가 다른 요구라는 점을 확인하기 위한 새 연습이다.
