# 07 CSS 텍스트와 글꼴 — 연습문제

[해당 본문](../../07_CSS_텍스트와_글꼴.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모에 글꼴을 주고 자식에 다른 글자색을 지정한 뒤 무엇이 상속되고 덮이는지 설명하자.

**확인 기준:** 부모와 자식의 실제 중첩을 그린 뒤 글꼴과 색을 각각 어느 선언에서 얻는지 적는다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

부모에 `font-family: sans-serif; color: blue;`, 자식에 `color: red;`를 선언했다면 자식은 글꼴을 물려받고 색은 직접 지정한 빨강을 사용한다. 부모의 파랑과 자식의 빨강이 **같은 요소에 직접 선언된 경쟁**이라고 설명하면 안 된다. 모든 CSS 속성이 같은 방식으로 상속되지는 않는다.

</details>

## 원본과 연결하기

강사님·내 원본의 웹폰트 예제는 **폰트 등록**과 **요소에 폰트 사용**이라는 두 단계로 읽는다. 이 문제의 `sans-serif`는 상속을 확인하기 위해 새로 구성한 조건이다. 원본 웹폰트 파일 경로까지 자동으로 준비된 것은 아니다.
