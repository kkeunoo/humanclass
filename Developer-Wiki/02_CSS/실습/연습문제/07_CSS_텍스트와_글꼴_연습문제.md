# 07 CSS 텍스트와 글꼴 — 연습문제

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모에 글꼴을 주고 자식에 다른 글자색을 지정한 뒤 무엇이 상속되고 덮이는지 설명하자.

**확인 기준:** 부모 글꼴은 자식에 이어지고 자식의 직접 색 선언은 우선 적용된다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

실제 HTML 중첩을 먼저 확인한다. 모든 CSS 속성이 같은 방식으로 상속되지는 않는다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
