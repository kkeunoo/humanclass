# 04 CSS Display와 요소배치 — 연습문제

[해당 본문](../../04_CSS_Display와_요소배치.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

연속된 두 `div`를 한 줄에 놓되 각 상자에 너비를 주려면 어떤 display를 시험할지 적자.

**확인 기준:** 두 상자의 `display` 값을 바꾼 뒤 너비 지정과 줄 배치가 각각 어떻게 달라지는지 관찰한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`display: inline-block`을 두 상자에 준다. 각 상자에 `width`를 지정할 수 있고, 공간이 충분하면 한 줄에 놓인다. 다만 소스의 공백과 부모 너비 때문에 **항상 한 줄**이라는 보장은 없다. `inline`으로 바꿔 두 선언의 차이를 확인하자.

</details>

## 원본과 연결하기

강사님·내 display 실습에서도 `inline-block` 사이 공백이 결과에 영향을 줬다. 간격이 생기면 `margin`만 의심하지 말고 HTML에서 두 요소 사이의 줄바꿈·공백도 살펴본다. 이후 [종합실습](../../17_CSS_종합실습.md)에서 다시 연결한다.
