# 08 CSS Position과 요소위치 — 연습문제

[해당 본문](../../08_CSS_Position과_요소위치.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모를 위치 기준으로 삼아 자식을 부모의 오른쪽 위에서 10px 떨어뜨리자.

**확인 기준:** 자식의 위쪽·오른쪽 간격이 **무엇을 기준으로** 계산되는지 먼저 정한다. 부모의 크기와 위치를 바꾸었을 때 함께 이동하는지 본다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

부모에 `position: relative`, 자식에 `position: absolute; top: 10px; right: 10px;`를 준다. 이 경우 위치가 지정된 부모를 기준으로 자식을 놓는다. `right: 10px`을 무조건 화면 오른쪽에서 10px이라고 읽지 않는다.

</details>

## 원본과 연결하기

강사님·내 원본에서도 부모에 위치 기준을 주고 자식을 이동시켰다. 이 문제의 10px은 새 연습 값이다. `position: fixed`는 다른 기준으로 움직이므로 [본문 2절](../../08_CSS_Position과_요소위치.md)에서 스크롤과 함께 비교하자.
