# 08 CSS Position과 요소위치 — 연습문제

[해당 본문](../../08_CSS_Position과_요소위치.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

부모를 위치 기준으로 삼아 자식을 부모의 오른쪽 위에서 10px 떨어뜨리자.

**확인 기준:** 부모에 `position:relative`, 자식에 `position:absolute; top:10px; right:10px`를 둔다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

절대 위치 요소의 기준이 어느 조상인지 확인한다. `right`가 화면 오른쪽이라는 뜻은 아니다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
