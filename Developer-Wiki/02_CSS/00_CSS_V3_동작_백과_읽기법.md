# CSS를 읽는 법 — 선택한 요소와 바뀐 값 찾기

[CSS 목차](README.md) · [첫 장: 선택자](01_CSS_선택자와_적용방법.md)

CSS를 다시 읽을 때는 **규칙 한 덩어리에서 시작**한다. 다음은 수업 문법으로 만든 설명용 예제다.

```css
h2 {
    color: blue;
    font-size: 30px;
}
```

1. `h2`: 어떤 HTML 요소를 고르는가?
2. `color`, `font-size`: 그 요소의 어떤 부분을 바꾸는가?
3. `blue`, `30px`: 적용하려는 값은 무엇인가?
4. 브라우저에서 **어느 요소의 어떤 모습**이 달라졌는가?

값이 예상과 다르면 **CSS 파일 연결 → 선택자가 실제 HTML에 맞는지 → 다른 규칙과 충돌하는지 → 부모에서 물려받은 값인지** 순으로 확인한다. 충돌과 상속은 [01-02](01-02_CSS_우선순위와_상속.md)에서 다룬다.

강사님·내 원본 코드는 각 장에 표시되어 있다. 실습을 위해 새로 만든 코드는 **설명용 재구성**이라고 적는다. 기능 이름이 낯설더라도 먼저 수업 원본에서 확인된 동작을 익히고, 원본에 없던 확장은 해당 장의 **추가로 알면 좋은 것**으로 넘긴다.
