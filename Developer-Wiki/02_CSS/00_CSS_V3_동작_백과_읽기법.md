# CSS를 공부하고 다시 찾는 법

[CSS 목차](README.md) · [첫 장](01_CSS_선택자와_적용방법.md)

CSS는 ‘누구를 → 어떤 속성으로 → 무엇을 기준 삼아 → 어떤 상태에서 바꾸는가’ 순서로 읽는다. 결과만 외우기보다 같은 선언이 어떤 조건에서 다르게 보이는지 설명하는 것이 목표다.

## 1. 본문을 처음 읽는 순서

각 본문은 목표 → 개념 → 작은 전체 예제 → 내 원본 풀이 → 연결 → 평가 → 필요한 비교 → 결과·변경 → TIP·출처 → 복습의 열 절이다. 개념과 예제로 원리를 익힌 뒤 실제 원본을 판단한다. 강사님 인용은 이해에 필요한 차이에만 사용한다.

| 단계 | 던질 질문 |
| --- | --- |
| 선택 | 실제로 어느 HTML 요소에 맞는가? |
| 선언 | 속성 이름과 값이 유효한가? 주석 밖인가? |
| 기준 | 부모·자기·루트·뷰포트 중 무엇인가? |
| 경쟁 | 다른 규칙과 어떤 값이 경쟁하는가? |
| 결과 | 배치 크기·그림·자리·조작 중 무엇이 달라지는가? |

## 2. 원본·예제·학습 범위 구분

| 표기 | 의미 |
| --- | --- |
| 내 원본 발췌 | 실제 파일의 해당 행이다. 주석의 잘못된 표현도 보존하고 아래에서 교정한다. |
| 새 설명 예제 | 원리를 분리해 관찰하려고 새로 만든 코드다. 실제 수업 원본인 것처럼 읽지 않는다. |
| 개선안 | 요구사항에 맞춘 제안이며 원본 파일에 적용하지 않았다. |
| 📚 출처 | 이미 배운 기능의 뜻을 공식 자료로 확인한 근거다. |
| 💡 TIP | 수업 범위 밖 선택 학습이다. 본문 하단에 둔다. |
| 코드 기준 예상 | 조건을 놓고 계산한 값이다. 실제 화면 재실행 기록과 다르다. |

var·calc·vmin/vmax·font-display의 기본 사용은 실제 원본에 있어 본문이다. Grid·basis 명시 실험·새 선택자·전체 설계 체계는 추가 학습이다. BACKUP의 좋은 설명 방식은 참고하되 거기 있는 기능을 모두 배운 것으로 옮기지는 않는다.

## 3. 실행 조건을 먼저 맞추기

본문의 작은 예제는 내부 style을 포함한 전체 HTML로 제공한다. 먼저 별도로 열고 한 조건만 바꾼다. 원본에 CSS를 덧붙이면 기존 선택자·상속·단축 선언·뒤 선언과 경쟁해 결과가 달라질 수 있다.

외부 CSS는 HTML의 link href부터 확인한다. 외부 CSS의 상대 url은 CSS 파일 위치 기준이고, 내부 style의 상대 url은 문서 위치 기준이다. 이미지·글꼴이 로드되지 않는 문제와 배치 계산 오류를 구분한다.

원본의 주석 실험을 모두 동시에 켜지 않는다. 현재 활성값을 적은 뒤 후보 하나를 켜서 비교한다. 반응형은 경계 바로 아래·경계·바로 위를 보고, 전환은 진입·복귀를 따로 관찰한다.

## 4. 나중에 다시 찾는 순서

각 장 위 목차 → 끝의 빠른 표 → 작은 예제 → 내 원본 풀이 순으로 필요한 깊이까지 읽는다. [장별 문제](실습/연습문제/README.md)에서 예상·이유·수정을 해 보고 [종합실습](17_CSS_종합실습.md)에서 크기와 흐름을 연결한다.

문법·원본 대조·실제 화면·상호작용·자원 로드는 서로 다른 검사다. 실제 수행한 범위만 [검증 기록](../편집기록/02_CSS_최종_검증기록.md)에 남긴다.
