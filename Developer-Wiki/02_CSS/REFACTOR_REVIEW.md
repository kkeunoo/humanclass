# CSS 리팩토링 검토 기록

## 최종 결론

이번 판은 제목·목차만 바꾸지 않았습니다. 기존 상세 본문을 유지하면서 선택 대상, 값의 입력·기준, 처리 순서, 계산 결과, 실제 확인법을 보강하고 원본 대조에서 발견한 잘못된 계산을 직접 수정했습니다. 17개 주제는 기존 분류를 유지합니다.

## 실제 소스 비교에서 확인한 차이

- 01_selector: 중요한 border 우선순위 예제는 두 파일 같은 핵심 동작. 주석과 추가 설명을 실행 효과로 꾸미지 않았습니다.
- 02_단위: %·em·rem의 중첩 실험과 body 기준이라는 부정확한 설명을 대조했습니다.
- 03_box CSS: 내 #auto는250px, 강사님150px. 첫 .box에는 두 파일 모두 padding이 없고 .box-sizing에만50px가 있습니다.
- 04: 내04_display와 강사님04_dispaly의 실제 이름을 구분했습니다. 외부 CSS 이름은 둘 다04_display입니다.
- 05: 살아 있는 opacity는 두 파일 모두0. 주석0.3·0.7은 현재 결과 차이가 아닙니다.
- 06: contain·cover·fixed·축약과 후속 size를 실제 선언 순서대로 읽었습니다.
- 07: 서로 다른 웹폰트와 자간0em/-0.1em, 공통 p/div 오류, 굵기2000 무효를 설명했습니다.
- 08: submenu top은 내1px/강사님-1px. 공통 sticky의 마지막top50px와 position 메모를 대조했습니다.
- 09: 내width130px/강사님100px, 문장 내용 차이를 기록했습니다.
- 10: 공통 clearfix·기사이미지float:right와 내 추가 .coup 규칙을 확인했습니다.
- 11: gray/grey는 같은 회색. cursor:pointer가 클릭 기능을 만들지 않음을 설명했습니다.
- 12: 내background 축약/강사님background-color, hover에만 transition이 있는 공통 문제를 구분했습니다.
- 13: total의 내scaleX/강사님scale 차이, 다른 실제 파일명, 공통border1px를 확인했습니다.
- 14: 핵심 코드가 같은 원본에 가짜 차이를 만들지 않았습니다.
- 15: 공통 order·shrink·min-width 조건과 직접 자식 구조를 기준으로 설명했습니다.
- 내 추가 실습 연습_01.css의 sold→solid 사례는 강사님 동일 파일 비교가 아니라 사용자 코드의 선언 오타로 표시했습니다.

## 보존 검증

기존 17개 본문의 번호형 대단원1019개가 같은 순서로 남는지 확인했습니다. 원본 읽기법과 본문의 CSS·HTML·JavaScript 코드 블록1944개가 내용·순서를 유지하는지 대조했습니다. 코드 블록 전체2390개 중 계산 오류를 고친 text 결과 블록2개는 의도적 수정으로 별도 기록했습니다. 기존 실습·정답·단계 설명은 유지했고 학습 목표만 간결하게 정리했습니다.

목차 앵커·내부 링크·울타리 쌍·깨진 문자를 검사했습니다. 다른 파트로 가는 README 링크는 전체 Developer-Wiki에 설치할 때 연결됩니다. 원본 소스 파일과 최신 ZIP은 수정하지 않았습니다.

## 숫자와 결과 검사

별도 실행 검사에서302·198·51·149, 중첩 글자54, grow예제87.5/125/87.5, order시각순서3/1/4/5/2를 대조했습니다. 이는 제시한 가정에 대한 산술·정렬 검증입니다. 실제 브라우저의 모든 배치값을 실측한 결과라고 주장하지 않습니다.

각 주제의 Console 명령에는 실행할 파일, 필요한 상태, 예상 결과와 한계를 적었습니다. 계산된 스타일·변환 후 표시 경계·스크롤 영역을 같은 측정값처럼 혼용하지 않았습니다.

## 초보자·숙련자 관점으로 다시 검토한 결과

초보자 관점에서는 용어 정의 다음에 필요한 이유와 소스 연결을 두고, 작은 발췌를 계산·결과·확인 문제로 이어 읽을 수 있게 했습니다. 숙련자 관점에서는 예외 조건, 기본값, 선언 유효성, 원본과 재현 실험 차이를 검사했습니다. 계산과 요약이 모순되는 부분은 본문까지 다시 고쳤습니다.

전구는 수업 밖 진단API·설계·재현 예제에 사용하고 장식 제목은 늘리지 않았습니다. 16 실무 기준과17 통합 프로젝트는 모든 코드가 원본 강의에 그대로 있다는 오해를 막도록 확장 범위를 표시했습니다. 큰 완성 코드는 마지막 대조 자료이며 작은 설명을 대신하지 않습니다.

## 검증 한계와 다음 단계

현재 환경에 실행 가능한 테스트 브라우저가 없어 실제 화면 렌더링, 모든 Console 결과, 키보드·스크린 리더 동작 전부를 확인하지 못했습니다. 외부 이미지·웹폰트 성공도 보장하지 않습니다. 학습자가 직접 검증할 절차와 조건을 제공했고 전체 브라우저 검증 완료라고 표시하지 않았습니다.

이번 전달은 CSS만입니다. 사용자 확인 후 JavaScript를 진행합니다. 용어색인·전체 README와 파트 간 일관성은 모든 파트가 완료된 뒤 재검토합니다.
