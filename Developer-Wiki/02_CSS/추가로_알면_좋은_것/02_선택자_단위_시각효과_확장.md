## 1. 선택 조건과 상호작용

| 기능 | 기본 선택자 이후에 생기는 질문 |
| --- | --- |
| :is() | 여러 선택 조건을 한 곳에서 묶고 싶을 때 |
| :where() | 묶은 조건의 명시도를 0으로 다루고 싶을 때 |
| :has() | 관계를 만족하는 요소의 존재에 따라 대상을 고를 때 |
| :focus-visible | 브라우저가 포커스 표시가 필요하다고 판단한 상태를 표현할 때 |
| pointer-events | 포인터 대상 처리와 키보드 포커스를 구분할 때 |
| inert·aria-hidden | CSS 표시 외에 조작·접근성 의미를 다룰 때. HTML·접근성의 별도 학습 필요 |

```css
/* 추가 예제: 실제 button 요소의 키보드 포커스 표현 */
.action:focus-visible {
    outline: 3px solid #185abc;
    outline-offset: 3px;
}
```

focus-visible을 “Tab을 눌렀을 때만”이라는 단일 조건으로 외우지 않는다. 기본 :focus와 목적을 비교한다. 포커스 표시를 제거하고 대체 표시도 주지 않는 방향으로 사용하지 않는다. [선택자 표준](https://www.w3.org/TR/selectors-4/#the-focus-visible-pseudo)

## 2. 크기·방향·색의 확장

| 기능 | 역할과 주의 |
| --- | --- |
| ch·lh | 글꼴의 문자 폭·줄 높이와 연결되는 길이. 항상 한 글자의 실제 폭과 같다고 단정하지 않음 |
| svh·lvh·dvh | 브라우저 UI 변화에 따른 뷰포트 높이 기준을 나누어 검토 |
| clamp | 최소·선호·최대 값을 함께 제한 |
| margin-inline·padding-block 등 | 물리적 좌우·상하 대신 쓰기 방향의 축으로 표현 |
| 색상 토큰·다크 모드 | 배경·글자·경계·상태 색을 함께 설계 |

```css
/* 추가 예제: 최소 1rem, 선호 2vw, 최대 1.5rem */
.fluid-text { font-size: clamp(1rem, 2vw, 1.5rem); }
```

수업의 calc·vmin/vmax·CSS 변수는 [단위](../02_CSS_단위와_색상.md)와 [position](../08_CSS_Position과_요소위치.md)에 있다. 변수를 사용했다고 디자인 토큰·다크 모드 전체를 배운 것은 아니다. [단위 표준](https://www.w3.org/TR/css-values-4/)

## 3. 배경·그림자·움직임 확장

```css
/* 추가 예제: x, y, blur, spread, 색 */
.raised { box-shadow: 0 4px 8px 2px #0003; }
```

여기서 2px는 spread다. 기본편의 원본은 세 길이만 있어 spread를 직접 실험한 코드로 보지 않았다. spread는 그림자 범위를 확장·축소하는 값이고 blur는 흐림이다. 둘은 다르다. [그림자 표준](https://www.w3.org/TR/css-backgrounds-3/#box-shadow)

| 기존 확장 주제 | 분리해 학습할 내용 |
| --- | --- |
| 다중 배경·gradient·origin/clip | 여러 층의 순서, 배경을 계산하고 칠하는 영역 |
| inset·다중 그림자 | 안쪽 그림자와 여러 그림자의 합성 |
| 3D 변환·개별 transform 속성 | 좌표·순서·기준의 추가 규칙 |
| transition delay·timing function | 전환 시작 지연과 진행 속도 |
| will-change·이벤트 | 성능 힌트와 JavaScript 동작. 무조건 붙이는 최적화가 아님 |
| prefers-reduced-motion | 사용자의 움직임 감소 선호를 반영하는 조건 |
| overflow:clip·overscroll-behavior | 잘림·스크롤 연결의 추가 제어 |

## 4. BACKUP의 글자·폰트 확장

pre·pre-wrap·pre-line, keep-all, 여러 줄 말줄임, writing-mode·direction, user-select는 각각 공백·줄바꿈·쓰기 방향·선택 정책을 다룬다. 본문은 원본의 nowrap·word-wrap·break-all·한 줄 ellipsis를 중심으로 읽는다.

폰트 굵기별 등록·가변 폰트·사전 로드·파일 분할·배포 최적화는 후속 주제다. 원본의 `font-display:swap` 기본 역할을 이 심화 묶음에 숨기지 않는다.
