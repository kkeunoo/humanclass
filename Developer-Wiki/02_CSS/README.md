# CSS Developer-Wiki

선택자와 속성 이름을 기억하는 요약집이 아니라, 수업 코드를 다시 읽고 계산·배치·상태 변화를 재현할 수 있는 상세 학습 문서입니다.

## 학습 목표

- 선택 대상과 속성의 의미를 설명한다.
- 계산 기준과 배치 흐름을 추적한다.
- 결과를 예측하고 오류를 수정한다.

## 이번 판에서 다시 설명한 내용

- 선택자 매칭→속성별 후보→캐스케이드→값 계산→배치·표시
- 부모·루트·뷰포트·변환 참조 박스를 구분한 단위 계산
- content-box/border-box와 원본 실제 padding·border의 차이
- display와 HTML 의미, 선언이 있어도 배치에 적용되지 않는 경우
- 보임·자리·클릭·포커스·접근성 상태의 차이
- CSS 파일 기준 이미지 URL, cover/contain의 크기 계산
- 웹폰트 요청과 실제 글꼴, DOM 보정이 상속에 미치는 영향
- containing block·정상 흐름·sticky·stacking context
- overflow 측정, float과 clear의 흐름, 그림자와 박스 크기
- transition 전후 상태와 보간, transform 참조 크기·합성
- 미디어 조건 경계와 터치 메뉴, flex 축·order·공간 분배

## 수업과 확장 학습

01~15는 사용자·강사님의 번호형 HTML과 연결된 CSS를 직접 비교합니다. 16 실무 설계와 17 통합 대시보드에는 💡 확장 학습이 포함됩니다. BEM·Grid·레이어 등 보충 지식을 수업에서 모두 그대로 사용했다고 소개하지 않습니다.

원본 파일명도 정확히 구분합니다. 내 04_display.html과 강사님 04_dispaly.html, 내 13_tranform.html과 강사님 13_transform.html은 서로 다른 실제 이름입니다. 문서 작업으로 원본 파일을 바꾸지 않았습니다.

## 반복 학습 순서

1. 속성이 무엇인지, 왜 필요한지 읽습니다.
2. 어떤 요소가 선택되는지 소스에서 찾습니다.
3. 계산 기준과 예상 크기·위치·상태를 기록합니다.
4. 파일을 열어 Styles·Computed·Box Model·Console에서 확인합니다.
5. 원본과 개선 예제의 차이를 이유와 함께 설명합니다.
6. 실습 문제를 먼저 풀고 정답·해설을 확인합니다.

큰 통합 코드는 마지막 대조 자료입니다. 코드 전체를 복사해 보이는 결과만 확인하지 말고 작은 발췌의 동작부터 연결합니다. 단위·크기·글꼴·스크롤바 결과는 전제 조건을 함께 읽습니다.

## 실습 전 확인

외부 CSS 요청이 성공했는지 먼저 확인합니다. 이미지·웹폰트·외부 서비스는 파일과 응답이 필요하며 예제만으로 성공을 보장하지 않습니다. Console 명령은 💡 JavaScript 진단법으로, CSS 파일에 붙이는 문법이 아닙니다.
