# 02. CSS — 실제 수업 코드로 읽기

**실제 학습한 내용이 메인이다.** 개념과 작은 전체 예제를 익힌 뒤 내 원본을 풀어 읽고, 필요한 차이만 강사님 코드와 비교한다. 선택 → 크기 계산 → 배치 → 상태 변화 순서로 결과와 이유를 설명한다.

[CSS를 읽는 네 가지 질문](00_CSS_V3_동작_백과_읽기법.md)으로 **선택한 요소 → 바뀐 속성 → 값 → 실제 결과**를 먼저 정리한다. 각 장에서는 짧은 설명용 예제로 원리를 잡고, 개념 → 작은 예제 → 내 원본 풀이 → 평가·필요한 비교 → 결과·복습으로 확인한다. 발췌의 경로·행 번호는 제공된 수업 코드 기준이다. 잘못된 주석·코드도 원문을 보존하고 설명에서 교정한다. 주석 처리된 실험은 현재 실행되는 코드와 구분한다.

- [학습 카드 확장 프로젝트](17_CSS_종합실습.md#extra-04-1): 기본 복습 이후 선택하는 작은 프로젝트.

각 장 끝의 **추가로 알면 좋은 것**은 기본 복습의 필수 조건이 아니다. 기존 Wiki·BACKUP에만 있다는 이유로 수업 범위로 넣지 않는다. 반대로 vmin/vmax·calc·CSS 변수·font-display의 기본 사용은 실제 원본에 있으므로 본문에 남겼다.

## 실행하고 다시 찾기

Markdown의 코드는 실행 화면이 아니다. 조각 코드는 해당 HTML·CSS 위치에 넣고, 전체 HTML은 파일로 저장하여 브라우저에서 연다. 원본 CSS의 여러 연속 선언은 마지막으로 유효하게 적용되는 값을 읽으며, 주석을 한 번에 모두 켜지 않는다.

- [실습 폴더와 본문 17장별 연습문제](실습/README.md)
- [수업 기반 display 복습 HTML](실습/display_복습.html)
- [추가 학습 카드 HTML](실습/학습카드_추가실습.html)
- [최종 개편·검증 기록](../편집기록/02_CSS_최종_검증기록.md)

| 막힌 질문 | 돌아갈 곳 |
| --- | --- |
| CSS 파일은 있는데 적용이 안 된다 | 01 선택자·적용 방법 → 01-02 우선순위 |
| 상자가 계산보다 크다 | 03 박스 모델 → 04 display |
| 간격·스크롤·위치가 이상하다 | 03-02 마진 → 08 position → 09 overflow |
| 안 보이는데 클릭이나 자리가 남는다 | 05 숨김 → 14 원본 메뉴의 한계 |
| Flex 정렬이 예상과 다르다 | 15의 주축·교차축과 주석 실험 조건 |

옛 파일명과 색인 주소는 이동 안내를 통해 찾아갈 수 있다. 다른 과목으로 이어 읽을 때는 [전체 Wiki 첫 화면](../README.md)과 [통합 용어색인](../99_Developer-Wiki_통합_용어색인.md)을 사용한다.

## 책형 개편의 활용

본문은 공통 10절, 종합실습은 과제·힌트·정답·추적의 8절, 문제는 예상·설명·수정의 흐름이다. [읽기 안내](00_CSS_V3_동작_백과_읽기법.md)에서 표기를 확인하고 [장별 전체 파일](실습/README.md)을 함께 사용한다. 원본 주석의 표현은 그대로 보존하되 교정 설명까지 읽는다. 실제 오류·수업용 단순화·설계 선택을 나누고, 실제 실행과 코드 기준 예상을 구별했다. 다음은 [JavaScript](../03_JavaScript/README.md)다.
