# 03-02. 마진 — 간격을 더했는데 왜 80px가 아닐까

[CSS 목차](README.md) · [박스 크기 계산](03_CSS_박스모델.md)

**마진**은 상자 테두리 바깥의 간격이다. 예를 들어 부모의 내용 너비가 500px이고 상자 너비가 200px일 때 `margin: 0 auto`를 주면 남은 가로 공간 300px이 좌우에 150px씩 배분된다. 이것은 **설명용 계산**이며 아래 원본의 상자 너비 150px·250px과 구별한다. 세로 마진은 같은 방식으로 항상 더해지지 않으므로 2절에서 따로 본다.

## 1. 가로 가운데 정렬

### 강사님 코드

`asset/css/03_box.css` 86~92행 — **원본 발췌**

```css
#auto {
    border: 1px solid red;
    width: 150px;

    /* margin: 0 auto; */
    margin: 10px auto;
}
```

일반 흐름의 block에서 사용할 너비가 정해지고 부모에 여유 공간이 있으면, 좌우 auto margin이 남는 공간을 나누어 가진다. 위아래는 10px다.

### 내 코드

`asset/css/03_box.css` 93~100행 — **원본 발췌**

```css
#auto {
    border: 1px solid red;
    width: 250px;

    /* margin: auto는 너비가 100%가 아닌 경우에만 가능함(100%일 경우에는 꽉 차있기 때문에) 
    위, 아래는 auto가 먹지 않기 때문에 0 auto로 기재한 것, 사이즈를 조절해도 가운데 고정 */
    margin: 10px auto;
}
```

원리는 같고 너비만 250px다. 내 주석의 “위아래 auto가 먹지 않는다”는 이 일반 block 배치에 한정해 읽는다. 다른 배치 방식까지 모두 불가능하다는 뜻은 아니다. 글자 자체를 가운데 놓는 `text-align:center`와 상자 자체의 가운데 정렬도 구분한다.

## 2. 세로 마진 상쇄

### 강사님 코드

`asset/css/03_box.css` 127~140행 — **원본 발췌**

```css
#div2, #div3{
    margin: 30px;
}
#div3 {
    margin: 50px;
}

#div1{
    /* border: 1px solid red; */

    /* padding-top: 1px; */

    overflow: hidden;
}
```

div2의 아래 margin은 30px, 다음 div3의 위 margin은 50px다. 일반 block 흐름에서 두 양수 세로 마진이 맞닿아 상쇄되면 간격은 80px가 아니라 큰 값인 50px가 된다.

### 내 코드

`asset/css/03_box.css` 139~153행 — **원본 발췌**

```css
#div2, #div3 {
    margin: 30px;
}

#div3 {
    margin: 50px;
}

#div1 {
    /* border: 1px solid red; */

    /* padding-top: 1px; */

    overflow: hidden;
}
```

선언은 같다. 부모 `#div1`의 `overflow:hidden`은 부모와 첫·마지막 자식 사이의 마진 상쇄를 막는 효과가 있다. **자식 div2와 div3 사이의 상쇄까지 전부 없애는 것은 아니다.**

| 관찰할 경우 | 읽는 방법 |
| --- | --- |
| 양수 세로 margin 30과 50 | 조건이 맞아 상쇄되면 50 |
| 부모와 첫 자식 | border·padding·내용 등으로 분리되는지 확인 |
| 가로 margin | 같은 방식의 마진 상쇄가 아님 |
| 음수 마진이 섞임 | 무조건 큰 값 하나라는 규칙으로 계산하지 않음 |

원본에서 주석 처리한 `padding-top:1px`, border, 콘텐츠 삽입은 각각 어떤 경계를 만드는지 관찰하는 실험이다. 모든 실험을 한 번에 켜면 원인을 구분하기 어렵다. `overflow:hidden`은 넘친 내용을 잘라낼 수도 있으므로 간격 문제에 항상 붙이는 해결책으로 외우지 않는다. [마진 상쇄 표준](https://www.w3.org/TR/CSS2/box.html#collapsing-margins)

<a id="section-3"></a>

## 복습

부모에 overflow:hidden이 있는데 자식 사이가 여전히 50px다. 속성이 적용되지 않은 것일까?

<details>
<summary>해설</summary>

그렇게 단정할 수 없다. 부모·자식 사이와 형제 사이의 상쇄는 서로 다른 관계다. 실제 부모 경계와 자식 사이 간격을 따로 확인한다.

</details>

**추가로 알면 좋은 것:** `display:flow-root`와 전체 서식 맥락 이론은 수업의 관찰 이후에 별도로 학습한다.
