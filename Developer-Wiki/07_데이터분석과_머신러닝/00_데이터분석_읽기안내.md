# 데이터 분석·머신러닝 읽기 안내 — 값의 모양과 평가 대상을 따라가기

[단원 목차](README.md)

## 1. 먼저 물을 것

한 행이 무엇인가? 정답을 누가 어떻게 만들었는가? 모델에 들어가는 열에 답이 남아 있는가? 이 세 질문에 답한 다음 학습으로 넘어간다. API의 요청·응답을 읽던 것처럼 여기서는 입력·학습 상태·예측·평가의 길을 읽는다.

## 2. 공통 흐름

| 단계 | 확인 |
| --- | --- |
| 표 | 파일·구분자·행·열·자료형 |
| 문제 정의 | quality 7 이상을 good=1로 정함 |
| 준비 | 입력 X·정답 y·짝인 분할 |
| 학습 | 학습 부분만 fit |
| 예측 | 같은 입력 열·행당 결과·클래스 순서 |
| 평가 | 실제 정답·클래스 답·양성 점수 |
| 선택 | 학습 부분의 교차 검증·후보 비교 |
| 마지막 시험 | 선택에 안 쓴 부분의 별도 평가 |

## 3. 예제·원본·결과 구분

본문 3절은 필요한 파일을 모두 제공한 새 예제다. 본문 4절은 출처와 행 번호가 있는 내 원본이며 바로 풀이를 붙였다. 원본의 과거 수치와 지금 재실행한 결과는 다를 수 있다. 강사님 코드는 차이가 도움이 될 때만 인용한다. 가상 데이터와 실제 CSV를 같은 실험으로 묶지 않는다.

## 4. 복습과 이후의 나

각 장의 결과를 먼저 예상하고 한 가지만 바꾼다. 잘못된 답은 정의·표·추적 흐름으로 돌아가 이유를 고친다. 실력이 늘면 스타일의 기록 표와 TIP을 확장할 수 있다. 당시 배운 모델과 나중에 추가한 절차를 명시하면 취업 뒤에도 실험의 범위를 다시 판단할 수 있다.
