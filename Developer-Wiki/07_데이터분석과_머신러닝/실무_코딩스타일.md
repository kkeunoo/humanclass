# 데이터 분석 실무 코딩스타일 — 와인 실습의 입력과 평가를 다시 읽기

[단원 목차](README.md) · [종합실습](종합실습.md)

강사님·내 `06_scikit_learn/01_main.py`의 같은 CSV와 코드에서 확인한 흐름을 **새 점검 자료**로 정리했다. 별도 실무 프로젝트를 실제로 배웠다는 뜻이 아니다.

## 1. CSV의 모양과 정답 기준을 먼저 고정하기

두 원본은 `pd.read_csv(..., sep=';')`로 1,599행·12열 CSV를 읽고 `head(3)`, `shape`, `info()`를 확인한다. `quality >= 7`을 `good`의 0·1 값으로 만들며, `X`에서는 `quality`와 `good`을 제외한다. 이 순서를 바꾸거나 정답 열을 `X`에 남기면 모델이 답을 입력에서 보게 된다. [01장 원본 비교](01_Pandas_와인데이터와_학습입력.md)에 두 코드가 있다.

```python
# 수업의 핵심 순서를 재구성한 설명용 조각
data_frame['good'] = (data_frame['quality'] >= 7).astype(int)
y = data_frame['good']
X = data_frame.drop(columns=['quality', 'good'])
```

이 조각은 `data_frame`을 읽어 둔 뒤의 일부다. **`X` 11열, `y` 1열**이라는 관계를 먼저 점검한다.

## 2. 학습·예측·평가의 대상 구분하기

[02장](02_RandomForest_학습과_예측.md)에서는 `fit`, `predict`, `predict_proba`가 서로 다른 역할을 한다. [03장](03_평가와_교차검증.md)의 F1·ROC AUC·교차 검증·GridSearchCV도 각각 무엇을 평가하고 비교하는지 구분한다. 내 주석과 실제로 전달한 인자가 다를 때는 **실행되는 인자**를 기준으로 기록한다.

| 확인 항목 | 스스로 물을 질문 |
| --- | --- |
| CSV | 구분자와 행·열 수가 맞는가? |
| 정답 | `good`의 기준은 7 이상인가? |
| 입력 | `quality`, `good`을 제외했는가? |
| 평가 | 예측 결과와 정답을 같은 분할에서 비교하는가? |
