# 03 평가와 교차검증 — 연습문제

[원본 비교 본문](../../03_평가와_교차검증.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

F1, ROC AUC, 교차 검증, GridSearchCV는 모두 같은 일을 하는가?

<details>
<summary>정답과 확인할 점</summary>

F1·ROC AUC는 평가 값이고, 교차 검증은 분할을 바꿔 평가하며, GridSearchCV는 지정한 조합을 비교한다. 원본의 점수를 고정 정답으로 외우지 않는다.

입력→처리→결과의 실제 원본 사례는 [본문](../../03_평가와_교차검증.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
