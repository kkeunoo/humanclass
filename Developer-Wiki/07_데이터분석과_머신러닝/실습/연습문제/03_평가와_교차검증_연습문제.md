# 03 평가와 교차검증 — 연습문제

[원본 비교 본문](../../03_평가와_교차검증.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. F1과 ROC AUC에 각각 어떤 예측 값을 넣는가? `[:, 1]`은 무엇을 고르는가?
2. 현재 실행되는 `cross_val_score`에는 `X, y`와 `X_train, y_train` 중 무엇을 주는가? `scores.mean()`은 어떤 평균인가?
3. `GridSearchCV`의 후보는 총 몇 조합인가? 강사님과 내 코드에서 실제 실행되는 `cv` 값은 각각 얼마인가?
4. 마지막 `StratifiedKFold`가 전체 `X, y`를 사용한 점수를 독립된 시험 점수로 설명하기 어려운 이유는?

<details>
<summary>정답과 확인할 점</summary>

1. F1에는 실제 정답과 `predict`의 0·1 결과, ROC AUC에는 실제 정답과 `predict_proba(X_test)[:, 1]`의 클래스 1 확률을 준다. `[:, 1]`은 모든 행의 두 번째 열을 고른다.
2. 현재 줄은 **`X_train, y_train`**을 사용한다. `scores.mean()`은 분할별 F1의 평균이며 `X_test`의 최종 점수가 아니다.
3. 2개 나무 수 × 3개 깊이 = **6조합**이다. 강사님은 `cv=3`, 내 코드는 주석 처리한 3이 아니라 실제 실행하는 **`cv=5`**다.
4. 전체 `X, y`에는 앞서 시험용으로 떼어 둔 행도 들어 있다. 따라서 그 검증 점수를 ‘건드리지 않은 시험 세트만의 최종 평가’라고 부를 수 없다.

입력→처리→결과의 실제 원본 사례는 [본문](../../03_평가와_교차검증.md)에서 확인한다.

</details>
