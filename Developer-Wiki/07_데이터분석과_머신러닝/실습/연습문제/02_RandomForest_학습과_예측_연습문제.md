# 02 RandomForest 학습과 예측 — 연습문제

[원본 비교 본문](../../02_RandomForest_학습과_예측.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

학습에 `fit`을 쓴 뒤 새 행의 분류와 확률을 각각 어느 호출로 얻는가?

<details>
<summary>정답과 확인할 점</summary>

`predict`는 분류 결과, `predict_proba`는 클래스별 확률을 돌려준다. 입력 열 구성은 학습 때와 맞춰야 한다.

입력→처리→결과의 실제 원본 사례는 [본문](../../02_RandomForest_학습과_예측.md)에서 확인한다.

</details>

## 추가로 알면 좋은 것

본문에 없는 기능을 추가했다면 실제 수업 구현과 구별해 기록한다. 외부 서비스의 실제 응답이나 미완성 코드를 성공 사례로 가정하지 않는다.
