# 02 RandomForest 학습과 예측 — 연습문제

[원본 비교 본문](../../02_RandomForest_학습과_예측.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 시험이나 내 당시 구현 코드가 아니다. 본문의 강사님 코드와 내 코드를 읽고 답을 예상한다. 외부 DB·API를 실제로 호출하지 않아도 풀 수 있다.

## 문제

1. `n_estimators=100`과 `random_state=42`는 각각 무엇을 정하는가? 나무 수만 늘리면 정확도가 반드시 좋아지는가?
2. `fit`에는 어느 변수 쌍을 주는가? 새 와인 한 개의 측정값 11개를 왜 `[[...]]`로 묶는가?
3. 새 와인의 0·1 분류와 클래스별 확률은 각각 어느 호출로 얻는가? `[[0.59, 0.41]]`은 어떤 순서로 읽는가?

<details>
<summary>정답과 확인할 점</summary>

1. `n_estimators`는 결정나무 개수, `random_state`는 무작위 선택을 되풀이할 때의 설정이다. 나무 수를 늘려도 점수가 항상 오르지는 않는다.
2. `fit(X_train, y_train)`으로 학습한다. 새 와인 한 개도 표에서는 **1행 11열**이므로 바깥 리스트로 행을 묶는다.
3. `predict`는 0·1 분류 배열, `predict_proba`는 클래스별 확률의 2차원 배열이다. 클래스 순서가 0·1이면 예시의 0.59는 0 쪽, 0.41은 1 쪽이다. 숫자는 원본의 기록 예시이며 새 실행의 정답은 아니다.

입력→처리→결과의 실제 원본 사례는 [본문](../../02_RandomForest_학습과_예측.md)에서 확인한다.

</details>
