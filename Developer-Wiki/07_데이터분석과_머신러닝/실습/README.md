## 2. 실행 조건

pandas·scikit-learn이 필요하다. 각 장의 폴더에서 example.py를 실행한다. CSV를 쓰는 장은 같은 위치의 파일을 빠뜨리지 않는다. 여기의 확인은 기존 수업 환경 pandas 3.0.5·scikit-learn 1.9.1에서 별도 임시 폴더로 수행했다. 다른 환경에서 마지막 소수점이나 모델 출력이 같다고 보장하지 않는다.

## 3. 확인 범위와 복습

원본 양쪽 CSV의 모양·정답 비율·분할을 확인하고 실제 원본도 사본으로 실행한다. 학생은 LF, 강사님은 CRLF 줄바꿈이어서 파일 바이트 해시는 다르지만 읽은 표의 값·순서는 같다. 결과는 원본 주석의 옛 기록과 구별한다. 가상 표의 성공은 실제 와인 품질 보장이 아니다. 막히면 출력보다 앞의 입력 열·행·정답·분할부터 확인한다. D 드라이브 원본과 패키지를 변경하지 않는다.
