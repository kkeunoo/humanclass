# 와인 품질 분류 종합실습 — 표에서 평가까지 추적하기

[단원 목차](README.md) · [장별 연습문제](실습/연습문제/README.md)

강사님·내 `01_main.py`의 **실제로 배운 흐름**을 종이에 다시 잇는 새 복습이다. 원본과 다른 모델이나 새로운 데이터셋을 요구하지 않는다. 라이브러리 환경과 실행 경로가 맞지 않으면 발췌를 그대로 실행하지 않고 각 장의 원본과 비교한다.

## 문제

1. CSV 한 행이 뜻하는 대상과 원본의 행·열 수를 적는다.
2. `quality` 7 이상이면 `good=1`, 아니면 0으로 만드는 식을 쓴다.
3. `X`와 `y`에 각각 무엇을 넣고, `X`에서 두 열을 왜 빼는지 설명한다.
4. 학습·시험 분리 후 `fit`에 넣을 것과 `predict`에 넣을 것을 구분한다.
5. F1·ROC AUC·교차 검증 결과가 **어떤 환경에서 나온 값인지** 확인하고, 주석의 숫자를 고정 정답으로 쓰지 않는다.

<summary>확인 표 — 먼저 직접 채운 뒤 펼치기</summary>

| 단계 | 이 수업에서 확인한 값 또는 동작 |
| --- | --- |
| 입력 표 | 세미콜론 구분 빨간 와인 CSV, 1,599행·12열 |
| 새 정답 | `good = (quality >= 7).astype(int)` |
| 학습 입력 | `quality`와 `good`을 제외한 11개 측정 열 |
| 학습 | 분리한 학습 입력과 학습 정답으로 `fit` |
| 예측 | 시험 입력 또는 같은 형태의 새 와인을 `predict`·`predict_proba`에 전달 |
| 평가 | 시험 정답과 예측을 비교; 교차 검증·조합 탐색은 [03장](03_평가와_교차검증.md)에서 별도 확인 |

</details>

실제 코드 비교는 [01 CSV와 정답](01_Pandas_와인데이터와_학습입력.md) → [02 학습과 예측](02_RandomForest_학습과_예측.md) → [03 평가](03_평가와_교차검증.md) 순서로 돌아간다. **성공 기준**은 모델 점수 재현이 아니라 입력·정답·예측·평가의 대상이 뒤섞이지 않도록 설명하는 것이다.

## 추가로 알면 좋은 것

운영 중 재학습, 모델 저장·배포, 다른 알고리즘 비교는 이 원본 파일의 구현 범위가 아니다.
