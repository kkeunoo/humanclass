# HTML 목록과 표

## 학습 목표

- 순서 있는 목록과 순서 없는 목록을 작성할 수 있다.
- 표의 행과 열 구조를 설명할 수 있다.
- 제목 셀과 데이터 셀을 구분할 수 있다.

## 왜 배우는가

목록은 반복되는 항목을 의미 있게 묶고, 표는 행과 열로 비교 가능한 데이터를 표현합니다. 구조에 맞는 태그를 사용해야 정보가 명확하게 전달됩니다.

## 기본 개념

### 목록

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ol>
    <li>회원가입</li>
    <li>로그인</li>
</ol>
```

### 표

```html
<table>
    <caption>수업 시간표</caption>
    <tr>
        <th>과목</th>
        <th>시간</th>
    </tr>
    <tr>
        <td>HTML</td>
        <td>09:00</td>
    </tr>
</table>
```

## 수업 예제

```html
<h2>학습 순서</h2>
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

<table>
    <caption>과정 정보</caption>
    <tr>
        <th>과정</th>
        <th>기간</th>
        <th>상태</th>
    </tr>
    <tr>
        <td>프론트엔드</td>
        <td>3개월</td>
        <td>모집 중</td>
    </tr>
</table>
```

## 수업 문제

### 문제

순서 있는 목록, 순서 없는 목록, 2행 3열 표를 작성하세요.

### 요구사항

- 학습 순서는 `ol`로 작성합니다.
- 준비물은 `ul`로 작성합니다.
- 표의 첫 행은 제목 셀 `th`를 사용합니다.
- 표에는 `caption`을 작성합니다.

### 직접 풀어 보기

해설을 열기 전에 빈 HTML 파일에 직접 작성하고 브라우저에서 결과를 확인합니다.

<details>
<summary>해설 보기</summary>

```html
<h2>학습 순서</h2>
<ol>
    <li>개념 읽기</li>
    <li>예제 실행</li>
    <li>문제 풀이</li>
</ol>

<h2>준비물</h2>
<ul>
    <li>노트북</li>
    <li>코드 편집기</li>
</ul>

<table>
    <caption>주간 학습 계획</caption>
    <tr>
        <th>요일</th>
        <th>과목</th>
        <th>시간</th>
    </tr>
    <tr>
        <td>월요일</td>
        <td>HTML</td>
        <td>2시간</td>
    </tr>
</table>
```

### 풀이 설명

목록의 각 항목은 `li`로 작성합니다. 표는 `tr`이 행을 만들고, `th`와 `td`가 각 행의 셀을 만듭니다.

</details>

## 자주 하는 실수

- 목록 항목을 `li` 없이 작성하는 경우
- 표의 셀 개수가 행마다 달라지는 경우
- 레이아웃 배치만을 위해 표를 사용하는 경우

## 실무 연결

메뉴, 단계 안내, 공지 목록에는 목록을 사용하고 가격표, 시간표, 비교표처럼 행과 열 관계가 있는 정보에는 표를 사용합니다.

## 📌 더 알아보기

### 표 구조 나누기

큰 표에서는 `thead`, `tbody`, `tfoot`으로 영역을 구분할 수 있습니다. `rowspan`과 `colspan`은 셀을 합칠 때 사용하지만 기본 표 구조를 익힌 뒤 적용합니다.

## 직접 해보기

- 목록 항목을 하나씩 추가한다.
- 표에 데이터 행을 한 줄 추가한다.
- 표 제목을 설명하는 `caption` 내용을 변경한다.

## Check Point

- [ ] `ul`과 `ol`의 차이를 설명할 수 있다.
- [ ] `tr`, `th`, `td`의 역할을 구분할 수 있다.
- [ ] 비교 가능한 데이터에 표를 사용할 수 있다.

## 최종 요약

목록은 항목의 묶음, 표는 행과 열의 관계를 표현합니다. 의미에 맞는 구조를 선택하고 표의 제목은 `caption`으로 제공합니다.
