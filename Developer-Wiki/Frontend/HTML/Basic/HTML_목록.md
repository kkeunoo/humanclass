# HTML 목록

## 개념

순서 없는 목록은 `ul`, 순서 있는 목록은 `ol`, 각 항목은 `li`로 표현한다.

## 문법

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

## 예제

```html
<ol>
    <li>입력</li>
    <li>확인</li>
</ol>
```

## 실무 예제

메뉴, 상품 특징, 작업 순서처럼 반복되는 항목을 의미에 맞는 목록으로 구성한다.

## 주의사항

`li`는 `ul` 또는 `ol`의 자식으로 사용한다. 단순히 줄을 맞추기 위해 목록 태그를 쓰지 않는다.

## 면접 포인트

`ul`과 `ol`의 차이를 설명한다.

## 요약

항목의 순서 의미에 따라 목록 종류를 선택한다.
