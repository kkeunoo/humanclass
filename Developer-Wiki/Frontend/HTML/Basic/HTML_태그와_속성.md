# HTML 태그와 속성

## 개념

속성은 요소에 주소, 설명, 식별자 같은 추가 정보를 제공한다.

## 문법

```html
<태그 속성명="속성값">내용</태그>
```

## 예제

```html
<a href="detail.html" title="상세보기">이동</a>
<img src="img/photo.png" alt="사진 설명">
```

## 실무 예제

`id`는 한 요소를 식별하고, `class`는 여러 요소를 같은 스타일 대상으로 묶는 데 사용한다.

## 주의사항

속성값은 큰따옴표로 감싸고, 같은 문서에서 `id`를 중복 사용하지 않는다.

## 면접 포인트

태그는 구조를 만들고 속성은 세부 정보를 제공한다는 차이를 설명한다.

## 요약

요소의 목적에 맞는 태그와 필요한 속성만 사용한다.
