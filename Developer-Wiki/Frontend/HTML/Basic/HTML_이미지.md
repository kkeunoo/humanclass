# HTML 이미지

## 개념

`img`는 외부 이미지 파일을 문서에 표시하는 빈 요소다.

## 문법

```html
<img src="asset/photo.png" alt="수업 화면" width="300">
```

## 예제

```html
<a href="detail.html">
    <img src="asset/thumb.png" alt="상세 페이지 이동">
</a>
```

## 실무 예제

이미지를 링크 안에 넣어 카드나 썸네일을 클릭하면 상세 페이지로 이동하게 만든다.

## 주의사항

`alt`는 이미지가 보이지 않을 때 의미를 전달하도록 작성한다. 파일 경로와 대소문자를 확인한다.

## 면접 포인트

`src`와 `alt`의 역할을 설명한다.

## 요약

이미지는 정확한 경로와 의미 있는 대체 텍스트가 중요하다.
