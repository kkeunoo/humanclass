# HTML 제목 태그

## 📖 개요

HTML에서는 제목(Heading)을 표현하기 위해 `h1`부터 `h6`까지의 제목 태그를 제공한다.

제목 태그는 단순히 글자를 크게 표시하기 위한 태그가 아니라 **문서의 구조와 계층을 표현하는 태그**이다.

검색 엔진(SEO), 웹 접근성, 화면 낭독기(Screen Reader) 모두 제목 태그의 계층 구조를 참고하여 문서를 이해한다.

---

# 핵심 개념

HTML은 제목을 6단계로 구분한다.

| 태그 | 의미 |
|------|------|
| h1 | 가장 중요한 제목 |
| h2 | 두 번째 단계 제목 |
| h3 | 세 번째 단계 제목 |
| h4 | 네 번째 단계 제목 |
| h5 | 다섯 번째 단계 제목 |
| h6 | 여섯 번째 단계 제목 |

예시

```html
<h1>Developer Wiki</h1>

<h2>Frontend</h2>

<h3>HTML</h3>

<h2>Backend</h2>

<h3>Java</h3>
```

---

# 기본 문법

```html
<h1>가장 중요한 제목</h1>

<h2>두 번째 제목</h2>

<h3>세 번째 제목</h3>

<h4>네 번째 제목</h4>

<h5>다섯 번째 제목</h5>

<h6>여섯 번째 제목</h6>
```

숫자가 커질수록 글자가 작아지는 것이 아니라,

**문서의 중요도가 낮아진다.**

---

# 제목의 계층 구조

다음과 같은 문서가 있다고 가정하자.

```text
웹 개발
 ├── Frontend
 │      ├── HTML
 │      └── CSS
 └── Backend
        ├── Java
        └── Spring
```

HTML에서는 다음과 같이 표현한다.

```html
<h1>웹 개발</h1>

<h2>Frontend</h2>

<h3>HTML</h3>

<h3>CSS</h3>

<h2>Backend</h2>

<h3>Java</h3>

<h3>Spring</h3>
```

이처럼 제목 태그는 **문서의 목차를 표현하는 역할**을 한다.

---

# h1의 역할

`h1`은 문서에서 가장 중요한 제목이다.

보통 하나의 페이지에는 하나의 `h1`을 사용하는 것이 일반적이다.

```html
<h1>Developer Wiki</h1>
```

이후 세부 항목은 `h2`부터 시작한다.

```html
<h2>HTML</h2>

<h2>CSS</h2>

<h2>JavaScript</h2>
```

---

# 제목은 순서대로 작성한다

권장되는 구조

```html
<h1>웹 개발</h1>

<h2>Frontend</h2>

<h3>HTML</h3>

<h2>Backend</h2>

<h3>Java</h3>
```

좋지 않은 예

```html
<h1>웹 개발</h1>

<h4>HTML</h4>
```

중간 단계를 건너뛰면 문서 구조를 이해하기 어려워질 수 있다.

---

# h1과 title의 차이

많은 초보자가 혼동하는 부분이다.

```html
<head>

<title>Developer Wiki</title>

</head>

<body>

<h1>Developer Wiki</h1>

</body>
```

| 요소 | 역할 |
|------|------|
| title | 브라우저 탭 제목 |
| h1 | 페이지의 가장 중요한 제목 |

---

# 제목 태그와 CSS

제목 태그는 기본적으로 글자가 크게 보인다.

하지만 중요한 점은

> **크기 때문에 사용하는 것이 아니다.**

필요하다면 CSS로 크기를 변경할 수 있다.

```css
h1{

font-size:24px;

}
```

CSS를 적용해도 여전히 `h1`은 가장 중요한 제목이다.

---

# 실무 활용

기업 홈페이지를 보면 다음과 같은 구조를 자주 볼 수 있다.

```html
<h1>ABC Academy</h1>

<h2>교육 과정</h2>

<h3>Frontend 과정</h3>

<h3>Backend 과정</h3>

<h2>취업 후기</h2>

<h2>오시는 길</h2>
```

검색 엔진과 화면 낭독기는 이 구조를 이용하여 페이지를 이해한다.

---

# 실무 예제 프로젝트

국비교육 홈페이지의 메인 화면이라고 가정한다.

```html
<main>

<h1>실무 중심 IT 교육</h1>

<section>

<h2>교육 과정</h2>

<h3>HTML & CSS</h3>

<h3>JavaScript</h3>

<h3>React</h3>

</section>

<section>

<h2>취업 지원</h2>

<h3>포트폴리오 제작</h3>

<h3>기업 연계 프로젝트</h3>

</section>

</main>
```

## 구조 분석

```text
h1
 ├── h2
 │      ├── h3
 │      ├── h3
 │      └── h3
 └── h2
        ├── h3
        └── h3
```

하나의 페이지가 목차처럼 구성되어 있다는 것을 확인할 수 있다.

# 자주 하는 실수

## 1.

글자를 크게 만들려고 h1을 사용한다.

❌

```html
<h1>공지사항</h1>
```

(단순히 크게 보이기 위해 사용)

✅

```html
<p class="title">

공지사항

</p>
```

CSS로 크기를 조절한다.

---

## 2.

h1을 여러 개 사용한다.

```html
<h1>HTML</h1>

<h1>CSS</h1>

<h1>JavaScript</h1>
```

하나의 문서를 기준으로 가장 중요한 제목을 `h1`으로 작성하는 것이 일반적이다.

---

## 3.

계층을 건너뛴다.

```html
<h1>웹 개발</h1>

<h4>HTML</h4>
```

가능하면 순차적으로 사용하는 것이 좋다.

# 면접 포인트

### Q1.

h1과 title의 차이는?

- title → 브라우저 탭
- h1 → 페이지 제목

---

### Q2.

제목 태그는 왜 필요한가?

문서 구조를 표현하기 위해 사용한다.

검색 엔진과 접근성에서도 중요한 역할을 한다.

---

### Q3.

h1을 여러 개 사용해도 되나요?

HTML5에서는 상황에 따라 여러 개의 `h1`도 기술적으로 가능하지만, 일반적인 웹 페이지에서는 **페이지의 대표 제목으로 하나의 `h1`을 사용하는 것이 가장 권장되는 방식**이다.

---

### Q4.

글자를 크게 만들려면 h1을 써야 하나요?

아니다.

제목은 제목 태그를,

스타일은 CSS를 사용한다.

---

# 핵심 정리

- 제목 태그는 문서의 계층 구조를 표현한다.
- `h1`은 페이지에서 가장 중요한 제목이다.
- `h2`부터 `h6`까지는 하위 제목을 나타낸다.
- `title`과 `h1`은 서로 다른 역할을 한다.
- 제목 태그는 글자 크기가 아니라 의미를 표현하기 위해 사용한다.
- CSS를 이용해 제목의 크기와 디자인을 자유롭게 변경할 수 있다.
- 검색 엔진과 웹 접근성을 고려하여 올바른 계층 구조를 유지하는 것이 중요하다.
