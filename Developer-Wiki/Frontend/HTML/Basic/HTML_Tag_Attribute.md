# HTML 태그와 속성

## 학습 목표

- 태그와 속성의 차이를 설명할 수 있다.
- 제목, 문단, 강조 태그를 사용할 수 있다.
- `id`, `class`, `title` 속성을 작성할 수 있다.

## 왜 배우는가

태그는 콘텐츠의 의미와 구조를 만들고 속성은 태그에 추가 정보를 제공합니다. 올바른 태그를 선택하면 문서가 읽기 쉽고 접근성과 유지보수성이 좋아집니다.

## 기본 개념

### 태그

```html
<h1>가장 중요한 제목</h1>
<p>하나의 문단입니다.</p>
<strong>중요한 내용</strong>
```

### 속성

```html
<p id="intro" class="description" title="소개 문장">안녕하세요.</p>
```

- `id`: 문서 안에서 한 요소를 고유하게 식별합니다.
- `class`: 여러 요소를 같은 그룹으로 묶습니다.
- `title`: 요소에 대한 보조 설명을 제공합니다.

## 수업 예제

```html
<section class="course">
    <h2 id="html-title">HTML 기초</h2>
    <p title="과정 설명">웹 문서의 구조를 배웁니다.</p>
    <button type="button">수강 신청</button>
</section>
```

## 수업 문제

### 문제

제목, 설명, 버튼으로 이루어진 강의 안내 영역을 작성하세요.

### 요구사항

- 제목에는 `id`를 사용합니다.
- 설명에는 `class`와 `title`을 사용합니다.
- 버튼의 `type`은 `button`으로 지정합니다.

### 직접 풀어 보기

해설을 열기 전에 빈 HTML 파일에 직접 작성하고 브라우저에서 결과를 확인합니다.

<details>
<summary>해설 보기</summary>

```html
<section class="course">
    <h2 id="frontend-title">프론트엔드 과정</h2>
    <p class="course-description" title="과정 안내">HTML과 CSS를 학습합니다.</p>
    <button type="button">자세히 보기</button>
</section>
```

### 풀이 설명

각 태그는 제목, 설명, 동작 요소라는 의미를 표현합니다. `id`는 고유 식별자, `class`는 그룹 식별자로 사용합니다.

</details>

## 자주 하는 실수

- 모든 내용을 `div`로만 작성하는 경우
- 같은 문서에서 동일한 `id`를 여러 번 사용하는 경우
- 속성값의 따옴표를 빠뜨리는 경우

## 실무 연결

페이지의 제목, 카드, 버튼, 안내 문구는 모두 태그와 속성의 조합으로 구성됩니다. 의미에 맞는 태그를 사용하면 CSS와 JavaScript 작업도 쉬워집니다.

## 📌 더 알아보기

### 블록 요소와 인라인 요소

블록 요소는 보통 새 줄에서 시작하고, 인라인 요소는 문장 흐름 안에 배치됩니다. 실제 배치 방식은 이후 CSS의 `display` 속성으로 변경할 수 있습니다.

## 직접 해보기

- `h2`를 `h3`로 바꾸어 문서 구조를 비교한다.
- 같은 `class`를 가진 문단을 하나 더 추가한다.
- 버튼에 `title` 속성을 추가한다.
