# HTML 문서와 태그

## 개념

HTML은 웹 페이지의 구조를 표현하는 마크업 언어다. 태그는 요소의 의미와 범위를 나타낸다.

## 문법

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>문서 제목</title>
</head>
<body>
    <h1>Hello HTML</h1>
</body>
</html>
```

## 예제

```html
<p>문단입니다.</p>
<br>
<hr>
```

## 실무 예제

제목과 문단을 계층에 맞게 배치해 간단한 소개 페이지의 뼈대를 만든다.

## 주의사항

태그 이름은 소문자로 작성하고, 중첩 순서를 지킨다. 빈 요소는 종료 태그가 없다.

## 면접 포인트

태그와 요소의 차이, `head`와 `body`의 역할을 설명한다.

## 요약

HTML은 태그를 사용해 문서 구조와 의미를 표현한다.
