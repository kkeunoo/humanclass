## 왜 이 내용을 배우는가?

Date은(는) 이후 예제와 문제를 이해하기 위한 기본 도구다. 문법만 외우기보다 어떤 상황에서 필요하고, 코드가 어떤 순서로 동작하는지 이해해야 다른 문제에도 적용할 수 있다.

> [!TIP]
> 문법을 외우기 전에 **무엇을 해결하기 위한 문법인지** 먼저 확인한다. 같은 문법도 목적을 이해하면 다른 예제에서 다시 사용할 수 있다.


<!-- V4.1-QA-START -->
> [!NOTE]
> **💡 WHY — 왜 중요한가?**  
> Date 객체는 현재 시각과 날짜 정보를 다룬다. 월, 요일, 시간 계산 방식의 차이를 알아야 화면에 정확한 날짜를 표시할 수 있다.

> [!TIP]
> **⭐ 실무 TIP**  
> 월 값이 0부터 시작하는지, 날짜가 지역 시간 기준인지 확인하고 출력 형식을 명확하게 만든다.

> [!IMPORTANT]
> **📌 반드시 기억하기**  
> `getMonth()` 결과는 0부터 11이므로 사람이 보는 월로 표시할 때 1을 더한다.

> [!WARNING]
> **⚠️ 주제별 자주 하는 실수**  
> 날짜 숫자를 문자열로 바로 이어 붙이면 한 자리 월과 일이 일정하지 않게 보일 수 있다.

> [!NOTE]
> **🏫 수업 메모**  
> 예제 코드를 실행한 뒤 값이나 선택자를 하나씩 바꾸고, 결과가 달라지는 이유를 자신의 말로 설명한다. 정답 코드보다 실행 순서와 오류 원인을 설명할 수 있는지가 더 중요하다.

# 개념과 수업 예제

```js
const now = new Date();
console.log(now.getFullYear());
console.log(now.getMonth() + 1);
console.log(now.getDate());
```

`getMonth()`는 0부터 시작하므로 사람이 보는 월은 1을 더한다.

```js
const future = new Date();
future.setDate(future.getDate() + 7);
```

## 실무 연결

현재 시간 표시, 마감일 계산, 날짜 비교에 사용한다.

## 주의사항

문자열 날짜 형식과 시간대에 따라 결과가 달라질 수 있다. 수업 단계에서는 Date 객체의 생성과 기본 getter/setter에 집중한다.

# 자주 하는 실수

- 예제 코드를 그대로 복사하고 각 줄의 역할을 확인하지 않는 실수
- 입력값과 출력값의 자료형을 확인하지 않는 실수
- 한 번에 많은 코드를 작성해 오류가 발생한 위치를 찾기 어렵게 만드는 실수
- 브라우저 또는 콘솔에서 직접 결과를 확인하지 않는 실수

> [!WARNING]
> 오류가 발생하면 코드를 한꺼번에 바꾸지 않는다. 선택 결과, 변수값, 자료형, 조건식 결과를 `console.log()` 또는 출력문으로 하나씩 확인한다.
