# JavaScript 함수와 화살표 함수

## 학습 목표

- 함수 선언, 매개변수, 반환값을 이해하고 화살표 함수와 비교한다.
- 예제의 실행 순서를 설명한다.
- 현재까지 배운 문법으로 문제를 해결한다.

## 왜 배우는가

JavaScript는 값과 화면을 연결하고 사용자 행동에 반응하게 만듭니다. 새로운 문법을 짧게 쓰는 것보다 실행 흐름을 정확히 이해하는 것이 우선입니다.

## 기본 개념

```javascript
function add(a, b) {
    return a + b;
}

const result = add(3, 5);
console.log(result);
```

## 수업 예제

예제를 직접 입력한 뒤 변수값과 실행 순서를 `console.log()`로 확인합니다.

## 수업 문제

### 문제

두 수를 받아 큰 값을 반환하는 함수를 작성하세요.

### 요구사항

- 함수 이름은 `getMax`로 작성합니다.
- 두 개의 매개변수를 사용합니다.
- 결과를 `return`으로 반환합니다.

### 직접 풀어 보기

해설을 열기 전에 입력값, 처리 과정, 출력 결과를 나누어 적고 코드를 작성합니다.

<details>
<summary>해설 보기</summary>

```javascript
function getMax(a, b) {
    if (a > b) {
        return a;
    }

    return b;
}

console.log(getMax(10, 7));
```

### 풀이 설명

현재 문서까지 배운 문법을 중심으로 작성했습니다. 먼저 기본 풀이를 이해한 뒤 더 알아보기의 짧은 문법과 비교합니다.

</details>

## 자주 하는 실수

- 함수 안에서 출력만 하고 반환값이 있다고 생각하는 경우
- 함수를 선언하고 호출하지 않는 경우
- 지역 변수를 함수 밖에서 사용하려는 경우

## 실무 연결

반복되는 계산과 동작을 함수로 분리하면 코드 중복을 줄이고 테스트하기 쉬워집니다.

## 📌 더 알아보기

### 화살표 함수

일반 함수를 충분히 이해한 뒤 짧은 함수 표현식으로 사용할 수 있습니다.

```javascript
const add = (a, b) => a + b;
```

`this`의 동작 차이는 객체와 이벤트 문맥을 더 학습한 뒤 다룹니다.

- 오류가 발생한 줄과 오류 메시지를 읽고 원인을 기록한다.
