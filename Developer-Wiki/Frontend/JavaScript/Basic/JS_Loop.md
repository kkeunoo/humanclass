## 왜 이 내용을 배우는가?

반복문은(는) 이후 예제와 문제를 이해하기 위한 기본 도구다. 문법만 외우기보다 어떤 상황에서 필요하고, 코드가 어떤 순서로 동작하는지 이해해야 다른 문제에도 적용할 수 있다.

> [!TIP]
> 문법을 외우기 전에 **무엇을 해결하기 위한 문법인지** 먼저 확인한다. 같은 문법도 목적을 이해하면 다른 예제에서 다시 사용할 수 있다.

> [!NOTE]
> **💡 WHY — 왜 중요한가?**  
> 반복문은 같은 작업을 데이터나 횟수에 따라 반복한다. 복사한 코드를 줄이는 것보다 반복의 시작, 종료, 변화 조건을 설계하는 능력이 중요하다.

> [!TIP]
> **⭐ 실무 TIP**  
> 반복문을 작성하기 전에 “몇 번 반복하는가, 무엇이 변하는가, 언제 끝나는가”를 먼저 적는다.

> [!IMPORTANT]
> **📌 반드시 기억하기**  
> 배열 반복에서는 인덱스 범위가 `0`부터 `length - 1`까지임을 기억한다.

> [!WARNING]
> **⚠️ 주제별 자주 하는 실수**  
> 증감식이나 종료 조건이 잘못되면 무한 반복 또는 마지막 요소 누락이 발생한다.

> [!NOTE]
> **🏫 수업 메모**  
> 예제 코드를 실행한 뒤 값이나 선택자를 하나씩 바꾸고, 결과가 달라지는 이유를 자신의 말로 설명한다. 정답 코드보다 실행 순서와 오류 원인을 설명할 수 있는지가 더 중요하다.

# 개념과 수업 예제

## for

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

## while

```js
let count = 0;
while (count < 3) {
  console.log(count);
  count++;
}
```

## 중첩 반복문

```js
for (let i = 1; i <= 6; i++) {
  for (let j = 1; j <= 6; j++) {
    console.log(i, j);
  }
}
```

## break와 continue

- break: 반복 종료
- continue: 현재 반복만 건너뜀

## 주의사항

while문에서는 조건을 변화시키는 코드가 빠지면 무한 반복이 발생한다.

## 문제 1. 5부터 1까지 역순 출력

### 설계

| 항목 | 값 |
|---|---|
| 시작값 | 5 |
| 계속 조건 | 1 이상 |
| 변화식 | 1씩 감소 |

```js
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
```

### 자주 하는 실수

```js
for (let i = 5; i <= 1; i--)
```

처음부터 `5 <= 1`이 거짓이라 한 번도 실행되지 않는다.

## 문제 2. 1부터 5까지 홀짝 표시

```js
for (let i = 1; i <= 5; i++) {
  const type = i % 2 === 0 ? '짝수' : '홀수';
  console.log(`${i}: ${type}`);
}
```

### 개선 포인트

출력할 문자열을 `type` 변수에 먼저 저장하면 `console.log`가 짧아지고 의미도 분명해진다. 단순한 한 줄 분기에는 삼항 연산자를 사용할 수 있지만, 처리 내용이 여러 줄이면 `if`가 더 읽기 쉽다.

## 문제 3. 1부터 100까지 합계

### 사고 과정

1. 합계를 저장할 변수 `sum`을 0으로 만든다.
2. 1부터 100까지 숫자를 하나씩 꺼낸다.
3. 현재 숫자를 `sum`에 누적한다.
4. 반복이 끝난 뒤 결과를 출력한다.

```js
let sum = 0;

for (let i = 1; i <= 100; i++) {
  sum += i;
}

console.log(sum);
```

> [!IMPORTANT]
> `console.log(sum)`을 반복문 안에 두면 중간 합계가 100번 출력된다. 최종 합계만 필요하면 반복문 밖에서 출력한다.

## 문제 4. 주사위 두 개의 모든 경우

### 왜 중첩 반복문인가

첫 번째 주사위의 각 값마다 두 번째 주사위가 1부터 6까지 모두 변해야 한다. “각 경우마다 또 다른 전체 반복”이 필요하므로 반복문을 중첩한다.

```js
for (let first = 1; first <= 6; first++) {
  for (let second = 1; second <= 6; second++) {
    console.log(first, second);
  }
}
```

총 경우의 수는 `6 × 6 = 36`이다.

### 조건이 추가된 경우

두 주사위 합이 7인 경우만 출력한다.

```js
for (let first = 1; first <= 6; first++) {
  for (let second = 1; second <= 6; second++) {
    if (first + second === 7) {
      console.log(first, second);
    }
  }
}
```

## 문제 5. 3이 나올 때까지 주사위 던지기

### `do...while`이 어울리는 이유

주사위는 최소 한 번은 던져야 한다. 먼저 실행한 뒤 결과에 따라 반복 여부를 정하므로 `do...while`이 자연스럽다.

```js
let count = 0;
let dice;

do {
  dice = Math.floor(Math.random() * 6) + 1;
  count++;
  console.log(`${count}번째: ${dice}`);
} while (dice !== 3);

console.log(`${count}번 만에 3이 나왔습니다.`);
```

### 개인 풀이와 강사 풀이 비교

- 개인 풀이는 시도 횟수와 각 주사위 값을 출력하여 실행 흐름을 확인하기 좋았다.
- 강사 풀이는 반복 조건과 랜덤 수 생성 공식을 간결하게 보여줬다.
- 학습 단계에서는 개인 방식처럼 중간 결과를 확인하고, 완성 뒤 불필요한 출력만 제거하는 방식이 좋다.

> [!WARNING]
> 랜덤 반복은 종료 시점을 예측할 수 없다. 조건을 잘못 쓰면 무한 반복이 될 수 있으므로 개발 중에는 최대 횟수 제한을 두는 것도 좋다.

```js
const MAX_TRY = 100;
let count = 0;
let dice;

do {
  dice = Math.floor(Math.random() * 6) + 1;
  count++;
} while (dice !== 3 && count < MAX_TRY);
```

## 문제 6. 별 찍기

```js
for (let row = 1; row <= 5; row++) {
  let line = '';

  for (let column = 1; column <= row; column++) {
    line += '*';
  }

  console.log(line);
}
```

### 해결 원리

- 바깥 반복문은 행의 수를 담당한다.
- 안쪽 반복문은 한 행에 들어갈 별의 수를 담당한다.
- 현재 행 번호와 별 개수가 같다는 규칙을 찾는 것이 핵심이다.

## 더 좋은 풀이 습관

- 반복 전에 손으로 2~3회 값을 적어본다.
- 반복 변수 이름을 `i`, `j`만 쓰지 말고 `row`, `column`, `first`, `second`처럼 역할에 맞게 붙인다.
- 무한 반복 가능성이 있으면 종료 조건을 먼저 확인한다.
- 누적값은 반복문 밖에서 초기화한다.

# 자주 하는 실수

- 예제 코드를 그대로 복사하고 각 줄의 역할을 확인하지 않는 실수
- 입력값과 출력값의 자료형을 확인하지 않는 실수
- 한 번에 많은 코드를 작성해 오류가 발생한 위치를 찾기 어렵게 만드는 실수
- 브라우저 또는 콘솔에서 직접 결과를 확인하지 않는 실수

> [!WARNING]
> 오류가 발생하면 코드를 한꺼번에 바꾸지 않는다. 선택 결과, 변수값, 자료형, 조건식 결과를 `console.log()` 또는 출력문으로 하나씩 확인한다.
