# JavaScript 외부 API 활용

## 학습 목표

- 외부 API 요청·응답의 기본 구조와 JSON 데이터 확인 방법을 이해한다.
- 예제의 실행 순서를 설명한다.
- 현재까지 배운 문법으로 문제를 해결한다.

## 왜 배우는가

JavaScript는 값과 화면을 연결하고 사용자 행동에 반응하게 만듭니다. 새로운 문법을 짧게 쓰는 것보다 실행 흐름을 정확히 이해하는 것이 우선입니다.

## 기본 개념

외부 API는 다른 서비스가 제공하는 데이터나 기능을 정해진 주소와 규칙으로 사용하는 방식입니다.

1. 요청 URL과 필요한 값 확인
2. 개발자 도구 Network에서 응답 상태 확인
3. JSON 구조 확인
4. 필요한 값만 화면에 표시

실제 요청 코드는 비동기 처리와 Fetch API를 배운 뒤 작성합니다.

## 수업 예제

예제를 직접 입력한 뒤 변수값과 실행 순서를 `console.log()`로 확인합니다.

## 수업 문제

### 문제

제공된 JSON 응답 객체에서 이름과 이메일을 읽어 사용자 카드 문구를 출력하세요.

### 요구사항

- 네트워크 요청 대신 이미 받은 객체를 사용합니다.
- 객체 속성에 접근합니다.
- 필요한 값만 문자열로 조합합니다.

### 직접 풀어 보기

해설을 열기 전에 입력값, 처리 과정, 출력 결과를 나누어 적고 코드를 작성합니다.

<details>
<summary>해설 보기</summary>

```javascript
const responseData = {
    name: '홍길동',
    email: 'hong@example.com'
};

const cardText = `${responseData.name} / ${responseData.email}`;
console.log(cardText);
```

### 풀이 설명

현재 문서까지 배운 문법을 중심으로 작성했습니다. 먼저 기본 풀이를 이해한 뒤 더 알아보기의 짧은 문법과 비교합니다.

</details>

## 자주 하는 실수

- API 문서를 읽지 않고 임의의 속성명을 사용하는 경우
- 응답 상태와 오류 메시지를 확인하지 않는 경우
- API 키를 공개 저장소에 직접 작성하는 경우

## 실무 연결

날씨, 지도, 결제, 로그인, 공공데이터처럼 외부 서비스와 연결할 때 API를 사용합니다.

## 📌 더 알아보기

API 키는 브라우저 코드에 노출하지 않는 것이 원칙입니다. 서버 환경 변수와 프록시 구조는 백엔드 학습 이후 다룹니다.
