# JavaScript 연산자

## 개념

연산자는 계산, 비교, 대입, 논리 판단을 수행한다.

## 문법

```javascript
const sum = 10 + 20;
const same = 10 === 10;
const result = age >= 20 && agreed === true;
```

## 예제

```javascript
let count = 0;
count += 1;
```

## 실무 예제

폼 검증에서 여러 조건을 논리 연산자로 연결한다.

## 주의사항

동등 비교는 값과 자료형을 함께 비교하는 `===`를 기본으로 사용한다.

## 면접 포인트

산술·비교·논리·대입 연산자의 역할을 설명한다.

## 요약

연산자는 값 계산과 조건 판단의 기초다.
