> [!NOTE]
> **💡 WHY — 왜 중요한가?**  
> float는 원래 이미지 주변에 글자를 흐르게 하기 위한 속성이고 shadow는 요소의 깊이감을 표현한다. 용도를 구분해야 오래된 배치 방식과 장식 효과를 혼동하지 않는다.

> [!TIP]
> **⭐ 실무 TIP**  
> 새로운 전체 레이아웃은 flex를 우선 검토하고, float를 사용했다면 부모 높이가 사라지는지 확인한다.

> [!IMPORTANT]
> **📌 반드시 기억하기**  
> 그림자는 정보 위계를 돕는 정도로 사용하고 지나치게 진하거나 많은 그림자를 피한다.

> [!WARNING]
> **⚠️ 주제별 자주 하는 실수**  
> float된 자식 때문에 부모 높이가 0처럼 보일 수 있으므로 clear 처리나 흐름 복구가 필요하다.

> [!NOTE]
> **🏫 수업 메모**  
> 예제 코드를 실행한 뒤 값이나 선택자를 하나씩 바꾸고, 결과가 달라지는 이유를 자신의 말로 설명한다. 정답 코드보다 실행 순서와 오류 원인을 설명할 수 있는지가 더 중요하다.

# 개념과 수업 예제

## float

```css
.thumb { float: left; width: 120px; margin-right: 16px; }
.article::after { content: ''; display: block; clear: both; }
```

float는 원래 이미지 주변으로 텍스트를 흐르게 만드는 용도다. 오래된 레이아웃에서 사용되지만 새 정렬은 Flexbox가 더 적합하다.

## shadow

```css
.card { box-shadow: 0 8px 20px rgba(0,0,0,.15); }
.title { text-shadow: 1px 1px 2px rgba(0,0,0,.2); }
```
