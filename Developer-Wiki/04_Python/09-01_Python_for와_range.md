## 1. 이 장에서 배울 것

range의 시작·끝 제외·간격과 reversed를 설명한다. 구구단·피라미드·FizzBuzz에서 바깥·안쪽 변수의 역할과 경계를 비교한다. 같은 모양을 만드는 다른 작성 방식의 장단점을 읽는다.

실제 원본·새 예제·개선안·선택 학습을 구분하고 입력·실행 순서·반환값·출력을 연결한다.

<a id="concepts"></a>

## 2. 무엇이며, 왜 필요한가

for value in 대상은 대상에서 값을 차례로 받아 value에 연결한 뒤 들여쓴 블록을 반복한다. range는 정수 범위를 제공한다. 끝 숫자는 포함하지 않고 간격을 생략하면 1이다. range(2,10,3)의 값은 2·5·8이다.

| 표현 | 값 | 횟수 |
| --- | --- | --- |
| range(5) | 0·1·2·3·4 | 5 |
| range(1,6) | 1·2·3·4·5 | 5 |
| range(2,10,3) | 2·5·8 | 3 |
| reversed(range(3)) | 2·1·0 | 3 |

중첩 for는 바깥 값 하나가 정해진 동안 안쪽을 끝까지 반복한다. 구구단에서 단이 2일 때 곱하는 수 1·2·3을 모두 처리한 뒤 단을 3으로 바꾼다. 단순히 두 반복문이 동시에 한 칸씩 움직이는 것이 아니다.

출력 모양에는 반복과 print 옵션이 함께 영향을 준다. end를 공백으로 두면 같은 줄에 이어지고, 안쪽 반복 뒤 print()를 호출하면 다음 바깥 값의 줄로 넘어간다. 모양이 맞아도 시작값·마지막값이 문제 조건과 맞는지 따로 확인한다.

> 📚 **출처 · 본문 설명 확인:** [Python for·range와 반복 제어](https://docs.python.org/ko/3/tutorial/controlflow.html#for-statements). 실제 배운 문법의 의미를 확인한 근거다. 예제·표·풀이 자체는 수업 자료를 바탕으로 새로 구성했다. 외부 문장을 직접 인용하지 않았다. 이번 문법 확인 기간: 2026-10-28~29.

## 3. 작은 예제로 먼저 이해하기

**새 설명 예제 · 전체 코드.** [실행 파일](실습/책형_복습/09-01_Python_for와_range.py)을 제공한다. Python이 설치된 환경에서 새 .py 파일로 저장해 실행한다. 터미널은 그 파일이 있는 폴더에서 열고 `python 파일이름.py`를 실행한다. VS Code의 Python 실행 기능을 사용해도 된다. 결과는 터미널에 표시된다.



```python
for table in range(2, 4):
    for number in range(1, 4):
        print(f'{table}x{number}={table * number}', end=' ')
    print()
height = 3
for line in range(1, height + 1):
    print(' ' * (height - line) + '*' * (line * 2 - 1))
for number in range(1, 7):
    if number % 3 == 0 and number % 5 == 0:
        print('FizzBuzz', end=' ')
    elif number % 3 == 0:
        print('Fizz', end=' ')
    elif number % 5 == 0:
        print('Buzz', end=' ')
    else:
        print(number, end=' ')
print()
```

구구단은 확인하기 쉽도록 2·3단의 곱하는 수 1~3만 출력한 새 예제다. 별은 줄 1·2·3에서 앞 공백 2·1·0개, 별 1·3·5개를 만든다. FizzBuzz는 1부터 6까지만 확인한다. 15처럼 두 조건을 모두 만족할 수 있는 값도 있으므로 공배수 조건을 먼저 둔다. 실제 print의 end 때문에 각 구구단·FizzBuzz 줄 끝에는 공백 한 칸도 출력되며 표시는 읽기 쉽게 보았다.

## 4. 내가 작성한 코드를 따라 읽기

아래는 원본 발췌다. 주석의 잘못된 설명도 원문을 보존하고 풀이에서 교정한다. 필요한 선언·호출·다른 파일의 정의는 다음 절까지 연결해 읽는다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/09_for.py` 2–9행

```python
for i in range(5) :
    print(i, end=' ')

print()

# reversed() 는 뭐가 되었든 거꾸로 바꿔주는 역할
for i in reversed(range(5)) :
    print(i, end=' ')
```

**발췌 바로 풀이:** `range(5)`로 꺼내는 값은 **0, 1, 2, 3, 4**다. `reversed(range(5))`는 이를 반대로 꺼낸다. `print(..., end=' ')`는 출력 뒤에 줄바꿈 대신 공백을 붙이고, 인자 없는 `print()`는 다음 줄로 옮긴다. 내 주석의 “`reversed()`는 뭐가 되었든 거꾸로”는 너무 넓다. 여기서는 `range`를 거꾸로 읽는 동작만 확인한다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/09_for.py` 14–23행

```python
for i in range(2,10,3) :
    for j in range(1,10) :
        print(f'''{i} x {j} = {i*j}''', end=' ')
        if i+1 < 10 :
            print(f'''{i+1} x {j} = {(i+1)*j}''', end=' ')
        if i+2 < 10 :
            print(f'''{i+2} x {j} = {(i+2)*j}''', end=' ')
        print()
    print()

```

**발췌 바로 풀이:** 강사님 코드는 바깥 `j`가 **2단부터 9단**, 안쪽 `i`가 **1부터 9**를 돈다. 내 코드는 바깥 `i`가 `2, 5, 8`을 돌며 한 줄에 3단씩 나란히 놓는다. 마지막 8단에서는 `i+2 < 10`이 거짓이라 10단을 출력하지 않는다. 같은 중첩 반복이지만 **반복 변수의 역할과 출력 모양**이 다르다.

inputUser = int(input('줄 수 : '))
for k in range(0,inputUser+1) :

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/09_for.py` 63–67행

```python
inputUser = int(input('줄 수 : '))
for j in range(1,inputUser+1) :
    print(' '*(inputUser-j),end='')
    print('*'*((j+j)-1),end='')
    print(' '*(inputUser-j))
```

**발췌 바로 풀이:** 첫 풀이에서 `k=0`인 첫 줄에는 별이 **0개**이고 공백만 출력된다. 두 번째 풀이에서는 `j=1`부터 시작하여 첫 줄부터 별 1개가 나온다. 따라서 같은 `inputUser`를 넣어도 출력 줄 수와 첫 줄이 다르다. 두 번째 풀이의 `' ' * (inputUser-j)`와 `'*' * ((j+j)-1)`은 앞에서 배운 **문자열 반복**을 활용해 중첩 반복문을 줄였다. 강사님은 `-`를 붙여 양쪽 모양을 표시하고, 내 코드는 공백으로 들여쓴다. 모두 실제 실습 코드다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/09_for.py` 91–99행

```python
for i in range(100) :
    if i % 3 == 0 and i % 5 == 0 :
        print('Fizz!Buzz!')
    elif i % 3 == 0 :
        print('Fizz!')
    elif i % 5 == 0 :
        print('Buzz!')
    else :
        print(i)
```

**발췌 바로 풀이:** 두 코드 모두 3과 5의 공배수 조건을 먼저 검사한 다음 각각의 배수를 검사한다. 내 `range(100)`은 **0부터 99까지**이므로, `0`에서도 `0 % 3 == 0`과 `0 % 5 == 0`이 참이 되어 첫 출력이 `Fizz!Buzz!`다. 반면 강사님 `range(1, 101)`의 첫 값은 1이다. 문제를 “1부터 100까지”로 생각하고 내 코드를 읽으면 결과를 잘못 예측할 수 있다.

내 구구단의 바깥 i는 2·5·8로 움직이며 한 줄에 i·i+1·i+2단을 출력한다. 마지막 8단에서 10단은 조건으로 제외한다. 첫 피라미드는 k=0부터 시작하여 처음 공백만 있는 줄이 생긴다. 두 번째는 1부터 시작해 별 1개가 첫 줄이다. 내 FizzBuzz는 range(100)이므로 0~99이며 첫 값 0도 두 나머지 조건을 만족하여 Fizz!Buzz!를 출력한다.

## 5. 선언·호출·파일이 연결되는 흐름

바깥 range에서 값 받기 → 안쪽 range 전체 반복 → 안쪽 종료 뒤 줄바꿈 → 다음 바깥 값 순서다. 별은 줄 수에서 현재 줄을 빼 공백을 만들고 2*줄-1로 별 수를 만든다. %는 이 FizzBuzz 원본에 실제 사용한 나머지 연산이다. 입력·나머지·논리 조건·출력까지 앞 장 문법을 연결한다.

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점:** 내 세 단 묶음은 경계 조건을 넣어 10단을 제외하고 문자열 반복으로 피라미드 코드를 간결히 만들었다. **경계 오류 가능성:** 첫 피라미드의 k=0 줄과 FizzBuzz의 0 시작은 문제의 요구 범위와 비교해야 한다. **설명 교정:** reversed가 어떤 객체든 무조건 뒤집는다고 확대하지 않는다. 현재 원본은 range를 역순으로 읽는다. **개선:** 반복 변수는 단·곱하는 수·줄처럼 역할을 이름이나 표로 분명히 한다.

개선안은 D 드라이브 원본을 수정한 결과가 아니다. 실제 오류·수업용 단순화·목적에 따른 선택을 구별한다.

## 7. 강사님 코드가 도움이 되는 비교

출처: `D:/workspace_teacher/workspace_python/_09_for.py` 47–60행

```python
k = 14
for i in range(2, k+1, 3) :
    for j in range(1, 9+1) :
        # print(f'{i}x{j}={i*j}', end='  ') 
        # if i+1 <= k :
        #     print(f'{i+1}x{j}={(i+1)*j}', end='  ')
        # if i+2 <= k :
        #     print(f'{i+2}x{j}={(i+2)*j}', end='  ')
        # print()
        for m in range(3) :
            if i+m <= k :
                print(f'{i+m}x{j}={(i+m)*j}', end='\t') 
        print()
    print()
```

강사님의 세 단 묶음 발췌는 각 단의 중복 조건을 m 반복으로 줄여 비교 가치가 있어 인용한다. 단, 강사님은 k=14까지, 내 코드는 9단까지라는 조건 차이를 먼저 맞춰야 한다. 피라미드 강사님 활성 코드는 line 직전까지라 입력 5일 때 4줄이며 -로 여백을 보인다. 내 두 번째 풀이는 입력 줄 수만큼 공백으로 출력한다. 같은 정답 모양이라고 단정하지 않는다.

## 8. 결과를 추적하고 한 가지 바꾸기

| 원본 비교 | 강사님 | 내 코드 |
| --- | --- | --- |
| FizzBuzz 범위 | 1~100 | 0~99 |
| FizzBuzz 숫자 표시 | 숫자 먼저 붙임 | 배수는 문구로 대체 |
| 피라미드 입력 5 | 4줄·- 여백 | 첫 풀이 빈 첫 줄, 둘째 풀이 별 5줄 |
| 묶음 구구단 | 마지막 확장 k=14 | 9단까지 |

비교할 때 표시 방식·문제 범위·반복 문법을 분리한다. 강사님보다 짧거나 길다는 이유만으로 우열을 정하지 않는다. 작은 예제에서 바깥 2회·안쪽 3회이면 곱셈 출력은 6회다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| 안쪽 range 끝을 5로 | 곱하는 수 1~4 | 끝 제외 |
| 피라미드를 0부터 시작 | 별 없는 첫 줄 추가 | 초기값 차이 |
| FizzBuzz 시작을 0으로 | 첫 문구 FizzBuzz | 0의 나머지도 0 |
| 공배수 분기를 뒤로 | 15가 앞의 3 배수에 잡힘 | elif의 첫 일치 선택 |

하나가 빠지거나 늘면 시작·끝 제외부터 확인한다. 출력이 한 줄에 붙으면 end와 print() 위치를 본다. 중첩 횟수는 각 반복을 표로 나누어 센다. 별 모양은 공백도 값이므로 보이지 않는 첫 줄까지 확인한다.
