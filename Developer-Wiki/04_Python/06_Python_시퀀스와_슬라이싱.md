## 개요

시퀀스는 여러 값을 순서대로 저장하고, 위치를 기준으로 값을 조회할 수 있는 자료형이다.

Python의 대표적인 시퀀스 자료형은 다음과 같다.

```text
문자열 str
리스트 list
튜플 tuple
range
    ↓
순서가 있음
    ↓
인덱스로 조회 가능
    ↓
슬라이싱 가능
```

시퀀스 자료형은 공통으로 다음 기능을 제공한다.

- 값 포함 여부 확인
- 시퀀스 연결과 반복
- 길이 확인
- 인덱싱
- 슬라이싱
- 반복문 순회

다만 자료형마다 변경 가능 여부는 다르다.

```text
list
→ 변경 가능

str, tuple, range
→ 변경 불가능
```

## 개념에서 실제 실행까지 — 슬라이싱이란? — 인덱스 경계와 선택 순서

### 무엇이며 왜 배워야 할까?

시퀀스는 요소에 순서가 있어 위치로 접근할 수 있는 자료형이다. 문자열·리스트·튜플·range를 같은 관점으로 읽되, 모든 시퀀스가 변경 가능한 것은 아니다. 인덱스는 한 위치를 조회하고 슬라이스는 선택한 범위를 만든다. a[99]는 없으면 IndexError지만 a[:99]는 가능한 범위까지만 선택한다.

a[start:stop:step]에서 stop 위치는 포함하지 않는다. step이 음수면 선택 순서가 거꾸로 움직이므로 양수 간격일 때와 기본 경계가 다르다. a[::-1]은 전체를 역순으로 선택한다. step=0은 ValueError다.

문자열 len은 Python 문자열의 코드 포인트 수이고 UTF-8로 인코딩한 bytes의 len은 바이트 수다. 한글 다섯 글자가 UTF-8에서 15바이트인 예제는 ‘문자 수와 전송 크기는 다르다’를 보여 준다. 💡 결합 문자·이모지는 눈으로 본 글자와 코드 포인트 수도 다를 수 있다.

리스트 슬라이스 대입은 구간을 반복 가능한 값으로 교체하여 길이를 바꿀 수 있다. step이 1이 아닌 확장 슬라이스 대입은 선택한 자리 수와 새 값 수가 맞아야 한다. 문자열에서는 같은 대입이 불가능하다.

### 독립 실행 예제: 입력에서 결과까지

다음 코드는 앞 문서의 변수 없이 새 .py 파일에서 실행할 수 있는 보충 예제다. 직접 적은 입력값을 사용하므로 같은 조건에서 아래 출력과 비교할 수 있다.

```python
a = [10, 20, 30, 40, 50]
print(a[1:4], a[::-1], a[:99])
a[1:3] = [7]
print(a)
text = '안녕하세요'
print(len(text), len(text.encode('utf-8')))
```

예상 출력:

```text
[20, 30, 40] [50, 40, 30, 20, 10] [10, 20, 30, 40, 50]
[10, 7, 40, 50]
5 15
```

### 실행 순서를 한 단계씩 따라가기

1. 소스에서 다섯 요소의 a를 생성한다.
2. 슬라이싱은 stop을 제외한 위치를 선택해 새 목록을 만든다. 역순 선택에서도 a 자체는 그대로다.
3. 구간 [1:3]에 한 요소를 대입하여 두 요소를 하나로 바꾸고 a의 길이가 줄어든다.
4. 문자열을 UTF-8 bytes로 변환한 새 객체의 길이와 원래 문자열 길이를 비교한다.

## 1. 시퀀스란?

시퀀스는 여러 값을 순서대로 저장하는 자료형이다.

```python
text = "Python"
numbers = [10, 20, 30]
point = (3, 5)
```

각 값은 위치를 나타내는 인덱스를 가진다.

```text
Python
012345
```

```text
값       10  20  30
인덱스    0   1   2
```

### 1-1. 공통 기능

```python
print(len(text))
print(text[0])
print(text[1:4])
print("P" in text)
```

### 1-2. 출력 결과

```text
6
P
yth
True
```

## 2. 포함 연산자 `in`

### 2-1. 내 코드

```python
a = [0, 10, 20, 30, 40]

print(20 in a)
print(200 in a)
```

### 2-2. 강사님 코드

```python
a = [0, 10, 20, 30, 40]

print(20 in a)
print(200 in a)
```

두 코드는 동일하다.

### 2-3. 출력 결과

```text
True
False
```

`in`은 왼쪽 값이 오른쪽 시퀀스 안에 있으면 `True`를 반환한다.

## 3. 포함되지 않음 `not in`

### 3-1. 원본 코드

```python
a = [0, 10, 20, 30, 40]

print(not (200 in a))
print(200 not in a)
```

### 3-2. 출력 결과

```text
True
True
```

두 표현은 같은 결과를 만든다.

```text
not (200 in a)
→ 포함 여부를 먼저 확인하고 결과 반전

200 not in a
→ 포함되지 않았는지 직접 확인
```

> [!TIP]
> 포함되지 않았는지 확인할 때는 `value not in sequence`가 더 직접적으로 읽힌다.

## 4. 문자열 포함 검사

`in`은 리스트뿐 아니라 문자열에도 사용할 수 있다.

```python
message = "Python is easy"

```

### 4-1. 출력 결과

```text
True
True
```

문자 하나뿐 아니라 연속된 문자열도 검색할 수 있다.

## 5. 리스트 연결 `+`

### 5-1. 내 코드와 강사님 코드

```python
a = [1, 2, 3]
b = [4, 5, 6]
c = a + b

print(c)
```

### 5-2. 출력 결과

```text
[1, 2, 3, 4, 5, 6]
```

`+`는 두 리스트를 연결한 새 리스트를 반환한다.

```python
print(a)
print(b)
```

출력:

```text
[1, 2, 3]
[4, 5, 6]
```

원본 리스트는 변경되지 않는다.

## 6. 문자열 연결 `+`

### 6-1. 원본 코드

```python
a = "hello"
b = "world"
c = a + b

print(c)
```

### 6-2. 출력 결과

```text
helloworld
```

공백이 필요하면 직접 포함한다.

```python
message = "hello" + " " + "world"

print(message)
```

출력:


## 8. `range` 연결

## 21. 슬라이싱 기본 구조

슬라이싱은 시퀀스의 일정 범위를 잘라 새 시퀀스를 반환한다.

```python
sequence[start:stop:step]
```

| 항목 | 의미 |
| --- | --- |
| `start` | 시작 인덱스, 포함 |
| `stop` | 종료 인덱스, 미포함 |
| `step` | 이동 간격 |

---

<a id="py-06-section-27"></a>

## 22. 기본 슬라이싱

### 22-1. 원본 코드

```python

print(a[1:4])
```

### 22-2. 출력 결과

```text
[1, 2, 3]
```

```text
시작 인덱스 1
→ 포함

종료 인덱스 4
→ 미포함
```

---

<a id="py-06-section-28"></a>

## 23. 음수 종료 인덱스

### 23-1. 원본 코드

```python

```

### 23-2. 출력 결과

```text
[4, 5, 6, 7, 8]
```

`-1`은 마지막 원소의 위치지만 종료 인덱스는 포함되지 않으므로 `9`는 결과에 들어가지 않는다.



```text
a[100]
→ IndexError

a[4:100]
→ 가능한 끝까지 반환
```

## 40. 두 목록의 같은 위치 연결

```python
ko = ["책", "알약", "철판"]
```

## 44. 내 코드와 강사님 코드 비교

| 항목 | 내 코드 | 강사님 코드 |
| --- | --- | --- |
| 포함 검사 | `not`과 `not in` 차이 메모 | 핵심 실행 예제 |
| 시퀀스 연결 | `range` 변환 조건을 추가 기록 | 리스트·문자열 연결 중심 |
| 길이 | 문자·숫자·튜플에 사용한다고 메모 | 문자열 길이 중심 |
| 인코딩 | UTF-8 바이트 길이 실험 | 같은 핵심 예제 |
| 인덱싱 | JavaScript와 오류 차이 메모 | 리스트 값 변경 예제 포함 |
| 튜플 | 읽기 전용이라고 메모 | 값 변경 불가 예제 |
| 슬라이싱 | 각 범위 결과를 자세히 기록 | 핵심 범위 예제 중심 |
| 슬라이스 대입 | 원하는 위치 변경 메모 | 같은 핵심 예제 |
| 다국어 목록 | 같은 위치 번역어 활용 메모 | 목록 전환 예제 |
| 역순 | 문자열 역순 | `TENET` 회문 참고 추가 |

### 44-1. 내 코드의 장점

- `in`, `not`, `not in`의 관계를 직접 비교했다.
- `range`는 직접 연결할 수 없다는 차이를 기록했다.
- UTF-8 인코딩 후 바이트 길이를 직접 확인했다.
- 단일 인덱스와 슬라이싱의 범위 초과 차이를 메모했다.
- 역방향 슬라이싱과 음수 인덱스를 다양한 범위로 실험했다.

### 44-2. 내 코드의 개선점

- `len()`은 숫자에 사용할 수 없다.
- 튜플을 단순한 `readonly`라고 하기보다 불변 시퀀스로 설명하는 것이 정확하다.
- `[시작INDEX, 끝INDEX, 반복INDEX]`가 아니라 `[start:stop:step]`이다.
- 두 번 연속 대입한 `view = ko`, `view = en`은 첫 대입이 바로 덮어써진다.
- 같은 위치의 두 목록을 처리할 때는 `zip()`을 사용하면 더 명확하다.

### 44-3. 강사님 코드의 장점

- 포함·연결·길이·인덱싱·슬라이싱을 한 흐름으로 실습한다.
- 리스트와 튜플의 변경 가능 여부를 비교할 수 있다.
- 범위를 벗어난 슬라이싱이 오류를 발생시키지 않는다는 점을 확인할 수 있다.
- 슬라이스 대입으로 리스트 길이가 달라지는 동작을 보여 준다.

### 44-4. 강사님 코드의 보충점

- `len()`이 무엇을 세는지 자료형별 설명이 필요하다.
- 문자열 글자 수와 바이트 길이의 차이를 보충해야 한다.
- 슬라이싱 결과가 새 객체인지 설명하면 복사 이해에 도움이 된다.
- 문자열과 튜플에는 슬라이스 대입을 사용할 수 없다는 설명이 필요하다.

## 45. 기존 코드에서 개선 코드로 바꾼 이유

### 45-1. 포함되지 않음 표현

기존:

```python
not (200 in values)
```

개선:

```python
200 not in values
```

이유:

- 의도가 한 번에 읽힌다.
- Python에서 자연스럽게 사용하는 표현이다.

### 45-2. 문자열과 숫자 연결

기존:

```python
message = "hello" + str(3)
```

개선:

```python
message = f"hello{3}"
```

### 45-3. 두 목록 함께 처리

기존 방식:

```python
for index in range(len(ko)):
    print(ko[index], en[index])
```

개선:

```python
for korean, english in zip(
    ko,
    en,
):
    print(korean, english)
```

### 45-4. 전체 리스트 복사

```python
copied = values[:]
```

의도가 더 분명한 방식:

```python
copied = values.copy()
```

두 방식 모두 얕은 복사다.

## 46. 실무형 예제: 검색 결과 페이지

```python
products = [
    "Keyboard",
    "Mouse",
    "Monitor",
    "Webcam",
    "Speaker",
    "Headset",
    "Microphone",
]

page_size = 3
page = 2

start = (
    (page - 1)
    * page_size
)
end = start + page_size

page_products = products[start:end]

print(
    f"{page}페이지 상품:"
)

for product in page_products:
    print("-", product)
```

### 46-1. 출력 결과

```text
2페이지 상품:
- Webcam
- Speaker
- Headset
```

### 46-2. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `page_size` | 한 페이지에 표시할 개수 |
| `start` | 슬라이싱 시작 위치 계산 |
| `end` | 슬라이싱 종료 위치 계산 |
| `products[start:end]` | 현재 페이지 범위만 추출 |
| 직접 순회 | 페이지 상품을 하나씩 출력 |

### 46-3. 실무에서는?

슬라이싱은 다음 작업에 사용할 수 있다.

- 목록 페이지 나누기
- 최근 데이터 일부 조회
- 상위 N개 항목 표시
- 문자열 일부 마스킹
- 테스트 데이터 일부 추출

## 49. 핵심 요약

```text
in
→ 포함 여부

not in
→ 미포함 여부

+
→ 같은 종류의 시퀀스 연결

len()
```

```text
sequence[index]
→ 값 하나 조회

sequence[start:stop:step]
→ 범위 조회

stop
→ 미포함

step < 0
→ 역방향
```

```text
list
→ 인덱스·슬라이스 변경 가능

str, tuple
→ 조회 가능, 변경 불가

[::-1]
→ 역순 새 시퀀스
```

## 마무리

시퀀스 처리의 핵심은 여러 값을 순서대로 저장하는 데서 끝나지 않는다.

```text
값의 포함 여부를 확인하고
    ↓
필요한 위치를 인덱스로 조회하고
    ↓
원하는 범위를 슬라이싱하고
    ↓
변경 가능한 자료형은 일부를 교체하고
    ↓
같은 규칙을 문자열·리스트·튜플에 적용하는 것
```

이 흐름을 이해하면 이후 딕셔너리·조건문·반복문에서도 데이터의 위치와 범위를 더 정확하게 다룰 수 있다.

## V3 동작 백과 보강 — 인덱스와 슬라이스 계산

문자열·리스트·튜플은 순서를 공유하므로 `value[index]`와 `value[start:stop:step]` 규칙을 함께 쓴다. 인덱스는 원소 하나를 선택하고 범위를 벗어나면 `IndexError`다. 슬라이스의 `stop`은 포함하지 않으며 범위를 넘어도 가능한 부분만 반환한다.

```python
data = [10, 20, 30, 40, 50]
print(data[1])
print(data[1:4])
print(data[::-1])
```

```text
20
[20, 30, 40]
[50, 40, 30, 20, 10]
```

리스트 슬라이스는 새 바깥 리스트를 만들지만 내부 객체 참조는 공유할 수 있다. 문자열과 튜플은 슬라이스 결과도 불변이고, 리스트만 슬라이스 대입으로 원본 범위를 바꿀 수 있다.
