# Python 코드를 읽는 법 — 값과 변화를 한 줄씩 따라가기

[Python 목차](README.md) · [첫 장: 출력과 주석](01_Python_출력과_주석.md)

Python을 복습할 때는 긴 원본 파일을 처음부터 모두 외우려 하지 말고 **현재 변수의 값 → 실행한 문장 → 바뀐 값 → 출력** 순서로 적는다. 다음은 수업 문법으로 만든 설명용 재구성이다.

```python
numbers = [1, 2]
numbers.append(3)
print(numbers)  # [1, 2, 3]
```

첫 줄에서 리스트를 만들고, 둘째 줄은 **그 리스트의 내용**을 바꾸며, 셋째 줄이 현재 상태를 보여 준다. `append()`가 무엇을 반환하는지와 `numbers`가 어떻게 바뀌었는지는 서로 다른 질문이다.

원본 비교가 나오는 장에서는 강사님 코드와 내 코드에 **같은 입력·같은 동작이 있는지** 먼저 본다. 다른 점이 실제 결과에 영향을 줄 때만 개선 방향을 적는다. 설명용 새 예제와 원본 발췌는 각 장에 표시되어 있다. 수업 원본에서 확인되지 않은 확장은 해당 장의 **추가로 알면 좋은 것**에 둔다.
