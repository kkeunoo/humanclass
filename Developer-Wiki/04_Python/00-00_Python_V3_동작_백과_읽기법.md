# Python V3 동작 백과 읽기법

> 이 문서는 Python 문서를 단순한 문법 요약이 아니라, 시간이 지난 뒤에도 다시 실행하고 수정할 수 있는 개인 강의 백과사전으로 읽기 위한 공통 기준이다.

## 1. 모든 예제를 읽는 순서

```text
값의 출처
→ Python이 값을 객체로 만들거나 외부에서 문자열로 받음
→ 변수 이름이 객체를 가리킴
→ 연산자·함수·메서드가 객체를 처리함
→ 변수 또는 객체의 상태가 바뀜
→ print·return·파일·예외로 결과가 관찰됨
```

`input()`의 값은 키보드에서 들어오고 항상 `str`이다. 소스 코드에 적은 리터럴은 Python이 실행하며 객체가 된다. 파일의 값은 `open()`으로 얻은 파일 객체를 통해 읽고, 함수의 값은 호출 인수가 매개변수에 연결되며 들어온다. 이 출처를 먼저 찾으면 자료형 오류를 훨씬 빨리 이해할 수 있다.

## 2. 실행 기록표

예제를 다시 공부할 때 다음 표를 직접 채운다.

| 시점 | 실행 문장 | 이름이 가리키는 값/자료형 | 외부에서 보이는 결과 |
|---|---|---|---|
| 실행 전 | 아직 실행하지 않음 | 이름 없음 | 출력 없음 |
| 입력/생성 | `age = input(...)` | `age -> str` | 프롬프트 표시 |
| 변환 | `age = int(age)` | `age -> int` | 출력 없음 |
| 사용 | `print(age + 1)` | `age`는 그대로 | 계산 결과와 줄바꿈 |

## 3. 출력과 반환값은 다르다

`print(value)`는 사람이 터미널에서 보도록 표준 출력으로 보낸다. `return value`는 함수를 호출한 코드에 값을 돌려준다. 메서드가 원본을 바꾸면서 `None`을 반환할 수도 있다. 따라서 예제마다 다음 세 가지를 구분한다.

```python
numbers = [3, 1, 2]
result = numbers.sort()
print(numbers)
print(result)
```

```text
[1, 2, 3]
None
```

`sort()`는 리스트 원본을 바꾸고, 그 변경 결과 자체는 반환하지 않는다.

## 4. 오류 읽는 순서

Traceback의 마지막 줄에서 예외 종류와 메시지를 먼저 확인하고, 그 위의 내 파일명과 줄 번호로 이동한다. 그 줄만 보지 말고 사용된 값이 어느 줄에서 들어오고 어떤 자료형이 되었는지 역추적한다. 오류가 없는데 결과가 틀리면 논리 오류이므로 중간값과 `type()`을 출력한다.

## 5. 원본 코드 표기 규칙

- `내 코드`는 `workspace_python`의 번호형 원본을 뜻한다.
- `강사님 코드`는 `workspace_python`의 `_` 접두사 번호형 원본을 뜻한다.
- 원본에 없는 심화 주제는 억지로 연결하지 않고 `Wiki 확장 학습`이라고 표시한다.
- 비교할 때는 누가 더 좋다는 결론보다 실행 결과, 자료형, 예외 가능성, 재사용성의 차이를 기록한다.
