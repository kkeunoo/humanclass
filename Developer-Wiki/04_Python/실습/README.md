## 2. 실행 방법

각 본문 3절의 전체 파일을 새 작업 폴더에서 실행한다. input이 있으면 해당 입력 순서를 준다. import 예제는 book_tools.py를 같은 폴더에 둔다. 파일 예제는 명시한 새 연습 파일을 만들며 D 드라이브 수업 파일을 쓰는 예제가 아니다. 오류를 관찰하는 예제는 예외 종류도 결과다.

## 3. 검토 방법

출력·반환값·파일 변경을 나눠 적는다. 예상과 다르면 여러 줄을 한꺼번에 고치지 말고 변수·자료형·조건을 한 가지씩 확인한다. 모듈·문자열·목록 예제의 파일명을 임의로 표준 모듈 이름으로 바꾸면 이름 충돌이 생길 수 있다.
