# 12-03 Python 클래스 과제비교 — 연습문제

[원본 비교 본문](../../12-03_Python_클래스_과제비교.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

[12-03장의 계정 문제](../../12-03_Python_클래스_과제비교.md)에서 “주소만 바꾸고 새 주소만 반환”하려면 강사님 `setAddr`·`getAddr`와 내 `setAccount`·`getAccount` 중 어느 쪽이 요구에 더 직접적인가? 내 코드가 실제로 바꾸는 값도 적자.

<details>
<summary>정답과 확인할 점</summary>

강사님 함수는 **주소만** 바꾸고 주소만 반환하므로 요구에 더 직접적이다. 내 `setAccount(id, pw, addr)`는 주소와 함께 ID·비밀번호도 새 값으로 바꾸고, `getAccount()`는 세 값을 함께 반환한다. 내 코드도 동작하지만 문제의 “주소만”이라는 조건과는 범위가 다르다. 이것은 양쪽 실제 풀이를 비교해 판단하는 문제이며, 새 클래스를 원본이라고 제시하지 않는다.


</details>
