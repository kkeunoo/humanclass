## 문제

튜플 `t = (1, 2)`에서 첫 값을 읽자. `t[0] = 3`을 시도하면 무엇이 일어나는가? `(3)`과 `(3,)`도 같은 자료형인지 확인하자.

<details>
<summary>정답과 확인할 점</summary>

`t[0]`은 1이다. `t[0] = 3`은 튜플의 요소를 바꾸려 하므로 `TypeError`가 난다. `(3)`은 정수 3, `(3,)`은 한 값이 있는 튜플이다. 원본에서 **쉼표가 튜플 생성의 핵심**이라는 점과 내 주석의 “빈 튜플 불가”가 틀린 설명이라는 점을 함께 확인한다.


</details>
