**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

리스트 `[2, 4, 6]` 끝에 `8`을 **한 요소로** 넣고 두 번째 값을 읽는 코드를 쓰자. 이어 `[10, 12]`를 `append`할 때와 `extend`할 때 최종 리스트의 모양이 어떻게 다른지 각각 예상하자.

<details>
<summary>정답과 확인할 점</summary>

```python
numbers = [2, 4, 6]
numbers.append(8)
print(numbers[1])  # 4
print(numbers)     # [2, 4, 6, 8]
```

위 코드 다음에 `numbers.append([10, 12])`를 쓰면 `[2, 4, 6, 8, [10, 12]]`다. 반면 초기 리스트 `[2, 4, 6, 8]`에 `extend([10, 12])`를 쓰면 `[2, 4, 6, 8, 10, 12]`다. `append`는 전달한 리스트 자체를 **한 요소**로 넣고, `extend`는 그 안의 값을 각각 붙인다.

강사님·내 원본의 `append([9,10])`도 같은 차이를 보여 준다. 이 예제는 숫자만 바꿔 직접 확인하도록 만든 새 문제다.
