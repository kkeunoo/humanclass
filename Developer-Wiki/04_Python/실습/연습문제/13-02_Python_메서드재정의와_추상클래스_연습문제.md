**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

부모 `Animal.speak()`와 자식 `Dog.speak()`가 모두 정의되어 있을 때 `Dog().speak()`의 결과는 어느 메서드에서 오는가? 자식의 `speak`를 지우면 어떻게 되는지도 예상하자.

<details>
<summary>정답과 확인할 점</summary>

`Dog`에 같은 이름의 메서드가 있으면 자식이 **재정의한 메서드**를 사용한다. 자식의 정의를 지우면 부모에게서 물려받은 `Animal.speak()`를 사용할 수 있다. 강사님·내 원본의 메서드 재정의도 **호출 대상 객체의 클래스**를 먼저 확인하자. 추상 클래스의 메서드 구현 조건은 본문 실제 예제에서 별도로 복습한다.


</details>
