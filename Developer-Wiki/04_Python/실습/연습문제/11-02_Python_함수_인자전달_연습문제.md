# 11-02 Python 함수 인자전달 — 연습문제

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`def add(a,b=1): return a+b`에서 `add(4)`와 `add(4,3)`의 결과를 예상하자.

<details>
<summary>정답과 확인할 점</summary>

`add(4)`는 두 번째 인자를 생략했으므로 기본값 1을 사용해 5다. `add(4, 3)`은 전달한 3이 기본값을 대신해 7이다. 양쪽 원본의 `info3(name, age, addr='비공개')`도 주소 인자를 생략한 때에만 기본 문구를 쓴다. **항상 기본값으로 고정되는 인자**라고 읽으면 안 된다.


</details>
