# 11-03 Python lambda와 변수범위 — 연습문제

[원본 비교 본문](../../11-03_Python_lambda와_변수범위.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`x=10`일 때 `lambda n: n+x`에 2를 주면 결과가 무엇인지 예상하자.

<details>
<summary>정답과 확인할 점</summary>

```python
x = 10
add_x = lambda n: n + x
print(add_x(2))  # 12
```

`n`은 호출에서 받은 2, `x`는 바깥 이름의 10을 읽는다. 같은 함수 안에서 `x = ...`를 새로 대입하는 문제와는 다르다. 강사님·내 원본의 `lambda`·정렬 기준 함수에서도 **함수가 받는 값과 바깥에서 읽는 값**을 나누어 보자.


</details>
