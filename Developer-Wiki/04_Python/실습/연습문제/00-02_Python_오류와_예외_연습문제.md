## 문제 1. 결과와 실행 순서 예상



```python
print('시작')
print(10 / 0)
print('끝')
```

<details>
<summary>힌트와 풀이</summary>

입력·현재 값·실행 순서·반환값·출력 위치를 따로 표시한다.

```text
시작
ZeroDivisionError: division by zero
(중간의 파일·줄 경로는 환경에 따라 다르며 끝은 출력되지 않음)
```

의도적으로 예외를 관찰하는 전체 예제다. 시작은 출력되지만 두 번째 줄의 나눗셈에서 실패하여 끝은 출력되지 않는다. 아래 관찰에는 핵심 오류 마지막 줄만 적었으며 실제 화면에는 파일 경로와 줄 번호도 보인다. 오류를 없애기 전에 어느 작업까지 진행했는지 설명해 본다.

</details>

## 문제 2. 이유를 자신의 말로 설명

1. print(10/0)은 숫자를 먼저 출력하는가?
2. 내 div의 y=0 호출은 ZeroDivisionError인가?
3. 강사님 함수가 안내 뒤 반환하는 값은?

<details>
<summary>풀이</summary>

나눗셈이 먼저 실패하므로 숫자 출력은 없다. 내 함수는 나눗셈을 건너뛴 뒤 result가 없어 UnboundLocalError가 난다. 강사님은 초기값 0을 반환한다.

| 호출 | 나눗셈 수행 | 내 result | 결과 |
| --- | --- | --- | --- |
| div(7, 2) | 수행 | 3.5 | 3.5 반환 |
| div(7, 0) | 안 함 | 준비 안 됨 | 안내 뒤 UnboundLocalError |
| 강사님 div(7, 0) | 안 함 | 초기값 0 | 안내 뒤 0 반환 |

본격적인 except 갈래·else·finally와 return의 관계는 [14-01](../../14-01_Python_예외처리_심화.md)에서 읽는다. 이 시작 장은 그 전체를 선행 암기하는 곳이 아니라, 이후 오류가 났을 때 돌아올 읽기 기준이다.

</details>

## 문제 3. 한 가지만 바꾸기

본문의 다음 실험에서 한 행만 골라 결과를 먼저 예상한다. 실행 후 원래 예제로 돌아가 다음 변경을 확인한다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| 작은 예제 분모를 2로 | 시작·5.0·끝 | 나눗셈이 성공 |
| 작은 예제 둘째 줄을 주석 처리 | 시작·끝 | 해당 계산 미실행 |
| 내 div의 첫 줄에 result=0 | 0 입력 때 안내 뒤 0 | 반환할 값이 준비됨 |

<details>
<summary>막힐 때 확인할 것</summary>

오류 마지막 줄과 해당 파일·줄부터 본다. 주석 속 오류 예시를 실제 실행 결과로 읽지 않는다. 예외가 두려워 모든 줄을 없애기보다 한 입력만 바꿔 실패 조건을 좁힌다. 함수 안 result 문제는 전역 이름을 임의로 추가하기보다 그 함수의 각 갈래를 확인한다.

</details>
