# 09-01 Python for와 range — 연습문제

[원본 비교 본문](../../09-01_Python_for와_range.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`range(1, 4)`를 `for`로 순회해 출력하면 어떤 숫자가 나오는가? `range(4, 1)`로 시작과 끝을 뒤집으면 어떻게 되는지도 예상하자.

<details>
<summary>정답과 확인할 점</summary>

`range(1, 4)`는 1, 2, 3을 차례로 준다. 끝 4는 포함되지 않는다. 기본 간격이 양수이므로 `range(4, 1)`은 값이 없어 반복 본문이 실행되지 않는다. 거꾸로 이동하려면 수업 원본의 `reversed(range(...))` 또는 간격을 명시한 `range`를 별도로 사용한다.


</details>
