# 08. 조건문 — 실행할 갈래와 검사할 순서를 정하기 — 연습문제

[본문](../../08_Python_조건문.md) · [문제 목차](README.md)

실제 수업 내용을 바탕으로 **새로 구성한 연습문제**다. 원래 수업 퀴즈·당시 내 풀이와 구별한다. 실행 전 예상 → 이유 설명 → 한 가지 수정 순서로 풀어 본다.

## 목표와 실행 조건

if·elif·else와 들여쓰기·pass를 설명한다. 빈 값의 진리값, 범위와 평균 검사 순서, match의 간단 상수 패턴, 한 줄 조건식을 실제 출력과 연결한다.

[전체 Python 파일](../책형_복습/08_Python_조건문.py)을 새 파일로 실행한다. 입력·준비 파일·import 조건은 [본문 3절](../../08_Python_조건문.md#example)을 먼저 확인한다. 의도적으로 예외를 관찰하는 예제는 오류 종류와 그 전에 나온 출력도 답에 적는다.

## 문제 1. 결과와 실행 순서 예상



```python
text = '90 80 70 80'
parts = text.split()
if len(parts) != 4:
    print('점수 개수 확인')
else:
    a, b, c, d = int(parts[0]), int(parts[1]), int(parts[2]), int(parts[3])
    if 0 <= a <= 100 and 0 <= b <= 100 and 0 <= c <= 100 and 0 <= d <= 100:
        average = (a + b + c + d) / 4
        if average >= 80:
            print('합격', average)
        else:
            print('불합격', average)
    else:
        print('점수 범위 확인')
button = 2
if button == 1:
    print('콜라')
elif button == 2:
    print('사이다')
else:
    print('다른 번호')
month = 7
match month:
    case 6 | 7 | 8:
        print('여름')
    case _:
        print('다른 계절')
print('있음' if parts else '없음')
```

<details>
<summary>힌트와 풀이</summary>

입력·현재 값·실행 순서·반환값·출력 위치를 따로 표시한다.

```text
합격 80.0
사이다
여름
있음
```

네 문자열을 숫자로 바꾼 뒤 범위를 통과하여 평균 80.0을 구한다. 기준을 >=80으로 정했으므로 합격이다. button=2는 사이다 한 갈래만 실행한다. 새 예제는 month라는 의미를 부여하여 7을 여름으로 표현했다. 원본의 a=7과 출력 문구 차이는 아래 비교에서 별도로 다룬다. 마지막 조건식은 parts가 비어 있지 않아 있음이라는 값을 반환하여 print에 넘긴다.

</details>

## 문제 2. 이유를 자신의 말로 설명

1. 여러 elif는 모두 실행되는가?
2. 원본 점수를 세 개 입력하면 범위 안내가 먼저인가?
3. pass는 break와 같은가?
4. 양쪽 a=7에서 실제 출력은?

<details>
<summary>풀이</summary>

먼저 참인 한 갈래만 선택한다. 원본은 네 번째 조회에서 먼저 오류가 난다. pass는 아무 동작 없는 자리 채움이다. 강사님 여름, 내 코드 봄이다.

| 입력·상태 | 원본에서 먼저 일어나는 것 | 결과 |
| --- | --- | --- |
| 점수 네 개·범위 정상·평균 80 | 숫자 변환·평균 후 검사 | 합격 |
| 점수 세 개 | 네 번째 위치 조회 | 범위 안내 전 IndexError |
| 숫자 아닌 점수 | int 호출 | 범위 안내 전 ValueError |
| 네 숫자 중 101 | 변환 성공 뒤 범위 검사 | 잘못된 입력 안내 |
| 빈 a 리스트 | if a 검사 | 거짓 갈래 |

한 줄 조건식은 값1 if 조건 else 값2이며 선택된 값만 평가한다. 여러 조건을 한 줄에 겹치면 읽기 어려울 수 있으므로 새 예제에서는 단순한 한 단계만 사용했다. pass는 반복 중단이나 함수 반환을 대신하지 않는다.

</details>

## 문제 3. 한 가지만 바꾸기

본문의 다음 실험에서 한 행만 골라 결과를 먼저 예상한다. 실행 후 원래 예제로 돌아가 다음 변경을 확인한다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| 점수 하나를 79로 내려 평균 80 미만 만들기 | 불합격 | 평균 조건 변경 |
| 네 값 중 하나를 101로 | 범위 안내 | 평균 합격보다 범위가 먼저 |
| 점수를 세 개로 변경 | 새 예제는 개수 안내 | 개선한 검사 순서 |
| button을 9로 | 다른 번호 | 어떤 앞 갈래도 안 맞음 |

<details>
<summary>막힐 때 확인할 것</summary>

원하지 않은 줄까지 실행되면 들여쓰기 범위를 본다. 입력 안내가 아니라 예외가 나면 안내 조건에 도달하기 전 계산을 확인한다. 공백 여러 칸 문제는 split 인수를 본다. match 문법 오류는 먼저 Python 버전 조건을 확인한다.

</details>
