**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

점수 `75`가 60 이상이면 합격, 아니면 불합격을 출력하는 `if/else`를 작성하자. 60점과 59점으로도 바꾸어 경계값을 확인하자.

<details>
<summary>정답과 확인할 점</summary>

```python
score = 75
if score >= 60:
    print('합격')
else:
    print('불합격')
```

75점과 60점은 합격, 59점은 불합격이다. `>=`에는 같은 값도 포함된다. 들여쓰기를 바꾸면 어느 문장이 조건에 속하는지 달라진다. 강사님·내 원본의 더 많은 점수 구간도 **경계값과 조건 순서**로 확인한다.


</details>
