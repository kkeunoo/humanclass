# 10-03 Python 파일에서 단어찾기 — 연습문제

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

문장 `'red blue red'`에서 공백으로 나눈 목록을 만들자. 대소문자를 구분하지 않고 `r`이 들어 있는 단어만 골라 출력한다면 무엇이 남을까?

<details>
<summary>정답과 확인할 점</summary>

`'red blue red'.split(' ')`는 `['red', 'blue', 'red']`다. 각 단어를 확인하면 `r`이 있는 `red` 두 개가 남는다. **중복된 단어도 원문에서 두 번 등장**했으므로 두 번 출력한다. 강사님·내 원본의 파일 문제는 구두점과 대소문자 처리도 있으므로 이 짧은 문장보다 조건이 더 많다.


</details>
