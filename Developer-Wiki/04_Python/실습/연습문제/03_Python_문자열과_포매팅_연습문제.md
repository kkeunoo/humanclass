## 문제

`name="민수"`, `age=20`을 f-string으로 `민수: 20` 형태로 만들어 보자.

<details>
<summary>정답과 확인할 점</summary>

`f"{name}: {age}"`로 변수 값을 문자열 안에 넣는다.

같은 개념이 실제로 어떻게 쓰였는지는 [본문의 원본 비교](../../03_Python_문자열과_포매팅.md)에서 다시 확인한다.

</details>
