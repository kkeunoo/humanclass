# 03 Python 문자열과 포매팅 — 연습문제

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`name="민수"`, `age=20`을 f-string으로 `민수: 20` 형태로 만들어 보자.

<details>
<summary>정답과 확인할 점</summary>

```python
name = '민수'
age = 20
print(f'{name}: {age}')  # 민수: 20
```

중괄호 안에서 변수 값을 읽어 문자열에 넣는다. 같은 결과를 `name + ': ' + str(age)`로도 만들 수 있지만 숫자 `age`를 그대로 문자열에 `+`할 수는 없다. 강사님·내 원본의 온도 출력도 **문자열 변환과 f-string**을 비교한다.


</details>
