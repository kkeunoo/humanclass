# 02. 변수·연산자·입출력 — 값의 종류와 계산 순서를 읽기 — 연습문제

[본문](../../02_Python_변수와_연산자_입출력.md) · [문제 목차](README.md)

실제 수업 내용을 바탕으로 **새로 구성한 연습문제**다. 원래 수업 퀴즈·당시 내 풀이와 구별한다. 실행 전 예상 → 이유 설명 → 한 가지 수정 순서로 풀어 본다.

## 목표와 실행 조건

대입과 계산 순서를 추적하고 입력 문자열을 숫자로 변환한다. /·//·int의 차이, 교환 두 번의 결과, sep·end, 논리 연산과 is의 의미를 실제 원본에 맞춰 설명한다.

[전체 Python 파일](../책형_복습/02_Python_변수와_연산자_입출력.py)을 새 파일로 실행한다. 입력·준비 파일·import 조건은 [본문 3절](../../02_Python_변수와_연산자_입출력.md#example)을 먼저 확인한다. 의도적으로 예외를 관찰하는 예제는 오류 종류와 그 전에 나온 출력도 답에 적는다.

## 문제 1. 결과와 실행 순서 예상



```python
price = 1000
typed = input('수량: ')
count = int(typed)
total = price * count
print('총액', total, sep=': ')
print(5 / 2, 5 // 2, -5 // 2)
print(int(-2.4))
a = 10
b = '오백원'
c = a
a = b
b = c
print('첫 교환', a, b)
a, b = b, a
print('둘째 교환', a, b)
x = 4
print(++x, --x, x)
print(1 == 1.0)
print(not False or not True and False)
print('글씨' or '쉬는시간')
print(1, 2, sep='', end='')
print(3)
```

<details>
<summary>힌트와 풀이</summary>

입력·현재 값·실행 순서·반환값·출력 위치를 따로 표시한다.

```text
수량: 3 ← 직접 입력
총액: 3000
2.5 2 -3
-2
첫 교환 오백원 10
둘째 교환 10 오백원
4 4 4
True
True
글씨
123
```

실행하면 수량 입력을 기다리므로 3을 입력하고 Enter를 누른다. 출력 예의 화살표 설명은 입력 안내이며 프로그램이 만든 글자가 아니다. typed는 문자열 3, count는 정수 3, total은 3000이다. 교환은 두 번 실행하여 원래 값으로 돌아온다. ++x와 --x는 증감이 아니라 단항 연산 두 번이므로 x도 그대로 4다. 마지막 두 print는 첫 출력의 end가 빈 문자열이어서 12와 3이 붙어 123 한 줄로 보인다.

</details>

## 문제 2. 이유를 자신의 말로 설명

1. input으로 3을 읽으면 어떤 종류인가?
2. int(-2.4)와 -5//2는 각각?
3. 두 교환을 연달아 실행하면 최종 값은?
4. is는 타입까지 같은 값 비교인가?

<details>
<summary>풀이</summary>

문자열이다. 각각 -2와 -3이다. a=10·b=오백원으로 돌아온다. is는 동일 객체 비교이며 타입을 포함한 값 비교로 대체하지 않는다.

| 관찰 | 강사님 | 내 코드 |
| --- | --- | --- |
| e의 첫 값 | 16 | 16 |
| 증가 줄 | 실행하여 17 | 주석으로 16 유지 |
| e**=2 뒤 | 289 | 256 |
| 두 교환 뒤 a·b | 10·오백원 | 10·오백원 |

4.3-2.7은 이진 부동소수점 표현 때문에 1.6과 정확히 같은 값 비교가 아닐 수 있으며 원본 결과는 False다. 단순 소수점 자리 수 규칙으로 보장하지 않는다. and가 or보다 우선하고 not이 더 먼저 적용된다. 논리식은 항상 boolean만 돌려주는 것도 아니다. a or '쉬는시간'은 a가 참으로 평가되면 그 값 자체를 돌려주므로 a='글씨'일 때 결과는 글씨다.

</details>

## 문제 3. 한 가지만 바꾸기

본문의 다음 실험에서 한 행만 골라 결과를 먼저 예상한다. 실행 후 원래 예제로 돌아가 다음 변경을 확인한다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| 수량에 4 입력 | 총액 4000 | 입력을 정수로 변환 |
| 둘째 교환 줄 제거 | 오백원·10 유지 | 교환 한 번만 실행 |
| 마지막 첫 print의 end를 줄바꿈으로 | 12와 3이 다른 줄 | 출력 끝 처리 변경 |
| a or 식의 a를 빈 문자열로 | 쉬는시간 | 거짓으로 평가된 첫 값 대신 뒤 값 |

<details>
<summary>막힐 때 확인할 것</summary>

숫자가 반복되거나 자료형 오류가 나면 input 결과와 변환 결과를 구분한다. 교환 값이 예상과 다르면 교환을 몇 번 실행했는지 본다. 출력이 붙으면 sep뿐 아니라 이전 print의 end도 확인한다. 실수의 정확 비교와 is를 같은 해결책으로 묶지 않는다.

</details>
