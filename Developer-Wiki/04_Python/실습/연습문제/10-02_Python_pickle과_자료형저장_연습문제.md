# 10-02 Python pickle과 자료형저장 — 연습문제

[원본 비교 본문](../../10-02_Python_pickle과_자료형저장.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`pickle.dump()`로 리스트를 파일에 저장하고 `pickle.load()`로 다시 읽으려 한다. 두 단계에서 파일 모드를 각각 어떻게 열지 적고, 텍스트 편집기로 내용을 읽을 수 있을지도 예상하자.

<details>
<summary>정답과 확인할 점</summary>

수업 원본처럼 쓰기는 `'wb'`, 읽기는 `'rb'` 바이너리 모드를 쓴다. 저장 결과는 일반 텍스트 문서처럼 읽기 좋은 문장이 아니다. `dump`로 쓴 순서와 `load`로 읽는 순서를 맞춰야 한다. 원본의 여러 번 `dump`·`load` 예제를 그 순서로 다시 읽자.

> [!TIP]
> 출처를 모르는 pickle 파일을 무심코 `load`하지 않는다. 이것은 기본 저장·복원 문제의 정답 조건이 아니라 파일을 다룰 때 알아둘 별도 주의점이다.


</details>
