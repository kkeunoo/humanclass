# 15 Python 모듈과 import — 연습문제

[원본 비교 본문](../../15_Python_모듈과_import.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

별도 파일 `helper.py`의 `add` 함수를 가져올 때 배운 `import` 방식 하나를 적고 호출 형태를 써 보자.

<details>
<summary>정답과 확인할 점</summary>

`import helper` 뒤 `helper.add(...)`처럼 모듈 이름을 붙여 호출할 수 있다. 파일을 찾는 위치를 확인한다.

같은 개념이 실제로 어떻게 쓰였는지는 [본문의 원본 비교](../../15_Python_모듈과_import.md)에서 다시 확인한다.

</details>
