**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

같은 폴더에 `helper.py`가 있고 그 안에 `add(a, b)`가 정의되어 있다고 가정한다. `main.py`에서 모듈 전체를 가져올 때와 함수 이름만 가져올 때 호출 형태가 어떻게 다른가?

<details>
<summary>정답과 확인할 점</summary>

`import helper`라면 `helper.add(2, 3)`처럼 모듈 이름을 붙인다. `from helper import add`라면 `add(2, 3)`으로 바로 호출한다. 두 예제의 합계는 모두 5다. 실제로 파일을 찾을 수 있어야 하므로 현재 파일과 모듈의 위치도 확인한다. 강사님·내 원본의 `fn.fn_15_1.add`와 일부 이름만 가져오는 코드를 같은 기준으로 비교하자.
