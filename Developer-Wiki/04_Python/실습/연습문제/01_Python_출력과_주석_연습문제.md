# 01 Python 출력과 주석 — 연습문제

[원본 비교 본문](../../01_Python_출력과_주석.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

다음 코드에서 **실제로 실행되는 줄**을 표시하고 출력 순서를 예상하자.

```python
print('봄')
# print('여름')
print('가을')
```

<details>
<summary>정답과 확인할 점</summary>

화면에는 `봄`, `가을`이 차례로 나온다. `#` 뒤의 `print('여름')`는 실행하지 않는 메모다. 강사님·내 원본에서도 실제 `print`가 두 줄이므로 `hello world`가 두 번 보인다. 내 코드의 세미콜론을 지워도 이 출력은 달라지지 않는다.


</details>
