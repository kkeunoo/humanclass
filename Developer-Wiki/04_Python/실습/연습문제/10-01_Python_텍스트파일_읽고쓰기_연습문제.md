**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

별도 연습 파일 `note.txt`에 `안녕`을 쓴 뒤 같은 글자를 읽는 순서를 적자. 두 번 실행하면 기존 내용에 붙는지, 다시 쓰이는지도 예상하자.

<details>
<summary>정답과 확인할 점</summary>

```python
with open('note.txt', 'w', encoding='utf-8') as file:
    file.write('안녕')
with open('note.txt', 'r', encoding='utf-8') as file:
    print(file.read())  # 안녕
```

`w`는 기존 파일이 있으면 내용을 새로 쓰므로 두 번 실행해도 `안녕안녕`으로 누적되지 않는다. `r`은 같은 파일을 읽는다. 파일 위치는 **실행 중인 작업 폴더**에 좌우되므로 수업 원본 파일을 덮지 않는 별도 연습 폴더에서 실행한다.


</details>
