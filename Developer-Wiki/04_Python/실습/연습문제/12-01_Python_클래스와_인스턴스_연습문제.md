**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`Student` 클래스의 `__init__(self, name)`에서 `self.name = name`을 했다. `Student('봄')`과 `Student('여름')` 두 인스턴스의 `name`은 각각 무엇인가? 첫 객체의 이름을 바꾸면 둘째도 바뀌는가?

<details>
<summary>정답과 확인할 점</summary>

첫 객체는 `'봄'`, 둘째는 `'여름'`이다. `self.name`은 **지금 생성 중인 인스턴스의 속성**이므로 첫 객체의 값을 바꿔도 둘째의 값은 그대로다. 강사님·내 `Person2` 코드에서도 `a`와 `b`에 서로 다른 값을 저장해 비교한다.


</details>
