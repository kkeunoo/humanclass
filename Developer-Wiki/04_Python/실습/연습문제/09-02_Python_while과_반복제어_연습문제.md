## 문제

`n = 3`에서 `while n > 0` 동안 `n`을 출력하고 1씩 줄이면 어떤 순서인가? 감소 문장이 조건문 안팎 어디에 있어야 반복이 끝나는지 설명하자.

<details>
<summary>정답과 확인할 점</summary>

```python
n = 3
while n > 0:
    print(n)
    n -= 1
```

3, 2, 1이 각각 출력된 뒤 `n`이 0이 되어 멈춘다. 감소를 빼면 조건이 계속 참이 되어 끝나지 않는다. 수업의 주사위 반복에서는 `n -= 1` 대신 **새 난수와 시도 횟수**가 어떻게 바뀌는지 추적한다.


</details>
