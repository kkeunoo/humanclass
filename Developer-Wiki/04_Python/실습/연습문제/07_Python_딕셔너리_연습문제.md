# 07 Python 딕셔너리 — 연습문제

**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

`{'사과': 1000}`에 `'배': 2000`을 추가하고 사과 가격을 읽어 보자. 이어 없는 `'귤'`을 `prices['귤']`과 `prices.get('귤')`로 읽으면 무엇이 다른지도 예상하자.

<details>
<summary>정답과 확인할 점</summary>

```python
prices = {'사과': 1000}
prices['배'] = 2000
print(prices['사과'])  # 1000
print(prices.get('귤'))  # None
```

없는 키를 `prices['귤']`로 읽으면 `KeyError`가 난다. `get`은 여기서는 `None`을 돌려준다. 강사님·내 원본의 `[]`와 `get()` 비교도 **없는 키에서의 결과**가 핵심이다.


</details>
