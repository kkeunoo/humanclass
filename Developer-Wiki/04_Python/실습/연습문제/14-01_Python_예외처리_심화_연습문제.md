**새로 구성한 복습 문제**다. 강사님이 낸 원본 문제나 내 당시 풀이가 아니다. 본문에서 강사님 코드와 내 코드를 먼저 읽고, 결과를 예상한 다음 답을 펼친다.

## 문제

다음 코드에서 `int('삼')`이 실패하면 어느 줄이 실행되는가? 숫자로 바꿀 수 있는 `'3'`으로 입력을 바꿨을 때도 `finally`의 출력이 남는지 확인하자.

```python
try:
    number = int('삼')
except ValueError:
    print('변환 실패')
finally:
    print('정리')
```

<details>
<summary>정답과 확인할 점</summary>

`'삼'`에서는 `ValueError`를 처리해 `변환 실패`, 그 뒤 `정리`가 나온다. `'3'`으로 바꾸면 변환이 성공해 `except`는 건너뛰지만 `finally`의 `정리`는 실행된다. 양쪽 원본의 여러 `except` 예제에서는 **실제 오류 종류와 처리 범위**를 먼저 맞춰 보자.


</details>
