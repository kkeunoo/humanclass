## 문제

다음 코드에서 어떤 줄이 실행되는지 찾고, 출력 순서를 적어 보자. 주석을 풀면 출력 줄은 어떻게 늘어나는가?

```python
print('A')
# print('주석')
print('B')
```

<details>
<summary>정답과 확인할 점</summary>

현재는 `A`, `B`가 두 줄로 나온다. 가운데 `#`를 지우면 `A`, `주석`, `B`가 세 줄로 나온다. 함수 정의·호출 순서는 [11장 함수](../../11_Python_함수.md)에서 배운 뒤 연습한다.


</details>
