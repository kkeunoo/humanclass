# 2. 변수란?

변수는 값을 저장한 객체를 가리키는 이름입니다.

```python
a = 10
print(a)
```

출력:

```text
10
```

`=`는 같다는 뜻의 비교 연산자가 아니라, 오른쪽 값을 왼쪽 이름에 연결하는 대입 연산자입니다.

```text
a = 10
│   └─ 값
└───── 변수 이름
```

Python에서는 변수 선언 시 자료형을 별도로 적지 않습니다.

```python
age = 20
name = "Python"
height = 175.5
```

# 3. 동적 타이핑

Python 변수는 실행 중 서로 다른 자료형의 객체를 다시 가리킬 수 있습니다.

```python
value = 10
value = "열"
```

이것을 동적 타이핑이라고 합니다.

다만 한 변수에 서로 다른 의미와 자료형을 계속 넣으면 읽기 어려워지므로, 실제 코드에서는 이름의 역할을 일관되게 유지하는 편이 좋습니다.

# 4. 기본 숫자 자료형

Python의 대표 숫자 자료형은 다음과 같습니다.

| 자료형 | 의미 | 예시 |
| --- | --- | --- |
| `int` | 정수 | `10`, `-3`, `0` |
| `float` | 실수 | `2.5`, `-1.2`, `5.0` |
| `complex` | 복소수 | `3 + 4j` |

원본에서는 주로 `int`와 `float`를 다룹니다.

```python
print(type(10))
print(type(2.5))
```

출력:

```text
<class 'int'>
<class 'float'>
```

보충 예제:

```python
number = 3 + 4j
print(type(number))
```

```text
<class 'complex'>
```

# 7. 몫 연산자 `//`

원본:

```python
c = 5 // 2
print(c)
```

출력:

```text
2
```

`//`는 단순히 소수점 이하를 잘라내는 연산자가 아니라, 나눗셈 결과를 음의 무한대 방향으로 내림하는 바닥 나눗셈입니다.

```python
print(5 // 2)
print(-5 // 2)
```

```text
2
-3
```

`-5 / 2`는 `-2.5`이고, 이를 아래쪽 정수로 내리면 `-3`입니다.

# 8. `//`와 `int()`의 차이

원본은 두 동작의 차이를 잘 보여 줍니다.

```python
print(-5 // 2)
print(int(-2.4))
```

출력:

```text
-3
-2
```

| 표현 | 처리 방식 | 결과 |
| --- | --- | ---: |
| `-5 // 2` | 나눗셈 결과를 내림 | `-3` |
| `int(-2.4)` | 0 방향으로 소수 부분 제거 | `-2` |

따라서 `//`를 단순한 소수점 버림이라고만 기억하면 음수에서 잘못 이해할 수 있습니다.

# 9. 나머지 연산자 `%`

원본에는 직접 실행 예제가 없지만 `//`와 함께 이해해야 하는 연산자입니다.

```python

```

```text
1
```

나눗셈 관계는 다음처럼 표현할 수 있습니다.

```text
피제수 = 제수 × 몫 + 나머지
5 = 2 × 2 + 1
```

활용 예:

```python
number = 8
print(number % 2 == 0)
```

짝수이면 `True`가 출력됩니다.

# 11. 복합 대입 연산자

원본:

```python
e **= 2
print(e)
```

`e **= 2`는 다음 코드와 같은 의미입니다.

```python
e = e ** 2
```

대표 복합 대입 연산자:

| 연산자 | 같은 의미 |
| --- | --- |
| `x += 1` | `x = x + 1` |
| `x -= 1` | `x = x - 1` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |
| `x //= 2` | `x = x // 2` |
| `x %= 2` | `x = x % 2` |
| `x **= 2` | `x = x ** 2` |

내 코드에서는 `e`가 먼저 `16`이므로 `e **= 2` 뒤에는 `256`이 됩니다.

강사님 코드는 그 전에 `e = e + 1`을 실행하므로 `17 ** 2`, 즉 `289`가 됩니다.

# 12. Python에는 `++`, `--` 증감 연산자가 없다

원본:

```python
x = 4
print(++x)
print(--x)
```

출력:

```text
4
4
```

이 코드는 증가·감소가 아닙니다.

```text
++x → +(+(x))
--x → -(-(x))
```

즉 단항 `+` 또는 단항 `-`가 두 번 적용될 뿐입니다.

증가와 감소는 다음처럼 작성합니다.

```python
x += 1
x -= 1
```

다음 문법은 사용할 수 없습니다.

```python
# x++
# x--
```

# 13. `int()` 형 변환

원본:

```python
print(int(2.4))
print(int(-2.4))
print(int("10") + 1)
```

출력:

```text
2
-2
11
```

`int()`는 정수로 변환 가능한 값을 정수로 만듭니다.

```python
print(int("100"))
```

문자열이 정수 형식이 아니라면 예외가 발생합니다.

```python
int("a")
```

```text
ValueError: invalid literal for int() with base 10: 'a'
```

JavaScript의 `NaN`처럼 변환 실패 값을 반환하는 것이 아니라, Python의 `int()`는 변환할 수 없으면 `ValueError`를 발생시킵니다.

# 16. 긴 실수와 출력 정밀도

원본:

```python
print(0.123456789012345678901234567890)
```

실행 결과:

```text

```

대부분의 Python 환경에서 `float`는 이진 부동소수점 형식을 사용합니다. 따라서 십진수의 모든 자릿수를 정확하게 저장하지 못할 수 있습니다.

이를 단순히 “16자리까지만 믿는다”라고 고정해서 기억하기보다는, `float`는 제한된 정밀도를 가진 근삿값이라고 이해하는 것이 정확합니다.

# 17. 부동소수점 오차

원본:

```python
print(4.3 - 2.7)
print(4.3 - 2.7 == 1.6)
```

출력:

```text
1.5999999999999996
False
```

`4.3`, `2.7`, `1.6` 같은 일부 십진 실수는 이진수로 정확히 표현되지 않습니다.

실수 비교에는 허용 오차를 고려할 수 있습니다.

```python
import math

result = 4.3 - 2.7
print(math.isclose(result, 1.6))
```

```text
True
```

금액처럼 십진 정확성이 중요한 계산에는 `decimal.Decimal` 사용도 검토할 수 있습니다.

# 19. 변수 값 교환

전통적인 방식:

```python
a = 10
b = "오백원"

c = a
```

```python
a, b = b, a
```

이 문법은 오른쪽 값을 먼저 묶은 뒤 왼쪽 변수에 각각 대입합니다.

# 20. 원본 Swap 코드의 실제 결과

두 원본은 전통적인 교환을 실행한 다음, Python 교환을 다시 실행합니다.

```python
a = 10
b = "오백원"

c = a
a = b
b = c

a, b = b, a

print(a)
print(b)
```

첫 번째 교환 뒤:

```text
a = "오백원"
b = 10
```

두 번째 교환 뒤에는 다시 원래 상태가 됩니다.

```text
a = 10
b = "오백원"
```

따라서 실제 출력은 다음과 같습니다.

```text
10
오백원
```

원본의 `# 오백원`, `# 10` 주석은 두 번째 교환까지 실행되는 전체 코드의 실제 결과와 일치하지 않습니다.

두 방식을 비교하려면 각각 별도 변수로 분리하는 것이 좋습니다.

# 25. `sep` 옵션

`sep`는 여러 출력값 사이에 넣을 문자열을 정합니다.

```python
print(1, 2, sep=",")
print(1, 2, sep="")
```

출력:

```text
1,2
12
```

활용 예:

```python
print("2026", "07", "30", sep="-")
```

```text
2026-07-30
```

---

# 26. `end` 옵션

`end`는 출력 마지막에 붙일 문자열을 정합니다. 기본값은 줄바꿈 `\n`입니다.

```python
print(1, end="")
print(2)
```

```text
12
```

원본처럼 `sep`와 함께 사용할 수도 있습니다.

```python
print(1, 2, end="", sep="")
print(1, 2, end="")
print(2)
```

여러 출력문이 같은 줄에 이어질 수 있으므로 결과를 예상하면서 사용해야 합니다.

# 28. 객체 동일성 `is`

```text
True
```

`is`는 값과 타입을 함께 비교하는 연산자가 아닙니다. 두 이름이 정확히 같은 객체를 가리키는지를 확인하는 객체 동일성 연산자입니다.

```python
first = [1, 2]
second = [1, 2]
third = first

print(first == second)  # 값은 같음
print(first is second)  # 서로 다른 객체
print(first is third)   # 같은 객체
```

```text
True
False
True
```

값 비교에는 `==`, 객체 동일성 확인에는 `is`를 사용합니다.

`None` 비교에는 `is`가 권장됩니다.

```python
value = None

if value is None:
    print("값이 없습니다.")
```

# 29. 숫자 리터럴과 `is` 사용 주의

다음 코드는 실행 환경에 따라 경고가 나타날 수 있습니다.

```python
print(1 is 1.0)
```

```text
SyntaxWarning: "is" with 'int' literal. Did you mean "=="?
```

숫자나 문자열 값 비교 목적으로 `is`를 사용해서는 안 됩니다.

```python
print(1 == 1.0)
```

타입까지 직접 확인하려면 다음처럼 구분해 검사할 수 있습니다.

```python
value = 1
print(value == 1.0 and type(value) is type(1.0))
```

하지만 일반적인 값 비교에서는 대부분 `==`가 목적에 맞습니다.

# 32. 단락 평가

`and`와 `or`는 결과가 결정되면 뒤 표현식을 평가하지 않을 수 있습니다.

```python

    print("길이가 3입니다.")
```

첫 조건이 `False`이면 `len(value)`를 실행하지 않으므로 오류를 피할 수 있습니다.

이를 단락 평가 또는 short-circuit evaluation이라고 합니다.

# 33. `and`, `or`는 항상 Boolean만 반환하지 않는다

원본:

```python
a = "글씨"
b = a or "쉬는시간"
print(b)
```

출력:

```text
글씨
```

Python의 `and`, `or`는 피연산자 중 하나의 실제 값을 반환할 수 있습니다.

`or`는 왼쪽 값이 truthy이면 왼쪽 값을 반환하고, falsy이면 오른쪽 값을 반환합니다.

```python
name = ""
display_name = name or "이름 없음"
print(display_name)
```

```text
이름 없음
```

이 방식은 간단한 기본값 선택에 유용하지만, `0`, `False`, 빈 문자열도 falsy라는 점을 주의해야 합니다.

# 46. Common Mistakes

- `=`와 `==`를 혼동합니다.
- `/` 결과가 항상 정수라고 생각합니다.
- `//`를 모든 경우의 소수점 버림으로만 기억합니다.
- `int(-2.4)`가 `-3`이라고 예상합니다.
- `++x`가 값을 1 증가시킨다고 생각합니다.
- `input()`이 숫자를 반환한다고 생각합니다.
- 문자열과 숫자를 `+`로 바로 연결합니다.
- 실수를 `==`로 무조건 직접 비교합니다.
- `is`를 값과 타입 비교에 사용합니다.
- `or`가 항상 `True` 또는 `False`만 반환한다고 생각합니다.
- 빈 문자열이나 `0`도 유효한 값일 수 있다는 점을 놓칩니다.
- 연산자 우선순위를 추측만 하고 괄호를 사용하지 않습니다.

# 47. Interview / Review

## Q1. `/`와 `//`의 차이는 무엇인가요?

`/`는 일반 나눗셈이며 보통 `float` 결과를 반환합니다. `//`는 나눗셈 결과를 음의 무한대 방향으로 내림합니다.

## Q2. `int(-2.4)`와 `-5 // 2`가 다른 이유는 무엇인가요?

`int()`는 0 방향으로 소수 부분을 제거하지만, `//`는 나눗셈 결과를 아래쪽 정수로 내립니다.

## Q3. Python에 `++` 연산자가 있나요?

없습니다. `++x`는 단항 `+`를 두 번 적용한 표현일 뿐입니다. 증가에는 `x += 1`을 사용합니다.

## Q4. `input()`의 반환 자료형은 무엇인가요?

항상 문자열 `str`입니다. 숫자 계산에는 `int()` 또는 `float()` 변환이 필요합니다.

## Q5. `==`와 `is`의 차이는 무엇인가요?

`==`는 값의 동등성을 비교하고, `is`는 두 참조가 같은 객체를 가리키는지 확인합니다.

## Q6. 실수 계산 결과를 왜 직접 `==`로 비교하면 위험할 수 있나요?

이진 부동소수점 표현 과정에서 작은 근사 오차가 생길 수 있기 때문입니다. 상황에 따라 `math.isclose()`를 사용할 수 있습니다.

## Q7. `a or b`는 무엇을 반환하나요?

`a`가 truthy이면 `a`를, falsy이면 `b`를 반환합니다. 반드시 Boolean만 반환하는 것은 아닙니다.

## Q8. `3 < 5 < 7`은 어떤 의미인가요?

`3 < 5 and 5 < 7`과 유사한 연속 비교입니다.

## 정답 2

```python
print(-7 // 2)       # -4
print(int(-7 / 2))   # -3
```

`//`는 내림하고 `int()`는 0 방향으로 소수 부분을 제거합니다.

## 정답 3

```python
number = int("25")
print(number + 5)
```

```python

```

## 정답 5

```python
a = "left"
b = "right"

a, b = b, a

print(a)

```

## 정답 6

```python
x = 3
x += 1
print(x)
```

`++x`는 단항 `+`를 두 번 적용하므로 값이 증가하지 않습니다.

## 정답 7

# 51. Key Summary

```text
변수는 값을 저장한 객체를 가리키는 이름이다.
/는 일반 나눗셈, //는 바닥 나눗셈이다.
int()는 0 방향으로 소수 부분을 제거한다.
**는 거듭제곱, +=와 **= 등은 복합 대입 연산자다.
Python에는 ++와 -- 증감 연산자가 없다.
input()은 항상 문자열을 반환한다.
float 계산에는 근사 오차가 발생할 수 있다.
==는 값 비교, is는 객체 동일성 비교다.
논리 연산자의 우선순위는 not → and → or 순서다.
and와 or는 Boolean이 아닌 실제 피연산자 값을 반환할 수 있다.
Python은 3 < 5 < 7 같은 연속 비교를 지원한다.
```
