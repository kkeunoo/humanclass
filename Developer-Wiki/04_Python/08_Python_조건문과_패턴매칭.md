## 1. 이 묶음의 목적

조건은 참·거짓을 판단하고 해당 갈래만 실행한다. match는 조건문을 무조건 더 짧게 만드는 대체물이 아니라 값의 형태에 맞춰 갈래를 고르는 구문이다. Python 버전 조건도 본문에서 확인한다.

## 2. 개념부터 실제 코드까지
