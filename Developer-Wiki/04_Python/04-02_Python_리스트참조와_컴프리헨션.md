## 1. 이 장에서 배울 것

대입·얕은 복사·is·==를 구별한다. enumerate의 번호와 실제 인덱스를 나누고 반복문·컴프리헨션·map의 간단 사용을 읽는다. 원본의 2차원 리스트 조회와 반복도 포함한다.

실제 원본·새 예제·개선안·선택 학습을 구분하고 입력·실행 순서·반환값·출력을 연결한다.

## 2. 무엇이며, 왜 필요한가

b=a는 새 리스트를 만들지 않는다. 두 이름이 같은 리스트를 가리킨다. b[0]을 바꾸면 a로 읽어도 같은 변경이 보인다. b=a.copy()는 바깥 리스트를 새로 만든다. 안쪽에 다시 리스트가 있으면 그 안쪽까지 독립적으로 복제한 것은 아니다.

```text
대입: a ─┐
         ├→ 같은 리스트
      b ─┘
복사: a → 원래 바깥 리스트
      b → 새 바깥 리스트 (안쪽 참조는 공유할 수 있음)
```

| 표현 | 받거나 만드는 것 | 혼동하지 않을 것 |
| --- | --- | --- |
| a==b | 내용이 같은지 비교 | 같은 객체라는 뜻 아님 |
| a is b | 동일 객체인지 비교 | 타입만 비교하는 것 아님 |
| for value in a | 각 요소 값 | 자동 인덱스가 아님 |
| enumerate(a,start=100) | 번호와 값 | 실제 a[0]을 a[100]으로 옮기지 않음 |
| [식 for 값 in 대상 if 조건] | 새 리스트 | 기존 결과에 자동 누적 아님 |

컴프리헨션은 먼저 대상에서 값을 꺼내고 조건을 확인하여 결과 식을 새 리스트에 넣는 구조로 읽는다. 글자 순서로 가장 앞에 보이는 식부터 모든 일을 시작한다고 읽지 않는다. 처음에는 같은 작업을 for와 append로 풀어 써 비교한다.

## 3. 작은 예제로 먼저 이해하기

**새 설명 예제 · 전체 코드.** [실행 파일](실습/책형_복습/04-02_Python_리스트참조와_컴프리헨션.py)을 제공한다. Python이 설치된 환경에서 새 .py 파일로 저장해 실행한다. 터미널은 그 파일이 있는 폴더에서 열고 `python 파일이름.py`를 실행한다. VS Code의 Python 실행 기능을 사용해도 된다. 결과는 터미널에 표시된다.



```python
a = [1, 2]
b = a
b.append(3)
print(a, b, a is b)
c = a.copy()
c[0] = 100
print(a, c, a is c)
same_values = a.copy()
print(a == same_values, a is same_values)
colors = ['빨강', '파랑']
for number, value in enumerate(colors, start=100):
    print(number, value)
by_loop = []
for number in range(6):
    if number % 2 == 0:
        by_loop.append(number * 2)
by_expression = [number * 2 for number in range(6) if number % 2 == 0]
print(by_loop)
print(by_expression)
print(list(map(int, [1.2, -3.5])))
matrix = [[10, 20], [30, 40], [50, 60]]
print(len(matrix), matrix[1][0])
print([0] * 4)
```

a와 b는 같은 리스트라 append 뒤 둘 다 세 요소다. c는 새 바깥 리스트이므로 c[0]만 100으로 바뀐다. 값이 같은 별도 복사본과 비교하면 ==는 True, is는 False다. enumerate는 100·101 번호를 주지만 colors의 인덱스는 0·1 그대로다. 반복문과 컴프리헨션은 짝수의 두 배 [0,4,8]을 각각 새로 만든다. map의 int는 -3.5를 -3으로 바꾸며, matrix의 바깥 길이는 3이고 두 번째 행의 첫 값은 30이다.

## 4. 내가 작성한 코드를 따라 읽기

아래는 원본 발췌다. 주석의 잘못된 설명도 원문을 보존하고 풀이에서 교정한다. 필요한 선언·호출·다른 파일의 정의는 다음 절까지 연결해 읽는다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/04_list.py` 120–135행

```python
a = [1,2,3,4,5]
b = a # 이렇게 넣으면 a = b의 주소값이 동일해지기 때문에, index값을 바꾸면 두개가 모두 바뀜
b[2] = 30
print(b)
print(a)

a = [1,2,3,4,5]
b = a.copy() # copy를 이용하면 모든 요소를 아예 복사해오기 때문에, 이럴 땐 주소값이 달라져 개별 값만 바꿔짐
b[2] = 30
print(b)
print(a)

a = [1,2,3,4,5]
b = a.copy() 
print( a is b ) # False (주소값이 다르기 때문에 주소까지 전부 같지 않음)
print( a == b ) # True (안에 있는 값은 같음)
```

**발췌 바로 풀이:** `b = a`는 새 리스트를 만들지 않으므로 `b[2] = 30`을 실행하면 `a[2]`도 30으로 보인다. `b = a.copy()`는 바깥 리스트를 새로 만들어 여기서처럼 숫자 요소만 있는 예제에서는 `b[2]`를 바꿔도 `a[2]`는 그대로다. 그래서 마지막의 `a is b`는 `False`, `a == b`는 `True`다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/04_list.py` 143–171행

```python
a, b = (1,2)
print(a, b)

a = [10,20,30]
for i in a :
    print(i)

# enumerate(인자)는 index, value를 같이 뽑아낼 수 있는 함수
for index, value in enumerate(a) :
    print(index, value)

# 아래처럼 인자와 ,를 쓰게되면 start로 시작 index를 조절할 수 있음
for index, value in enumerate(a, start=100) :
    print(index, value)

# 제일 큰 값을 찾기 위해 오름차순으로 정렬
a = [7,3,5,8,4]
a.sort()
print(a[len(a)-1])
print(a[-1])

# index, value 한 번 더 확인
# for index, value in enumerate(a) :
#     print(index, value)

# a의 len만큼 i를 돌게하고, 만약 i가 리스트의 마지막 일 때 그 값 출력
for i in range(len(a)) :
    if i == len(a)-1 :
        print(a[i])
```

**발췌 바로 풀이:** `for i in a`는 리스트의 값만 차례로 꺼낸다. `enumerate(a)`는 위치와 값을 함께 준다. `start=100`은 **보여 주는 번호**를 100부터 시작하게 하며 리스트 안의 실제 인덱스를 바꾸지 않는다. 내 코드에서는 정렬한 리스트의 마지막 값을 `a[-1]` 또는 길이를 이용한 위치로 읽어 본다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/04_list.py` 173–203행

```python
# a 배열에 0~9를 넣음

a = []
for i in range(10) :
    a.append(i)
print(a)

# for i in range(10)의 i를 배열로 만들어라
a = [ i for i in range(10) ] 
print(a)

a = []
for i in range(10) :
    if i % 2 == 0 :
        a.append(i)
print(a)

a = list( i for i in range(10) if i % 2 == 0 )
print(a)

# 값을 int로 바꿔서 저장
a = [1.2, 2.5, 3.7, 4.6, -3.5]
for i, value in enumerate(a) :
    a[i] = int(value)
print(a)

# 두번째 반복되는 것을 하나씩 꺼내서, 첫 번째 함수에 넣고
# 결과를 배열로 만들어 주는 것이 map과 int
a = [1.2, 2.5, 3.7, 4.6, -3.5]
a = list(map(int, a))
print(a)
```

**발췌 바로 풀이:** `for`로 빈 리스트에 `append`하는 방법과 `[i for i in range(10)]`은 이 예제에서 같은 0–9 값을 만든다. `if i % 2 == 0`을 붙이면 짝수만 남긴다. 내 `list(i for i in range(10) if i % 2 == 0)`도 결과를 리스트로 만드는 짧은 사용 예다. 이터레이터·제너레이터의 내부 구현은 사용자가 개념과 간단 사용만 배웠다고 확인했으므로 이 장의 기본 문제로 요구하지 않는다.

## 5. 선언·호출·파일이 연결되는 흐름

이름 대입 → 같은 객체 또는 새 바깥 객체 → 요소 변경 → 다른 이름으로 재관찰 순서다. 반복문은 각 값을 받거나 enumerate의 두 값을 분해해 받는다. list(map(int,a))는 각 항목에 int를 적용한 결과를 리스트로 모으는 간단 사용이다. matrix[1][0]은 바깥에서 두 번째 행을 먼저 고르고 그 행의 첫 요소를 읽는 두 번의 조회다. 함수 호출의 반환과 리스트 조회를 한 단계씩 읽는다.

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점:** 내 코드는 is와 ==를 직접 출력하고 같은 int 변환을 두 방식으로 확인했다. **교정:** copy가 모든 안쪽 요소까지 새로 만든다는 설명은 아니다. enumerate의 start는 표시 번호이며 리스트의 실제 위치 변경이 아니다. **선택:** 정렬해서 최댓값을 찾으면 원래 순서도 바뀐다. 단순 결과 확인과 입력 순서 보존 요구는 구분한다. **학습 범위:** list 안 제너레이터 표현식은 실제 간단 사용이며 내부 구현까지 요구하지 않는다.

개선안은 D 드라이브 원본을 수정한 결과가 아니다. 실제 오류·수업용 단순화·목적에 따른 선택을 구별한다.

## 7. 강사님 코드가 도움이 되는 비교



양쪽 참조·복사 원리는 같아 중복 인용하지 않는다. 강사님 컴프리헨션의 두 배 리스트 뒤 추가 append는 기존 결과에 다시 더하는 별도 작업이다. 내 코드는 빈 a로 초기화하여 짝수만 만든다. 같은 짧은 문법을 썼다고 앞 상태와 최종 결과까지 같은 것으로 묶지 않는다.

## 8. 결과를 추적하고 한 가지 바꾸기

| 조작 | a | 다른 이름의 관찰 |
| --- | --- | --- |
| a=[1,2], b=a | [1,2] | b도 같은 리스트 |
| b.append(3) | [1,2,3] | b도 [1,2,3] |
| c=a.copy(), c[0]=100 | [1,2,3] | c만 [100,2,3] |

컴프리헨션의 원본 대상 0~5 중 0·2·4가 조건을 통과하고 각 두 배 0·4·8을 결과에 넣는다. 2차원 리스트에서 len은 바깥 행 수다. [0]*10은 불변 숫자를 반복하는 현재 예제이며, 이를 그대로 중첩 리스트 행 생성에 바꾸면 참조 공유를 별도로 확인해야 한다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| b=a를 b=a.copy()로 | b 추가가 a에 안 보임 | 바깥 리스트 분리 |
| enumerate start를 1로 | 번호 1·2, 원래 목록 유지 | 번호만 변경 |
| 컴프리헨션 조건 제거 | 모든 값의 두 배 | 필터 없음 |
| matrix[1][0]을 [0][1]로 | 20 | 행과 열 선택 변경 |

다른 리스트도 바뀌면 같은 객체를 가리키는지 본다. 복사 뒤 중첩 값이 함께 바뀌면 바깥 복사와 안쪽 공유를 구분한다. 번호 100을 실제 인덱스로 넣지 않는다. 반복 결과가 누적되면 결과 리스트를 언제 새로 만들었는지 확인한다.
