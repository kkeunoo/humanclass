```text
01_hello.py
```

```bash
python 01_hello.py
```

```bash
py 01_hello.py
```

```text
hello world
```

따옴표 3개로 작성한 문자열은 `print()`에 전달하지 않았으므로 화면에 표시되지 않습니다.

# 3. print 함수

`print()`는 전달한 값을 표준 출력에 표시하는 Python 내장 함수입니다.

```python
print("hello world")
```

출력:

```text
hello world
```

여러 값도 출력할 수 있습니다.

```python
print(100)
print("Python", 100)
```

출력:

```text
100
Python 100
```

# 4. 문자열과 따옴표

Python 문자열은 작은따옴표 또는 큰따옴표로 작성할 수 있습니다.

```python
print('hello world')
print("hello world")
```

두 코드의 출력 결과는 같습니다.

```python
print("I'm learning Python")
print('그는 "Python"을 공부합니다')
```

문자열 내부에 포함할 따옴표에 따라 바깥 따옴표를 선택할 수 있습니다.

---

# 5. 한 줄 주석

Python의 한 줄 주석은 `#`으로 시작합니다.

```python
# 프로그램 실행 여부를 확인한다.
print("hello world")
```

코드 뒤에도 작성할 수 있습니다.

```python
print("hello")  # 인사말 출력
```

주석은 코드가 무엇을 하는지 그대로 반복하기보다 작성 이유나 주의점을 설명할 때 더 유용합니다.

---

# 6. 주석 처리된 들여쓰기 예제

두 원본에는 다음 형태가 있습니다.

```python
print('hello world')
    # print('hello world')
```

두 번째 줄은 주석이므로 실행되지 않습니다. 실제 실행문을 같은 위치에 작성하면 문제가 됩니다.

```python
print("hello world")
    print("hello world")
```

```text
IndentationError: unexpected indent
```

블록을 시작하지 않았는데 갑자기 들여쓰기된 실행문이 등장했기 때문입니다.

# 7. 올바른 들여쓰기

들여쓰기는 `if`, `for`, `while`, `def`, `class` 등의 하위 블록을 표현할 때 사용합니다.

```python
if True:
    print("hello world")
```

공백 4칸을 기본 단위로 사용하는 것이 일반적입니다.

# 10. 여러 줄 문자열은 주석인가?

원본에는 `여러줄 주석`이라고 작성되어 있지만, 정확히는 문자열 리터럴입니다.

| 표현 | 실제 의미 |
| --- | --- |
| `# 설명` | Python 한 줄 주석 |
| `'''...'''` | 여러 줄 문자열 |
| `"""..."""` | 여러 줄 문자열 |

단독 문자열은 결과가 사용되지 않아 주석처럼 보일 수 있지만 실제로는 문자열을 표현하는 문법입니다.

여러 줄 설명은 각 줄에 `#`을 작성하는 방법이 가장 명확합니다.

```python
# 첫 번째 설명
# 두 번째 설명
```

---

# 11. Docstring

함수, 클래스, 모듈의 첫 번째 문장에 작성한 문자열은 문서 문자열인 docstring으로 사용될 수 있습니다.

```python
def hello():
    """인사말을 출력하는 함수입니다."""
    print("hello")
```

```python
print(hello.__doc__)
```

출력:

```text
인사말을 출력하는 함수입니다.
```

# 12. 세미콜론

내 코드:

```python
print('hello world');
```

Python에서 문장 끝의 세미콜론은 필수가 아닙니다.

권장 형태:

```python
print('hello world')
```

한 줄에 여러 문장을 작성할 수는 있지만 읽기 어렵습니다.

```python
print("A"); print("B")
```

권장:

```python
print("A")
print("B")
```

# 17. 내 코드의 개선점

- 불필요한 세미콜론을 제거하는 것이 좋습니다.

# 21. 실무 활용

`print()`는 다음 상황에서 활용할 수 있습니다.

- 프로그램이 특정 위치까지 실행되었는지 확인
- 변수에 들어 있는 값 확인
- 조건문과 반복문의 실행 흐름 확인
- 간단한 스크립트 결과 출력
- 오류 재현 중 중간 상태 확인

규모가 큰 프로그램에서는 `print()` 외에 로깅 도구를 사용해 출력 수준과 저장 위치를 관리합니다.

# 22. Common Mistakes

- 문자열 따옴표를 열고 닫지 않습니다.
- `print`를 `Print`처럼 대문자로 작성합니다.
- `print` 뒤의 괄호를 빠뜨립니다.
- 블록이 아닌 위치에서 실행문을 임의로 들여씁니다.
- 탭과 공백을 섞습니다.
- 따옴표 3개를 공식 여러 줄 주석 문법이라고만 기억합니다.
- JavaScript 습관으로 모든 문장 끝에 세미콜론을 붙입니다.

# 23. Interview / Review

## Q1. `print()`는 무엇을 하나요?

전달받은 값을 표준 출력에 표시하는 Python 내장 함수입니다.

## Q2. Python 한 줄 주석은 어떻게 작성하나요?

`#` 뒤에 내용을 작성합니다.

## Q3. 따옴표 3개는 여러 줄 주석인가요?

정확히는 여러 줄 문자열입니다. 특정 위치에서는 docstring으로 사용될 수 있습니다.

## Q4. Python에서 세미콜론은 필수인가요?

필수가 아닙니다. 일반적으로 줄바꿈으로 문장을 구분합니다.

## Q5. `IndentationError: unexpected indent`는 언제 발생하나요?

블록이 시작되지 않은 위치에서 실행문이 갑자기 들여쓰기되거나 들여쓰기 규칙이 맞지 않을 때 발생할 수 있습니다.
