# 개요

Python 프로그램을 처음 작성할 때 가장 먼저 확인해야 하는 것은 코드가 실제로 실행되는지 여부다.

`print()`를 사용하면 문자열이나 숫자 같은 값을 화면에 출력할 수 있다.

```text
Python 코드 작성
    ↓
파일 실행
    ↓
print()가 값 출력
    ↓
실행 결과 확인
```

코드에는 실행문만 작성하는 것이 아니라, 작성 이유나 주의점을 남기기 위한 주석도 사용할 수 있다.

```text
실행할 코드
+
개발자를 위한 설명
    ↓
프로그램 동작과 코드 의도 확인
```

Python에서는 들여쓰기도 문법의 일부다. 블록이 아닌 위치에서 실행문을 임의로 들여쓰면 오류가 발생할 수 있다.

# 1. 첫 Python 출력

## 1-1. 내 코드

```python
print('hello world');
```

## 1-2. 강사님 코드

```python
print('hello world')
```

두 코드의 출력 결과는 같다.

내 코드에는 문장 끝에 세미콜론이 있고, 강사님 코드에는 세미콜론이 없다.

## 1-3. 구성

| 요소 | 의미 |
| --- | --- |
| `print` | 값을 출력하는 Python 내장 함수 |
| `()` | 함수에 전달할 값을 작성하는 위치 |
| `'hello world'` | 출력할 문자열 |
| `;` | Python에서는 일반적으로 필요하지 않은 문장 구분 기호 |

## 1-4. 실행

```python
print("hello world")
```

## 1-5. 출력 결과

```text
hello world
```

## 1-6. 동작 과정

```text
print() 호출
    ↓
괄호 안의 문자열 확인
    ↓
표준 출력에 문자열 표시
    ↓
기본 줄바꿈 실행
```

> [!IMPORTANT]
> Python은 대소문자를 구분한다.
>
> `print()`는 올바르지만 `Print()`는 다른 이름이므로 사용할 수 없다.

# 2. `print()`는 함수다

`print()`는 Python이 기본으로 제공하는 내장 함수다.

함수는 괄호 안에 전달받은 값을 이용해 정해진 작업을 수행한다.

```python
print("Python")
print(100)
print(True)
```

## 2-1. 출력 결과

```text
Python
100
True
```

문자열뿐 아니라 숫자와 불리언 값도 출력할 수 있다.

## 2-2. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `print("Python")` | 문자열 출력 |
| `print(100)` | 정수 출력 |
| `print(True)` | 불리언 값 출력 |

> [!TIP]
> 처음 코드를 작성할 때 `print()`로 중간값을 확인하면 코드가 예상대로 실행되는지 이해하기 쉽다.

---

# 3. 작은따옴표와 큰따옴표

Python 문자열은 작은따옴표 또는 큰따옴표로 작성할 수 있다.

```python
print('hello world')
print("hello world")
```

## 3-1. 출력 결과

```text
hello world
hello world
```

두 문자열의 값은 같다.

## 3-2. 따옴표 선택

문자열 안에 작은따옴표가 있다면 바깥에 큰따옴표를 사용할 수 있다.

```python
print("I'm learning Python")
```

문자열 안에 큰따옴표가 있다면 바깥에 작은따옴표를 사용할 수 있다.

```python
print('그는 "Python"을 공부합니다.')
```

## 3-3. 출력 결과

```text
I'm learning Python
그는 "Python"을 공부합니다.
```

> [!TIP]
> 프로젝트에서는 작은따옴표와 큰따옴표 중 한 가지 스타일을 정해 일관되게 사용하는 것이 좋다.

# 4. 여러 값 출력

`print()`에는 여러 값을 쉼표로 구분해 전달할 수 있다.

```python
print("학습 번호:", 1)
print("언어:", "Python")
```

## 4-1. 출력 결과

```text
학습 번호: 1
언어: Python
```

여러 값을 전달하면 기본적으로 값 사이에 공백이 들어간다.

```text
"학습 번호:"
+
공백
+
1
```

이후 문서에서 `sep`과 `end`를 이용해 출력 형식을 변경하는 방법을 학습한다.

# 5. 한 줄 주석

Python의 한 줄 주석은 `#`으로 시작한다.

## 5-1. 내 코드

```python
# 주석
# python은 들여쓰기로 판단함
```

## 5-2. 강사님 코드

```python
# 주석
```

내 코드에는 주석의 기본 예시와 들여쓰기에 관한 추가 메모가 있다.

## 5-3. 실행 예시

```python
# 프로그램 실행 여부를 확인한다.
print("프로그램 시작")
```

## 5-4. 출력 결과

```text
프로그램 시작
```

주석은 실행되지 않으므로 화면에 표시되지 않는다.

## 5-5. 왜 사용할까?

- 코드의 작성 이유를 남길 수 있다.
- 주의해야 할 조건을 설명할 수 있다.
- 임시 작업이나 복습 내용을 기록할 수 있다.
- 다른 개발자가 코드 의도를 파악하도록 도울 수 있다.

---

# 6. 코드 뒤의 주석

실행문 뒤에도 주석을 작성할 수 있다.

```python
print("프로그램 시작")  # 실행 시작 여부 확인
```

## 6-1. 출력 결과

```text
프로그램 시작
```

## 6-2. 주의할 점

코드 뒤의 주석은 짧은 설명에 적합하다.

좋지 않은 예:

```python
print("프로그램 시작")  # 프로그램 시작을 출력한다.
```

코드가 이미 같은 내용을 보여주기 때문에 주석의 가치가 크지 않다.

개선:

```python
# 배포 환경에서 초기화가 완료되었는지 확인하기 위한 임시 출력
print("프로그램 시작")
```

> [!TIP]
> 주석은 **무엇을 하는지**보다 **왜 이렇게 작성했는지**를 설명할 때 더 유용하다.

---

# 7. 주석으로 코드 실행 제외

코드 앞에 `#`을 작성하면 해당 줄은 실행되지 않는다.

```python
print("첫 번째 출력")
# print("두 번째 출력")
print("세 번째 출력")
```

## 7-1. 출력 결과

```text
첫 번째 출력
세 번째 출력
```

두 번째 출력문은 주석 처리되어 실행되지 않는다.

## 7-2. 언제 사용할까?

- 오류가 발생하는 예제를 잠시 비활성화할 때
- 코드 일부를 비교하며 실행할 때
- 학습 과정에서 다른 결과를 확인할 때

> [!WARNING]
> 사용하지 않는 코드를 장기간 주석으로 남겨두면 파일이 복잡해질 수 있다.
>
> 더 이상 필요하지 않은 코드는 Git 기록을 믿고 삭제하는 것이 좋다.

# 8. 작은따옴표 3개

## 8-1. 내 코드

```python
'''
여러줄 주석
여러줄 주석
'''
```

## 8-2. 강사님 코드

```python
'''
여러 줄
여러 줄
'''
```

두 코드 모두 작은따옴표 3개로 여러 줄 문자열을 작성한다.

원본에서는 `여러줄 주석`이라고 표현했지만 정확한 의미는 **여러 줄 문자열**이다.

## 8-3. 변수에 저장

```python
message = '''첫 번째 줄
두 번째 줄'''

print(message)
```

## 8-4. 출력 결과

```text
첫 번째 줄
두 번째 줄
```

# 9. 큰따옴표 3개

## 9-1. 내 코드

```python
"""
여러줄 주석
여러줄 주석
"""
```

## 9-2. 강사님 코드

```python
"""
여러 줄
여러 줄
"""
```

큰따옴표 3개도 여러 줄 문자열을 만든다.

message = """Python

Python

| `'''...'''` | 작은따옴표로 만든 여러 줄 문자열 |

둘 다 여러 줄 문자열을 만들 수 있다.

# 10. 여러 줄 문자열은 주석일까?

여러 줄 문자열은 실제 주석 문법이 아니다.

```python
"""
이 문장은 문자열입니다.
"""
```

독립적으로 작성하고 결과를 사용하지 않으면 화면에 출력되지 않아 주석처럼 보일 수 있다.

하지만 Python은 이 표현을 문자열 객체로 해석한다.

## 10-1. 실제 여러 줄 주석

여러 줄 설명을 일반 주석으로 작성하려면 각 줄에 `#`을 사용한다.

```python
# 첫 번째 설명
# 두 번째 설명
# 세 번째 설명
```

## 10-2. 구분

```text
# 설명
→ 실제 주석

'''설명'''
"""설명"""
→ 여러 줄 문자열
```

> [!IMPORTANT]
> 작은따옴표 또는 큰따옴표 3개를 “Python의 여러 줄 주석 문법”이라고만 기억하면 안 된다.
>
> 정확히는 여러 줄 문자열이며, 특정 위치에서 Docstring으로 사용될 수 있다.

---

# 11. Docstring

함수·클래스·모듈의 첫 번째 문장에 작성한 문자열은 Docstring으로 사용될 수 있다.

## 11-1. 함수 Docstring

```python
def greet():
    """인사말을 출력한다."""
    print("안녕하세요")
```

## 11-2. 실행

```python
greet()
print(greet.__doc__)
```

## 11-3. 출력 결과

```text
안녕하세요
인사말을 출력한다.
```

## 11-4. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `"""인사말을 출력한다."""` | 함수의 목적 설명 |
| `greet()` | 함수 실행 |
| `greet.__doc__` | 함수에 저장된 Docstring 확인 |

## 11-5. 실무에서는?

Docstring은 다음 내용을 설명할 때 활용할 수 있다.

- 함수의 목적
- 입력값의 규칙
- 반환값의 의미
- 발생 가능한 예외
- 공개 클래스와 메서드의 사용법

단순한 코드에 과도하게 긴 Docstring을 작성할 필요는 없다.

# 12. Python과 들여쓰기

Python은 들여쓰기로 코드 블록을 구분한다.

## 12-1. 내 코드의 메모

```python
# 'indent' err는 들여쓰기를 잘못했다는 것
# python은 들여쓰기로 판단함
```

이 메모는 Python에서 들여쓰기가 단순한 정렬이 아니라 문법이라는 점을 강조한다.

## 12-2. 정상 코드

```python
if True:
    print("조건문 내부")
```

## 12-3. 출력 결과

```text
조건문 내부
```

`print()`가 `if`문의 내부 코드이므로 들여쓰기되어 있다.

> [!TIP]
> Python에서는 일반적으로 공백 4칸을 들여쓰기 한 단계로 사용한다.

---

# 13. 주석 처리된 들여쓰기

두 원본에는 다음 형태가 있다.

```python
print("hello world")
    # print("hello world")
```

두 번째 줄은 주석이므로 현재 파일을 실행할 때 오류가 발생하지 않는다.

Python은 주석의 들여쓰기를 실행문의 블록으로 처리하지 않는다.

## 13-1. 실제 실행문으로 변경하면

```python
print("hello world")
    print("hello world")
```

## 13-2. 발생 결과

```text
IndentationError: unexpected indent
```

## 13-3. 오류 원인

```text
첫 번째 출력문 실행
    ↓
블록을 시작하는 문법 없음
    ↓
두 번째 실행문이 갑자기 들여쓰기됨
    ↓
IndentationError
```

## 13-4. 올바른 코드

```python
print("hello world")
print("hello world")
```

## 13-5. 출력 결과

```text
hello world
hello world
```

# 14. `IndentationError`

`IndentationError`는 들여쓰기 규칙이 맞지 않을 때 발생한다.

대표적인 원인:

- 블록이 아닌 위치에서 갑자기 들여쓰기
- 같은 블록의 들여쓰기 너비가 다름
- 탭과 공백 혼용
- 하위 블록에 실행문이 없음

## 14-1. 잘못된 너비

```python
if True:
    print("첫 번째")
      print("두 번째")
```

## 14-2. 개선

```python
if True:
    print("첫 번째")
    print("두 번째")
```

> [!WARNING]
> 들여쓰기를 화면에서 비슷하게 맞추는 것만으로는 부족하다.
>
> 에디터에서 탭과 공백 설정을 통일하고 공백 4칸을 사용하는 것이 좋다.

# 15. 세미콜론

## 15-1. 내 코드

```python
print('hello world');
```

## 15-2. 강사님 코드

```python
print('hello world')
```

Python에서 문장 끝의 세미콜론은 필수가 아니다.

## 15-3. 권장 형태

```python
print("hello world")
```

## 15-4. 한 줄에 여러 문장

문법적으로 다음과 같이 작성할 수 있다.

```python
print("A"); print("B")
```

## 15-5. 출력 결과

```text
A
B
```

하지만 일반적으로 한 줄에 하나의 문장을 작성한다.

```python
print("A")
print("B")
```

## 15-6. 왜 제거할까?

- Python의 일반적인 코드 스타일과 맞는다.
- 한 줄의 실행 흐름이 단순해진다.
- 수정 내역을 확인하기 쉽다.
- JavaScript 등 다른 언어의 습관과 구분할 수 있다.

# 16. 내 코드와 강사님 코드 비교

| 비교 항목 | 내 코드 | 강사님 코드 |
| --- | --- | --- |
| `print()` | 세미콜론 사용 | 세미콜론 없음 |
| 들여쓰기 오류 | 오류 이름과 원인 메모 추가 | 잘못 들여쓴 주석 예시 |
| 한 줄 주석 | 주석과 들여쓰기 설명 | 기본 주석 예시 |
| 작은따옴표 3개 | `여러줄 주석`이라고 기록 | `여러 줄`이라고 기록 |
| 큰따옴표 3개 | `여러줄 주석`이라고 기록 | `여러 줄`이라고 기록 |
| 최종 출력 | `hello world` 출력 | `hello world` 출력 |

## 16-1. 내 코드의 장점

- `IndentationError: unexpected indent`를 직접 기록했다.
- Python이 들여쓰기로 블록을 구분한다는 점을 메모했다.
- 수업 중 이해한 내용을 코드 가까이에 남겼다.

## 16-2. 내 코드의 개선점

- 불필요한 세미콜론을 제거하는 것이 좋다.
- `여러줄 주석`을 `여러 줄 문자열`로 구분해야 한다.
- 코드의 역할을 그대로 반복하는 주석보다 오류 원인과 작성 이유를 남기는 것이 좋다.

## 16-3. 강사님 코드의 장점

- 첫 Python 파일에 필요한 문법을 간결하게 보여 준다.
- Python 스타일에 맞게 세미콜론을 사용하지 않는다.
- 작은따옴표와 큰따옴표 3개를 함께 비교할 수 있다.

## 16-4. 강사님 코드의 보충점

- 들여쓰기된 주석과 실제 실행문의 차이를 설명하면 더 명확하다.
- 따옴표 3개가 실제 주석이 아니라 문자열이라는 보충 설명이 필요하다.
- 오류 발생 코드와 수정 코드를 함께 비교하면 이해하기 쉽다.

# 17. 기존 코드에서 개선 코드로 바꾼 이유

## 17-1. 세미콜론 제거

기존:

```python
print('hello world');
```

개선:

```python
print("hello world")
```

개선 이유:

- Python에서는 세미콜론이 필요하지 않다.
- 일반적인 Python 코드 스타일과 맞는다.

## 17-2. 여러 줄 주석 표현 수정

기존 이해:

```text
'''...'''
"""..."""
→ 여러 줄 주석
```

개선된 이해:

```text
'''...'''
"""..."""
→ 여러 줄 문자열
→ 특정 위치에서는 Docstring
```

## 17-3. 주석 내용 개선

기존:

```python
# 주석
```

개선:

```python
# 블록이 아닌 위치에서 실행문을 들여쓰면
# IndentationError가 발생할 수 있다.
```

개선 이유:

- 주석만 보고도 어떤 내용을 주의해야 하는지 알 수 있다.
- 코드가 보여주지 않는 오류 원인을 설명한다.

# 18. 실무형 출력 예제

프로그램의 시작과 처리 결과를 확인하는 간단한 예제다.

```python
app_name = "HumanClass"
loaded_user_count = 3

print(f"{app_name} 프로그램을 시작합니다.")
print("불러온 사용자 수:", loaded_user_count)
```

## 18-1. 출력 결과

```text
HumanClass 프로그램을 시작합니다.
불러온 사용자 수: 3
```

## 18-2. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `app_name` | 프로그램 이름 저장 |
| `loaded_user_count` | 불러온 사용자 수 저장 |
| f-string | 문자열 안에 변수값 삽입 |
| 여러 인자 `print()` | 설명과 숫자를 함께 출력 |

## 18-3. 실무에서는?

학습 단계에서는 `print()`로 다음 내용을 확인할 수 있다.

- 함수가 실행되었는지
- 변수에 어떤 값이 저장되었는지
- 조건문이 어느 경로로 실행되었는지
- 반복문이 몇 번 실행되는지
- 파일에서 데이터를 정상적으로 읽었는지

규모가 큰 프로그램에서는 출력 수준과 저장 위치를 관리할 수 있는 `logging` 모듈을 사용한다.

> [!TIP]
> `print()`는 빠른 확인에 유용하지만, 확인용 출력이 너무 많아지면 실제 결과와 섞일 수 있다.
>
> 작업이 끝난 디버깅 출력은 제거하거나 로그로 전환한다.

# 마무리

출력과 주석은 Python 학습의 시작이지만 이후 모든 코드에서 계속 사용된다.

```text
print()로 실행 결과 확인
    ↓
주석으로 코드 의도 기록
    ↓
들여쓰기로 코드 구조 표현
    ↓
오류 원인을 확인하며 수정
```

이 기본 흐름을 익히면 이후 변수·조건문·반복문·함수에서 코드가 어떤 순서로 실행되는지 더 쉽게 확인할 수 있다.

# V3 동작 백과 보강 — `print()`가 화면에 보이기까지

`print("A", 10, sep="-")`에서 문자열과 정수는 소스 코드에서 만들어진 인수다. Python은 `print`를 호출하고 각 값을 문자열 표현으로 바꾼 뒤 `sep`로 연결하며, 기본 `end="\n"`을 붙여 표준 출력(stdout)으로 보낸다. 터미널은 그 표준 출력을 화면에 표시한다.

```python
name = "Python"
print("학습", name, sep=": ", end="!\n")
# 이 줄은 실행되지 않는다.
```

```text
학습: Python!
```

주석은 설명용 텍스트라 실행 결과가 없다. 반면 잘못된 들여쓰기는 블록의 소속을 바꾸거나 `IndentationError`를 일으킨다. 출력이 예상과 다르면 값뿐 아니라 `sep`, `end`, 이스케이프 문자, 실행 순서를 함께 확인한다.
