## 1. 이 장에서 배울 것

print의 인수와 출력 결과를 구별하고 주석 줄이 실행되지 않는 이유를 설명한다. 여러 줄 문자열을 주석 문법으로 외우지 않고, 들여쓰기 오류 예시와 현재 정상 코드도 나누어 읽는다.

실제 원본·새 예제·개선안·선택 학습을 구분하고 입력·실행 순서·반환값·출력을 연결한다.

<a id="concepts"></a>

## 2. 무엇이며, 왜 필요한가

print는 전달한 값을 출력하는 함수다. print('hello world')에서 따옴표는 문자열의 시작과 끝을 구별하는 코드 표기이고, 기본 출력에는 그 따옴표가 붙지 않는다. print라는 이름에 괄호를 붙여 호출하며 기본적으로 출력 끝에서 줄을 바꾼다.

#은 문자열 바깥에서 그 줄의 주석을 시작한다. 사람이 남긴 의도·메모를 Python의 실행 작업과 구분한다. 반대로 '# 표시'처럼 문자열 안에 있는 #은 글자 자체다. 주석 처리한 print와 # 글자를 출력하는 print는 다르다.

| 작성 | 역할 | .py 파일의 출력 |
| --- | --- | --- |
| print('시작') | 함수 호출 | 시작 |
| # print('메모') | 주석 | 없음 |
| '그냥 문자열' | 문자열 표현식 | 자동 출력 없음 |
| 따옴표 세 개의 문자열 | 여러 줄 문자열 값 | print 등에 쓰지 않으면 자동 출력 없음 |

따옴표 세 개는 여러 줄 문자열을 만드는 문법이다. 독립 표현식으로 놓아 화면에 안 나온 것과 # 주석인 것은 같은 문법이 아니다. 함수 첫 문장의 설명 문자열인 docstring은 함수 장에서 용도와 위치를 다시 읽는다.

> 📚 **출처 · 본문 설명 확인:** [Python 공식 입문: 주석과 문자열](https://docs.python.org/ko/3/tutorial/introduction.html), [print](https://docs.python.org/ko/3/library/functions.html#print). 실제 배운 문법의 의미를 확인한 근거다. 예제·표·풀이 자체는 수업 자료를 바탕으로 새로 구성했다. 외부 문장을 직접 인용하지 않았다. 이번 문법 확인 기간: 2026-10-28~29.

## 3. 작은 예제로 먼저 이해하기

**새 설명 예제 · 전체 코드.** [실행 파일](실습/책형_복습/01_Python_출력과_주석.py)을 제공한다. Python이 설치된 환경에서 새 .py 파일로 저장해 실행한다. 터미널은 그 파일이 있는 폴더에서 열고 `python 파일이름.py`를 실행한다. VS Code의 Python 실행 기능을 사용해도 된다. 결과는 터미널에 표시된다.



```python
print('시작')
# print('주석 안의 호출')
'''
여러 줄 문자열
하지만 이 파일에서는 출력하지 않음
'''
print('#은 문자열 안에서는 글자')
print('끝')
```

첫 호출이 시작을 출력한다. 주석의 호출은 실행하지 않고 여러 줄 문자열도 출력에 전달하지 않았다. 다음 print의 #은 따옴표 안이라 일반 글자로 보인다. 마지막 끝이 세 번째 출력 줄이 된다. 줄 수만 세지 말고 각 줄이 어느 호출에서 나왔는지 연결한다.

**예상 출력 또는 관찰:**

```text
시작
#은 문자열 안에서는 글자
끝
```

## 4. 내가 작성한 코드를 따라 읽기

아래는 원본 발췌다. 주석의 잘못된 설명도 원문을 보존하고 풀이에서 교정한다. 필요한 선언·호출·다른 파일의 정의는 다음 절까지 연결해 읽는다.

### 내 코드 — 원본 발췌

출처: `D:/workspace/workspace_python/01_hello.py` 1–19행

```python
# 'indent' err는 들여쓰기를 잘못했다는 것
# 아래처럼 진행하면 IndentationError: unexpected indent 가 나옴
print('hello world');
    # print('hello world'); 

# 주석
# python은 들여쓰기로 판단함

'''
여러줄 주석
여러줄 주석
'''

"""
여러줄 주석
여러줄 주석
"""

print('hello world');
```

**발췌 바로 풀이:** 첫 print와 마지막 print만 호출되어 hello world가 두 줄 나온다. 세미콜론은 이 자리에서 허용되나 필수가 아니다. 중간의 # 줄과 여러 줄 문자열은 서로 다른 문법이며, 이 파일의 문자열 표현식은 출력하지 않는다.

내 파일의 활성 print는 처음과 끝 두 개다. 각각 hello world를 출력하므로 결과도 같은 글자 두 줄이다. 들여쓴 # print는 주석이라 현재 파일에서 들여쓰기 예외를 만들지 않는다. 여러 줄 주석이라는 내 메모는 실행에서 출력되지 않는 문자열 표현식을 가리키지만 정확한 문법 이름은 여러 줄 문자열이다.

<a id="connections"></a>

## 5. 선언·호출·파일이 연결되는 흐름

문자열 값 준비 → print에 인수 전달 → 함수가 터미널 출력과 줄바꿈 수행 → 다음 실행 줄 순서다. # 뒤 코드는 호출 연결에 들어가지 않는다. 지금은 사용자 정의 함수나 import 대상이 없으며 Python 내장 print를 바로 사용한다.

<a id="review"></a>

## 6. 잘한 점·아쉬운 점·개선 방향

**잘한 점:** 내 주석은 들여쓰기와 실행 줄을 관찰하려는 흔적이다. **교정:** 현재 주석 줄 때문에 오류가 난다고 설명하지 않는다. **표현 개선:** 여러 줄 주석이라는 편의 표현만 남기면 함수의 docstring이나 문자열 값과 헷갈릴 수 있어 정확한 차이를 함께 적는다. **작성 선택:** 세미콜론을 제거해도 현재 출력은 같으며 한 줄에 한 작업을 쓰면 비교하기 쉽다.

개선안은 D 드라이브 원본을 수정한 결과가 아니다. 실제 오류·수업용 단순화·목적에 따른 선택을 구별한다.

<a id="teacher"></a>

## 7. 강사님 코드가 도움이 되는 비교



양쪽 활성 print가 두 개여서 실제 출력은 같다. 강사님은 줄 끝 세미콜론 없이 썼다. 이 차이는 결과 오류가 아니므로 양쪽 전체 코드를 나열하지 않고 내 원본을 기준으로 설명한다.

<a id="results"></a>

## 8. 결과를 추적하고 한 가지 바꾸기

| 원본 구간 | 실제 호출 수 | 화면 |
| --- | --- | --- |
| 첫 print | 1 | hello world |
| # 주석 | 0 | 없음 |
| 여러 줄 문자열 둘 | print 호출 0 | 없음 |
| 마지막 print | 1 | hello world |

문자열 표현식이 파일에서 화면에 안 나온다고 모든 환경에서 평가 자체가 금지되거나 오류라는 뜻은 아니다. 대화형 실행의 자동 값 표시와 파일의 출력 동작을 구별한다.

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| 주석의 # 제거 | 주석 안의 호출도 출력 | 실행 문장으로 바뀜 |
| 첫 문자열만 다른 글로 변경 | 첫 출력만 변경 | 각 호출의 인수 차이 |
| 마지막 print 제거 | 끝 출력 없음 | 해당 호출 없음 |

결과에 따옴표까지 보여야 한다고 생각하지 않는다. #이 출력되는지 궁금하면 문자열 안인지 바깥인지 먼저 본다. 임의 들여쓰기 문법 오류를 실험할 때는 기존 정상 파일의 복사본에서 한 줄만 바꿔 확인한다.

## 10. 복습과 빠른 정리

1. 내 원본의 hello world 출력은 몇 줄인가?
2. 문자열 안 #도 주석인가?
3. 따옴표 세 개는 #과 같은 주석 문법인가?

<details>
<summary>풀이 — 먼저 자신의 답을 적은 뒤 펼치기</summary>

두 줄이다. 문자열 안 #은 글자다. 따옴표 세 개는 문자열 문법이며 이 파일에서 출력하지 않은 것과 주석은 구별한다.
