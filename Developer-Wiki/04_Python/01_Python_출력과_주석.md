# 01. 출력과 주석 — 처음 실행해 보는 Python

[Python 목차](README.md) · [이전: 오류 읽기](00-02_Python_오류와_예외.md)

첫 실습은 `print`로 글자를 출력하고, `#`로 실행하지 않을 메모를 남기는 것이다. 같은 문자열이 두 번 출력되는 이유를 원본 코드에서 직접 세어 보자.

### 강사님 코드

출처: `teacher/workspace_python/_01_hello.py` 1–15행 · **원본 발췌**

```python
print('hello world')
    # print('hello world')

# 주석

'''
여러 줄
여러 줄
'''

"""
여러 줄
여러 줄
"""
print('hello world')
```

### 내 코드

출처: `me/workspace_python/01_hello.py` 1–19행 · **원본 발췌**

```python
# 'indent' err는 들여쓰기를 잘못했다는 것
# 아래처럼 진행하면 IndentationError: unexpected indent 가 나옴
print('hello world');
    # print('hello world'); 

# 주석
# python은 들여쓰기로 판단함

'''
여러줄 주석
여러줄 주석
'''

"""
여러줄 주석
여러줄 주석
"""

print('hello world');
```

`print('hello world')`는 괄호 안 문자열을 화면에 출력한다. 두 파일 모두 주석이 아닌 `print`가 두 번이므로 출력도 두 줄이다. 내 코드는 세미콜론을 붙였지만 이 예제의 출력 결과는 같다. 강사님 코드처럼 쓰면 한 문장씩 읽기 쉽다.

`#` 뒤의 내용은 그 줄에서 실행되지 않는다. 들여쓴 주석 줄은 실행되지 않으므로 여기서는 들여쓰기 오류가 나지 않는다. 반면 `print` 같은 실행 문장을 아무 블록 없이 갑자기 들여쓰면 오류가 날 수 있다. **실제로 실행되는 줄인지**부터 보고 오류를 판단하자.

따옴표 세 개로 묶인 문자열은 여러 줄에 걸쳐 쓸 수 있다. 이 파일에서는 변수에 저장하거나 `print`에 전달하지 않았으므로 화면에 나오지 않는다. 함수에 설명을 붙이는 docstring과 단순 `#` 주석은 쓰임이 다르며, 자세한 docstring은 함수 장에서 다시 본다.
