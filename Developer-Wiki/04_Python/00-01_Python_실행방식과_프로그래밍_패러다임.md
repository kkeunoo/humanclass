# 00-01. Python 실행 방식 — 파일을 읽고 결과를 확인하기

[Python 목차](README.md) · [다음: 오류 읽기](00-02_Python_오류와_예외.md)

먼저 `.py` 파일을 실행하면 **주석이 아닌 문장이 위에서 아래로 실행**된다고 이해하자. 실제 수업 원본은 간단한 출력·주석·들여쓰기부터 시작한다. “인터프리터 언어”나 “객체지향 언어”라는 이름을 암기하기보다, 눈앞의 코드가 실행될 때 무엇이 출력되는지 읽는 연습이 우선이다.

**설명용 작은 예제 — 원본 발췌 아님**

```python
print('첫째')
# print('이 줄은 실행되지 않음')
print('둘째')
# 출력: 첫째 → 둘째 (두 줄)
```

주석의 `print`는 실행하지 않는다. 이 결과를 먼저 예상한 뒤 양쪽 수업 원본에서 실제로 실행되는 줄을 찾아보자.

### 강사님 코드

출처: `teacher/workspace_python/_01_hello.py` 1–2행 · **원본 발췌**

```python
print('hello world')
    # print('hello world')
```

### 내 코드

출처: `me/workspace_python/01_hello.py` 1–4행 · **원본 발췌**

```python
# 'indent' err는 들여쓰기를 잘못했다는 것
# 아래처럼 진행하면 IndentationError: unexpected indent 가 나옴
print('hello world');
    # print('hello world'); 
```

첫 두 줄만 비교해도 실행 문장과 주석의 차이를 볼 수 있다. **전체 파일의 두 번째 `print`와 실제 출력**은 [01 출력과 주석](01_Python_출력과_주석.md)에서 확인한다. 들여쓴 `# print(...)`도 주석이므로 현재 원본 실행에서 `IndentationError`를 일으키지 않는다. 내 주석은 그 줄을 실행 코드로 바꾸어 잘못 들여썼다면 오류가 날 수 있음을 설명한다.

내 `print(...);`의 마지막 세미콜론은 이 자리에서 허용되지만 줄 끝에 꼭 써야 하는 문법은 아니다. 강사님 코드는 세미콜론 없이 같은 출력 결과를 만든다. 처음 공부할 때에는 강사님처럼 한 줄에 문장 하나를 쓰는 편이 읽기 쉽다.

## 실행을 읽는 순서

1. 실행되는 줄과 주석을 구분한다.
2. `print`가 몇 번 호출되는지 센다.
3. 출력이 어느 순서로 나오는지 예상한다.
4. 파일을 실행해 예상과 비교한다.

이 원본을 실행하면 `hello world`가 두 줄 출력된다. 여러 줄 따옴표 부분은 이 예제에서 독립된 문자열 표현식으로 놓여 있어 화면에 출력되지 않는다. `#` 주석과 문자열 표현식은 같은 문법이 아니므로 둘을 동일한 “여러 줄 주석” 문법으로 외우지 않는다.

## 추가로 알면 좋은 것

Python 실행 과정의 바이트코드나 가상 머신 내부 구현, 여러 프로그래밍 패러다임의 분류는 이 시작 실습의 필수 범위가 아니다. 코드의 실행 순서와 결과가 익숙해진 뒤 별도로 읽으면 된다.
