# 개요

프로그램은 값을 저장하고, 계산하고, 비교하고, 사용자에게 입력받아 결과를 출력하며 동작한다.

```text
값 저장
    ↓
연산
    ↓
자료형 변환
    ↓
입력
    ↓
비교와 판단
    ↓
결과 출력
```

예를 들어 상품 가격을 계산하는 프로그램은 다음 과정이 필요하다.

```text
상품 가격과 수량을 변수에 저장
    ↓
곱셈으로 총액 계산
    ↓
필요하면 문자열로 출력
    ↓
사용자 입력값을 숫자로 변환
```

이번 문서는 이후 조건문과 반복문에서 계속 사용하게 될 기본 연산과 입출력 흐름을 다룬다.

# 4. 바닥 나눗셈 `//`

`//`는 나눗셈 결과보다 크지 않은 가장 큰 정수를 반환한다.

## 4-1. 양수

```python
c = 5 // 2
print(c)
```

출력:

```text
2
```

## 4-2. 음수

```python
d = -5 // 2
print(d)
```

출력:

```text
-3
```

## 4-3. 왜 `-2`가 아닐까?

```text
-5 / 2
→ -2.5

-2.5보다 크지 않은 가장 큰 정수
→ -3
```

> [!IMPORTANT]
> `//`는 소수점만 단순히 잘라내는 연산이 아니다.
>
> 결과를 음의 무한대 방향으로 내리는 바닥 나눗셈이다.


| 표현 | 동작 |
| --- | --- |
| `-5 // 2` | 나눗셈 결과를 아래 정수로 내림 |

```text
→ -2
```

# 8. Python에는 `++`, `--`가 없다

원본에는 다음 메모가 있다.

```python
# e++ , e-- 는 없음
```

Python에서는 다음 문법을 사용할 수 없다.

```text
e++
e--
```

값을 1 증가시키려면 다음처럼 작성한다.

```python
e += 1
```

감소:

```python
e -= 1
```

## 8-1. 왜 `++x`는 실행될까?

```python
x = 4

print(++x)
print(--x)
```

출력:

```text
4
4
```

Python은 이를 증감 연산자로 해석하지 않는다.

```text
++x
→ +(+(x))

--x
→ -(-(x))
```

따라서 `x`의 값도 바뀌지 않는다.

> [!WARNING]
> `++x`가 실행된다고 해서 증가 연산이라고 이해하면 안 된다.

## 9-1. 내 코드와 강사님 코드

## 9-3. 코드에서 무엇을 사용하는 걸까?

| --- | --- |


# 13. 부동소수점 오차

## 13-1. 내 코드

```python
print(4.3 - 2.7)
print(4.3 - 2.7 == 1.6)
```

## 13-2. 강사님 코드

```python
print(4.3 - 2.7 == 1.6)
```

내 코드는 실제 계산값과 비교 결과를 함께 출력해 오차의 원인을 확인하기 쉽다.

## 13-3. 출력 결과

```text
1.5999999999999996
False
```

## 13-4. 왜 발생할까?

컴퓨터는 일부 십진 소수를 이진수로 정확하게 표현할 수 없다.

```text
4.3과 2.7을 근삿값으로 저장
    ↓
뺄셈
    ↓
1.6과 매우 가까운 값
    ↓
정확한 동등 비교는 False
```

## 13-5. 안전한 비교

```python
import math

result = 4.3 - 2.7

print(
    math.isclose(
        result,
        1.6,
    )
)
```

출력:

```text
True
```

# 15. 변수 값 교환

## 15-1. 내 코드와 강사님 코드

```python

b = "오백원"

```

이 방식은 임시 변수 `c`를 사용한다.

## 15-4. 동작 개념

```text
오른쪽 b, a 값을 먼저 준비
    ↓
왼쪽 a, b에 각각 대입
```

> [!TIP]
> Python의 다중 대입을 사용하면 임시 변수 없이 두 값을 교환할 수 있다.

# 17. `input()`의 결과는 문자열

사용자가 숫자를 입력해도 `input()`은 문자열을 반환한다.

```python
age = input("나이: ")

print(age)
print(type(age))
```

입력:

```text
20
```

출력:

```text
20
<class 'str'>
```

숫자로 계산하려면 변환한다.

```python
age = int(
    input("나이: ")
)

print(age + 1)
```

입력:

```text
20
```

출력:

```text
21
```

> [!IMPORTANT]
> `input()`으로 받은 값을 계산하기 전에는 필요한 자료형으로 변환해야 한다.

# 22. `==`와 `is`

## 22-1. 원본 코드

```python
print(1 == 1.0)
print(1 is 1.0)
print(1 is not 1.0)
```

## 22-2. 출력 결과

```text
True
False
True
```

## 22-3. 정확한 차이

| 연산자 | 확인 대상 |
| --- | --- |
| `==` | 두 값이 같은가 |
| `is` | 같은 객체인가 |
| `is not` | 서로 다른 객체인가 |

원본 주석에는 `is`를 JavaScript의 `===`처럼 설명했지만 완전히 같은 개념은 아니다.

`is`는 자료형까지 포함한 값 비교 연산자가 아니라 **객체 동일성**을 확인한다.

> [!IMPORTANT]
> 일반적인 숫자·문자열 값 비교에는 `==`를 사용한다.
>
> `is`는 주로 `None`과 비교할 때 사용한다.

```python
value = None

print(value is None)
```

# 25. 단락 평가

논리 연산자는 결과가 이미 정해지면 뒤의 표현식을 평가하지 않을 수 있다.

```python
user = None

print(
    user is not None
    and user["name"]
)
```

## 25-1. 출력 결과

> [!TIP]
> 뒤의 코드가 실행 가능한지 앞 조건에서 먼저 확인할 수 있다.

# 28. 내 코드와 강사님 코드 비교

| 항목 | 내 코드 | 강사님 코드 |
| --- | --- | --- |
| 바닥 나눗셈 | 음수 결과와 내림 개념을 상세 기록 | `내림`으로 간단히 표시 |
| 형 변환 | JavaScript와 비교한 추가 메모 | 핵심 실행 코드 중심 |
| 부동소수점 | 실제 계산값과 비교 결과 모두 출력 | 비교 결과 중심 |
| 변수 교환 | 전통 방식과 Python 방식을 설명 | 두 방식을 간결히 제시 |
| `print()` | `sep`, `end` 조합을 다양하게 실험 | 핵심 옵션 예제 중심 |
| 증감 연산 | `++x`, `--x`, `x++` 차이 기록 | `++x`와 `x++` 비교 |
| `is` | 타입까지 비교한다고 메모 | JavaScript `===`에 비유 |
| 논리 연산 | 우선순위와 단락 평가 추가 메모 | 핵심 논리식 중심 |

## 28-1. 내 코드의 장점

- 수업 중 헷갈린 부분을 구체적으로 기록했다.
- 음수 바닥 나눗셈과 부동소수점 문제를 직접 확인했다.
- 출력 옵션을 여러 방식으로 실험했다.
- 다른 언어와 비교하며 차이를 이해하려 했다.

## 28-2. 내 코드의 개선점

- `//`는 나머지를 내리는 연산이 아니라 몫을 바닥 방향으로 내리는 연산이다.
- `is`는 값과 타입을 함께 비교하는 연산자가 아니라 객체 동일성 연산자다.
- JavaScript와 비교한 메모는 도움이 되지만 Python 개념을 우선 정확히 정리해야 한다.
- 여러 개념이 한 파일에 있으므로 주제별로 구분하면 복습하기 쉽다.

## 28-3. 강사님 코드의 장점

- 핵심 문법을 짧은 예제로 빠르게 확인할 수 있다.
- 수업 진행 순서에 맞춰 다양한 연산을 한 파일에서 실습할 수 있다.
- 오류 코드를 주석 처리해 정상 코드와 비교할 수 있다.

## 28-4. 강사님 코드의 보충점

- `is`를 `===`와 동일하게 이해하지 않도록 객체 동일성 설명이 필요하다.
- 부동소수점 오차의 원인과 안전한 비교 방법이 필요하다.
- `input()`의 반환 자료형이 문자열이라는 설명이 필요하다.
- `++x`가 증가하지 않는 이유를 보충하면 이해하기 쉽다.

# 29. 기존 코드에서 개선 코드로 바꾼 이유

## 29-1. 변수 이름 개선

기존:

```python
a = input("입력하세요:")
```

개선:

```python
user_input = input(
    "입력하세요: "
)
```

이유:

- 값의 의미를 이름만 보고 알 수 있다.
- 이후 코드에서 입력값 역할이 명확하다.

## 29-2. 값 비교에 `==` 사용

기존 이해:

```text
is
→ 값과 타입까지 비교
```

개선된 이해:

```text
==
→ 값 비교

is
→ 객체 동일성 비교
```

## 29-3. 부동소수점 비교 개선

기존:

```python
result == 1.6
```

개선:

```python
math.isclose(
    result,
    1.6,
)
```

이유:

- 실수 표현 오차를 고려할 수 있다.

## 29-4. 사용자 입력 변환

기존:

```python
age = input("나이: ")
```

계산이 필요하다면:

```python
age = int(
    input("나이: ")
)
```

이유:

- `input()` 결과는 문자열이므로 숫자 계산 전에 변환해야 한다.

# 마무리

변수와 연산자·입출력은 이후 모든 Python 코드의 기반이다.

```text
값을 변수에 저장하고
    ↓
필요한 자료형으로 변환하고
    ↓
산술·비교·논리 연산을 수행하고
    ↓
사용자 입력을 받아
    ↓
원하는 형식으로 출력하는 것
```

이 흐름을 이해하면 이후 조건문에서 값을 판단하고, 반복문에서 여러 데이터를 처리하는 과정을 자연스럽게 연결할 수 있다.
