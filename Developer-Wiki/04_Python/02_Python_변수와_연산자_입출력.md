## 개요

프로그램은 값을 저장하고, 계산하고, 비교하고, 사용자에게 입력받아 결과를 출력하며 동작한다.

```text
값 저장
    ↓
연산
    ↓
자료형 변환
    ↓
입력
    ↓
비교와 판단
    ↓
결과 출력
```

예를 들어 상품 가격을 계산하는 프로그램은 다음 과정이 필요하다.

```text
상품 가격과 수량을 변수에 저장
    ↓
곱셈으로 총액 계산
    ↓
필요하면 문자열로 출력
    ↓
사용자 입력값을 숫자로 변환
```

이번 문서는 이후 조건문과 반복문에서 계속 사용하게 될 기본 연산과 입출력 흐름을 다룬다.

## 개념에서 실제 실행까지 — 변수란? — 이름과 객체, 입력 문자열과 계산

### 무엇이며 왜 배워야 할까?

변수는 객체를 가리키도록 연결된 이름이다. x = 4에서 4는 정수 객체이고 x는 그 객체에 연결된다. x += 1은 정수 객체 자체를 내부에서 고치는 것이 아니라 계산된 정수 결과에 x를 다시 연결한다. 리스트 같은 가변 객체를 변경하는 경우와 구분한다.

input은 터미널에 안내를 출력하고 사용자가 엔터로 보낸 한 줄을 문자열로 반환한다. 2를 입력해도 '2'이며 '2' * 3은 '222'다. 숫자 계산이 목적이면 int나 float로 변환하고 실패 가능성을 고려한다. 다음 예제의 raw는 재현을 위해 직접 넣은 값이며 실제 수업의 input 결과와 같은 str 계약을 갖는다.

==는 값의 동등성, is는 같은 객체인지를 확인한다. 같은 값을 가진 서로 다른 리스트에서는 ==가 True이고 is가 False다. is를 JavaScript ===나 ‘타입까지 확인하는 값 비교’로 외우면 잘못된다. None 확인에는 is None을 사용한다.

원본을 순서대로 읽어야 한다. 내 코드의 e는 16에서 바로 제곱하여 256이고, 강사님 코드는 먼저 1을 더해 17로 만든 뒤 제곱하여 289다. 두 파일 모두 임시 변수 교환 후 a,b=b,a를 다시 실행하므로 최종 a,b는 원래의 10,'오백원'으로 돌아온다. 독립적인 교환 예제의 출력과 원본 전체 출력은 다르다.

### 독립 실행 예제: 입력에서 결과까지

다음 코드는 앞 문서의 변수 없이 새 .py 파일에서 실행할 수 있는 보충 예제다. 직접 적은 입력값을 사용하므로 같은 조건에서 아래 출력과 비교할 수 있다.

```python
raw = '2'
quantity = int(raw)
print(raw * 3, quantity * 3)
a = [10]
b = [10]
c = a
print(a == b, a is b, a is c)
x = 4
print(++x, x)
print(-5 // 2, int(-2.5))
```

예상 출력:

```text
222 6
True False True
4 4
-3 -2
```

### 실행 순서를 한 단계씩 따라가기

1. raw는 직접 넣은 str이며 실제 input도 같은 자료형으로 값을 반환한다.
2. int(raw)가 새 정수 결과를 만들고 quantity가 그 결과를 가리킨다.
3. 문자열 반복과 숫자 곱셈은 각 자료형의 다른 연산이므로 222와 6이 나온다.
4. a,b는 다른 목록, c는 a와 같은 목록을 가리킨다. 값 비교와 동일성 검사를 각각 수행한다.

| 단계 | a | b |
| --- | --- | --- |

## 1. 변수에 값 저장

### 1-1. 내 코드

```python
a = 10
print(a)
```

### 1-2. 강사님 코드

```python
a = 10
print(a)
```

두 코드는 동일하다.

### 1-3. 구성

| 요소 | 의미 |
| --- | --- |
| `a` | 값을 저장할 변수 이름 |
| `=` | 오른쪽 값을 왼쪽 변수에 대입 |
| `10` | 정수 값 |
| `print(a)` | 변수에 저장된 값 출력 |

```text

```

### 1-5. 동작 과정

```text
정수 10 생성
    ↓
변수 a에 저장
    ↓
print(a)
    ↓
a가 가리키는 값 10 출력
```

> [!TIP]
> 학습 예제에서는 `a`, `b`를 사용할 수 있지만, 실제 코드에서는 `product_price`, `user_age`처럼 역할이 드러나는 이름을 사용한다.

## 3. 0으로 나눌 수 없는 이유

### 3-1. 원본의 오류 예제

```python
# b = 5 / 0
# print(b)
```

주석을 제거해 실행하면 다음 오류가 발생한다.

```text
ZeroDivisionError: division by zero
```

### 3-2. 오류 원인

수학적으로 0으로 나누는 연산의 결과를 정의할 수 없기 때문이다.

### 3-3. 안전한 처리

```python
number = 5
divisor = 0

if divisor != 0:
    print(number / divisor)
else:
    print("0으로 나눌 수 없습니다.")
```

### 3-4. 출력 결과

```text
0으로 나눌 수 없습니다.
```

예외 처리는 `14_Python_예외처리.md`에서 더 자세히 다룬다.

## 4. 바닥 나눗셈 `//`

`//`는 나눗셈 결과보다 크지 않은 가장 큰 정수를 반환한다.

### 4-1. 양수

```python
c = 5 // 2
print(c)
```

출력:

```text
2
```

### 4-2. 음수

```python
d = -5 // 2
print(d)
```

출력:

```text
-3
```

### 4-3. 왜 `-2`가 아닐까?

```text
-5 / 2
→ -2.5

-2.5보다 크지 않은 가장 큰 정수
→ -3
```

> [!IMPORTANT]
> `//`는 소수점만 단순히 잘라내는 연산이 아니다.
>
> 결과를 음의 무한대 방향으로 내리는 바닥 나눗셈이다.

## 5. `//`와 `int()` 비교

### 5-1. 실행

## 8. Python에는 `++`, `--`가 없다

원본에는 다음 메모가 있다.

```python
# e++ , e-- 는 없음
```

Python에서는 다음 문법을 사용할 수 없다.

```text
e++
e--
```

값을 1 증가시키려면 다음처럼 작성한다.

```python
e += 1
```

감소:

```python
e -= 1
```

### 8-1. 왜 `++x`는 실행될까?

```python
x = 4

print(++x)
print(--x)
```

출력:

```text
4
4
```

Python은 이를 증감 연산자로 해석하지 않는다.

```text
++x
→ +(+(x))

--x
→ -(-(x))
```

따라서 `x`의 값도 바뀌지 않는다.

> [!WARNING]
> `++x`가 실행된다고 해서 증가 연산이라고 이해하면 안 된다.

## 22. `==`와 `is`

```python

print(value is None)
```

## 25. 단락 평가

논리 연산자는 결과가 이미 정해지면 뒤의 표현식을 평가하지 않을 수 있다.

```python

print(
    user is not None
    and user["name"]
)
```

### 25-1. 출력 결과

```text

```

첫 번째 조건이 거짓이므로 뒤의 `user["name"]`을 실행하지 않는다.

이를 단락 평가 또는 Short-circuit Evaluation이라고 한다.

> [!TIP]
> 뒤의 코드가 실행 가능한지 앞 조건에서 먼저 확인할 수 있다.

## 28. 내 코드와 강사님 코드 비교

| 항목 | 내 코드 | 강사님 코드 |
| --- | --- | --- |
| 바닥 나눗셈 | 음수 결과와 내림 개념을 상세 기록 | `내림`으로 간단히 표시 |
| 형 변환 | JavaScript와 비교한 추가 메모 | 핵심 실행 코드 중심 |
| 부동소수점 | 실제 계산값과 비교 결과 모두 출력 | 비교 결과 중심 |
| 변수 교환 | 전통 방식과 Python 방식을 설명 | 두 방식을 간결히 제시 |
| `print()` | `sep`, `end` 조합을 다양하게 실험 | 핵심 옵션 예제 중심 |
| 증감 연산 | `++x`, `--x`, `x++` 차이 기록 | `++x`와 `x++` 비교 |
| `is` | 타입까지 비교한다고 메모 | JavaScript `===`에 비유 |
| 논리 연산 | 우선순위와 단락 평가 추가 메모 | 핵심 논리식 중심 |

### 28-1. 내 코드의 장점

- 수업 중 헷갈린 부분을 구체적으로 기록했다.
- 음수 바닥 나눗셈과 부동소수점 문제를 직접 확인했다.
- 출력 옵션을 여러 방식으로 실험했다.
- 다른 언어와 비교하며 차이를 이해하려 했다.

### 28-2. 내 코드의 개선점

- `//`는 나머지를 내리는 연산이 아니라 몫을 바닥 방향으로 내리는 연산이다.
- `is`는 값과 타입을 함께 비교하는 연산자가 아니라 객체 동일성 연산자다.
- JavaScript와 비교한 메모는 도움이 되지만 Python 개념을 우선 정확히 정리해야 한다.
- 여러 개념이 한 파일에 있으므로 주제별로 구분하면 복습하기 쉽다.

### 28-3. 강사님 코드의 장점

- 핵심 문법을 짧은 예제로 빠르게 확인할 수 있다.
- 수업 진행 순서에 맞춰 다양한 연산을 한 파일에서 실습할 수 있다.
- 오류 코드를 주석 처리해 정상 코드와 비교할 수 있다.

### 28-4. 강사님 코드의 보충점

- `is`를 `===`와 동일하게 이해하지 않도록 객체 동일성 설명이 필요하다.
- 부동소수점 오차의 원인과 안전한 비교 방법이 필요하다.
- `input()`의 반환 자료형이 문자열이라는 설명이 필요하다.
- `++x`가 증가하지 않는 이유를 보충하면 이해하기 쉽다.

## 29. 기존 코드에서 개선 코드로 바꾼 이유

### 29-1. 변수 이름 개선

기존:

```python
a = input("입력하세요:")
```

개선:

```python
user_input = input(
    "입력하세요: "
)
```

이유:

- 값의 의미를 이름만 보고 알 수 있다.
- 이후 코드에서 입력값 역할이 명확하다.

### 29-2. 값 비교에 `==` 사용

기존 이해:

```text
is
→ 값과 타입까지 비교
```

개선된 이해:

```text
==
→ 값 비교

is
→ 객체 동일성 비교
```

### 29-3. 부동소수점 비교 개선

기존:

```python
result == 1.6
```

개선:

```python
math.isclose(
    result,
    1.6,
)
```

이유:

- 실수 표현 오차를 고려할 수 있다.

### 29-4. 사용자 입력 변환

기존:

```python
age = input("나이: ")
```

계산이 필요하다면:

```python
age = int(
    input("나이: ")
)
```

이유:

- `input()` 결과는 문자열이므로 숫자 계산 전에 변환해야 한다.

## 30. 실무형 예제: 주문 금액 계산

```python
product_name = "키보드"
unit_price = 45000
quantity = int(
    input("구매 수량: ")
)

total_price = (
    unit_price * quantity
)

print(
    product_name,
    quantity,
    sep=" x ",
)

print(
    "총 결제 금액:",
    f"{total_price:,}원",
)
```

### 30-1. 실행 예시

입력:

```text
2
```

출력:

```text
키보드 x 2
총 결제 금액: 90,000원
```

### 30-2. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `product_name` | 상품 이름 저장 |
| `unit_price` | 상품 한 개 가격 저장 |
| `input()` | 구매 수량 입력 |
| `int()` | 입력 문자열을 정수로 변환 |
| `*` | 가격과 수량을 곱해 총액 계산 |
| `sep=" x "` | 상품과 수량 사이 형식 지정 |
| f-string | 금액 형식과 단위 출력 |

## V3 동작 백과 보강 — 입력값·변수·연산의 전체 경로

Python 변수는 값을 담는 고정 상자라기보다 객체를 가리키는 이름이다. `input()`은 터미널에 프롬프트를 출력하고 사용자가 Enter를 누를 때까지 기다린 뒤, 입력 문자를 항상 `str`로 반환한다. 계산 전에 필요한 자료형으로 명시적으로 변환해야 한다.

```python
raw_age = input("나이: ")
age = int(raw_age)
next_age = age + 1
print(raw_age, type(raw_age))
print(next_age, type(next_age))
```

사용자가 `20`을 입력하면 다음처럼 관찰된다.

```text
나이: 20
20 <class 'str'>
21 <class 'int'>
```

`int()` 전에 `raw_age + 1`을 계산하면 문자열과 정수를 더할 수 없어 `TypeError`가 난다. `int("스물")`은 변환할 수 없어 `ValueError`다. 연산자는 괄호와 우선순위에 따라 피연산자를 처리하고 새 결과 객체를 만든다.
