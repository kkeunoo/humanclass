# 20. Python 종합실습 — 주문 한 줄의 합계 구하기

[Python 목차](README.md) · [장별 연습문제](실습/연습문제/README.md)

강사님과 내 실제 자료에는 [자료형 퀴즈](실습-01a_Python_자료형_퀴즈_집계와_로그인.md)와 [내 주문 파일 평가](실습-02_Python_주문파일_평가실습.md)가 있다. 이 장은 그 문제를 다시 출제한 원본이 아니라 **이미 배운 문자열·리스트·반복·조건·함수만으로 새로 구성한 복습**이다. 원본 평가의 요구 조건·실제 출력은 원본 비교 장에서 확인한다.

## 1. 풀기 전에 예상하기

입력은 `상품, 수량, 가격원` 형식의 문자열 세 개다. 앞뒤 공백을 제거하고 숫자로 바꾼다. 수량이 0 이상이고 가격이 0 이상 10,000 이하인 주문만 결과 목록에 넣고 `수량 × 가격`을 합산한다.

```text
사과, 2, 3000원
배, -1, 4000원
귤, 3, 2000원
```

예상 결과는 `[['사과', 2, 3000], ['귤', 3, 2000]]`와 총액 `12000`이다. 먼저 종이에 각 줄의 분리·변환·검사 결과를 적어 본다.

## 2. 직접 작성할 순서

1. 위 세 줄을 리스트에 넣고 `for`로 순회한다.
2. `split(',')`로 세 칸으로 나누고 각 칸에 `strip()`을 적용한다.
3. 가격 끝의 `원`을 제거한 다음 수량과 가격을 `int()`로 바꾼다.
4. 조건에 맞는 주문만 모으고 합계를 누적한다.
5. 합계 계산을 함수로 옮겨 `return` 값을 사용해 본다.

<details>
<summary>예시 풀이 — 먼저 직접 작성한 뒤 펼치기</summary>

```python
# 수업 문법으로 새로 구성한 예시. 원본 제출 코드가 아니다.
rows = ['사과, 2, 3000원', '배, -1, 4000원', '귤, 3, 2000원']

def line_total(quantity, price):
    return quantity * price

accepted = []
sales = 0
for row in rows:
    parts = [part.strip() for part in row.split(',')]
    name = parts[0]
    quantity = int(parts[1])
    price = int(parts[2].replace('원', ''))
    if quantity >= 0 and 0 <= price <= 10000:
        accepted.append([name, quantity, price])
        sales += line_total(quantity, price)

print(accepted)
print(sales)
```

`배`는 수량이 음수여서 제외된다. `사과` 6000원과 `귤` 6000원을 더해 12000원이다. 함수가 `print`만 했다면 `sales += ...`에 쓸 숫자를 돌려받을 수 없다.

</details>
