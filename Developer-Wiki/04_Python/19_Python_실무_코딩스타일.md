## 1. 값을 만들고 출력하는 일을 구분하기

[함수와 반환값](11-01_Python_함수와_반환값.md)에서 강사님과 내 코드는 `print(a+b)`와 `return a+b`의 차이를 함께 확인한다. 뒤에서 계산 결과를 다시 사용할 때에는 반환값이 필요하다.

```python
# 수업 문법으로 재구성한 예시
def line_total(quantity, price):
    return quantity * price

total = line_total(2, 3000)
print(total)  # 6000
```

반대로 화면에 `6000`을 보이는 것만 필요하면 함수 안의 `print`도 가능하다. 어느 방식이든 **호출한 자리에서 받을 값이 있는지**를 먼저 정한다.

## 2. 입력 한 줄을 단계별로 확인하기

[내 주문 파일 평가 코드](실습-02_Python_주문파일_평가실습.md)는 `split(',')` → `strip()` → `replace('원', '')` → `int()` → 조건 검사 → 합계의 순서로 진행한다. 강사님 파일 읽기 예시는 기반 개념이며 이 평가의 직접 정답 파일은 아니다. 아래는 그 순서만 줄 단위로 재구성한 코드다.

```python
# 원본 발췌가 아닌 복습용 재구성
row = '사과, 2, 3000원'
parts = [part.strip() for part in row.split(',')]
name = parts[0]
quantity = int(parts[1])
price = int(parts[2].replace('원', ''))
if quantity >= 0 and 0 <= price <= 10000:
    print(name, quantity * price)  # 사과 6000
```

내 원본처럼 제공된 형식이 올바르다는 전제에서는 이 순서가 작동한다. 파일의 빈 줄이나 칸 수 오류까지 처리하는 입력 검증은 [주문 과제의 추가 설명](실습-02_Python_주문파일_평가실습.md#section-5)에서 구분해 읽는다.

```python
# 독립적인 새 실습 파일에서만 실행한다. 기존 수업 파일은 덮어쓰지 않는다.
with open('practice_note.txt', 'w', encoding='utf-8') as file:
```
