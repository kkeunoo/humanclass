# 05. 튜플 — 쉼표로 만드는 순서 있는 값 묶음

[Python 목차](README.md) · [이전: 리스트 참조·순회](04-02_Python_리스트참조와_컴프리헨션.md)

양쪽 수업 파일은 짧다. **여러 값을 튜플로 묶는 방법과 한 값일 때의 쉼표**를 먼저 확인하고, 내 코드에만 있는 리스트·튜플 변환을 덧붙인다.

### 강사님 코드

출처: `teacher/workspace_python/_05_tuple.py` 1–11행 · **원본 발췌**

```python
# 선언
a = (1,2,3)
print(a, type(a))

b = 1,2,3
print(b, type(b))

# 값이 하나인 튜플 선언
c = (3,)
d = 4,
print(d, type(d))
```

### 내 코드

출처: `me/workspace_python/05_tuple.py` 1–20행 · **원본 발췌**

```python
# 선언 (readonly list)
# a = () 처럼 빈 것으로 선언 불가하며, 값은 바꾸지 못 함
a = (1,2,3)
print(a, type(a))

# tuple은 ()없이도 선언해서 사용할 수 있음
b = 1,2,3
print(b, type(b))

# 값이 1개인 tuple을 선언하기 위해서는 ','를 써줘야 함
c = (3,)
print(c, type(c))
d = 4,
print(d, type(d))

# 아래와 같이 tuple > list , list > tuple 변경 가능
e = [1,2,3]
print(tuple(e))
f = (1,2,3)
print(list(f))
```

`(1,2,3)`과 `1,2,3`은 이 문맥에서 모두 세 값의 튜플이다. 한 값만 담을 때에는 `(3,)` 또는 `4,`처럼 **쉼표**가 필요하다. `(3)`은 괄호로 묶은 정수 3이지 한 값의 튜플이 아니다.

내 주석의 “`a = ()`처럼 빈 것으로 선언 불가”는 사실과 다르다. **`()`는 정상적인 빈 튜플**이다. 튜플은 만든 뒤 리스트처럼 요소 위치에 새 값을 대입할 수 없다. ‘readonly list’라는 내 표현은 값을 바꾸지 못한다는 차이를 기억하는 말이지만, 튜플과 리스트가 같은 자료형이라는 뜻은 아니다.

내 코드에서는 `tuple([1,2,3])`으로 리스트의 값에서 튜플을 만들고, `list((1,2,3))`으로 튜플의 값에서 리스트를 만든다. `print(tuple(e))`는 변환 결과를 보여 줄 뿐 변수 `e`의 자료형을 바꾸지는 않는다. `print(list(f))`도 원래 변수 `f`를 그대로 둔다.
