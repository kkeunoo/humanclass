# 개요

튜플은 여러 값을 순서대로 저장하는 자료형이다.

리스트와 비슷하지만 생성한 뒤 원소를 추가·삭제·변경할 수 없다는 차이가 있다.

```text
여러 값 저장
    ↓
순서 유지
    ↓
인덱스로 조회
    ↓
생성 후 원소 변경 불가
```

튜플은 다음과 같은 데이터를 표현할 때 사용할 수 있다.

- 좌표
- RGB 색상
- 날짜의 연·월·일
- 함수에서 반환하는 여러 값
- 변경하지 않을 설정값 묶음

```python
position = (10, 20)
rgb = (255, 128, 0)
date = (2026, 8, 6)
```

> [!IMPORTANT]
> 튜플은 “괄호로 만든 리스트”가 아니다.
>
> 순서가 있는 여러 값을 저장하지만, 원소 구성을 변경할 수 없는 별도의 자료형이다.

# 1. 튜플 선언

## 1-1. 내 코드

```python
a = (1, 2, 3)

print(a, type(a))
```

## 1-2. 강사님 코드

```python
a = (1, 2, 3)

print(a, type(a))
```

두 코드는 동일하다.

## 1-3. 출력 결과

```text
(1, 2, 3) <class 'tuple'>
```

## 1-4. 구성

| 요소 | 의미 |
| --- | --- |
| `a` | 튜플을 저장하는 변수 |
| `(1, 2, 3)` | 세 개의 정수를 가진 튜플 |
| `type(a)` | 자료형 확인 |

## 1-5. 동작 과정

```text
1, 2, 3 준비
    ↓
하나의 튜플로 묶음
    ↓
변수 a에 저장
```

# 2. 괄호 없는 튜플

## 2-1. 내 코드와 강사님 코드

```python
b = 1, 2, 3

print(b, type(b))
```

## 2-2. 출력 결과

```text
(1, 2, 3) <class 'tuple'>
```

괄호가 없어도 쉼표로 값을 나열하면 튜플이 만들어진다.

```text
1, 2, 3
→ 튜플
```

> [!IMPORTANT]
> 튜플을 결정하는 핵심은 괄호보다 쉼표다.

# 3. 괄호는 왜 사용할까?

다음 두 코드는 같은 튜플을 만든다.

```python
a = (1, 2, 3)
b = 1, 2, 3
```

하지만 괄호를 사용하면 값들이 하나의 튜플이라는 점이 더 명확하게 보인다.

```python
user_info = (
    "Kim",
    21,
    True,
)
```

여러 줄로 작성할 때도 괄호를 사용하면 읽기 쉽다.

> [!TIP]
> 괄호 없이 만들 수 있더라도, 함수 호출·연산식·여러 줄 데이터에서는 괄호를 사용해 의도를 명확하게 표현한다.

# 4. 원소 하나인 튜플

## 4-1. 내 코드

```python
c = (3,)
d = 4,

print(c, type(c))
print(d, type(d))
```

## 4-2. 강사님 코드

```python
c = (3,)
d = 4,

print(d, type(d))
```

내 코드는 괄호를 사용한 방식과 괄호 없는 방식을 모두 출력해 확인한다.

## 4-3. 출력 결과

```text
(3,) <class 'tuple'>
(4,) <class 'tuple'>
```

## 4-4. 왜 쉼표가 필요할까?

다음 코드는 튜플이 아니다.

```python
value = (3)

print(type(value))
```

출력:

```text
<class 'int'>
```

괄호는 단순히 계산 우선순위를 묶는 역할로 해석된다.

원소 하나인 튜플:

```python
value = (3,)
```

```text
(3)
→ 정수 3

(3,)
→ 원소 하나인 튜플
```

# 5. 빈 튜플

내 코드 주석에는 빈 튜플을 만들 수 없다고 기록되어 있지만, Python에서는 빈 튜플을 만들 수 있다.

```python
empty_tuple_1 = ()
empty_tuple_2 = tuple()

print(empty_tuple_1)
print(empty_tuple_2)
```

## 5-1. 출력 결과

```text
()
()
```

## 5-2. 원본 메모 바로잡기

기존 메모:

```text
a = ()처럼 빈 것으로 선언 불가
```

정확한 설명:

```text
()
→ 빈 튜플 생성 가능

(3)
→ 정수

(3,)
→ 원소 하나인 튜플
```

> [!IMPORTANT]
> 빈 튜플은 만들 수 있다.
>
> 쉼표가 반드시 필요한 경우는 원소가 하나인 튜플이다.

# 9. 튜플 슬라이싱

슬라이싱을 사용하면 튜플 일부를 새 튜플로 반환한다.


# 10. 튜플은 불변 자료형

내 코드에서는 튜플을 `readonly list`라고 표현했다.

학습 관점에서는 리스트처럼 여러 값을 저장하지만 변경할 수 없다는 의미로 이해할 수 있다.

정확하게는 튜플은 **불변(immutable) 자료형**이다.

```python
numbers = (
    1,
    2,
    3,
)
```

다음 작업은 사용할 수 없다.

- 원소 대입
- `append()`
- `remove()`
- `pop()`
- `sort()`

---

# 11. 튜플 원소 변경 오류

```python
numbers = (
    1,
    2,
    3,
)

numbers[0] = 100
```

## 11-1. 발생 결과

```text
TypeError: 'tuple' object does not support item assignment
```

## 11-2. 오류 원인

튜플은 생성 후 특정 위치의 원소를 다른 값으로 바꿀 수 없다.

```text
numbers[0]
→ 조회 가능

numbers[0] = 100
→ 변경 불가
```

---

# 12. 튜플에 추가 메서드가 없는 이유

리스트에는 다음 메서드가 있다.

```text
append()
extend()
insert()
remove()
pop()
clear()
sort()
reverse()
```

튜플은 원소 구성을 변경할 수 없으므로 이러한 변경 메서드를 제공하지 않는다.

```python
numbers = (
    1,
    2,
    3,
)

numbers.append(4)
```

발생 결과:

```text
AttributeError
```

# 13. 튜플 결합

튜플끼리 `+`를 사용하면 새 튜플을 만들 수 있다.

```python
first = (
    1,
    2,
)

second = (
    3,
    4,
)

result = first + second

print(result)
print(first)
```

## 13-1. 출력 결과

```text
(1, 2, 3, 4)
(1, 2)
```

원본 튜플은 변경되지 않는다.

```text
기존 튜플 변경
→ 아님

새 튜플 생성
→ 맞음
```

# 16. `count()`

`count()`는 특정 값이 몇 번 나타나는지 반환한다.

```python
numbers = (
    1,
    2,
    3,
    2,
    2,
```


# 20. `enumerate()`로 순회

인덱스와 값이 모두 필요하면 `enumerate()`를 사용한다.

```python
languages = (
    "Python",
    "Java",
    "JavaScript",
)

for number, language in enumerate(
    languages,
    start=1,
):
    print(number, language)
```

## 20-1. 출력 결과

```text
1 Python
2 Java
3 JavaScript
```

# 21. 튜플 언패킹

```python
name, age = (
```

# 22. 필요 없는 값 무시

사용하지 않을 값에는 관례적으로 `_`를 사용할 수 있다.

```python
user = (
    1,
    "Kim",
    21,
)

user_id, name, _ = user

print(user_id)
print(name)
```

## 22-1. 출력 결과

```text
1
Kim
```

> [!TIP]
> `_`는 문법적으로 특별한 무시 키워드는 아니지만, “이 값은 사용하지 않는다”는 관례로 자주 사용한다.

# 23. 확장 언패킹

`*`를 사용하면 여러 원소를 하나의 리스트로 받을 수 있다.

```python
numbers = (
    1,
    2,
    3,
    4,
    5,
)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

## 23-1. 출력 결과

```text
1
[2, 3, 4]
5
```

`middle`은 튜플이 아니라 리스트로 저장된다.

# 24. 변수 값 교환

튜플 패킹과 언패킹을 이용해 두 변수의 값을 교환할 수 있다.

```python
a = 10
b = 20

a, b = b, a

print(a)
print(b)
```

## 24-1. 출력 결과

```text
20
10
```

개념적으로 다음과 같다.

```text
오른쪽 b, a를 튜플처럼 묶음
    ↓
왼쪽 a, b에 순서대로 언패킹
```

# 25. 함수에서 여러 값 반환

Python 함수가 쉼표로 여러 값을 반환하면 튜플 형태로 전달된다.

```python
def get_user():

```

## 25-1. 하나의 변수로 받기

```python
result = get_user()

print(result)
print(type(result))
```

출력:

```text
('Kim', 21)
<class 'tuple'>
```

## 25-2. 언패킹하기

```python
name, age = get_user()

print(name)
print(age)
```

출력:

```text
Kim
21
```

# 26. 리스트를 튜플로 변환

## 26-1. 내 코드

```python
values = [
    1,
    2,
    3,
]

print(tuple(values))
```

## 26-2. 출력 결과


# 29. 튜플 안의 리스트

튜플 자체는 불변이지만, 튜플 안에 저장된 가변 객체는 변경될 수 있다.

```python
data = (
    "Python",
    [1, 2, 3],
)

data[1].append(4)

print(data)
```

## 29-1. 출력 결과

```text
('Python', [1, 2, 3, 4])
```

## 29-2. 왜 가능할까?

```text
튜플의 두 번째 원소
→ 같은 리스트 객체를 계속 가리킴

리스트 내부 값
→ 변경 가능
```

튜플의 원소 자체를 다른 객체로 바꾼 것은 아니다.

> [!WARNING]
> 튜플이라고 해서 내부 데이터 전체가 항상 완전히 변경 불가능한 것은 아니다.
>
> 내부에 리스트·딕셔너리 같은 가변 객체가 있으면 그 객체의 내용은 바뀔 수 있다.

# 31. 리스트와 튜플 비교

| 구분 | 리스트 | 튜플 |
| --- | --- | --- |
| 기호 | `[]` | `()` 또는 쉼표 |
| 변경 가능 | 가능 | 불가능 |
| 값 추가·삭제 | 가능 | 불가능 |
| 인덱싱·슬라이싱 | 가능 | 가능 |
| 중복 값 | 가능 | 가능 |
| 순서 유지 | 예 | 예 |
| 주요 사용 | 변경되는 목록 | 고정된 값 묶음 |

## 31-1. 리스트가 적합한 경우

- 상품 목록이 계속 추가됨
- 사용자 목록을 삭제·수정함
- 정렬과 변경이 자주 필요함
- 반복 처리 결과를 누적함

## 31-2. 튜플이 적합한 경우

- 좌표처럼 값의 의미와 개수가 고정됨
- 함수에서 여러 값을 반환함
- 변경하지 않을 설정값 묶음
- 딕셔너리 키로 사용할 고정 조합

# 32. 내 코드와 강사님 코드 비교

| 항목 | 내 코드 | 강사님 코드 |
| --- | --- | --- |
| 기본 선언 | `(1, 2, 3)` | `(1, 2, 3)` |
| 괄호 없는 선언 | `1, 2, 3` | `1, 2, 3` |
| 원소 하나 | 괄호·괄호 없는 방식 모두 출력 | 두 방식 선언 후 `d` 출력 |
| 빈 튜플 | 생성 불가라고 메모 | 별도 설명 없음 |
| 리스트 변환 | 리스트→튜플, 튜플→리스트 모두 실습 | 별도 변환 예제 없음 |
| 불변성 | `readonly list`, 값 변경 불가 메모 | 기본 선언 중심 |

## 32-1. 내 코드의 장점

- 원소 하나인 튜플에 쉼표가 필요한 점을 정확히 기록했다.
- 괄호 없이 튜플을 만들 수 있다는 점을 확인했다.
- 리스트와 튜플의 상호 변환을 직접 실습했다.
- 튜플이 변경 불가능하다는 핵심 특징을 메모했다.

## 32-2. 내 코드의 개선점

- 빈 튜플은 `()` 또는 `tuple()`로 만들 수 있다.
- 튜플은 `readonly list`라기보다 불변 시퀀스라고 설명하는 것이 정확하다.
- 튜플 내부에 가변 객체가 있으면 그 객체 내용은 바뀔 수 있다.
- 튜플도 `count()`와 `index()` 같은 조회 메서드를 제공한다.

## 32-3. 강사님 코드의 장점

- 튜플 선언의 세 가지 핵심 형태를 간결하게 보여 준다.
- 원소 하나인 튜플의 쉼표 문법을 학습할 수 있다.
- 첫 튜플 학습 파일로 필요한 최소 개념이 명확하다.

## 32-4. 강사님 코드의 보충점

- 빈 튜플 생성 방법이 필요하다.
- 불변성 오류 예제가 있으면 리스트와 차이를 이해하기 쉽다.
- 인덱싱·언패킹·변환 사용법을 보충할 필요가 있다.
- 실제 활용 상황을 연결하면 튜플 선택 기준이 명확해진다.

# 33. 기존 코드에서 개선 코드로 바꾼 이유

## 33-1. 빈 튜플 설명 수정

기존 이해:

```text
()
→ 선언 불가
```

개선된 이해:

```python
empty_tuple = ()
```

```text
()
→ 정상적인 빈 튜플
```

## 33-2. 용어 개선

기존:

```text
readonly list
```

개선:

```text
불변 시퀀스 자료형
```

이유:

- 리스트와 튜플은 서로 다른 자료형이다.
- 튜플은 리스트의 읽기 전용 모드가 아니다.

## 33-3. 의미 있는 변수명

기존:

```python
a = (1, 2, 3)
```

개선:

```python
coordinates = (
    10,
    20,
    30,
)
```

학습 예제에서는 `a`도 가능하지만 실제 코드에서는 값의 역할을 드러내는 이름이 좋다.

# 34. 실무형 예제: 사용자 검색 조건

검색 조건은 한 번 정한 뒤 변경하지 않는 값 묶음으로 표현할 수 있다.

```python

    "개발",
    19,
    True,
)

department, minimum_age, active_only = (
    search_condition
)

print("부서:", department)
print("최소 나이:", minimum_age)
print("활성 사용자만:", active_only)
```

## 34-1. 출력 결과

```text
부서: 개발
최소 나이: 19
활성 사용자만: True
```

## 34-2. 코드에서 무엇을 사용하는 걸까?

| 코드 | 사용하는 이유 |
| --- | --- |
| `search_condition` | 고정된 검색 조건 묶음 저장 |
| 튜플 | 값의 순서와 개수를 유지 |
| 언패킹 | 각 조건을 의미 있는 변수로 분리 |

## 34-3. 주의점

튜플 원소가 많아지면 위치만으로 의미를 이해하기 어려워질 수 있다.

복잡한 데이터 구조라면 다음을 검토한다.

- 딕셔너리
- `NamedTuple`
- `dataclass`
- 클래스

> [!TIP]
> 튜플은 작고 의미가 명확한 고정 값 묶음에 적합하다.

# 마무리

튜플의 핵심은 단순히 값을 여러 개 묶는 것이 아니다.

```text
여러 값을 순서대로 저장하고
    ↓
원소의 위치와 개수를 유지하며
    ↓
생성 후 구성을 변경하지 않고
    ↓
언패킹으로 각각의 값에 의미를 부여하는 것
```

값의 추가·삭제가 필요한 목록은 리스트를 사용하고, 작고 고정된 값 묶음은 튜플을 고려한다.
