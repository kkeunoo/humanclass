## 3. 근거와 범위

현재 양쪽 수업 파일을 읽어 인용 행과 내용을 대조했다. 교재에 보존된 원본 주석을 수정하지 않고 바로 아래 풀이에서 교정한다. BACKUP의 정의·예제·단계 풀이 방식은 참고하되 그것만으로 학습 범위를 정하지 않았다. 이터레이터·제너레이터·정규식은 개념·간단 사용이라는 사용자 확인을 유지한다.

새 함수·고정 입력·실패 대응은 당시 제출 코드와 표시를 나눴다. 공식 출처는 배운 개념의 의미 확인이고, 미학습 확장은 본문 하단 TIP이다. 현재 실제 파일에 없는 추가 메모의 대응은 이후 첨부 때 다시 판단한다.

## 4. 검증 방법과 한계

새 예제는 입력·출력·의도한 예외·보조 모듈·생성 파일을 별도 임시 폴더에서 확인한다. 종합실습은 기본·빈 입력·0 경계·상한 초과·정수 오류·칸 수 오류·정상 전체 입력으로 확인한다. 실제 주문 코드는 현재 데이터 사본만 임시 폴더에 두고 해당 처리 구간을 실행해 대조한다. D 드라이브 원본에는 쓰지 않는다.

공통 절·장별 문제·기존 경로·명시 앵커·파일 링크도 검사한다. 최신 수치는 outputs의 책형 검증 결과와 work/book-python-subject-verification.json에 기록한다. 원본 전체 파일에는 입력·창·외부 요청이 섞여 있으므로 전부 통째로 실행했다고 주장하지 않는다. 외부 웹 응답·거북이 창은 이번 검수 대상이 아니다.
