각 문서는 주제에 필요한 항목만 선택해 사용하지만, 전체적으로 다음 학습 흐름을 유지합니다.

| 개요와 핵심 개념 | 학습 주제의 목적과 주요 용어를 정리합니다. |

| 입력값과 실행 결과 | 실제 값을 넣었을 때 어떤 결과가 나오는지 확인합니다. |

| 코드 비교와 개선 이유 | 기존 코드의 장점과 개선할 부분을 함께 설명합니다. |

| 핵심 요약·체크리스트 | 문서 내용을 짧게 복습하고 학습 상태를 점검합니다. |

> 각 개념을 설명하는 데 필요한 부분만 발췌하고, 차이와 활용법을 함께 정리합니다.

| --- | --- |

| Editor | Visual Studio Code |
| Terminal | PowerShell / Git Bash |

Python 버전은 학습 환경에 따라 달라질 수 있습니다.  
`match·case`는 Python 3.10 이상, 일부 최신 타입 힌트 문법은 Python 버전에 따라 지원 범위가 다를 수 있습니다.

버전 확인:

```bash
python --version
```

```bash
python 파일명.py
```

```powershell
.\venv\Scripts\Activate.ps1
```

## ✅ 학습 완료 기준

다음 항목을 설명하고 직접 구현할 수 있다면 Python 기본 학습 과정을 완료한 것으로 볼 수 있습니다.

- 입력받은 데이터를 필요한 자료형으로 변환할 수 있습니다.
- 조건문과 반복문으로 프로그램 흐름을 제어할 수 있습니다.
- 리스트와 딕셔너리를 이용해 여러 데이터를 처리할 수 있습니다.
- 중복 코드를 함수로 분리하고 결과를 반환할 수 있습니다.
- 클래스로 데이터와 관련 동작을 하나의 객체로 구성할 수 있습니다.
- 파일에 데이터를 저장하고 다시 불러올 수 있습니다.
- 예외 상황을 예상하고 안전하게 처리할 수 있습니다.
- 모듈로 코드를 나누어 관리할 수 있습니다.
- 타입 힌트와 명확한 이름으로 코드 의도를 표현할 수 있습니다.
