## 📌 Overview

Python은 간결하고 읽기 쉬운 문법을 바탕으로 다양한 분야에서 활용되는 프로그래밍 언어입니다.

이 디렉토리는 Python을 학습하며 작성한 문서를 모아둔 공간으로, 문법을 단순히 암기하는 데 그치지 않고 실제 코드의 실행 흐름과 자료형의 동작을 이해할 수 있도록 정리했습니다.

- Python 실행 방식과 프로그래밍 패러다임
- 오류 메시지와 예외 확인
- 출력, 변수, 자료형, 문자열
- 리스트, 튜플, 함수
- 딕셔너리와 집합
- 조건문과 반복문
- 강사 코드 비교 및 개선 포인트
- 복습 문제, Quiz 및 체크리스트

Developer-Wiki는 **학습 → 비교 → 개선 → 복습**의 흐름을 반복하며 Python의 기초를 체계적으로 익히는 것을 목표로 합니다.
