# 08 SQL 숫자 날짜 NULL함수 — 연습문제

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

`comm`이 NULL일 때 0으로 보고 계산하려면 수업에서 본 NULL 처리 함수는?

<details>
<summary>정답과 확인할 점</summary>

`IFNULL(comm, 0)`을 사용할 수 있다. 실제 결과는 사용 DB의 함수와 자료형에 맞춰 확인한다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../08_SQL_숫자_날짜_NULL함수.md)에서 비교한다.

</details>
