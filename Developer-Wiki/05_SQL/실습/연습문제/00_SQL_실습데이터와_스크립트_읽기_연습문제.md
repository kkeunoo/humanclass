# 00 SQL 실습데이터와 스크립트 읽기 — 연습문제

[원본 비교 본문](../../00_SQL_실습데이터와_스크립트_읽기.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

`Script.sql`을 맨 위부터 한 번에 실행하면 왜 뒤의 SELECT 결과가 일정하지 않을 수 있는가?

<details>
<summary>정답과 확인할 점</summary>

원본에는 CREATE·DROP·INSERT·UPDATE와 일부러 실패하는 문장이 섞였다. 앞에서 실행한 문장에 따라 표와 행의 상태가 달라진다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../00_SQL_실습데이터와_스크립트_읽기.md)에서 비교한다.

</details>
