# 15 SQL DML — 연습문제

[원본 비교 본문](../../15_SQL_DML.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

UPDATE 전에 동일한 WHERE 조건으로 어떤 문장을 먼저 실행해 대상 행을 확인할 수 있는가?

<details>
<summary>정답과 확인할 점</summary>

`SELECT ... FROM ... WHERE ...`로 먼저 대상 행을 읽는다. 연습 DB에서만 변경을 시도한다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../15_SQL_DML.md)에서 비교한다.

</details>
