# 18 SQL Recursive CTE — 연습문제

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

재귀 CTE에서 시작 행을 만드는 부분과 이전 결과로 다음 행을 만드는 부분을 각각 무엇이라 하는가?

<details>
<summary>정답과 확인할 점</summary>

시작 부분은 앵커, 반복 부분은 재귀 부분이다. 종료 조건이 없으면 의도한 범위에서 멈추지 않을 수 있다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../18_SQL_Recursive_CTE.md)에서 비교한다.

</details>
