# 03 SQL LIKE와 NULL — 연습문제

[원본 비교 본문](../../03_SQL_LIKE와_NULL.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

이름이 `A`로 시작하는 조건과 `comm`이 NULL인 조건을 각각 적어 보자.

<details>
<summary>정답과 확인할 점</summary>

`ename LIKE 'A%'`, `comm IS NULL`이다. NULL은 `= NULL`로 비교하지 않는다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../03_SQL_LIKE와_NULL.md)에서 비교한다.

</details>
