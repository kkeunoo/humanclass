# 11 SQL 서브쿼리 — 연습문제

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

최고 급여 값과 같은 급여의 사원을 찾을 때 안쪽 조회는 무엇을 구하는가?

<details>
<summary>정답과 확인할 점</summary>

`SELECT MAX(sal) FROM emp`를 안쪽에 두고 바깥에서 `sal = (...)`로 비교한다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../11_SQL_서브쿼리.md)에서 비교한다.

</details>
