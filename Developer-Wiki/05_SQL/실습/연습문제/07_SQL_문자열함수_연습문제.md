## 문제

<summary>정답과 확인할 점</summary>

`SUBSTR(ename, 1, 3)`처럼 시작 위치와 길이를 준다. 수업 DB의 함수 표기를 본문에서 확인한다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../07_SQL_문자열함수.md)에서 비교한다.
