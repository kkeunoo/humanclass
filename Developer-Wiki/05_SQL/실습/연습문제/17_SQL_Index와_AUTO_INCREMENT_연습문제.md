# 17 SQL Index와 AUTO INCREMENT — 연습문제

[원본 비교 본문](../../17_SQL_Index와_AUTO_INCREMENT.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

인덱스와 AUTO_INCREMENT는 각각 조회와 삽입에서 어떤 역할을 하는가?

<details>
<summary>정답과 확인할 점</summary>

인덱스는 검색 경로에 쓰일 수 있고, AUTO_INCREMENT는 새 행의 번호를 자동으로 매긴다. 인덱스가 모든 조회를 빠르게 만든다고 단정하지 않는다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../17_SQL_Index와_AUTO_INCREMENT.md)에서 비교한다.

</details>
