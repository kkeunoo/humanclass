# 09 SQL CASE 조건식 — 연습문제

[원본 비교 본문](../../09_SQL_CASE_조건식.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

급여가 2000 이상이면 `높음`, 아니면 `낮음`을 반환하는 CASE의 분기를 적어 보자.

<details>
<summary>정답과 확인할 점</summary>

`CASE WHEN sal >= 2000 THEN '높음' ELSE '낮음' END`다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../09_SQL_CASE_조건식.md)에서 비교한다.

</details>
