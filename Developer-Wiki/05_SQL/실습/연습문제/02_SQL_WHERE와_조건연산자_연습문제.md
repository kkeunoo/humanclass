## 문제

급여가 2000 이상인 사원만 읽으려면 어떤 `WHERE` 조건을 쓰는가?

<details>
<summary>정답과 확인할 점</summary>

`WHERE sal >= 2000`을 사용한다. `>`라면 2000인 행은 빠진다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../02_SQL_WHERE와_조건연산자.md)에서 비교한다.

</details>
