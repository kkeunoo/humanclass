# 16 SQL Transaction — 연습문제

[원본 비교 본문](../../16_SQL_Transaction.md) · [연습문제 목차](README.md)

**새로 구성한 복습 문제**이며 강사님 원본 문제나 내 당시 풀이가 아니다. `Script.sql`에는 상태를 바꾸는 문장이 있으므로 원본 전체를 실행하지 말고, 먼저 쿼리의 의미와 결과를 예상한다.

## 문제

변경 후 `COMMIT`과 `ROLLBACK`은 각각 어떤 방향으로 끝내는가?

<details>
<summary>정답과 확인할 점</summary>

`COMMIT`은 변경을 확정하고 `ROLLBACK`은 아직 확정하지 않은 변경을 되돌린다. 원본 실행 상태를 먼저 확인한다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../16_SQL_Transaction.md)에서 비교한다.

</details>
