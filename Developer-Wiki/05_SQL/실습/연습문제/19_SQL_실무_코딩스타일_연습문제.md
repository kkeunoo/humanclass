# 19. SQL 실무 코딩스타일 — 요구·관계·집계 단위를 드러내기 — 연습문제

[본문](../../19_SQL_실무_코딩스타일.md) · [문제 목차](README.md)

실제 수업 내용을 바탕으로 **새로 구성한 연습문제**다. 원래 퀴즈·내 풀이와 구별하며, 새 book_emp 가상 데이터와 원본 EMP 초기 자료를 혼동하지 않는다.

## 목표와 준비

필요한 결과 열·표 별칭·관계별 ON·그룹 키·정렬 기준을 명확히 적는다. 표현 정리와 실제 논리 수정, 더 좋은 코드와 목적이 다른 코드를 구별한다.

[준비문 포함 전체 SQL](../책형_복습/19_SQL_실무_코딩스타일.sql)을 제공한다. [본문 3절](../../19_SQL_실무_코딩스타일.md#example)의 같은 연결·새 임시 표·입력 행을 확인한다. D 드라이브 원본 전체를 실행해 준비하는 문제가 아니다.

## 문제 1. 행·열·값 예상

```sql
SELECT
    d.deptno,
    d.dname,
    COUNT(e.empno) AS people,
    MAX(e.sal) - MIN(e.sal) AS sal_gap
FROM book_dept d
LEFT JOIN book_emp e ON e.deptno = d.deptno
GROUP BY d.deptno, d.dname
ORDER BY d.deptno;
```

결과 행 수·열 의미·각 값을 적는다. 빈 결과 0행과 NULL 한 칸을 구별한다.

<details>
<summary>풀이</summary>

| 번호 | 부서 | 인원 | 급여 차이 |
| --- | --- | --- | --- |
| 10 | ALPHA | 1 | 0 |
| 20 | BETA | 3 | 2000 |
| 30 | GAMMA | 2 | 100 |
| 40 | EMPTY | 0 | NULL |

한 명인 ALPHA의 최고·최저는 같은1300이므로 차이0이다. BETA는3000−1000=2000, GAMMA는1600−1500=100이다. EMPTY는 사원이 없어 인원0이지만 급여 차이는NULL이다. 0명과 차이0원을 자동으로 같은 뜻으로 만들지 않는다. 결과의 한 행은 사원이 아니라 부서다.

</details>

## 문제 2. 이유 설명

1. INNER→LEFT는 표현만 바뀌는가?
2. 빈 부서 차이는 반드시0인가?
3. 별칭 변경은 결과 값도 바꾸는가?
4. 그룹에 sal을 잘못 넣은 문제는 들여쓰기로 해결되는가?

<details>
<summary>풀이</summary>

보존 대상이 바뀐다. 기본 집계에서는 NULL이다. 이름만 일관되게 바꾸면 값은 같다. 그룹 기준 자체를 수정해야 한다.

| 검토 질문 | 이번 답 |
| --- | --- |
| 한 행의 단위 | 부서 |
| 빠지면 안 되는 행 | 빈 부서 |
| 중복 집계 방지 | 부서번호·이름으로 그룹 |
| NULL의 뜻 | 계산할 급여 없음 |

</details>

## 문제 3. 한 가지만 바꾸기

| 한 가지만 변경 | 예상 | 이유 |
| --- | --- | --- |
| LEFT를 내부 JOIN으로 | EMPTY 제외 | 보존 정책 변경 |
| COUNT(e.empno)를COUNT(*)로 | EMPTY1 | 빈 조합 행 포함 |
| 열 별칭만 변경 | 값 동일 | 표현 변경 |
| WHERE e.sal>2000 추가 | 낮은 급여·빈 부서 제외 | 입력 행 정책 변경 |

한 행씩 골라 예상하고 실행한다. 다음 실험 전에 원래 준비 자료로 돌아간다.

<details>
<summary>막힐 때 확인</summary>

수정 뒤 결과가 달라졌으면 줄바꿈·이름만 바꿨는지 관계·조건·그룹도 바뀌었는지 본다. 여러 조인으로 인원이 커지면 관계의 매칭 수와 집계 단위를 확인한다. 예쁜 정렬만으로 의미 검토를 대신하지 않는다.

</details>

## 채점과 복습

값만 맞히지 말고 대상·상태·조건·NULL·정렬을 설명한다. 원본 코드와 새 개선안을 구별한다. 이 예제의 공통 조회 결과는 SQLite 메모리 DB 교차 확인이며 MariaDB 서버 실행 확인은 아니다. 공식 문법과 DB별 설정의 차이를 본문에서 확인한다. TIP 선택 확장은 필수 정답이 아니다.
