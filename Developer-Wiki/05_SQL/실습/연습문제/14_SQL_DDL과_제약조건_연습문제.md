## 문제

`CREATE TABLE`의 기본키와 NOT NULL 제약은 각각 무엇을 제한하는가?

<details>
<summary>정답과 확인할 점</summary>

기본키는 행을 구별하는 값의 중복과 NULL을 허용하지 않고, NOT NULL은 해당 열의 NULL을 막는다.

강사님 코드와 내 실제 코드의 작성 방식은 [본문](../../14_SQL_DDL과_제약조건.md)에서 비교한다.

</details>
