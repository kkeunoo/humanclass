## 2. 실행

각 본문 3절의 전체 파일을 같은 MariaDB 연습 연결에서 준비문부터 읽는다. book_ 임시 표는 새 예제 장치다. 기존 EMP를 초기화하거나 원본 Script.sql을 통째로 실행하는 절차가 아니다. 장마다 다른 반례 입력은 해당 준비문을 다시 확인한다.

## 3. 검증 구분

이 교재 작성 중에는 SQLite 메모리 DB 교차 확인과 MariaDB 공식 문법 대조를 했다. MariaDB 서버에 접속하지 않았다. 서버별 함수·제약·트랜잭션·자동 번호 차이는 각 본문에서 조건부 예상과 확인 범위를 적었다. 속도 향상·외부 DB 상태 변경을 확인했다고 표시하지 않는다.

## 4. 다시 읽기
