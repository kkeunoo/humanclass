## 3. 자체 피드백

| 부분 | 보완 |
| --- | --- |
| SELECT | DISTINCT 조합·별칭·원본 변경 구분 |
| 조건 | AND·OR·경계·대소문자 일반화 교정 |
| 정렬 | DESC 생략 가능이라는 주석 오류 교정 |
| 집계 | NULL·0·빈 입력·COUNT 결과 한 행 구분 |
| 그룹 | sal 기준 추가로 평균 의미가 바뀜 |
| 최대 사원 | sal IN 목록과 자기 부서 최대 구분 |
| 외부 조인 | 빈 그룹 COUNT(*)가1이 되는 반례 |
| DDL | 제약 복사·변경 후 옛 이름 삭제·외래 키 전제 |
| 트랜잭션 | 확정·취소·DDL 경계·임시 표 수명 구분 |
| 범위 | CHAR_LENGTH·상관쿼리·재귀를 미학습으로 내리지 않음 |

## 4. 실행과 한계

공통 구문의 행·값과 일부 제약·상태 변화는 별도 SQLite 메모리 DB에서 교차 확인했다. 임시 DROP·트랜잭션 시작·엔진 표기는 테스트에서 대응했다. 활성 트랜잭션 없는 SQLite ROLLBACK의 차이도 문서에 적었다. MariaDB 자체를 실행하지 않았으며 DB별 함수·오류번호·성능·문자열 설정을 같은 것으로 검증했다고 하지 않는다.

제공 초기화 SQL의 데이터도 별도 메모리 DB에 읽어 초기 개수·집계·등급을 대조한다. 서버의 STR_TO_DATE 실행을 대체 입증한 것이 아니라 그 입력 날짜를 테스트에 맞게 해석해 자료 값을 확인한다. 최신 결과 수치는 work/book-sql-subject-verification.json과 책형 검증 결과에 기록한다.
