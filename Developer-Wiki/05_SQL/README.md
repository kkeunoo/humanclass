## 추가로 알면 좋은 것

[기존 SQL 자료의 학습 범위 분류](추가편_기존자료_학습범위_분류.md)에는 원본 수업에서 확인되지 않은 확장 주제를 따로 표시했다. 기존 Wiki의 파일별 새 위치는 [기존 문서 대응표](../편집기록/05_SQL_기존문서_대응표.md)를 참고한다.

원본 `Script.sql`은 조회, 표 생성·삭제, 일부러 실패하는 실험과 변경 문장이 섞인 **학습 기록**이다. 전체 파일을 한 번에 실행해 같은 결과가 나온다고 가정하지 않는다. [전체 Wiki 첫 화면](../README.md)에서 다른 과목으로 이어 읽는다.
