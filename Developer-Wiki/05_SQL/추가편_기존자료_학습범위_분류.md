# 추가로 알면 좋은 것 — 기존 SQL 자료의 학습 범위

[SQL 목차](README.md)

이 표는 기존 Wiki를 버리기 위한 목록이 아니라 **실제 수업 코드와 확장 설명을 구분하는 안내**다. 강사님·내 `workspace_sql/Script.sql`과 제공된 초기화 SQL에 있는 내용을 메인으로 정했다. 기존 Wiki의 제목이나 “수업 원본”이라는 표현만으로 실제 배운 범위를 넓히지 않는다.

| 기존 자료의 주제 | 분류 | 읽을 위치 |
| --- | --- | --- |
| `SELECT`·조건·패턴·정렬·집계·함수·`CASE`·`UNION`·서브쿼리·JOIN | 실제 수업 본문 | [01–13 목차](README.md) |
| `CREATE TABLE`·기본 키·외래 키·`INSERT`·`UPDATE`·`DELETE`·`COMMIT`·`ROLLBACK` | 실제 수업 본문 | [14–16 목차](README.md) |
| `CREATE INDEX`·`FORCE INDEX`·`AUTO_INCREMENT` | 실제 수업 본문 | [17 인덱스와 자동 번호](17_SQL_Index와_AUTO_INCREMENT.md) |
| `WITH RECURSIVE`로 관리자 관계 따라가기 | 실제 수업 본문 | [18 재귀 CTE](18_SQL_Recursive_CTE.md) |
| 원본 뒤쪽 7개 문제와 내 시험문제 풀이 | 실제 수업·평가 실습 | [원본 문제 비교](실습_SQL_원본문제_비교.md) |
| 기존 17번의 복합·커버링 인덱스, 선택도·실행 계획의 상세 해석 | **추가로 알면 좋은 것** | 원본에서는 인덱스 생성·힌트까지만 확인됨 |
| 기존 18번의 순환 감지·깊이 제한 등 고급 재귀 설계 | **추가로 알면 좋은 것** | 원본 재귀 쿼리에는 없음 |
| 기존 19번의 독립적인 실무 코딩 스타일 전반 | **추가로 알면 좋은 것** | 원본에서 비교 가능한 읽기 좋은 방식만 각 장에 포함 |
| 기존 20번의 새 8단계 종합 프로젝트·새 실습 표·보고서 확장 | **추가로 알면 좋은 것** | 실제 원본 문제는 메인 실습으로 분리 |
| 기존 Wiki의 MariaDB 12.3.2 보충 검증 결과·반례·성능 측정 | **추가로 알면 좋은 것** | 실제 수업 코드의 실행 기록으로 취급하지 않음 |

원본 스크립트의 주석에도 일반화하면 틀리는 설명이 있다. 예를 들어 `LENGTH`를 글자 수로 보기, `AUTO_INCREMENT`는 기본 키에만 가능하다고 보기, `COUNT(*)`로 빈 외부 조인 대상을 0명으로 세기, `ROLLBACK`이 DDL 이전까지 되돌린다고 보기는 각 본문에서 실제 코드와 함께 바로잡았다.
