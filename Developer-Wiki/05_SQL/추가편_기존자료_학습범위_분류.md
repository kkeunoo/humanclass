## 1. 근거

현재 양쪽 workspace_sql/Script.sql과 내 초기화 SQL을 기준으로 삼았다. 예전 Wiki·BACKUP의 풍부한 정의와 예제 구성은 참고하되 그 파일에 있다는 이유만으로 배웠다고 판단하지 않았다. SQL 관련 BACKUP 독립 문서가 확인되지 않는 경우 다른 언어 파일을 SQL 학습 증거로 사용하지 않는다.

## 2. 실제 학습 본문

SELECT·WHERE·LIKE·NULL·정렬·집계·그룹·함수·CASE·UNION·서브쿼리·조인·DDL·DML·트랜잭션·인덱스·자동 번호·재귀 CTE는 실제 원본의 구문이다. 내 뒤쪽 CHAR_LENGTH도 실제 사용이고 시험의 상관 서브쿼리도 본문이다. 이름이 고급처럼 보인다는 이유로 모두 추가 학습으로 옮기지 않는다.

## 3. 새 설명과 TIP

가상 book_ 자료, 빈 그룹·다른 연도 동점 반례, 부서 키와 최대 급여를 함께 연결한 개선은 교재가 새로 만든 예제다. 당시 코드와 구별한다. 임시 표는 기존 자료를 바꾸지 않고 설명하기 위한 새 실행 준비 장치이며 상세 기능을 수업 본문으로 승격하지 않는다.

EXPLAIN 결과 읽기·고급 인덱스·격리·잠금·순환 탐지·대용량 최적화·스키마 이전 도구는 각 본문 하단 💡 TIP에 둔다. 추가로 알면 좋은 내용을 읽기 위해 다른 폴더로 이동할 필요는 없다. 📚 출처는 학습 문법 확인 근거로 구별한다.

## 4. 이후 첨부

댓글 계층 메모의 테이블 구조·실제 바인딩 실행 환경이 없으면 완성 실행 결과는 확정하지 않는다. 아직 없는 자료를 상상해 채우지 않고 이후 첨부 때 현재 코드와 다시 대조한다. 현재 원본의 누락 조건·열 대응 오류는 지금 확인 가능한 범위에서 설명한다.
