# 09. 실무 코딩스타일 — 교정과 추가 설계 분리

원본 코드의 오류 교정은 해당 기본 장에 통합했다. 같은 교정을 별도 필수 진도로 반복하지 않는다.

- [원본 교정의 대표 위치와 추가 검수](추가로_알면_좋은_것/03_설계와_검수.md#basic)
- [추가 요소와 속성](추가로_알면_좋은_것/02_확장_요소와_속성.md)
- [기본 종합복습](10_HTML_종합실습.md)

원본 밖의 설계·협업 규칙·ARIA 상세·검수 전체 과정은 **추가로 알면 좋은 것**에 해당한다. 이 파일은 이전 링크를 위한 이동 안내다.
