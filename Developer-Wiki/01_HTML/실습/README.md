# HTML 실습

[HTML 목차](../README.md) · [종합실습](../10_HTML_종합실습.md)

이 폴더의 HTML 파일은 **수업에서 배운 태그를 묶어 새로 구성한 복습**이다. 현재 HTML 단원에 이 이름과 대응하는 강사님 원본 퀴즈가 있었다는 뜻은 아니다. 다른 과목의 실제 원본 퀴즈와 내 당시 풀이가 있는 경우에는 `실습-OOO` 본문에서 별도로 비교한다.

1. [본문 8장별 연습문제](연습문제/README.md) — 문서 구조부터 GET·POST 전송까지 한 장씩
2. [목록·표·폼 GET 제출 복습](목록_표_폼_GET제출_복습.html) — 가상의 복습 모임 신청값이 쿼리로 어떻게 만들어지는지 확인
3. [교육과정 페이지 추가실습](교육과정_추가실습.html) — 시맨틱 구조·새 입력 속성을 **추가로 알면 좋은 것**으로 연습
4. [HTML 종합실습 해설](../10_HTML_종합실습.md) — 원본 범위의 기본 과제와 확장 과제 구분

GitHub에서는 `.html`의 코드가 보일 수 있다. 실제 화면은 파일을 내려받아 브라우저에서 열고, GET 주소를 확인하려면 로컬 HTTP 서버에서 제출한다. 저장 서버는 없다.
