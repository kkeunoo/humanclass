## 실제 확인 순서

1. 폴더를 함께 내려받는다. 03 하위 폴더와 assets의 위치를 유지한다.
2. 파일을 브라우저로 열어 예상과 비교한다.
3. 한 조건만 바꾸고 저장·새로고침한다. 다음 실험 전 원래 상태로 되돌린다.
4. 요청은 이미 사용하던 Live Server 같은 HTTP 환경에서 확인한다. GET 주소·POST 요청·서버 응답을 구분한다.

HTML만으로 입력을 서버에 저장하지는 않는다. 정적 파일 서버가 POST를 지원하지 않으면 오류 응답이 올 수 있다. 이번 편집에서 실제 브라우저 요청을 새로 수행했다고 주장하지 않는다.
