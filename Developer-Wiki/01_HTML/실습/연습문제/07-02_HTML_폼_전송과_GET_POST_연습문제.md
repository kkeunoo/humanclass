# 07-02 HTML 폼 전송과 GET POST — 연습문제

[해당 본문](../../07-02_HTML_폼_전송과_GET_POST.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`name="learner" value="kim"` 입력과 `name="topic" value="html" checked` 체크박스를 GET 제출할 때 쿼리를 예상하자.

**확인 기준:** `learner=kim&topic=html`이 제출 대상이다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

제출 여부는 `name`·값·선택 상태로 읽는다. 서버에 저장됐다는 뜻은 아니다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
