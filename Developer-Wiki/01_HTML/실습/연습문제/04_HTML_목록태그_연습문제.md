# 04 HTML 목록태그 — 연습문제

[해당 본문](../../04_HTML_목록태그.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

준비물 세 개는 순서 없는 목록, 작업 단계 두 개는 번호 목록으로 작성하자.

**확인 기준:** 준비물은 `ul`, 단계는 `ol` 아래 각각 `li`로 보인다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<ul><li>노트</li><li>펜</li><li>교재</li></ul>
<ol><li>코드 읽기</li><li>실행하기</li></ol>
```
준비물은 순서가 중요하지 않고, 작업 단계는 순서가 중요하다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
