# 04 HTML 목록태그 — 연습문제

[해당 본문](../../04_HTML_목록태그.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. [본문의 세 가지 목록](../../04_HTML_목록태그.md#types)을 보고 순서가 중요한지 먼저 판단한다.

## 문제

준비물 세 개는 순서 없는 목록, 작업 단계 두 개는 번호 목록으로 작성하자.

**확인 기준:** 준비물의 순서를 바꾸어도 뜻이 유지되는지, 단계의 순서를 바꾸면 뜻이 달라지는지 설명한다. 각 항목은 해당 목록의 `li` 안에 둔다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<ul><li>노트</li><li>펜</li><li>교재</li></ul>
<ol><li>코드 읽기</li><li>실행하기</li></ol>
```
준비물은 순서가 중요하지 않고, 작업 단계는 순서가 중요하다.

위 한 줄 예제도 동작하지만, 실제 문서에서는 각 `li`를 줄로 나누고 들여쓰면 구조를 확인하기 쉽다. 소스의 줄바꿈이 목록의 의미를 결정하지는 않는다.

</details>

## 응용 — 하위 항목 추가

`교재` 안에 `HTML 교재`와 `CSS 교재`를 하위 목록으로 넣으려면, 바깥쪽 `교재`의 `<li>`를 닫기 **전에** 안쪽 `<ul>`을 배치한다. [본문의 실제 중첩 목록](../../04_HTML_목록태그.md#nested)과 비교해 보자. 이 응용은 원본의 구조를 다른 단어로 연습한 것이다.
