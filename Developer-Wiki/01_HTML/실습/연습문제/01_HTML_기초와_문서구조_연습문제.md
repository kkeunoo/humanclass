# 01 HTML 기초와 문서구조 — 연습문제

[해당 본문](../../01_HTML_기초와_문서구조.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 강사님·내 원본의 `hello world`와 `head`·`body` 구분을 다른 문구로 적용한다. [본문 1~3절](../../01_HTML_기초와_문서구조.md)에서 탭과 화면의 위치를 먼저 확인하자.

## 문제

탭 제목은 `첫 문서`, 본문 제목은 `HTML 연습`인 최소 HTML 문서를 작성하자. 문서 언어도 표시한다.

**확인 기준:** 문서 언어, 탭 제목, 화면 제목을 각기 알맞은 위치에 넣었는지 설명할 수 있다. 저장 후 브라우저 탭과 페이지 본문을 각각 확인한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<!doctype html>
<html lang="ko">
<head><meta charset="utf-8"><title>첫 문서</title></head>
<body><h1>HTML 연습</h1></body>
</html>
```
`title`은 탭, `h1`은 본문 제목이다.

`lang="ko"`는 한국어 문서임을 알리는 속성이다. 화면에 별도 문구로 나타나지 않는다. `<h1>`을 `<head>`에 넣거나 `<title>`을 `<body>`에 넣어 우연히 글자가 보여도 올바른 문서 구조라고 판단하지 않는다.

</details>

## 바꾸어 보기

화면의 `<h1>`을 지워도 탭의 `첫 문서`는 남는다. 반대로 `<title>`의 글자만 `복습`으로 바꾸면 페이지 안의 `HTML 연습`은 그대로다. 두 위치가 독립적이라는 점을 직접 확인하자. 원본의 `hello world` 두 줄은 **일반 텍스트와 제목 요소의 차이**를 보여 준다.
