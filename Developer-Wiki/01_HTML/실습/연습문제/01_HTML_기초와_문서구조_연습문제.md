# 문서의 제목과 본문 — 연습문제

[본문으로](../../01_HTML_기초와_문서구조.md) · [문제 목차](README.md)

이 파일은 수업 원본을 바탕으로 **새로 구성한 연습문제**다. 실제 강사님 퀴즈와 구분한다. 풀이 전에 예상과 이유를 직접 적고, 본문의 실행 파일에 적용해 확인한다.

## 목표와 실행 조건

문서 전체와 body 안의 조각을 구별하고, title·h1·title 속성의 역할을 설명한다.

HTML 조각은 본문에서 제공한 전체 파일의 적절한 위치에 넣는다. ‘코드로 예상한 결과’와 ‘브라우저에서 실제 확인한 결과’를 따로 적는다. 폼 요청은 로컬 HTTP 환경에서 관찰하고, 서버 저장 기능을 이 문제에 임의로 추가하지 않는다.

## 문제 1. 먼저 결과 예상하기

다음은 **새 설명 예제 · body 안에 넣는 조각**이다. 파일의 head에는 `<title>복습 기록</title>`이 있다고 가정한다.

```html
<h1 title="큰 제목의 설명">나의 첫 문서</h1>
오늘의 기록
```

탭 제목·본문 큰 제목·일반 글자를 각각 적는다. h1의 title 속성이 탭 제목을 바꾸는지도 답한다.

<details>
<summary>힌트와 풀이</summary>

**힌트:** 속성 이름과 현재 값을 구별하고, 이 코드가 전체 문서인지 조각인지 먼저 확인한다.

탭은 ‘복습 기록’, 본문 큰 제목은 ‘나의 첫 문서’, 일반 글자는 ‘오늘의 기록’이다. h1의 title 속성은 해당 요소의 보충 설명이고 탭 제목을 정하는 title 요소와 다르다. 포인터로 보충 설명을 관찰할 수 있지만, 항상 보이는 본문을 대신하게 만들지는 않는다.

</details>

## 문제 2. 이유를 설명하기

코드의 내용이 그대로 보인다고 해서 모두 같은 역할인 것은 아니다. `나의 첫 문서`를 h1로 감쌌을 때와 태그 없이 적었을 때, ‘의미’와 ‘기본 화면’에서 무엇이 달라지는지 설명한다.

<details>
<summary>풀이</summary>

h1은 제목이라는 역할을 표현한다. 기본 스타일에서는 큰 글씨와 여백으로 구분되지만, 글자 크기가 h1의 정의인 것은 아니다. 일반 글자도 화면에 보이지만 문서 제목 요소가 되지 않는다. 이후 CSS로 같은 크기를 주어도 의미의 차이는 남는다.

</details>

## 문제 3. 고치고 한 가지 바꾸기

빈 HTML 파일에서 위 조각을 실행하고 싶다. DOCTYPE·html·head·meta charset·title·body를 포함한 전체 문서를 작성한다. 본문은 head 밖에 두고, 모든 요소의 닫는 위치를 확인한다.

<details>
<summary>예시 정답과 변경 실험</summary>

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>복습 기록</title>
</head>
<body>
    <h1 title="큰 제목의 설명">나의 첫 문서</h1>
    오늘의 기록
</body>
</html>
```

title 속성만 삭제한 뒤 탭과 본문이 어떻게 되는지 예상한다. 둘의 글자는 그대로다. 삭제한 것은 h1의 보충 설명이다. 원래 예제의 h1 내용만 바꾸면 본문 제목이 바뀌고 탭은 그대로다.

</details>

## 채점과 복습

| 점검 | 스스로 확인할 것 |
| --- | --- |
| 예상 | 결과를 먼저 썼는가? |
| 설명 | 왜 그런지 태그·속성·위치로 설명했는가? |
| 수정 | 요구한 조건만 바꾸었는가? |
| 검증 | 저장·새로고침 후 실제 결과와 비교했는가? |

title 요소와 title 속성을 이름만 보고 같은 것으로 외우지 않는다. 조각 코드가 보인다는 이유로 문서 전체 구조 검토를 생략하지 않는다.

정답 글자를 외우기보다 원인을 설명하지 못한 부분을 [본문](../../01_HTML_기초와_문서구조.md)에서 다시 읽는다. 본문의 📚 출처는 배운 기능의 설명을 확인하는 근거이며, 💡 TIP은 선택 학습이다. 이 문제의 정답에 TIP 기능이 필수로 들어가지는 않는다.
