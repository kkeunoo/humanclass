# 02 HTML 기본태그 — 연습문제

[해당 본문](../../02_HTML_기본태그.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`중요한 단어`는 강한 강조, `읽기 순서`는 일반 강조로 표시하고 문단 둘을 만들자.

**확인 기준:** 문단 둘과 서로 다른 의미의 강조가 DOM에 남는다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<p><strong>중요한 단어</strong>를 확인합니다.</p>
<p><em>읽기 순서</em>를 따라갑니다.</p>
```
`strong`과 `em`은 의미가 다르다. 화면의 굵기·기울기만으로 목적을 설명하지 않는다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
