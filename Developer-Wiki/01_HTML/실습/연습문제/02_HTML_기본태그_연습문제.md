# 02 HTML 기본태그 — 연습문제

[해당 본문](../../02_HTML_기본태그.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. [본문의 `strong`·`em` 비교](../../02_HTML_기본태그.md#meaning)를 읽고, 모양만 보고 태그를 고르는 습관을 점검한다.

## 문제

`중요한 단어`는 강한 강조, `읽기 순서`는 일반 강조로 표시하고 문단 둘을 만들자.

**확인 기준:** 문단 두 개를 `p`로 나누고, 중요한 내용과 읽을 때 힘을 주는 부분을 각각 어떤 태그로 표시했는지 이유를 말한다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<p><strong>중요한 단어</strong>를 확인합니다.</p>
<p><em>읽기 순서</em>를 따라갑니다.</p>
```
`strong`과 `em`은 의미가 다르다. 화면의 굵기·기울기만으로 목적을 설명하지 않는다.

첫 문장은 중요한 정보를, 둘째 문장은 읽는 강세를 표시한다. 두 줄을 단순히 `<br>`로 나누면 문단 두 개라는 구조가 남지 않는다.

</details>

## 한 단계 더

두 문단 사이에 `<hr>`을 넣을지는 **주제가 전환되는지** 보고 판단한다. 단순히 공간을 넓히려고 넣는다면 이 태그의 의미와 맞지 않는다. 강사님·내 원본에서도 `strong`과 `em`을 사용했지만, 이 문제의 문장은 새로 구성했다.
