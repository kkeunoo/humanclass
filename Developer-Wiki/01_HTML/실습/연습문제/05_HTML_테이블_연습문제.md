# 격자로 셀 추적하기 — 연습문제

[본문으로](../../05_HTML_테이블.md) · [문제 목차](README.md)

이 파일은 수업 원본을 바탕으로 **새로 구성한 연습문제**다. 실제 강사님 퀴즈와 구분한다. 풀이 전에 예상과 이유를 직접 적고, 본문의 실행 파일에 적용해 확인한다.

## 목표와 실행 조건

행·셀·병합을 구분하고 표 제목과 제목 셀의 역할을 설명한다.

HTML 조각은 본문에서 제공한 전체 파일의 적절한 위치에 넣는다. ‘코드로 예상한 결과’와 ‘브라우저에서 실제 확인한 결과’를 따로 적는다. 폼 요청은 로컬 HTTP 환경에서 관찰하고, 서버 저장 기능을 이 문제에 임의로 추가하지 않는다.

## 문제 1. 먼저 결과 예상하기

**새 설명 예제 · table 조각.** 다음 표를 두 행·두 열의 칸 그림으로 그린다. 두 번째 tr에 td가 하나인 이유도 쓴다.

```html
<table border="1">
    <tr><td rowspan="2">공통</td><td>A</td></tr>
    <tr><td>B</td></tr>
</table>
```

border는 수업처럼 경계를 관찰하는 용도다.

<details>
<summary>힌트와 풀이</summary>

**힌트:** 속성 이름과 현재 값을 구별하고, 이 코드가 전체 문서인지 조각인지 먼저 확인한다.

첫 행은 ‘공통 | A’, 둘째 행은 ‘위에서 이어지는 공통 | B’다. 공통 셀이 두 행을 차지하므로 둘째 행의 첫 칸을 이미 점유한다. 둘째 tr에는 남은 두 번째 칸 B만 작성했다. td 개수만 세어서 전체 칸 수를 계산하면 병합을 놓친다.

</details>

## 문제 2. 이유를 설명하기

caption·th·td는 모두 글자를 담는데 역할이 어떻게 다른가? caption에 hidden을 붙이면 표 제목을 화면에서 보고 이해하도록 돕는 목적을 달성하는지도 답한다.

<details>
<summary>풀이</summary>

caption은 표 전체의 제목, th는 행·열의 제목 셀, td는 일반 데이터 셀이다. 역할과 범위가 다르다. hidden은 보통 화면에 표시하지 않게 하므로 보이는 표 제목으로 쓰려는 목적과 맞지 않는다. 숨김 자체를 접근성 설명 제공으로 단정할 수도 없다.

</details>

## 문제 3. 고치고 한 가지 바꾸기

다음 구조를 ‘복습 시간’이라는 표 제목, ‘과목·시간’ 제목 행, 데이터 한 행으로 고친다. 잘못된 닫는 태그도 찾는다.

```html
<table>
    <summary>복습 시간</summary>
    <tr><th>과목</td><th>시간</th></tr>
    <tr><td>HTML</td><td>30분</td></tr>
</table>
```

summary가 어느 요소의 이름인지 자세한 사용은 이 문제의 필수 범위가 아니다.

<details>
<summary>예시 정답과 변경 실험</summary>

```html
<table>
    <caption>복습 시간</caption>
    <thead>
        <tr><th>과목</th><th>시간</th></tr>
    </thead>
    <tbody>
        <tr><td>HTML</td><td>30분</td></tr>
    </tbody>
</table>
```

summary를 caption으로 고치고 th의 닫기를 맞췄다. thead·tbody는 제목 행과 데이터 영역을 묶는다. 첫 문제의 rowspan만 1로 바꾸면 둘째 행 첫 칸이 더 이상 점유되지 않아 B가 첫 열로 간다. 이전 배치를 유지하려면 둘째 행도 새 열 조건에 맞게 작성해야 한다.

</details>
