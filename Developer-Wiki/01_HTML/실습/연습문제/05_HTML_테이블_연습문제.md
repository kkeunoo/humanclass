# 05 HTML 테이블 — 연습문제

[해당 본문](../../05_HTML_테이블.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. [본문의 표 구조](../../05_HTML_테이블.md#parts)에서 행과 셀을 먼저 그린 뒤 코드로 바꾼다.

## 문제

과목·시간 열의 표에 데이터 두 행을 만들고, 맨 위에 표 제목을 넣자.

**확인 기준:** 표 전체 제목, 열 제목 두 개, 데이터 두 행이 각각 어떤 태그에 해당하는지 설명한다. 브라우저에서 셀을 세어 본다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

```html
<table>
  <caption>복습 시간표</caption>
  <tr><th>과목</th><th>시간</th></tr>
  <tr><td>HTML</td><td>1시간</td></tr>
  <tr><td>CSS</td><td>1시간</td></tr>
</table>
```
`caption`은 표의 제목, `th`는 열 제목, `td`는 데이터다.

첫 번째 `tr`은 제목 셀 두 개, 다음 두 `tr`은 각각 데이터 셀 두 개를 가진다. 총 3행 × 2열이다. `caption`은 이 셀 개수에 넣지 않는다.

</details>

## 응용 — 병합 여부 판단

위 표에는 두 열에 걸친 셀이 없다. 따라서 `colspan`을 붙일 필요가 없다. 두 칸을 하나로 합친 별도 행을 넣고 싶을 때만 [본문의 병합 예시](../../05_HTML_테이블.md#merge)와 비교해 적용한다. 강사님·내 원본에는 병합 실험이 있지만, 병합을 모든 표에 쓰라는 뜻은 아니다.
