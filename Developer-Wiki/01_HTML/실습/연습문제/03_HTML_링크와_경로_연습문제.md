# 03 HTML 링크와 경로 — 연습문제

[해당 본문](../../03_HTML_링크와_경로.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 원본의 `../asset/detail.html`을 이해했는지 다른 폴더 배치로 확인한다. [본문 2절](../../03_HTML_링크와_경로.md#relative)에서 현재 위치를 기준으로 계산하는 법을 먼저 읽자.

## 문제

다음 폴더에서 `pages/start.html`에 로고 파일로 이동하는 **링크**를 만들려 한다. `href`에 적을 상대 경로를 쓰고, 출발점부터 목적지까지 지나가는 폴더를 말해 보자.

```text
site/
├── pages/
│   └── start.html  ← 현재 파일
└── images/
    └── logo.png    ← 목적지
```

**확인 기준:** 현재 파일 기준으로 경로를 계산하고, 링크의 목적지는 `href`에 적었는지 확인한다. 이미지를 페이지 안에 표시하는 `img`·`src`는 06장에서 배운다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`pages`에서 `..`으로 부모인 `site`로 나와 `images/logo.png`로 들어간다. 따라서 `<a href="../images/logo.png">로고 파일 열기</a>`가 한 답이다. 이동 목적지를 `href`에 적는다. 이 링크를 누르면 브라우저가 해당 이미지 파일로 이동한다. 페이지 안에 그림을 바로 표시하려면 06장의 `img`를 사용한다.

</details>

## 응용 — 같은 위치의 다른 파일

목적지가 `pages/help.html`로 바뀌면 `start.html`에서 어떻게 적을까? 답은 `help.html` 또는 `./help.html`이다. 부모로 올라갈 필요가 없다. 강사님과 내 원본의 `../asset/detail.html`은 **목적지 폴더가 현재 폴더의 형제 폴더**라는 점에서 첫 문제와 같다.
