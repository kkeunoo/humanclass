# 문서 위치에서 경로 계산 — 연습문제

[본문으로](../../03_HTML_링크와_경로.md) · [문제 목차](README.md)

이 파일은 수업 원본을 바탕으로 **새로 구성한 연습문제**다. 실제 강사님 퀴즈와 구분한다. 풀이 전에 예상과 이유를 직접 적고, 본문의 실행 파일에 적용해 확인한다.

## 목표와 실행 조건

현재 파일 기준 상대 경로와 사이트 루트 경로, 문서 내부 ID 이동을 구분한다.

HTML 조각은 본문에서 제공한 전체 파일의 적절한 위치에 넣는다. ‘코드로 예상한 결과’와 ‘브라우저에서 실제 확인한 결과’를 따로 적는다. 폼 요청은 로컬 HTTP 환경에서 관찰하고, 서버 저장 기능을 이 문제에 임의로 추가하지 않는다.

## 문제 1. 먼저 결과 예상하기

현재 주소는 `http://localhost:8000/pages/detail.html`이다. 다음 상대 주소가 가리키는 URL을 각각 적는다. 여기서는 HTTP로 제공되는 문서라고 가정한다.

```html
<a href="index.html">가까운 파일</a>
<a href="../index.html">상위 폴더의 파일</a>
<a href="/index.html">사이트 루트의 파일</a>
```

첫 번째 파일이 실제로 존재하는지는 URL 계산과 별도로 답한다.

<details>
<summary>힌트와 풀이</summary>

**힌트:** 속성 이름과 현재 값을 구별하고, 이 코드가 전체 문서인지 조각인지 먼저 확인한다.

순서대로 `http://localhost:8000/pages/index.html`, `http://localhost:8000/index.html`, `http://localhost:8000/index.html`이다. 이번 위치에서는 두 번째와 세 번째 결과가 같지만 출발 기준이 다르다. 파일의 존재는 서버의 실제 파일 배치를 보아야 알 수 있다.

</details>

## 문제 2. 이유를 설명하기

위 문서를 `pages/archive/detail.html`로 옮기고 같은 서버 주소를 사용한다. `../index.html`과 `/index.html`의 목적지는 각각 어떻게 되는가? 문서를 이동하면 모든 경로가 같은 방식으로 바뀌는지 설명한다.

<details>
<summary>풀이</summary>

`../index.html`은 `/pages/index.html`, `/index.html`은 계속 사이트 루트의 `/index.html`이다. 상대 경로는 현재 문서 위치를 따라 기준이 바뀐다. 루트 경로는 현재 폴더 깊이를 따라가지 않는다. 로컬 파일로 여는 경우와 HTTP 서버의 루트를 혼동하지 않는다.

</details>

## 문제 3. 고치고 한 가지 바꾸기

본문 예제 폴더를 기준으로 `03_경로_복습/pages/detail.html`에서 `03_경로_복습/index.html`로 돌아오는 링크와, detail.html 안의 id="answer"로 이동하는 링크를 작성한다. 아래는 body 조각이다.

<details>
<summary>예시 정답과 변경 실험</summary>

```html
<a href="../index.html">목차로</a>
<a href="#answer">풀이로</a>
<h2 id="answer">풀이</h2>
```

같은 문서 내부 이동에는 파일 폴더를 거슬러 올라갈 필요가 없다. href="#answer"를 "#Answer"로만 바꾸는 실험에서는 ID 철자가 달라져 같은 목적지를 찾지 못할 수 있다. 주소 계산·파일 존재·ID 존재를 각각 확인한다.

</details>

## 채점과 복습

| 점검 | 스스로 확인할 것 |
| --- | --- |
| 예상 | 결과를 먼저 썼는가? |
| 설명 | 왜 그런지 태그·속성·위치로 설명했는가? |
| 수정 | 요구한 조건만 바꾸었는가? |
| 검증 | 저장·새로고침 후 실제 결과와 비교했는가? |

모든 경로 앞에 ../를 붙여 해결하지 않는다. 현재 문서, 목표 파일, 필요한 상위 이동 횟수를 먼저 적는다.

정답 글자를 외우기보다 원인을 설명하지 못한 부분을 [본문](../../03_HTML_링크와_경로.md)에서 다시 읽는다. 본문의 📚 출처는 배운 기능의 설명을 확인하는 근거이며, 💡 TIP은 선택 학습이다. 이 문제의 정답에 TIP 기능이 필수로 들어가지는 않는다.
