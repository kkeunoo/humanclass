# 03 HTML 링크와 경로 — 연습문제

[해당 본문](../../03_HTML_링크와_경로.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

현재 파일이 `pages/start.html`이고 대상이 같은 부모의 `images/logo.png`일 때 이미지의 상대 경로를 적자.

**확인 기준:** `../images/logo.png`로 파일을 가리킨다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`pages`에서 부모로 한 단계 나와 `images`로 들어간다. `href`와 `src`의 목적은 서로 다르다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
