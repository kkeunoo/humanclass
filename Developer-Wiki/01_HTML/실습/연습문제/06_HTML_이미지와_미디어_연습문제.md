# 경로·비율·대체 설명 — 연습문제

[본문으로](../../06_HTML_이미지와_미디어.md) · [문제 목차](README.md)

이 파일은 수업 원본을 바탕으로 **새로 구성한 연습문제**다. 실제 강사님 퀴즈와 구분한다. 풀이 전에 예상과 이유를 직접 적고, 본문의 실행 파일에 적용해 확인한다.

## 목표와 실행 조건

이미지 로딩 문제와 크기 문제를 구별하고, Boolean 속성의 유무를 읽는다.

HTML 조각은 본문에서 제공한 전체 파일의 적절한 위치에 넣는다. ‘코드로 예상한 결과’와 ‘브라우저에서 실제 확인한 결과’를 따로 적는다. 폼 요청은 로컬 HTTP 환경에서 관찰하고, 서버 저장 기능을 이 문제에 임의로 추가하지 않는다.

## 문제 1. 먼저 결과 예상하기

본문에 제공한 원본 PNG는 100×83이다. **새 설명 예제 · body 조각**에서 별도 CSS가 없을 때 너비·높이를 예상한다.

```html
<img src="assets/lesson-character.png" alt="학습 예제 캐릭터" width="200">
<img src="assets/lesson-character.png" alt="학습 예제 캐릭터" width="200" height="300">
```

파일은 실습 폴더에, 이미지는 그 안의 assets 폴더에 있다고 가정한다.

<details>
<summary>힌트와 풀이</summary>

**힌트:** 속성 이름과 현재 값을 구별하고, 이 코드가 전체 문서인지 조각인지 먼저 확인한다.

첫 이미지는 원래 비율을 따르면 200×166이다. 너비가 두 배이므로 높이도 두 배다. 둘째는 두 크기를 모두 지정해 200×300으로 표시되며 원래 비율과 달라 늘어나 보일 수 있다. CSS 등 다른 크기 조건이 개입하면 결과를 다시 살펴야 한다.

</details>

## 문제 2. 이유를 설명하기

이미지가 보이지 않을 때 width를 바꾸면 고쳐질까? src·alt·title이 각각 무엇을 담당하는지와 함께 답한다. alt를 파일명으로만 적는 것이 설명 목적에 맞는지도 생각한다.

<details>
<summary>풀이</summary>

경로가 잘못된 것은 크기를 바꾸어 해결되지 않는다. src는 자원 위치, alt는 그림의 내용·역할을 대신 설명하는 글, title은 보충 설명이다. 이미지가 없어도 이해해야 할 내용을 alt에 적는다. 단지 파일명으로만 적으면 그 역할을 전달하지 못할 수 있다. 실제 깨짐은 파일 존재·상대 경로·로딩 상태부터 확인한다.

</details>

## 문제 3. 고치고 한 가지 바꾸기

다음 video 조각을 보고 ‘조작 막대를 보이고 반복은 하지 않기’로 고친다. 주소는 실제로 존재하는 동영상이라고 가정하며, 이 문제는 재생 성공 자체를 보장하지 않는다.

```html
<video src="lesson.mp4" controls="false" loop="false"></video>
```

고친 이유와 브라우저별 화면 차이를 구분해 설명한다.

<details>
<summary>예시 정답과 변경 실험</summary>

```html
<video src="lesson.mp4" controls></video>
```

controls·loop는 Boolean 속성이다. false라는 글자를 넣어 끄는 것이 아니라 속성 유무가 핵심이므로 loop를 제거한다. controls="false"도 속성이 존재하는 상태였으므로 조작 막대를 끄는 뜻이 아니었다. 실제 조작 UI·지원 형식·네트워크 로딩 여부는 브라우저와 자원 조건에 따라 확인한다.

</details>
