# 06 HTML 이미지와 미디어 — 연습문제

[해당 본문](../../06_HTML_이미지와_미디어.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. [본문의 `src`와 `alt` 설명](../../06_HTML_이미지와_미디어.md)을 읽은 뒤, 실제 파일이 있는 경우와 없는 경우를 나누어 예상한다.

## 문제

`images/notice.png`의 공지 이미지와 간단한 대체 텍스트를 넣고, 파일이 없을 때를 예상하자.

**확인 기준:** `src`와 `alt`가 각각 무엇을 나타내는지 말하고, 파일을 찾을 수 없을 때 경로부터 확인한다. 대체 텍스트의 화면 표시 방식은 브라우저에 따라 다를 수 있다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`<img src="images/notice.png" alt="복습 일정 안내">`처럼 경로와 내용을 나눠 적는다. `alt`에 파일명만 반복하지 않는다. 여기서 `images/notice.png`는 **현재 HTML 파일이 있는 폴더 아래**의 `images`를 뜻한다. 그림이 안 나오면 이 위치에 실제 파일이 있는지 먼저 확인한다. `alt`는 잘못된 경로를 고쳐 주는 속성은 아니다.

</details>

## 응용 — 같은 그림, 다른 위치

HTML 파일이 `pages/notice.html`, 그림이 그 형제 폴더인 `images/notice.png`에 있으면 경로는 `../images/notice.png`가 된다. 이는 [링크와 경로의 상대 경로 계산](../../03_HTML_링크와_경로.md#relative)을 이미지에 다시 적용한 것이다. 강사님·내 원본의 이미지 경로도 파일 위치와 함께 읽어야 한다.
