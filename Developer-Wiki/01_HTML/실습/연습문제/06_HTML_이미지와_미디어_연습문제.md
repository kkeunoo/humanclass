# 06 HTML 이미지와 미디어 — 연습문제

[해당 본문](../../06_HTML_이미지와_미디어.md) · [장별 문제 목차](README.md)

**새로 구성한 문제**다. 먼저 강사님·내 코드의 실제 결과를 읽고 아래 조건을 직접 구현하거나 계산하자.

## 문제

`images/notice.png`의 공지 이미지와 간단한 대체 텍스트를 넣고, 파일이 없을 때를 예상하자.

**확인 기준:** 이미지가 없으면 대체 텍스트와 경로 문제를 확인할 수 있다.

<details>
<summary>해설 — 먼저 풀고 펼치기</summary>

`<img src="images/notice.png" alt="복습 일정 안내">`처럼 경로와 내용을 나눠 적는다. `alt`에 파일명만 반복하지 않는다.

</details>

원본의 입력·구조·결과와 이 연습문제에서 바꾼 조건을 한 문장으로 비교해 보자.
