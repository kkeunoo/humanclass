HTML은 문서의 내용과 구조를 표시하는 언어다. **요소**, 그 요소를 표시하는 **태그**, 추가 정보를 주는 **속성**을 구별하고, `head`의 문서 정보와 `body`의 본문을 나눠 작성한다.

| 기준일 | 2026-10-28의 실제 파일과 제공된 원본 대조 |

| 필요한 것 | 텍스트 편집기와 웹 브라우저; 추가 패키지·서버 불필요 |

## 2. 개념부터 이해하기

### 2.1 태그와 요소, 속성을 나눠 읽기

`<h1 title="설명">나의 학습 기록</h1>`은 제목을 나타내는 요소 하나다. 앞의 `<h1 ...>`은 시작 태그, 뒤의 `</h1>`은 종료 태그다. 그 사이의 글자가 내용이고, 시작 태그 안의 `title="설명"`이 속성이다.

| 조각 | 이름 | 뜻 |
| --- | --- | --- |
| `h1` | 요소의 이름 | 가장 높은 수준의 제목 |
| `<h1 ...>` | 시작 태그 | 제목의 시작을 표시 |
| `title` | 속성명 | 이 요소의 보충 설명을 지정 |
| `"설명"` | 속성값 | 보충 설명에 사용할 글자 |
| `나의 학습 기록` | 내용 | 페이지 안에서 읽을 제목 |
| `</h1>` | 종료 태그 | 제목 요소의 끝 |

태그는 글자를 장식하는 괄호만이 아니다. 그 안의 내용이 문서에서 맡는 역할을 표시한다. 브라우저는 기본 스타일로 제목을 크게 보일 수 있지만, 글자 크기의 세밀한 조절은 뒤의 CSS에서 다룬다.

> 📚 **출처 · 본문 설명 확인:** 요소·태그·속성과 문서 골격은 [MDN — Basic HTML syntax](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax)로 확인했다. 이 장의 기능은 수업 코드에 있는 것을 기준으로 설명한다.

### 2.2 문서 정보와 화면 내용이 있는 자리

```text
HTML 문서
└── html: 문서의 루트
    ├── head: 문서 정보
    │   ├── meta: 인코딩·화면 설정
    │   └── title: 탭 등에 사용하는 문서 제목
    └── body: 페이지 안에 보여 줄 본문
        └── h1: 본문의 제목
```

이 그림은 포함 관계다. `head`가 모니터의 위쪽 영역이고 `body`가 아래쪽 영역이라는 화면 배치 그림이 아니다. `head`의 정보는 브라우저가 문서를 해석할 때 사용하고, `body`는 실제로 페이지 안에서 읽을 내용이다.

| 문장·요소 | 하는 일 | 혼동하지 말 것 |
| --- | --- | --- |
| `<!DOCTYPE html>` | 현대 HTML 문서 선언 | 본문에 출력할 제목이 아님 |
| `<html lang="ko">` | 문서의 루트와 주 언어 표시 | 한국어로 번역하는 명령이 아님 |
| `<meta charset="UTF-8">` | 문자를 읽을 인코딩 선언 | 파일도 그 인코딩으로 저장해야 함 |
| `viewport` 메타 정보 | 모바일 뷰포트의 기본 설정 | 모든 화면에서 자동으로 레이아웃을 완성하지 않음 |
| `<title>...</title>` | 문서 제목 | 페이지 본문의 큰 제목과 구별 |
| `<body>...</body>` | 페이지 본문 | 문서 정보를 아무 곳에나 넣는 영역이 아님 |

### 2.3 이름이 같은 `title` 두 가지

`<title>HTML 공부</title>`은 `head`에 놓는 **요소**이고, `<h1 title="첫 제목">...</h1>`의 `title`은 제목 요소에 붙인 **속성**이다. 같은 철자라도 위치와 역할이 다르다.

탭의 글자를 바꾸려면 `title` 요소 안을, 특정 요소의 보충 설명을 바꾸려면 그 요소의 `title` 속성을 수정한다. 속성의 보충 설명은 마우스를 올릴 때 나타날 수 있으나 입력 방식과 브라우저에 따라 표시가 다르므로 중요한 안내를 거기에만 넣지 않는다.

> 📚 **출처 · 본문 설명 확인:** 문서 제목의 위치와 의미는 [HTML 표준 — title 요소](https://html.spec.whatwg.org/multipage/semantics.html#the-title-element)로 확인했다. 수업 주석과 브라우저의 오류 복구 결과를 작성 규칙으로 혼동하지 않는다.

## 3. 작은 예제와 결과

**설명용 새 예제 · 전체 문서.** 아래는 [01_문서구조_복습.html](실습/01_문서구조_복습.html)의 전체 내용이다. 이미지나 외부 사이트 없이도 열 수 있다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML 첫 실습</title>
</head>
<body>
    <h1 title="첫 번째 제목">나의 학습 기록</h1>
    HTML 문서의 정보와 본문을 나누어 작성했다.
</body>
</html>
```

**기본 브라우저 표시 기준 예상:** 탭 제목은 `HTML 첫 실습`, 페이지 안의 제목은 `나의 학습 기록`이다. 그 아래에 본문 글자가 보인다. 글꼴·기본 크기·여백은 브라우저와 설정에 따라 달라질 수 있으므로 픽셀 수를 고정 정답으로 외우지 않는다.

| 위치 | 바꿔 볼 값 | 예상되는 변화 |
| --- | --- | --- |
| `head`의 `title` 내용 | `복습 노트` | 탭 제목 변경 |
| `h1`의 내용 | `오늘 배운 HTML` | 페이지 본문 제목 변경 |
| `h1`의 `title` 속성값 | `제목의 보충 설명` | 요소의 보충 설명 변경; 제목 글자 자체는 그대로 |

한 번에 하나씩 바꾸고 **저장 후 새로고침**한다. 세 곳을 한 번에 바꾸면 어떤 설정이 어느 결과를 만든 것인지 확인하기 어렵다.

## 4. 내 코드 따라 읽기

### 4.1 같은 글자에 제목 역할을 붙이기

**내 코드 · 원본 발췌** — `workspace_html/01_hello.html` 1–2행.

```html
hello world
<h1>hello world</h1>
```

첫 줄은 일반 텍스트이고 둘째 줄은 제목 요소다. 기본 스타일에서 `h1`이 더 크고 굵게 보일 수 있지만, 코드가 표현한 차이는 **제목 역할이 있는가**다. 강사님 대응 두 줄도 같아 중복 인용하지 않는다.

문서 선언·루트 구조가 없는 두 줄도 브라우저가 표시할 수 있다. 이것은 작은 태그 실험으로 볼 수 있으며, 완성 문서의 골격을 생략해도 된다는 권장 양식으로 받아들이지는 않는다.

### 4.2 내 제목 속성

**내 코드 · 원본 발췌** — `workspace_html/01_hello.html` 13행.

```html
<h1 title="글씨">타이틀</h1>
```

페이지 안의 제목은 `타이틀`이고 속성값은 `글씨`다. `title="글씨"`가 탭 제목을 `글씨`로 만든 것은 아니다. 요소와 속성을 구별하는지 이 한 줄로 확인할 수 있다.

### 4.3 내 문서의 head

**내 코드 · 원본 발췌** — `workspace_html/02_tag.html` 6–9행.

```html
    <head>
        <!-- 속성값이 아닌 title의 경우 body에 넣어도 맨 마지막것으로 끌어오긴 하나 맞는 구역에 넣는것이 좋음 -->
        <title>정근욱</title>
    </head>
```

여기서는 문서 제목을 `head`에 작성한 실제 구조가 적절하다. 다만 주석의 ‘body에 넣어도 맨 마지막 것으로 끌어온다’는 말은 일반 작성 규칙이 아니다. 잘못 놓인 요소에 대한 복구와 올바른 작성 위치는 구별한다.

## 5. 다른 파일과 연결하기

이 장의 원본과 새 HTML 예제는 Python처럼 `def` 함수를 import하지 않는다. **파일 저장 → 브라우저가 문서 읽기 → 정보와 본문 해석 → 화면 표시**의 연결을 확인하는 단계다.

| 파일 | 연결 관계 |
| --- | --- |
| `01_hello.html` | 태그의 작은 표시 실험 |
| `02_tag.html` | `head`·`body`에 여러 태그를 넣는 수업 |
| 새 `01_문서구조_복습.html` | 둘의 배운 구조를 작은 전체 문서로 재구성 |

다른 HTML 파일을 자동으로 합치거나 실행 순서대로 import하는 관계가 아니다. 문서 사이로 이동시키는 **링크**와 이미지 파일을 읽는 **경로**는 다음 장에서 연결한다. 한 파일의 태그 구조를 먼저 이해하면 경로 문제가 문서 구조 문제와 섞이지 않는다.

## 6. 내 코드 돌아보기

내 코드는 같은 텍스트에 태그를 붙여 결과 차이를 확인하고, 속성명과 속성값을 주석으로 기록했다. 문법 용어를 실제 예제로 확인한 점이 좋다. 다만 브라우저가 잘못된 구조도 보여 주는 특성 때문에 **표시 성공을 문법의 적절함으로 단정**한 메모는 보완해야 한다.

| 원본의 상황 | 평가 종류 | 보완할 설명 |
| --- | --- | --- |
| 두 줄만 적은 첫 파일 | 작은 수업 실험 | 완성 문서 골격과 구별 |
| `head` 안에 title 작성 | 적절한 구조 | 탭 제목과 본문 제목 구분 |
| title을 body에 넣어도 된다는 주석 해석 | 설명 교정 | 작성 위치는 head를 따름 |
| 인코딩 선언이 있으면 무조건 한글 정상 | 조건 누락 | 실제 파일 저장 인코딩도 맞아야 함 |

**개선 예시 · 원본에 미적용:** 3절의 전체 문서는 원본의 배운 요소를 올바른 위치에 다시 배치한 구성이다. 별도의 새로운 화면 기능을 추가하는 것이 아니라 문서 정보와 본문을 분명히 한다.

## 7. 강사님 코드에서 배울 점

이 장의 `hello world`와 제목 속성은 강사님 코드와 같아 별도 인용이 필요 없다. `02_tag.html`의 문서 제목 글자는 강사님과 내가 다르지만 **내용 차이와 구조 차이**는 구별한다. 이름이 다른 것이 개선점은 아니다.

목록 원본에서는 `title` 안팎에 주석을 둔 차이가 있다. 그 차이는 [목록 장의 필요한 비교](04_HTML_목록태그.md)에서 실제 구간을 보며 다룬다. 지금은 **문서 제목에는 필요한 텍스트를, 일반 주석은 그 밖에** 적는 원칙만 이해하면 된다.

## 8. 결과와 확인 방법

| 확인할 곳 | 정상적으로 기대하는 것 | 어긋날 때 먼저 볼 것 |
| --- | --- | --- |
| 탭 | title 요소의 글자 | head 안의 title, 저장 여부, 다른 파일을 연 것은 아닌지 |
| 페이지 본문 | h1과 본문 글자 | body 안의 내용 |
| 한글 | 원래 적은 한국어 | UTF-8 저장과 charset 선언 |
| 수정 뒤 결과 | 새 내용 표시 | 저장·새로고침·브라우저의 파일 경로 |

파일을 `예제.html.txt`로 저장하면 HTML 파일로 열리지 않을 수 있다. 편집기의 파일명과 실제 확장자를 함께 확인한다. 특정 브라우저의 기본 글자 크기와 정확한 화면 배치는 고정 결과로 주장하지 않는다.

새 예제의 문서 구조·문자 정보·제목 내용을 정적으로 검사한다. 이 책형 개편에서 모든 브라우저·모바일 환경을 실행해 같은 화면을 재현한 기록은 아니다. 화면 예상과 구조 검사 결과를 구별한다.

## 9. 추가로 알면 좋은 것

> 💡 **TIP · 수업 범위 밖:** 브라우저는 잘못된 HTML도 화면에 표시하려고 구조를 복구할 수 있다. 복구 규칙 자체를 배우려면 HTML 파싱을 따로 공부할 수 있다. 지금은 ‘보이니까 올바르다’고 판단하지 않고 작성한 구조를 확인하는 습관을 먼저 익힌다.

> 💡 **TIP · 수업 범위 밖:** 접근성 도구가 문서 구조를 읽는 방법은 추가 학습이다. 기본 제목을 실제 제목 요소로 작성하는 선택은 이후 접근성 학습과도 연결된다. 자세한 도구 사용을 이 장의 필수 문제에 요구하지 않는다.

## 10. 복습과 다음 학습

### 결과 예상 → 이유 설명 → 작은 수정

1. `<title>공부</title>`과 `<h1 title="설명">첫날</h1>`에서 탭과 본문에 각각 어떤 글자가 보일까?
2. 왜 `title`이라는 글자가 같아도 같은 기능이라고 볼 수 없을까?
3. 탭은 `나의 Wiki`, 본문 제목은 `HTML 공부`가 되도록 3절 예제를 고쳐 본다.

<details>
<summary>풀이</summary>

탭 제목은 `공부`, 본문 제목은 `첫날`이다. 앞의 title은 문서의 요소이고 뒤의 title은 h1의 속성이다. 원하는 수정은 `head`의 title 내용과 `body`의 h1 내용을 각각 바꾸면 된다. `lang="ko"`는 이 글자들을 자동 번역하는 설정이 아니다.

</details>

### 빠른 확인표

| 찾을 것 | 확인할 코드 | 결과 위치 |
| --- | --- | --- |
| 탭 제목 | head의 title 요소 | 브라우저 탭 |
| 본문 제목 | body의 h1 | 페이지 안 |
| 보충 설명 | 요소의 title 속성 | 환경에 따른 툴팁 등 |
| 인코딩 | meta charset와 파일 저장 | 글자 해석 |
| 문서 언어 | html의 lang | 주 언어 정보 |
