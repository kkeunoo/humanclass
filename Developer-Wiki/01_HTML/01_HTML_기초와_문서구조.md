# 1. HTML이란?

HTML은 **HyperText Markup Language**의 약자입니다.

| 단어 | 의미 |
| --- | --- |
| HyperText | 다른 문서나 자원으로 연결할 수 있는 텍스트 |
| Markup | 태그로 콘텐츠의 의미와 구조를 표시하는 방식 |
| Language | 정해진 문법에 따라 작성하는 언어 |

HTML은 프로그래밍 언어처럼 계산이나 조건 처리를 주목적으로 하지 않습니다. 제목, 문단, 이미지, 링크, 목록처럼 웹 페이지를 구성하는 콘텐츠의 의미와 구조를 브라우저에 전달합니다.

```html
<h1>웹 개발 학습</h1>
<p>HTML은 웹 페이지의 구조를 만듭니다.</p>
```

브라우저는 태그를 그대로 출력하지 않고 각 요소의 의미에 맞게 화면을 구성합니다.

# 2. HTML, CSS, JavaScript의 역할

| 기술 | 주요 역할 | 예시 |
| --- | --- | --- |
| HTML | 내용과 구조 | 제목, 문단, 이미지, 버튼 |
| CSS | 디자인과 배치 | 색상, 크기, 간격, 반응형 |
| JavaScript | 동작과 상태 변화 | 클릭, 입력 검사, 데이터 처리 |

```text
HTML       → 무엇이 있는가?
CSS        → 어떻게 보이는가?
JavaScript → 어떻게 동작하는가?
```

HTML만 작성해도 페이지는 표시되지만, 디자인과 상호작용은 제한적입니다. 이후 CSS와 JavaScript가 HTML 구조를 기준으로 연결됩니다.

# 3. 일반 텍스트와 HTML 요소

원본 실습의 첫 부분은 다음과 같습니다.

```html
hello world
<h1>hello world</h1>
```

두 줄 모두 화면에 글자가 표시되지만 의미는 다릅니다.

| 코드 | 브라우저 해석 |
| --- | --- |
| `hello world` | 의미가 지정되지 않은 일반 텍스트 |
| `<h1>hello world</h1>` | 페이지의 가장 중요한 1단계 제목 |

HTML에서는 단순히 글자가 보이는 것뿐 아니라 **그 글자가 어떤 역할을 하는지**가 중요합니다.

```html
<h1>쇼핑몰</h1>
<p>신상품을 소개합니다.</p>
```

제목에는 제목 태그를, 문단에는 문단 태그를 사용해야 문서 구조가 분명해집니다.

# 4. 태그와 요소

## 4.1 기본 형태

```html
<태그명>내용</태그명>
```

```html
<h1>hello world</h1>
```

| 구분 | 코드 | 설명 |
| --- | --- | --- |
| 시작 태그 | `<h1>` | 요소의 시작 |
| 콘텐츠 | `hello world` | 화면에 표시할 내용 |
| 종료 태그 | `</h1>` | 요소의 끝 |
| 요소 | `<h1>hello world</h1>` | 시작 태그부터 종료 태그까지 전체 |

태그는 `<h1>`처럼 마크업에 사용하는 기호이고, 요소는 태그와 콘텐츠를 포함한 전체 단위입니다.

## 4.2 종료 태그가 없는 요소

일부 HTML 요소는 콘텐츠를 감싸지 않으므로 종료 태그를 작성하지 않습니다.

```html
<img src="cat.png" alt="의자에 앉아 있는 고양이">
```

대표적인 빈 요소는 다음과 같습니다.

| 요소 | 역할 |
| --- | --- |
| `<img>` | 이미지 삽입 |
| `<br>` | 줄바꿈 |
| `<hr>` | 주제 구분선 |
| `<input>` | 사용자 입력 필드 |
| `<meta>` | 문서 정보 제공 |
| `<link>` | 외부 자원 연결 |

HTML에서는 `<img />`처럼 슬래시를 붙여도 동작하지만, 일반적인 HTML 문서에서는 `<img>` 형식을 많이 사용합니다.

# 5. 속성과 속성값

원본 실습에는 다음 코드가 있습니다.

```html
<img
  title="고양이"
  src="https://www.fitpetmall.com/wp-content/uploads/2023/10/shutterstock_1844153299-1024x683-1.png"
>
```

속성은 요소에 추가 정보나 설정을 제공합니다.

```html
<태그명 속성명="속성값">내용</태그명>
```

| 구분 | 예시 | 역할 |
| --- | --- | --- |
| 태그명 | `img` | 이미지 요소 생성 |
| 속성명 | `src` | 이미지 경로 지정 |
| 속성값 | 이미지 URL | 실제 불러올 자원 위치 |
| 속성명 | `title` | 보조 설명 제공 |
| 속성값 | `고양이` | 마우스를 올렸을 때 표시될 수 있는 문구 |

속성이 여러 개이면 공백으로 구분합니다.

```html
<img src="cat.jpg" alt="창가에 앉아 있는 고양이" width="400">
```

## 5.1 속성 작성 기본 원칙

- 속성명은 시작 태그 안에 작성합니다.
- 속성명과 속성값은 `=`로 연결합니다.
- 속성값은 큰따옴표로 감싸는 방식을 권장합니다.
- 같은 속성을 한 요소에 중복 작성하지 않습니다.
- 요소의 목적에 맞는 속성을 사용합니다.

잘못된 예시는 다음과 같습니다.

```html
<!-- 속성 사이 공백 누락 -->
<img src="cat.jpg"alt="고양이">

<!-- 같은 속성 중복 -->
<img src="cat.jpg" src="dog.jpg" alt="동물 사진">
```

수정하면 다음과 같습니다.

```html
<img src="cat.jpg" alt="고양이">
```

# 6. `src`, `title`, `alt` 속성

## 6.1 `src`

`src`는 브라우저가 불러올 자원의 위치를 지정합니다.

```html
<img src="images/cat.jpg" alt="고양이">
```

경로가 잘못되거나 파일이 존재하지 않으면 이미지가 표시되지 않습니다.

외부 Site의 이미지 URL은 상대 Site가 파일을 변경·삭제하거나 외부 요청을 제한하면 갑자기 표시되지 않을 수 있습니다. 실제 Project에서는 사용 권한을 확인한 이미지를 Project 내부 또는 관리 가능한 Storage에 두는 방식을 우선 검토합니다.

## 6.2 `title`

`title` 속성은 요소에 대한 보조 정보를 제공합니다.

```html
<h1 title="페이지의 대표 제목">타이틀</h1>
```

일반적인 데스크톱 브라우저에서는 Pointer를 올렸을 때 툴팁처럼 보일 수 있습니다. 그러나 Touch 환경에는 동일한 Hover 동작이 없고, Keyboard와 Screen Reader에서 일관되게 전달된다고 보장할 수 없으므로 중요한 설명을 `title` 속성에만 의존하면 안 됩니다.

## 6.3 `alt`

이미지에는 목적에 맞는 `alt` 속성을 작성하는 것이 중요합니다.

```html
<img src="cat.jpg" alt="창가에서 밖을 바라보는 고양이">
```

| 상황 | 권장 `alt` |
| --- | --- |
| 정보를 전달하는 이미지 | 이미지의 의미를 간결하게 설명 |
| 링크나 버튼 역할의 이미지 | 수행되는 동작이나 목적 설명 |
| 순수 장식 이미지 | 빈 값 `alt=""` 사용 |
| 이미지 안에 글자가 있는 경우 | 필요한 텍스트 정보를 포함 |

`title`은 선택적인 보조 정보이고, `alt`는 이미지 대체 텍스트입니다. 두 속성은 역할이 다릅니다.

```html
<img
  src="cat.jpg"
  alt="의자에 앉아 있는 고양이"
  title="고양이 사진"
>
```

# 7. HTML 주석

HTML 주석은 브라우저 화면에는 표시하지 않고 코드 안에 메모를 남길 때 사용합니다.

```html
<!-- 한 줄 주석 -->
```

여러 줄도 같은 문법을 사용합니다.

```html
<!--
  src는 속성명이다.
  따옴표 안의 값은 속성값이다.
-->
```

## 7.1 주석의 활용

- 코드의 목적 설명
- 구역 구분
- 임시 코드 비활성화
- 협업자를 위한 메모

```html
<!-- 메인 콘텐츠 시작 -->
<main>
  <h1>강의 목록</h1>
</main>
<!-- 메인 콘텐츠 끝 -->
```

## 7.2 주석 사용 시 주의점

주석도 사용자가 개발자 도구나 소스 보기를 통해 확인할 수 있습니다. 비밀번호, API 키, 개인정보처럼 노출되면 안 되는 내용은 주석에 작성하지 않습니다.

```html
<!-- 잘못된 예: 비밀 정보 저장 금지 -->
<!-- admin password: 1234 -->
```

오래된 코드와 불필요한 메모를 계속 남기면 문서가 복잡해지므로 작업이 끝난 뒤 정리합니다.

# 8. 기본 HTML 문서 구조

원본 첫 실습은 태그의 기본 개념을 확인하기 위한 짧은 코드입니다. 실제 HTML 파일은 다음과 같은 문서 구조로 작성하는 것이 기본입니다.

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML 첫 문서</title>
</head>
<body>
  <h1>hello world</h1>
  <p>HTML 학습을 시작합니다.</p>
</body>
</html>
```

## 8.1 구조 비교표

| 코드 | 역할 |
| --- | --- |
| `<!doctype html>` | HTML5 문서임을 선언 |
| `<html lang="ko">` | 문서 전체의 최상위 요소와 주 언어 지정 |
| `<head>` | 화면에 직접 표시되지 않는 문서 정보 |
| `<meta charset="UTF-8">` | 문자 인코딩 지정 |
| `<meta name="viewport" ...>` | 모바일 화면 너비와 배율 설정 |
| `<title>` | 브라우저 탭과 북마크 등에 표시되는 문서 제목 |
| `<body>` | 실제 페이지에 표시되는 콘텐츠 |

# 9. `title` 속성과 `<title>` 요소의 차이

이름은 같지만 역할과 작성 위치가 다릅니다.

| 구분 | `title` 속성 | `<title>` 요소 |
| --- | --- | --- |
| 작성 위치 | 개별 요소의 시작 태그 | `<head>` 내부 |
| 역할 | 해당 요소의 보조 정보 | 문서 전체의 제목 |
| 예시 | `<h1 title="설명">제목</h1>` | `<title>홈페이지</title>` |
| 화면 표시 | 상황에 따라 툴팁 | 브라우저 탭 등에 표시 |
| 필수 여부 | 선택 사항 | 모든 문서에 작성 권장 |

```html
<head>
  <title>고양이 사진관</title>
</head>
<body>
  <h1 title="사진관의 대표 제목">고양이 사진관</h1>
</body>
```

# 10. 들여쓰기와 코드 정리

브라우저는 많은 공백과 줄바꿈을 하나의 공백처럼 처리하지만, 개발자는 구조를 쉽게 파악할 수 있도록 들여쓰기를 사용합니다.

정리되지 않은 코드:

```html
<html><head><title>페이지</title></head><body><h1>제목</h1><p>내용</p></body></html>
```

정리한 코드:

```html
<html>
<head>
  <title>페이지</title>
</head>
<body>
  <h1>제목</h1>
  <p>내용</p>
</body>
</html>
```

권장 기준은 다음과 같습니다.

- 자식 요소는 부모 요소보다 한 단계 들여씁니다.
- 프로젝트 안에서 들여쓰기 크기를 통일합니다.
- 한 줄이 지나치게 길면 속성을 여러 줄로 나눕니다.
- 의미가 바뀌는 구역에만 빈 줄을 사용합니다.
- 필요 이상의 연속된 빈 줄은 제거합니다.

# 11. 내 코드와 강사님 코드 비교

## 11.1 강사님 코드

```html
hello world
<h1>hello world</h1>

<!--
  주석
  src를 속성명이라고 한다
  뒤의 값을 속성 값이라고 한다
-->
<img title="고양이" src="https://www.fitpetmall.com/wp-content/uploads/2023/10/shutterstock_1844153299-1024x683-1.png">

<h1 title="글씨">타이틀</h1>
```

## 11.2 내가 작성한 코드

```html
hello world
<h1>hello world</h1>

<!-- 0723_HTML_helloworld_restore -->

<!--
  src를 속성명이라고 한다
  뒤의 값을 속성 값이라고 한다
-->
<img title="고양이" src="https://www.fitpetmall.com/wp-content/uploads/2023/10/shutterstock_1844153299-1024x683-1.png">

<!-- title의 경우 마우스를 올렸을 때 해당 텍스트를 나타내게 함 -->
<h1 title="글씨">타이틀</h1>
```

## 11.3 차이점

| 비교 항목 | 강사님 코드 | 내 코드 | 평가 |
| --- | --- | --- | --- |
| 기본 출력 | 동일 | 동일 | 학습 결과 동일 |
| 속성 설명 | `src`의 명칭 설명 | 같은 설명 유지 | 핵심 개념 보존 |
| 복원 메모 | 없음 | 복원 이력 주석 추가 | 개인 작업 기록에는 유용하지만 최종 학습 문서에서는 선택적으로 유지 |
| `title` 설명 | 별도 설명 없음 | 마우스 오버 설명 추가 | 이해를 돕는 보완 설명 |
| 문서 구조 | 전체 문서 구조 없음 | 전체 문서 구조 없음 | 첫 실습용으로는 가능, 실제 페이지에서는 보완 필요 |
| 이미지 대체 텍스트 | `alt` 없음 | `alt` 없음 | 접근성 측면에서 개선 필요 |

## 11.4 잘한 점

- 강사님 코드의 핵심 실습 내용을 빠뜨리지 않았습니다.
- `title` 속성의 동작을 주석으로 추가해 복습할 때 의미를 파악하기 쉽습니다.
- 복원 이력을 남겨 파일 변경 목적을 추적할 수 있습니다.

## 11.5 개선할 점

1. 이미지에 `alt` 속성을 추가합니다.
2. 실제 문서로 사용할 때는 `doctype`, `html`, `head`, `body` 구조를 작성합니다.
3. `title` 속성은 중요한 정보를 전달하는 유일한 수단으로 사용하지 않습니다.
4. 복원 이력처럼 버전 관리로 확인할 수 있는 정보는 최종 코드에서 제거해도 됩니다.
5. 설명 주석은 정확한 문장으로 간결하게 작성합니다.

## 11.6 통합 개선 코드

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML 첫 실습</title>
</head>
<body>
  <p>hello world</p>
  <h1>hello world</h1>

  <!-- src는 이미지 경로, alt는 이미지 대체 텍스트를 지정한다. -->
  <img
    src="https://www.fitpetmall.com/wp-content/uploads/2023/10/shutterstock_1844153299-1024x683-1.png"
    alt="의자에 앉아 있는 고양이"
    title="고양이"
  >

  <h2 title="보조 설명">타이틀</h2>
</body>
</html>
```

첫 번째 일반 텍스트도 의미가 드러나도록 `<p>` 요소로 감쌌습니다. 같은 문서에 대표 제목을 여러 개 사용하지 않도록 두 번째 제목은 예제상 `<h2>`로 조정했습니다.

# 13. 자주 하는 실수

## 13.1 종료 태그 누락

```html
<!-- 잘못된 예 -->
<h1>제목
<p>내용</p>
```

```html
<!-- 수정 -->
<h1>제목</h1>
<p>내용</p>
```

브라우저가 일부 코드를 자동 보정하더라도 의도하지 않은 구조가 만들어질 수 있습니다.

## 13.2 태그 중첩 순서 오류

```html
<!-- 잘못된 예 -->
<p><strong>중요한 내용</p></strong>
```

```html
<!-- 수정 -->
<p><strong>중요한 내용</strong></p>
```

나중에 연 요소를 먼저 닫는 방식으로 생각하면 이해하기 쉽습니다.

## 13.3 속성 따옴표 누락

```html
<!-- 가능하지만 권장하지 않음 -->
<img src=cat.jpg alt=고양이>
```

```html
<!-- 권장 -->
<img src="cat.jpg" alt="고양이">
```

공백이나 특수문자가 포함되면 오류가 발생하기 쉬우므로 따옴표를 일관되게 사용합니다.

## 13.4 `title`만으로 설명 제공

```html
<!-- 중요한 설명을 title에만 제공하지 않는다. -->
<button title="작성한 내용을 서버에 저장합니다.">저장</button>
```

버튼 텍스트와 주변 설명만으로도 목적을 알 수 있도록 설계해야 합니다.

## 13.5 로컬 파일 경로를 절대 경로로 작성

```html
<!-- 다른 컴퓨터에서는 동작하지 않을 수 있음 -->
<img src="C:\Users\user\Desktop\cat.jpg" alt="고양이">
```

프로젝트 내부의 상대 경로를 사용합니다.

```html
<img src="images/cat.jpg" alt="고양이">
```

## 13.6 주석에 비밀 정보 저장

HTML 주석은 완전히 숨겨진 정보가 아닙니다. 민감한 데이터는 작성하지 않습니다.
