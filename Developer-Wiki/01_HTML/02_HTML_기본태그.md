# 02. 기본 태그 — 보이는 모양과 의미 구분하기

[HTML 읽기 안내](README.md) · [이전: 문서 구조](01_HTML_기초와_문서구조.md) · [다음: 링크와 경로](03_HTML_링크와_경로.md)

같은 글자라도 제목·문단·강조·삭제 중 무엇을 뜻하는지에 따라 태그가 달라진다. 이번 장은 양쪽 `workspace_html/02_tag.html`에 실제로 등장한 태그와 문자 표기를 다룬다.

## 1. 제목은 `h1`부터 `h6`까지

### 강사님 코드 — 원본 발췌

강사님 `workspace_html/02_tag.html` 11~17행

```html
        <h1>h1</h1>
        <h2>h2</h2>
        <h3>h3</h3>
        <h4>h4</h4>
        <h5>h5</h5>
        <h6>h6</h6>
        <h7>h7</h7>
```

`h1`~`h6`은 제목의 수준을 나타낸다. `h7`은 표준 제목 요소가 아니다. 브라우저가 그 안의 글자를 표시해도 일곱 번째 제목 수준이 만들어진 것은 아니다.

### 내 코드 — 원본 발췌

내 코드 `workspace_html/02_tag.html` 15~21행

```html
        <h1>h1</h1>
        <h2>h2</h2>
        <h3>h3</h3>
        <h4>h4</h4>
        <h5>h5</h5>
        <h6>h6</h6>
        <h7>h7</h7><br>
```

나는 `h7` 뒤에 `br`도 썼다. 그 뒤 줄바꿈 여부는 달라질 수 있지만, `h7`이 표준 제목이 아니라는 점은 같다. 양쪽 모두 실험용 부분과 실제 작성에 사용할 구조를 구분해야 한다.

### 이렇게 정리하면 좋다 — 설명용 수정

```html
<h1>HTML 학습 기록</h1>
<h2>기본 태그</h2>
<h3>문단과 줄바꿈</h3>
```

제목 크기만 보고 태그를 선택하지 않는다. 큰 주제 아래 작은 주제가 놓이는 구조를 표시한다. 크기·색상을 바꾸는 방법은 CSS에서 다룬다. 화면 크기는 CSS나 브라우저 기본 스타일에 따라 달라질 수 있다.

원본의 `<choi>`와 `<jeong>`도 표준 HTML 태그가 아니다. 글자가 보이는 실험과 표준 요소 사용을 구분한다. 사용자 정의 요소를 만드는 방법은 이번 수업 본문에 추가하지 않는다.

<a id="meaning"></a>

## 2. 강조·표시·삭제는 서로 다른 뜻이다

### 강사님 코드 — 원본 발췌

강사님 `workspace_html/02_tag.html` 21~23행

```html
        <strong>굵어서 강조하는 글씨</strong>
        <br>
        <em>기울여서 강조하는 글씨</em>
```

`strong`과 `em`을 각각 중요성과 강세의 관점에서 읽는다. 기본 스타일의 굵기·기울임은 그 의미를 표현하는 방식 중 하나다.

### 내 코드 — 원본 발췌

내 코드 `workspace_html/02_tag.html` 26~29행

```html
        <strong>굵어서 강조하는 글씨</strong><br>

        <!-- i tag와 동일하게 사용할 수 있지만, i는 시맨틱태그가 아니기에 em을 사용함 -->
        <em>기울여서 강조하는 글씨</em><br>
```

화면에서 비슷하게 보인다는 이유로 `strong`과 `b`, `em`과 `i`를 언제나 같은 의미로 바꾸지는 않는다. 내 주석의 “b·i는 의미가 없으므로 무조건 대체”라는 식의 해석도 피한다. 이번 수업에서는 실제로 작성한 `strong`과 `em`의 의미를 먼저 익힌다.

| 수업 태그 | 의미 | 기본 스타일에서 흔히 보이는 모습 |
| --- | --- | --- |
| `strong` | 중요성·심각성·긴급성 | 굵은 글씨 |
| `em` | 문장의 강세 | 기울어진 글씨 |
| `mark` | 현재 문맥에서 눈여겨볼 부분 | 배경 강조 |
| `del` | 삭제된 내용 | 취소선 |
| `hr` | 주제의 전환·구분 | 가로선 |

원본에서 강사님은 `<del>del</del>`, 나는 `<del>mark</del>`로 적었다. 안의 글자가 `mark`여도 요소는 `del`이므로 삭제 의미를 갖는다. 예제의 글자를 태그 이름과 맞추면 복습할 때 혼동을 줄일 수 있다.

`mark`의 배경색이 반드시 노란색으로 고정되는 것은 아니다. `del`도 취소선 장식이 필요할 때 아무 곳에 쓰기보다 삭제 의미가 있는지 먼저 생각한다.

<a id="space"></a>

## 3. 문단과 줄바꿈은 다르다

양쪽 원본은 `p` 안의 긴 문장과 `br`을 넣은 문장을 비교한다. 긴 테스트 문장을 그대로 반복하기보다 다음 **설명용 재구성**으로 확인한다.

```html
<p>첫 번째 문단입니다.</p>
<p>두 번째 문단의 첫 줄<br>두 번째 문단의 다음 줄</p>
<hr>
<p>다른 주제입니다.</p>
```

| 요소 | 하는 일 | 사용 판단 |
| --- | --- | --- |
| `p` | 하나의 문단 표시 | 문단이 달라졌는가? |
| `br` | 같은 흐름 안에서 줄바꿈 | 같은 문단에서 줄을 바꿔야 하는가? |
| `hr` | 주제 구분 | 내용의 전환을 나타내는가? |

새 문단을 만들기 위해 `br`을 여러 번 반복하는 방식은 피한다. 원본의 많은 `br`은 화면 이동 실험에도 사용되는데, 완성 문서의 여백 설계와 구분한다.

### 편집기의 Enter가 그대로 보이지 않는 이유

일반적인 기본 표시에서는 연속된 공백과 소스 줄바꿈이 그대로 여러 칸·여러 줄로 표시되지 않는다. 다음 **설명용 예제**의 문장은 보통 `하나 둘 셋`처럼 보인다.

```html
<p>하나     둘
셋</p>
```

이는 기본 공백 처리의 설명이다. CSS 설정이나 `pre` 등 다른 문맥까지 “HTML은 항상 공백을 하나로 만든다”라고 넓히지 않는다.

<a id="pre"></a>

## 4. `pre`와 문자 참조

### 강사님 코드 — 원본 발췌

강사님 `workspace_html/02_tag.html` 41~45행

```html
        <pre>1
            2<br>
            3
            4
        </pre>
```

`pre`는 공백과 줄바꿈을 보존하는 텍스트를 나타낸다. 코드에서 들여쓴 공백도 표시될 수 있다.

### 내 코드 — 원본 발췌

내 코드 `workspace_html/02_tag.html` 57~61행

```html
        <Pre>1
            2<br>
            3
            4
        </Pre><br>
```

내 원본의 `<Pre>`는 `text/html` 문서에서 소문자 `<pre>`와 같은 요소로 해석된다. 표기 일관성을 위해 소문자를 쓰는 것이 읽기 편하다. 두 원본 모두 내부에 `br`이 있으므로, `pre`가 안의 모든 내용을 “태그도 무시한 글자 그대로” 출력한다고 이해하면 안 된다.

### 화면에 `<br>`라는 글자를 적으려면?

설명용 재구성 — 양쪽 원본에 등장한 문자 참조다.

```html
<p>&lt;br&gt; &copy; &amp;</p>
<p>1&nbsp;&nbsp;&nbsp;2</p>
```

첫 문단은 `<br> © &`라는 글자를 보여 준다. 첫 번째 `<br>` 표시는 줄바꿈 태그로 실행되지 않는다. 두 번째는 `1`과 `2` 사이에 줄바꿈되지 않는 공백 세 개를 넣는다.

| 표기 | 나타내는 문자·성질 |
| --- | --- |
| `&lt;` / `&gt;` | `<` / `>` |
| `&amp;` | `&` |
| `&copy;` | `©` |
| `&nbsp;` | 줄바꿈되지 않는 공백 |

`&nbsp;`로 페이지 전체의 정렬과 여백을 맞추는 것은 목적에 맞지 않는다. 여백 조절은 CSS 장으로 연결한다.

<a id="review"></a>

## 5. 원본 주석 교정과 복습

| 오해하기 쉬운 표현 | 고쳐 읽기 |
| --- | --- |
| `h1`은 큰 글씨, `h6`은 작은 글씨 | 제목 수준을 먼저 나타낸다. |
| `mark`는 노란색으로 고정 | 문맥상 강조를 표시하며 모양은 바뀔 수 있다. |
| `pre`는 코드를 전부 그대로 출력 | 공백·줄바꿈을 보존하지만 태그 해석까지 중단하지 않는다. |
| 화면에 보이면 표준 태그 | `h7` 같은 실험도 글자는 보일 수 있다. |

### 문제

1. `<p>&lt;h1&gt;</p>`는 큰 제목을 만들까, `<h1>` 글자를 보일까?
2. 문단 두 개를 만들 때 `p` 두 개와 `br` 두 개 중 무엇을 선택할까?
3. 강의 이름을 삭제했다는 뜻을 나타내려면 `mark`와 `del` 중 무엇을 선택할까?

<details>
<summary>정답과 이유</summary>

1. `<h1>` 글자를 보인다. 문자 참조로 표시한 텍스트다.
2. `p` 두 개를 쓴다. 줄바꿈과 문단 구조는 다르다.
3. `del`을 쓴다. 배경 강조와 삭제 의미를 구분한다.

</details>

**추가로 알면 좋은 것:** `abbr`·`time`·`address`·인용 태그·사용자 정의 요소는 이번 원본 비교의 필수 진도에 넣지 않는다.
