# HTML을 읽는 법 — 태그에서 화면까지

[HTML 목차](README.md) · [첫 장: 문서 구조](01_HTML_기초와_문서구조.md)

이 안내는 **수업 코드를 다시 읽는 순서**다. 새 HTML 기능을 선행해서 알아야 한다는 뜻은 아니다.

## 한 줄을 읽는 네 가지 질문

수업의 `<h1>hello world</h1>`을 예로 들면 다음 순서가 편하다.

1. **내용:** 화면에 읽을 글자는 `hello world`다.
2. **태그:** `h1`은 이 글이 제목임을 표시한다.
3. **속성:** 이 줄에는 별도 속성이 없다. 다른 예제의 `href`, `src`, `name`처럼 속성이 있으면 이름과 값을 나누어 읽는다.
4. **확인:** 브라우저에서 보이는 글자와 문서에서 맡는 역할을 함께 확인한다. 기본 글자 크기만 보고 태그의 뜻을 결정하지 않는다.

## 코드를 실행할 때

Markdown의 코드블록은 설명을 보여 준다. HTML 조각이라면 `body`에, 완전한 문서라면 `.html` 파일 전체에 저장해 브라우저로 연다. 파일을 바꾼 뒤 **저장 → 새로고침 → 예상과 비교**한다. 이미지나 링크가 있는 경우에는 HTML 파일의 현재 위치도 함께 확인한다.

## 강사님 코드와 내 코드 비교 순서

먼저 양쪽 코드에서 **같은 입력·구조·결과**를 찾고, 실제 차이가 있을 때만 그 차이가 결과에 미치는 영향을 적는다. 원본 발췌와 새로 만든 설명용 코드는 각 장에 표시되어 있다. 실제로 사용한 기능은 본문에서 익히고, 수업 밖 내용은 해당 장의 **추가로 알면 좋은 것**에서 읽는다.
