# HTML 읽는 법 — 공통 안내로 통합

[HTML 목차와 읽는 순서](README.md)에서 시작한다. 이전 동작 백과의 핵심 읽기법은 각 장에 통합했다.

1. 원본 파일과 코드가 놓이는 문맥을 확인한다.
2. 태그의 역할과 속성값을 읽는다.
3. 입력·클릭 전 상태를 적는다.
4. 어떤 화면·주소·제출값을 예상하는지 적는다.
5. 확인한 결과를 예상과 비교한다.

이전에 선수 지식처럼 나왔던 렌더링 엔진·접근성 트리·원본 밖 API는 기본 진도에서 분리했다. 심화 검토는 [추가편의 설계와 검수](추가로_알면_좋은_것/03_설계와_검수.md)에서 읽는다.
