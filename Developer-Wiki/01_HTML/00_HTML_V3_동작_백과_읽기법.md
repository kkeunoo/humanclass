# HTML을 공부하고 다시 찾는 법

[HTML 목차](README.md) · [첫 장](01_HTML_기초와_문서구조.md)

이 과목은 태그의 뜻과 내 수업 기록을 함께 읽는 학습 장이다. 개념과 작은 예제를 이해한 다음 내 원본을 따라간다. 강사님 코드는 판단에 도움이 되는 차이가 있을 때만 인용한다.

## 1. 처음 읽을 때 — 개념에서 내 코드로

본문은 같은 열 절로 읽는다. 배울 것 → 개념 → 작은 예제 → 내 코드 풀이 → 파일·요소 연결 → 평가 → 필요한 강사님 비교 → 결과·변경 실험 → 추가 학습·출처 → 복습 순서다. **뜻과 결과를 이해한 뒤 실제 코드를 판단**하는 흐름은 같다.

| 읽는 단계 | 답할 질문 |
| --- | --- |
| 개념 | 무엇이며 왜 필요한가? 비슷한 용어와 어떻게 다른가? |
| 예제 | 어느 파일의 어디에 넣는가? 무엇이 보이거나 제출되는가? |
| 원본 | 내가 작성한 어느 줄이 그 일을 하는가? |
| 평가 | 실제 오류인가, 수업용 단순화인가, 설계 선택인가? |
| 복습 | 한 가지를 바꾸면 결과가 어떻게 달라지는가? |

HTML의 연결 설명은 링크·이미지·ID·입력과 현재 문서의 관계를 추적한다. 함수 호출이 없는 장에 억지로 import 설명을 넣지는 않는다.

## 2. 표기를 구별하기

| 표기 | 읽는 방법 |
| --- | --- |
| 내 코드 — 원본 발췌 | 실제 작성 기록이다. 오류가 있다면 아래 풀이까지 읽는다. |
| 강사님 코드 — 필요한 비교 | 실제 차이가 주는 효과를 확인한다. 무조건 정답이라는 뜻은 아니다. |
| 새 설명 예제 | 이해를 돕기 위해 새로 만든 코드다. 원본 발췌가 아니다. |
| 개선안 | 원본의 목적에 맞춰 고친 제안이다. 원본 파일에는 적용하지 않았다. |
| 📚 출처 · 본문 설명 확인 | 배운 기능의 정확한 뜻을 공식 자료로 확인한 근거다. |
| 💡 TIP · 수업 범위 밖 | 아직 배우지 않은 선택 학습이다. 본문 아래에 둔다. |
| 코드 기준 예상 | 조건에 따라 계산한 결과다. 실제 실행 확인과 구분한다. |

배운 기능을 자세히 설명하는 것과 미학습 기능을 넣는 것은 다르다. name·선택 상태에서 제출값을 계산하는 설명은 본문이다. required·ARIA처럼 현재 수업 원본에 없는 기능은 TIP이다.

## 3. 실행할 때 — 파일·위치·조건부터

전체 문서는 HTML 파일 전체에, 조각은 표시된 head·body·form 등의 위치에 넣는다. 저장 → 새로고침 → 예상과 비교 순서로 확인한다. 경로는 **지금 연 문서 위치**에서 계산한다.

| 작업 | 전제 | 주의할 오해 |
| --- | --- | --- |
| 제목·표 보기 | 브라우저로 파일 열기 | 화면이 나오면 구조도 모두 정확하다 |
| 파일 이동 | 대상 파일·폴더 배치 유지 | 어디에 옮겨도 상대 경로는 같다 |
| 이미지 보기 | assets 파일 유지 | 크기를 바꾸면 잘못된 src도 고쳐진다 |
| GET·POST 관찰 | HTTP 환경·요청과 응답 확인 | 화면이 다시 보이면 저장됐다 |

구조 검사·화면 확인·요청 관찰은 서로 확인 범위가 다르다. 편집 검증 기록도 그 범위를 구분한다.

## 4. 다시 읽을 때 — 목차와 빠른 표

각 장의 내부 목차로 필요한 절에 이동한다. 끝의 빠른 표로 용어를 찾고, 애매하면 작은 예제와 원본 풀이로 돌아간다. 복습은 [장별 문제](실습/연습문제/README.md)에서 예상·설명·수정을 먼저 수행하고 [종합실습](10_HTML_종합실습.md)으로 연결한다. [실행 자료](실습/README.md)는 본문의 전체 파일과 같다.
