# 테이블 — 행·열·병합을 격자로 읽기

표는 여러 칸을 화면에 그리는 데서 끝나지 않는다. 어떤 행과 열의 관계를 보여 주는 자료인지, 어느 칸이 제목인지, 병합한 칸이 어디까지 차지하는지 이해해야 한다. 이 장은 내 표 실습의 주석과 실제 구조를 대조하며 **태그 수보다 격자 점유**를 먼저 보는 연습을 한다.

## 2. 개념부터 이해하기

### 2.1 표·행·셀의 포함 관계

| 요소 | 역할 | 읽는 단위 |
| --- | --- | --- |
| `table` | 표 전체 | 행들을 묶은 자료 |
| `tr` | 행 | 가로 방향으로 배열할 셀 묶음 |
| `td` | 데이터 셀 | 실제 값 하나가 들어갈 칸 |
| `th` | 제목 셀 | 행 또는 열의 의미를 알려 주는 칸 |

한 행에 `<th>과목</th><th>시간</th>`을 두면 제목 칸 두 개다. 다음 행의 HTML·2시간은 그 열에 대응하는 값이다. `th`는 굵은 글씨를 얻는 장식용 요소가 아니라 **주변 자료를 설명하는 제목 역할**이다.

```text
table
├── tr: th 과목 | th 시간
└── tr: td HTML | td 2시간
```

제목 셀은 꼭 첫 행의 열 제목만 되는 것이 아니다. 내 수업처럼 한 행의 첫 칸에 지역·이름을 두면 행 제목으로도 사용할 수 있다.

### 2.2 병합은 몇 칸을 차지하는가?

`rowspan="2"`는 두 **행**에 걸쳐 세로로, `colspan="2"`는 두 **열**에 걸쳐 가로로 차지한다. span을 간격의 픽셀 수로 읽지 않는다. 셀이 덮는 칸의 수다.

```text
2행 × 3열의 격자
┌───────┬───────────────┐
│       │      1-2      │  ← 두 열 차지
│  1-1  ├───────┬───────┤
│       │  2-2  │  2-3  │
└───────┴───────┴───────┘
  두 행 차지
```

두 번째 행은 첫 열을 윗행의 병합 셀이 이미 사용하고 있으므로 새 셀 두 개만 작성한다. **행마다 td 태그가 똑같이 세 개여야 한다**는 규칙으로 맞추면 오히려 의도한 격자를 넘어서게 된다.

<a id="groups"></a>

### 2.3 표 제목과 제목 행은 다르다

| 요소 | 뜻 | 예 |
| --- | --- | --- |
| `caption` | 표의 제목·설명 | 학습 시간표 |
| `thead` | 제목 행의 구역 | 과목·시간이라는 셀을 담은 행 |
| `tbody` | 데이터 행의 구역 | HTML·2시간의 행들 |

thead와 tbody 자체의 이름이 화면에 출력되는 것은 아니다. 하지만 **그 안의 셀 내용은 보인다.** ‘구역 태그는 따로 보이지 않는다’와 ‘안의 내용이 숨겨진다’를 구별한다.

> 📚 **출처 · 본문 설명 확인:** 표 요소·셀·구역·병합의 역할은 [HTML 표준 — Tables](https://html.spec.whatwg.org/multipage/tables.html)로 확인했다. 수업의 표를 읽는 규칙으로 적용하며 고급 제목 셀 연결은 9절 보충에 둔다.

## 3. 작은 예제와 결과

**설명용 새 예제 · 전체 문서.** [05_테이블_복습.html](실습/05_테이블_복습.html)은 기본 표와 병합 표를 함께 비교한다. border는 수업처럼 경계를 관찰하기 위해 남겼으며 최신 스타일 설계의 예제가 아니다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>표 복습</title>
</head>
<body>
    <h1>표의 구조</h1>
    <table border="1">
        <caption>학습 시간</caption>
        <thead>
            <tr><th>과목</th><th>시간</th></tr>
        </thead>
        <tbody>
            <tr><td>HTML</td><td>2시간</td></tr>
            <tr><td>CSS</td><td>3시간</td></tr>
        </tbody>
    </table>
    <h2>병합 격자</h2>
    <table border="1">
        <tr>
            <td rowspan="2">1-1</td>
            <td colspan="2">1-2</td>
        </tr>
        <tr>
            <td>2-2</td>
            <td>2-3</td>
        </tr>
    </table>
</body>
</html>
```

**기본 표시 기준 예상:** 첫 표에는 학습 시간이라는 제목과 제목 행 하나, 데이터 행 두 개가 있다. 둘째 표는 2절 그림처럼 2행×3열을 네 셀로 채운다. 같은 자료를 그리는 데 실제 셀 요소 수와 격자의 칸 수가 다른 이유는 병합 때문이다.

**한 가지 변경 실험:** 첫 표의 caption에 `hidden`을 붙인다. 다른 셀 내용은 그대로지만 표 제목이 화면에서 숨겨진다. 다음 실험 전에는 hidden을 제거한다. ‘기계만 읽게 설정한 것’이라고 해석하지 않는다.

## 4. 내 코드 따라 읽기

### 4.1 병합한 위치를 주석으로 남긴 원본

**내 코드 · 원본 발췌** — `workspace_html/05_table.html` 80–93행.

```html
        <table border="1">
            <tr>
                <!-- col(컬럼)span(간격) 컬럼의 간격 / row(행)span(간격) 열의 간격 -->
                <!-- 만들 땐 한 번에 합치지 말고 다 만들어둔 뒤에 영향을 받는 구역을 지우는게 편리함 -->
                <td rowspan="2">1-1</td>
                <td colspan="2">1-2</td>
                <!-- <td>1-3</td> -->
            </tr>
            <tr>
                <!-- <td>2-1</td> -->
                <td>2-2</td>
                <td>2-3</td>
            </tr>
        </table>
```

첫 행의 1-1이 다음 행 첫 열까지 차지한다. 1-2는 첫 행 두 번째·세 번째 열을 함께 사용한다. 그래서 원래 격자의 1-3·2-1 위치를 별도의 td로 만들지 않고 주석으로 남겼다.

| 격자 위치 | 사용하는 셀 | 새 td를 또 만드는가? |
| --- | --- | --- |
| 1행 1열·2행 1열 | rowspan 1-1 | 2행 1열에는 만들지 않음 |
| 1행 2열·1행 3열 | colspan 1-2 | 1행 3열에는 만들지 않음 |
| 2행 2열 | 2-2 | 작성 |
| 2행 3열 | 2-3 | 작성 |

내 ‘먼저 격자를 만든 뒤 영향을 받는 구역을 지운다’는 메모는 초보자가 점유를 계산하기에 도움이 된다. 다만 주석의 row·column 용어가 섞여 있어 **행은 row, 열은 column**으로 교정해서 읽는다.

### 4.2 표 제목을 숨기고 summary를 넣은 원본

**내 코드 · 원본 발췌** — 같은 파일 101–103행.

```html
            <caption hidden>테이블 내용에 대한 설명을 함</caption>
            <!-- 컬럼명을 나열하며 대략적으로 무엇이 있는지 요약을 해주는 것 -->
            <summary hidden>제목, 작성자 <!--(컬럼 나열)--></summary>
```

caption은 표의 제목·설명이다. hidden을 붙이면 일반적으로 화면에 보이지 않게 된다. 보조기기에게만 설명하는 전용 속성이라고 생각하면 안 된다.

여기의 summary 요소는 표의 요약 요소가 아니다. details와 함께 사용하는 별도의 요소이므로 표 안의 이 위치에서 제거해야 한다. **caption과 summary가 둘 다 이름상 ‘설명’처럼 들린다는 이유로 같은 기능이 되지 않는다.**

> 📚 **출처 · 본문 설명 확인:** hidden의 의미는 [MDN — hidden](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/hidden), summary의 용도는 [HTML 표준 — Interactive elements](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-summary-element)로 확인했다.

## 5. 다른 파일과 연결하기

이 장의 표는 문서 안의 값들을 행·열로 관계 짓는 단계다. 외부 함수를 import하거나 DB 데이터를 자동으로 불러오는 코드가 아니다. 표 안에 값을 적었다는 사실만으로 나중의 SQL 조회와 연결됐다고 설명하지 않는다.

| 앞뒤 단원 | 연결되는 생각 |
| --- | --- |
| 목록 | 관련 항목을 묶되 행·열의 자료 관계가 필요하면 표를 선택 |
| CSS | 테두리·너비·정렬을 별도 표시 규칙으로 다룸 |
| SQL·서버 템플릿 | 이후에는 조회한 행으로 표 내용을 만들 수 있음 |

현재는 손으로 작성한 셀과 격자부터 읽는다. 실제 데이터 파일이나 서버 함수가 연결된 예제는 해당 단원에서 정의와 호출까지 추적한다.

## 6. 내 코드 돌아보기

병합될 칸을 주석으로 표시한 점은 좋다. 화면에서 보이는 칸과 작성할 요소의 개수를 따로 생각하게 해 준다. 반면 표시되지 않는 구역 태그·숨김 속성·오류 복구를 섞어 설명한 메모는 교정해야 한다.

| 확인한 점 | 평가 종류 | 더 좋은 설명·수정 |
| --- | --- | --- |
| 병합할 칸 표시 | 좋은 점검 방식 | 행·열 용어만 정확히 구별 |
| 각 행의 td 수가 같아야 함 | 조건 누락 | 병합 점유를 포함한 격자 확인 |
| summary를 표 요약으로 사용 | 요소 용도 오류 | 잘못된 summary 제거, caption으로 표 제목 작성 |
| thead·tbody는 실제 표시 안 됨 | 설명 보완 | 구역 이름표는 없지만 셀은 표시됨 |
| `<th width="30"></td>` | 닫기 태그 오류 | th를 th로 닫기 |
| width·border로 크기·경계 관찰 | 수업 방식 | 현대 표시 설계와 구별해 CSS로 연결 |

**개선 예시 · 원본에 미적용:** 3절의 첫 표는 caption을 보이고 제목·본문 구역을 각각 둔 재구성이다. summary와 잘못 짝지은 닫기 태그를 사용하지 않는다. 배우지 않은 접근성 속성을 필수 조건으로 끼워 넣지 않아도 이 구조 오류는 고칠 수 있다.

## 7. 강사님 코드에서 배울 점

병합의 실행문은 양쪽이 같아 중복 인용하지 않는다. 강사님은 caption을 숨기지 않아 표 제목이 보이도록 했다는 점을 참고할 수 있다. 하지만 바로 뒤의 summary를 표에 넣은 것은 양쪽 모두 고칠 부분이다.

한쪽 코드의 좋은 부분과 잘못된 부분을 함께 판단한다. ‘강사님은 summary를 썼으니 표의 정석’이라고 외우지 않고 요소의 목적과 실제 표준 구조를 확인한다.

## 8. 결과와 확인 방법

### 병합은 순서대로 빈칸을 확인

1. 기준 격자의 행·열 수를 그린다.
2. rowspan·colspan 셀이 차지한 구역을 표시한다.
3. 각 행에서 이미 차지한 칸을 제외하고 새 셀을 놓는다.
4. 셀끼리 겹치거나 행·열이 의도보다 늘어났는지 본다.

| 현상 | 먼저 확인할 것 |
| --- | --- |
| 다음 행이 한 칸 밀린 듯 보임 | 윗행에서 내려온 rowspan 자리에 새 셀을 또 넣었는가? |
| 표 제목이 안 보임 | caption의 hidden 여부 |
| summary 글자가 엉뚱한 위치에 보임 | 표에 적절하지 않은 요소를 넣었는가? |
| th 내용은 보이는데 구조가 불안정 | 시작·종료 태그가 맞는가? |
| 셀 너비가 적은 값과 다름 | 같은 열·내용·표 배치 조건과 CSS |

기본 표와 병합 예제의 행·열·점유 관계는 정적으로 검사한다. 브라우저가 잘못된 표를 복구하는 정확한 화면 위치나 모든 크기를 새로 실행 확인한 기록은 아니다. 원본의 표시 속성 숫자가 셀마다 독립적인 최종 픽셀 값이 된다고 단정하지 않는다.

## 9. 추가로 알면 좋은 것

<a id="extra-02-4"></a>

> 💡 **TIP · 수업 범위 밖:** 더 복잡한 표에서는 제목 셀의 범위를 `scope`로 표시하거나 `headers`·`id`로 관계를 연결할 수 있다. `colgroup` 등의 열 묶음도 추가 학습이다. 현재 기본 병합 문제에 이 속성들을 반드시 요구하지 않는다. [출처: HTML 표준 — Tables](https://html.spec.whatwg.org/multipage/tables.html).

scope는 테두리나 가운데 정렬을 바꾸려는 속성이 아니다. 표 구조가 복잡해질 때 무엇을 설명하는 제목인지 더 분명히 하는 기능으로 공부한다. 테두리·여백·너비 같은 모양은 CSS와 구분한다.

## 10. 복습과 다음 학습

1. 세로 두 행을 차지하는 속성은 무엇인가?
2. 첫 행의 첫 셀이 rowspan 2라면 둘째 행 첫 위치에 새 td를 또 넣어야 할까?
3. `<th>작성자</td>`와 표 안의 summary를 어떻게 고칠까?

<details>
<summary>풀이</summary>

세로 병합은 `rowspan="2"`다. 그 셀이 다음 행 첫 열을 이미 쓰므로 새 셀로 중복하지 않는다. 제목 셀은 `</th>`로 닫고 표 안의 잘못된 summary는 제거한다. 표의 제목은 caption으로 작성한다.

</details>

| 빠른 확인 | 구조·속성 |
| --- | --- |
| 행 / 데이터 셀 / 제목 셀 | tr / td / th |
| 표 제목 | caption |
| 제목·본문 구역 | thead / tbody |
