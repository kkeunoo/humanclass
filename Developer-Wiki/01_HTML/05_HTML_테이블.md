# 05. 표 — 행·열·병합 영역을 먼저 그리기

## 1. `table` → `tr` → `th` 또는 `td`

| 요소 | 뜻 | 원본에서 확인할 위치 |
| --- | --- | --- |
| `table` | 표 전체 | 여러 행을 감쌈 |
| `tr` | 행 하나 | 가로 방향으로 셀을 나열 |
| `td` | 데이터 셀 | 내용·지역명·이름 등 |
| `th` | 제목 역할의 셀 | 열 제목 또는 행 제목 |

설명용 재구성:

```html
<table border="1">
    <tr>
        <th>이름</th>
        <th>지역</th>
    </tr>
    <tr>
        <td>학습자</td>
        <td>천안</td>
    </tr>
</table>
```

결과는 두 행·두 열이다. 첫 행은 제목, 두 번째 행은 데이터다. 원본에도 있는 `border="1"`은 수업에서 경계를 관찰한 오래된 표현 방식으로 남겼다. 현대 문서의 테두리·크기 지정은 CSS로 정리하는 것이 적절하다. 여기서는 CSS를 먼저 배워야 예제를 읽을 수 있게 만들지 않는다.

`th`는 굵은 글씨를 만드는 장식용 요소가 아니다. 기본 스타일에서 굵게·가운데 정렬되어 보일 수 있지만, 제목 셀이라는 역할을 먼저 선택한다. 원본의 `지역`, `이름` 표처럼 첫 열의 `th`가 행 제목이 될 수도 있다.

## 2. `rowspan`과 `colspan` 비교

### 강사님 코드 — 원본 발췌

강사님 `workspace_html/05_table.html` 81~92행

```html
    <table border="1">
        <tr>
            <td rowspan="2">1-1</td>
            <td colspan="2">1-2</td>
            <!-- <td>1-3</td> -->
        </tr>
        <tr>
            <!-- <td>2-1</td> -->
            <td>2-2</td>
            <td>2-3</td>
        </tr>
    </table>
```

`rowspan="2"`는 두 행에 걸쳐 세로로 차지하고, `colspan="2"`는 두 열에 걸쳐 가로로 차지한다. 합쳐진 위치에 별도 셀을 또 만들지 않도록 원본에서는 해당 `td`를 주석 처리했다.

### 내 코드 — 원본 발췌

내 코드 `workspace_html/05_table.html` 80~93행

```html
        <table border="1">
            <tr>
                <!-- col(컬럼)span(간격) 컬럼의 간격 / row(행)span(간격) 열의 간격 -->
                <!-- 만들 땐 한 번에 합치지 말고 다 만들어둔 뒤에 영향을 받는 구역을 지우는게 편리함 -->
                <td rowspan="2">1-1</td>
                <td colspan="2">1-2</td>
                <!-- <td>1-3</td> -->
            </tr>
            <tr>
                <!-- <td>2-1</td> -->
                <td>2-2</td>
                <td>2-3</td>
            </tr>
        </table>
```

병합 결과는 같다. 내 “다 만든 뒤 영향을 받는 구역을 지운다”라는 메모는 처음 격자를 그릴 때 도움이 된다. 다만 row는 **행**, column은 **열**이므로 주석 속 용어가 섞인 부분은 구별해서 읽는다.

```text
전체 격자: 2행 × 3열

┌───────┬───────────────┐
│       │      1-2      │  ← colspan="2"
│  1-1  ├───────┬───────┤
│       │  2-2  │  2-3  │
└───────┴───────┴───────┘
    ↑ rowspan="2"
```

두 번째 행에는 `td`가 두 개뿐이지만, 첫 행에서 내려온 병합 셀이 첫 열을 차지한다. **태그 개수만 같게 맞추는 것이 아니라 병합을 포함한 격자 점유를 확인한다.**

## 3. 표 설명과 제목·본문 구역

### 강사님 코드 — 원본 발췌

강사님 `workspace_html/05_table.html` 98~99행

```html
        <caption>테이블 내용에 대한 설명</caption>
        <summary>제목, 작성자 <!--(컬럼 나열)--></summary>
```

`caption`은 표의 제목·설명을 나타내는 적절한 요소다. 그러나 바로 뒤의 `summary`를 표의 설명 요소처럼 넣은 부분은 고쳐야 한다.

### 내 코드 — 원본 발췌

내 코드 `workspace_html/05_table.html` 101~103행

```html
            <caption hidden>테이블 내용에 대한 설명을 함</caption>
            <!-- 컬럼명을 나열하며 대략적으로 무엇이 있는지 요약을 해주는 것 -->
            <summary hidden>제목, 작성자 <!--(컬럼 나열)--></summary>
```

나는 두 요소에 `hidden`을 추가했다. 이것은 기계에게만 읽히게 하는 전용 설정이 아니다. 특히 `caption`을 숨기면 화면에서 표 제목도 보이지 않는다. “숨겨도 보조기기가 표 설명으로 알아서 읽는다”라고 가정하지 않는다.

### 이렇게 고치면 좋다 — 설명용 수정

```html
<table border="1">
    <caption>게시글 목록</caption>
    <thead>
        <tr>
            <th>제목</th>
            <th>작성자</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>HTML 복습</td>
            <td>학습자</td>
        </tr>
    </tbody>
</table>
```

| 구성 | 역할 | 화면에서 확인 |
| --- | --- | --- |
| `caption` | 표의 제목·설명 | `게시글 목록` |
| `thead` | 제목 행의 묶음 | 내부의 `제목`, `작성자` 셀 |
| `tbody` | 데이터 행의 묶음 | 내부의 `HTML 복습`, `학습자` 셀 |

`thead`와 `tbody`에 이름표가 따로 표시되지는 않지만, **그 안의 셀 내용은 보인다.** 내 원본 주석의 “실제로 표기 안 됨”을 내부 내용까지 안 보인다는 뜻으로 읽지 않는다.

`summary` 요소는 `details`와 함께 사용하는 요소이며 표의 요약 요소가 아니다. 양쪽 원본 모두 고칠 부분이다. `details`를 직접 구현하는 심화 예제와 표 접근성의 상세 속성 설계는 추가편으로 분리한다. [HTML 표준 — 표](https://html.spec.whatwg.org/dev/tables.html), [summary](https://html.spec.whatwg.org/dev/interactive-elements.html#the-summary-element)

## 4. 크기·열 수·닫기 태그 다시 보기

양쪽 원본은 같은 열에 `width="200"`인 셀과 `width="250"`인 셀을 두었다. 셀의 너비는 표의 열 배치에 함께 영향을 준다. 셀마다 지정한 숫자가 무조건 독립적인 최종 픽셀 크기가 되는 것은 아니다. 내용과 표 배치 조건을 함께 보며, 새 문서의 크기 조정은 CSS에서 다룬다.

내 마지막 게시판 표에는 `<th width="30"></td>`가 있다. 시작과 종료 요소가 다르므로 다음처럼 고친다.

```html
<th width="30"></th>
```

이것은 **원본의 닫기 오류만 고친 조각**이다. `width` 사용을 현대적인 권장 스타일로 제시하는 예제는 아니다. 브라우저가 화면을 복구해 보여 주어도 잘못된 닫기 태그를 그대로 유지하지 않는다.

| 원본에서 생길 수 있는 오해 | 교정 |
| --- | --- |
| 각 행의 `td` 개수는 무조건 같아야 한다 | 병합된 셀까지 포함한 격자를 확인한다. |
| 행의 셀 개수가 다르면 항상 실행 오류가 난다 | 브라우저가 표를 구성할 수 있어도 의도한 격자와 다를 수 있다. |
| `hidden`은 기계만 읽게 하는 속성이다 | 일반적으로 내용을 숨긴다. 전용 접근성 설명 수단으로 사용하지 않는다. |
| `summary`를 넣으면 표 요약이 된다 | 표에는 `caption`을 사용하고 잘못된 `summary`는 제거한다. |
| 제목 셀은 열 제목만 가능하다 | 행 제목도 `th`로 표시할 수 있다. |

## 5. 복습

1. 세로 두 행을 차지하는 셀에는 `rowspan`과 `colspan` 중 무엇을 쓸까?
2. 첫 행의 첫 셀이 `rowspan="2"`라면 다음 행 첫 위치에 새 셀을 또 넣어야 할까?
3. 표 제목 `수강생 목록`은 `caption`과 `summary` 중 어디에 넣을까?
4. `<th>작성자</td>`는 어떻게 고칠까?

<details>
<summary>정답과 이유</summary>

1. `rowspan="2"`를 쓴다.
2. 그 위치는 이미 차지했으므로 중복해서 새 셀을 넣지 않는다.
3. `<caption>수강생 목록</caption>`을 쓴다.
4. `<th>작성자</th>`로 닫는다.

</details>

**추가로 알면 좋은 것:** `colgroup`·`scope`·`headers`를 이용한 복잡한 표 설계는 원본에서 실제 사용한 범위를 넘어가는 별도 내용이다.
