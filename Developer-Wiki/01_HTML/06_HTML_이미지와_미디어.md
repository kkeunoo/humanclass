## 2. 개념부터 이해하기

### 2.1 img는 어느 파일을 무엇으로 보여 줄까?

`img`는 그림을 문서 안에 표시하는 요소다. `src`는 파일을 가져올 위치이고 `alt`는 그림을 대신할 텍스트다. img는 내용을 시작·종료 태그 사이에 넣는 요소가 아니므로 `</img>`를 붙여 그림을 감싸는 방식으로 쓰지 않는다.

| 속성 | 질문 | 예 |
| --- | --- | --- |
| `src` | 어떤 파일을 읽는가? | `assets/lesson-character.png` |
| `alt` | 그림이 전하던 정보를 글로 대신하면? | 웃고 있는 캐릭터 |
| `width` | 표시할 너비는? | `200` |
| `height` | 표시할 높이는? | `300` |

alt는 다른 이미지의 파일명이나 자동 생성 명령이 아니다. 파일이 읽히지 않을 때에도 원래 그림의 정보를 전달할 텍스트를 생각한다. 중요 정보를 ‘이미지가 없습니다’라고만 쓰면 무엇이 있었는지 알기 어렵다. title 속성의 보충 설명과도 역할이 다르다.

> 📚 **출처 · 본문 설명 확인:** 이미지 요소의 src·대체 텍스트·크기 속성은 [MDN — img](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img)로 확인했다. 이미지가 직접 생성되거나 파일 자체가 편집되는 기능으로 설명하지 않는다.

### 2.2 파일 크기와 표시 크기는 다르다

수업 PNG의 실제 픽셀 크기를 확인하면 **100×83**이다. 원본 비율은 100:83이다. 파일의 픽셀 데이터와 브라우저가 화면에 그릴 너비·높이는 구별해야 한다.

![수업에 사용된 웃고 있는 캐릭터 PNG](실습/assets/lesson-character.png)

위 그림은 수업 자료를 그대로 복사한 것이다. 출처 파일은 1절에 적었다. 이미지를 200×300으로 지정해도 그 PNG 자체를 200×300 파일로 변환한 것은 아니다.

| HTML 설정 | 다른 CSS가 없을 때 예상 표시 | 비율 |
| --- | --- | --- |
| width·height 미지정 | 원본의 100×83 CSS 픽셀 | 원래 비율 |
| `width="200"`만 지정 | 200×166 CSS 픽셀 | 비율 유지 |
| `width="200" height="300"` | 200×300 CSS 픽셀 | 원본과 달라 늘어나 보일 수 있음 |

너비만 두 배로 키우면 높이도 비율에 따라 두 배가 돼 166이다. 양쪽 길이를 다른 비율로 고정하면 브라우저는 그 지정된 상자에 표시한다. CSS가 덮어쓰는 경우는 이 조건에서 제외한다. 원본 이미지에 고유한 비율이 있는 이 사례의 계산이지, 모든 이미지 형식을 같은 조건으로 일반화하지 않는다.

### 2.3 동영상의 제어와 반복은 다르다

| 속성 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| `src` | 읽을 동영상 주소 지정 | 파일의 존재나 지원 형식 보장 |
| `controls` | 브라우저의 재생 제어 UI 표시 요청 | 곧바로 자동 재생 |
| `loop` | 끝난 뒤 반복하도록 설정 | 자동 재생을 켜는 것 |

controls와 loop는 **불리언 속성**이다. 이 문맥에서는 속성이 있으면 켜진 상태를 나타낸다. 따라서 `loop="false"`처럼 적어도 끈 상태가 아니다. 끄려면 loop 속성을 제거한다.

> 📚 **출처 · 본문 설명 확인:** 제어·반복 속성과 브라우저 미디어 동작은 [MDN — video](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)로 확인했다. 원본에는 autoplay가 없으며 loop를 자동 재생이라고 풀이하지 않는다.

## 3. 작은 예제와 결과

**설명용 새 예제 · 전체 문서.** [06_이미지_복습.html](실습/06_이미지_복습.html)과 assets의 PNG를 함께 둔다. 이미지 예제는 로컬 파일이고 동영상은 외부 주소다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>이미지와 영상 복습</title>
</head>
<body>
    <h1>같은 파일의 다른 표시 크기</h1>
    <h2>너비와 높이를 모두 지정</h2>
    <img src="assets/lesson-character.png"
         alt="웃고 있는 캐릭터"
         width="200"
         height="300">
    <h2>너비만 지정</h2>
    <img src="assets/lesson-character.png"
         alt="웃고 있는 캐릭터"
         width="200">
    <h2>재생 제어와 반복 설정</h2>
    <video controls loop src="https://www.w3schools.com/tags/movie.mp4"></video>
</body>
</html>
```

**기본 표시 조건의 예상:** 같은 PNG가 서로 다른 높이로 보이고, 동영상에는 브라우저의 재생 제어가 요청된다. 외부 영상의 로드 성공과 UI의 세부 모양은 네트워크·브라우저에 따라 확인해야 한다.

**하나만 바꾸는 실험:** 첫 이미지의 `height="300"`만 지우고 저장·새로고침한다. 그러면 두 이미지가 모두 너비 200, 비율을 유지한 높이 166으로 표시될 것으로 예상한다. 새 이미지 파일을 만들거나 src를 바꾸지 않아도 표시 크기는 달라진다.

다음 실험에서는 src 파일명을 존재하지 않는 이름으로 한 번만 바꿔 본다. 파일 로딩 실패 상황에서 대체 텍스트가 어떤 정보를 전하는지 확인하고, 실제 예제에서는 올바른 파일명으로 되돌린다. 실패 UI를 모든 브라우저에서 똑같이 보장하는 실험은 아니다.

## 4. 내 코드 따라 읽기

### 4.1 원본의 이미지 한 줄

**내 코드 · 원본 발췌** — `workspace_html/06_img.html` 18행.

```html
        <img src="asset/Spongebob-Christmas-PNG-Picture.png" alt="스폰지밥이 웃고있는 사진" width="200" height="300">
```

src는 문서 옆 asset 폴더에서 PNG를 찾는다. alt는 그 그림의 내용을 설명하고, width·height는 표시 상자의 크기를 지정한다. 이 값들이 각각 다른 역할이므로 ‘그림이 안 보임’과 ‘비율이 이상함’을 같은 문제로 취급하지 않는다.

내 주석에는 너비·높이 하나만 지정해 비율을 확인한 기록이 있다. 이 조건을 실제 원본 PNG의 크기와 비교하면 왜 200×300이 다른 비율인지 설명할 수 있다.

### 4.2 원본의 동영상

**내 코드 · 원본 발췌** — 같은 파일 28–32행.

```html
        <video 
            controls="controls" 
            loop="loop"
            src="https://www.w3schools.com/tags/movie.mp4">
        </video>
```

`controls="controls"`와 `loop="loop"`는 두 기능을 켜 둔 표현이다. 새 예제의 `controls loop`처럼 속성명만 적어도 같은 켜짐을 나타낸다. 속성값을 문자열 `false`로 바꾸는 방식으로 끄지 않는다.

## 5. 다른 파일과 연결하기

이 장의 연결 대상은 함수가 아니라 **이미지 파일과 외부 동영상 자원**이다. 그림이 어느 폴더에 있어야 하는지까지 설명해야 실행할 수 있다.

```text
실습/
├── 06_이미지_복습.html
└── assets/
    └── lesson-character.png
```

| 현재 문서 | src | 실제 연결 |
| --- | --- | --- |
| 원본 `06_img.html` | `asset/...png` | 원본 옆 asset 폴더 |
| 새 예제 | `assets/lesson-character.png` | 새 예제 옆 assets 폴더 |
| video | `https://.../movie.mp4` | 외부 서버의 자원 |

새 예제는 파일명을 짧게 바꾸어 복사했지만 이미지의 바이트 내용은 수업 PNG와 같다. 파일 위치가 달라지면 상대 경로도 달라지므로 [링크와 경로](03_HTML_링크와_경로.md)에서 배운 기준을 그대로 사용한다.

## 6. 내 코드 돌아보기

src뿐 아니라 대체 텍스트를 작성하고, 너비·높이를 바꿔 비율 차이를 시험한 점이 좋다. 미디어 기능을 추가할 때 ‘무엇을 표시하는가’와 ‘어떻게 조절할 수 있는가’를 함께 살펴볼 수 있다.

| 원본의 설명·선택 | 평가 종류 | 보완 |
| --- | --- | --- |
| 이미지에 alt 작성 | 정보 전달에 도움이 되는 선택 | 실제 그림의 정보를 설명 |
| 200×300 두 크기 지정 | 수업용 비율 실험 | 원본 비율과 다름을 알고 비교 |
| alt로 이후 이미지 표기 가능하다는 메모 | 설명 보완 | alt는 텍스트이며 src처럼 이미지를 지정하지 않음 |
| 항상 특정 임시 폴더로 다운로드한다는 설명 | 구현 단정 주의 | 브라우저 캐시 내부를 일반 규칙으로 외우지 않음 |
| controls·loop 사용 | 기능 선택 | 제어 UI와 반복을 구분 |

**개선 예시 · 원본에 미적용:** 비율 유지가 목적이면 3절 두 번째 이미지처럼 너비만 지정하는 방법을 확인할 수 있다. 반드시 모든 이미지의 높이를 지우라는 규칙이 아니라 **원하는 표시와 원본 비율에 맞춰 선택**한다.

## 7. 강사님 코드에서 배울 점

강사님과 내 이미지 src·alt·200×300 설정, 동영상 제어·반복은 같다. 동작 차이가 없어 원본 전체를 다시 인용하지 않는다.

강사님은 이미지 속성을 여러 줄로 나누었다. src·alt·크기를 한눈에 비교해야 할 때 그 형식을 참고하면 좋다. 3절의 새 예제도 속성마다 줄을 나눴다. 하지만 줄을 나눈 형식 자체가 이미지 크기나 재생 동작을 바꾸지는 않는다.

## 8. 결과와 확인 방법

| 현상 | 먼저 확인할 것 |
| --- | --- |
| 이미지가 없음 | 현재 HTML 위치, src의 폴더·파일명·확장자 |
| 파일은 맞는데 찌그러짐 | 원본 비율, 두 표시 크기, 덮어쓰는 CSS |
| 마우스를 올려도 alt가 안 보임 | alt를 title 툴팁과 혼동했는가? |
| 동영상 제어는 있는데 안 재생됨 | 실제 로드·지원 형식·서버 응답 |
| loop="false"인데 반복 설정이 남음 | 불리언 속성의 존재 여부 |

원본 PNG의 파일 내용과 자연 크기 100×83, 새 문서의 src·속성값은 검사한다. 너비 200만 있는 경우의 200×166은 원본 비율과 기본 표시 조건에서 계산한 예상이다. **이 책형 개편에서 외부 영상 재생이나 모든 브라우저 화면을 새로 실행 확인한 기록은 아니다.** 이전 검증 기록의 특정 시점 영상 재생 결과를 현재의 보장으로 옮기지 않는다.

</details>

| --- | --- |
| src / alt | 파일 위치 / 대체 설명 |
| width·height | 표시 크기, 파일 픽셀 편집 아님 |
| controls / loop | 제어 UI / 반복 |
| 원본과 새 파일 | 같은 PNG를 다른 경로에서 사용 |
| 영상 결과 | 외부 환경에서 실제 확인 필요 |

외부 자료는 표시된 문서로 2026-10-28 확인했다. BACKUP 이미지 문서의 정의·속성별 풀이·사용 상황을 참고했고, 미학습 확장을 구분했다.
