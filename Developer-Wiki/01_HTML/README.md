# 01. HTML — 실제 수업 코드로 읽는 웹 문서

**실제 학습한 내용이 메인이다.** 강사님 코드와 내 코드를 비교하며 문서 구조 → 링크·목록·표 → 미디어 → 입력·전송 순서로 읽는다. 코드를 처음 배우는 사람이 화면과 값의 변화를 따라갈 수 있도록 설명과 결과를 함께 정리했다.

기존 07번의 입력요소 설명과 전송 설명을 두 문서로 나눴다. `name`·입력 상태가 제출 결과에 어떻게 연결되는지 읽는 순서다.

08번 [시맨틱 페이지 구조](08_HTML_시맨틱태그와_페이지구조.md)는 수업 원본에서 확인되지 않은 선택 학습이다. 기본 흐름에서는 07-02 뒤에 09·10의 배운 내용 복습으로 이어지고, 08은 필요할 때 읽는다.

## 읽는 방법

먼저 [HTML을 읽는 네 가지 질문](00_HTML_V3_동작_백과_읽기법.md)으로 **내용 → 태그·속성 → 예상 화면**을 잡는다. 각 장에서는 개념과 작은 예제를 이해한 뒤 강사님 원본·내 원본을 대조하고, 마지막에 출력을 예상해 보자. 경로와 행 번호는 제공된 수업 소스를 기준으로 한다. 설명용으로 이름·값·구성을 바꾼 예제는 원본과 구분했다.

브라우저에서 HTML을 실행하려면 코드블록을 HTML 파일로 저장해야 한다. `head` 안에 넣을 조각, `body` 안에 넣을 조각, 전체 문서를 구분한다. Markdown의 코드블록을 읽는 것과 웹페이지를 실행하는 것은 다르다.

화면은 나오지만 구조가 잘못된 원본도 있다. 원본을 그대로 옮긴 코드가 언제나 권장 코드라는 뜻은 아니다. 바로 아래의 교정 설명을 함께 읽는다.

추가편을 몰라도 기본편의 예제와 문제를 풀 수 있다. `tel:`·`mailto:`와 color·date·time·number·range는 양쪽 원본에 실제로 있으므로 기본편에 포함했다. 반대로 기존 Wiki에 자세한 설명이 있었다는 이유만으로 수업 범위를 넓히지 않았다.

## 다시 찾을 때

| 궁금한 것 | 읽을 곳 |

| 화면은 나오는데 구조가 이상하다 | 01·02장의 교정, 04 목록·05 표의 원본 비교 |

| 체크했는데 값이 on이다 | 07의 양쪽 coffee 코드 비교 |
| POST 후 오류가 나왔다 | 07-02의 요청과 서버 응답 구분 |
