# 01. HTML — 내용의 구조에서 입력·제출까지

HTML은 웹 문서의 내용과 역할을 표현한다. 이 과목은 **개념 → 작은 예제 → 내 코드 풀이 → 평가와 필요한 비교 → 결과와 복습** 순서로 읽는다. 실제 배운 내용이 본문이며 미학습 기능은 하단 TIP으로 구별한다.

## 복습과 실행

1. 작은 전체 파일을 열어 예상 화면과 비교한다.
2. [장별 문제 8개](실습/연습문제/README.md)에서 예상·설명·수정을 수행한다.
3. [종합실습](10_HTML_종합실습.md)의 요구사항만 보고 작성한 뒤 정답과 비교한다.

[실습 폴더](실습/README.md)에는 본문과 같은 파일을 모았다. ‘참여 입력’은 가상 복습 모임의 입력 연습이며 실제 신청 서비스가 아니다. 화면은 브라우저로, 요청은 로컬 HTTP 환경에서 확인한다. 저장 서버는 제공하지 않는다.
