## 📌 Overview

CSS는 HTML 문서의 색상, 크기, 간격, 배치와 반응형 표현을 담당합니다. 이 과정은 선택자와 기본 속성부터 박스 모델, 요소 배치, 시각 효과, 미디어 쿼리와 Flexbox까지 총 15개의 문서로 구성되어 있습니다.

학습 순서는 개별 속성의 이해에서 시작하여 여러 요소를 조합한 레이아웃 구현으로 확장됩니다.

## ✨ What You'll Learn

| Area | Learning Goal |
|:--|:--|
| Selectors | 원하는 요소를 정확히 선택하고 스타일 적용 |
| Values | 단위와 색상 표현 방식 이해 |
| Box Model | 크기와 여백 구조 계산 |
| Layout | display, position, float를 통한 요소 배치 |
| Visual Effects | 배경, 투명도, 그림자 표현 |
| Interaction | transition과 transform으로 상태 변화 구현 |
| Responsive Web | 미디어 쿼리로 화면 크기에 대응 |
| Flexbox | 유연한 1차원 레이아웃 구성 |

## 🎯 Learning Outcome

CSS 학습을 마치면 다음 내용을 수행할 수 있습니다.

- 선택자와 우선순위를 고려하여 스타일을 적용합니다.
- 박스 모델을 기준으로 요소의 크기와 간격을 계산합니다.
- display, position, float와 Flexbox를 이용해 레이아웃을 구성합니다.
- 배경, 글꼴, 그림자와 상태 변화 효과를 구현합니다.
- 미디어 쿼리를 사용하여 다양한 화면 크기에 대응합니다.
