## 📌 Overview

CSS(Cascading Style Sheets)는 HTML에 디자인과 레이아웃을 적용하는 스타일 언어입니다.

이 디렉토리는 CSS를 학습하며 작성한 문서를 모아둔 공간으로, 단순한 속성 암기를 넘어 다음 내용을 함께 기록합니다.

- 스타일 속성 실습
- 강사 코드와 비교 분석
- 개선 포인트 정리
- 실무 레이아웃 구현
- 복습 문제 및 체크리스트

Developer-Wiki는 **학습 → 비교 → 개선 → 복습**의 흐름을 반복하며 CSS를 체계적으로 정리하는 것을 목표로 합니다.
