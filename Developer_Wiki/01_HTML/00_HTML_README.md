## 📌 Overview

HTML(HyperText Markup Language)은 모든 웹 개발의 시작입니다.

이 디렉토리는 HTML을 학습하며 작성한 문서를 모아둔 공간으로, 단순한 문법 정리를 넘어 다음 내용을 함께 기록합니다.

- 실습 코드 작성
- 강사 코드와 비교 분석
- 개선 포인트 정리
- 실무 활용 예시
- 복습 문제 및 체크리스트

Developer-Wiki는 **학습 → 비교 → 개선 → 복습**의 흐름을 반복하며 지식을 체계적으로 축적하는 것을 목표로 합니다.
