## 📌 Overview

HTML은 웹 페이지의 내용과 구조를 정의하는 마크업 언어입니다. 이 과정은 문서의 기본 골격부터 링크, 목록, 표, 미디어, 폼, 시맨틱 구조까지 총 8개의 문서로 구성되어 있습니다.

각 문서는 태그의 사용법만 나열하지 않고, 실제 작성 코드와 강사 코드의 차이, 개선 방법, 자주 발생하는 실수를 함께 기록합니다.

## ✨ What You'll Learn

| Area | Learning Goal |
|:--|:--|
| Document Structure | DOCTYPE, html, head, body의 역할 이해 |
| Text Content | 제목, 문단, 강조 등 기본 콘텐츠 작성 |
| Navigation | 링크와 절대·상대 경로 사용 |
| Structured Data | 목록과 테이블로 정보 구성 |
| Media | 이미지, 오디오, 비디오 삽입 |
| Forms | 사용자 입력을 받는 폼 구성 |
| Semantic HTML | 의미 있는 태그로 페이지 구조 설계 |

## 🎯 Learning Outcome

HTML 학습을 마치면 다음 내용을 수행할 수 있습니다.

- 올바른 HTML 문서 구조를 작성합니다.
- 콘텐츠의 성격에 맞는 태그를 선택합니다.
- 링크, 표, 이미지와 미디어를 문서에 배치합니다.
- 다양한 입력 요소로 폼을 구성합니다.
- 시맨틱 태그를 활용하여 의미 있고 유지보수하기 좋은 페이지를 설계합니다.
